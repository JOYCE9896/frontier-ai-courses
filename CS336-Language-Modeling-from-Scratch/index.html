CS336: Language Modeling from Scratch

从字节到对齐模型：亲手实现分词器、Transformer、分布式训练与 RLHF 的全栈语言模型工程课

主讲：Percy Liang（斯坦福大学计算机系教授）& Tatsunori Hashimoto（斯坦福大学计算机系助理教授）
整理：Joyce（@JOYCE9896）

核心概念说明

语言模型（Language Model）本质上就是一个给"下一个词该是什么"打概率分布的函数：输入一段已经出现的文字，它输出词表里每一个候选词接下来出现的可能性。像 ChatGPT、Claude 这样的产品，底层都是这样一个模型，只是被训练得足够好、又搭配了对话格式和安全对齐。

市面上绝大多数深度学习课程，会直接调用 PyTorch、Hugging Face 这些现成框架里写好的 Transformer 实现，几行代码就能拿到一个能跑的模型。CS336 反其道而行，它明确禁止使用这些现成组件，要求学生从最基础的模块（矩阵乘法、归一化层、注意力机制）开始，一行一行亲手实现一遍完整的语言模型训练流程，甚至连 AI 编程助手辅助写代码都被明文禁止。这种"从零构建"（from scratch）的教学法背后的判断是：只有真正亲手实现过、调试过、算过每一层显存和算力开销，才能建立起对"这个模型为什么这样设计""这个训练为什么会失败"的第一手直觉，而不是停留在"调用一个函数就能跑"的表面理解。

这门课的十讲内容，对应的正是训练一个语言模型从头到尾必须做的十件事：把文字切成模型能处理的最小单位（分词）、搭建模型架构本身、把模型塞进 GPU 显存里高效地跑起来、让训练能横跨成百上千张显卡并行进行、算清楚给定预算该把模型做多大、让训练好的模型能快速地对外提供服务、准备干净可用的训练数据、以及最后让模型学会把它学到的知识真正用在解决问题上。如果你是第一次接触这些内容，不需要具备任何深度学习背景，每一讲都会先给出对应技术概念的直接解释，再深入到具体的公式和工程细节。

课程目录（10 讲笔记 + 特辑）

01. Overview 与 Tokenization 的第一性原理

这门课"从零到什么程度"：为什么要手写而不是调用现成框架。讲解字节对编码（BPE）分词算法如何把文字切分成模型能处理的整数序列，从 Unicode 编码的基本原理讲起。

02. PyTorch 资源核算与显存精算

在写训练代码之前，先学会用纸笔算清楚一个模型需要多少次浮点运算、占多少显存。讲解 FLOPs 核算规则、AdamW 优化器的显存开销构成，以及交叉熵损失与困惑度的关系。

03. 模型架构与超参数选择的工程直觉

拆解 Transformer 的四个核心模块：RMSNorm 归一化、RoPE 旋转位置编码、缩放点积注意力与因果掩码、SwiGLU 前馈网络，逐一讲清楚每个模块解决的具体问题。

04. 混合专家模型 MoE 的路由与负载均衡

为什么"增加专家数量不增加计算量"，Top-K 路由如何工作，以及训练 MoE 时会遇到的负载不均衡、路由器数值不稳定等真实工程陷阱，附 DeepSeek/Qwen 等真实模型的路由配置对比。

05. GPU 计算范式与 Triton 底层内核优化

GPU 和 CPU 的根本设计差异、显存层级结构、算子融合与分块（tiling）等提速技巧，最后拆解 FlashAttention 如何把这些技巧组合成一次真实的性能突破。

06. 并行训练策略的全景解构

认识分布式训练的基本通信操作（broadcast、all-reduce 等），并逐一讲解数据并行、张量并行、流水线并行三种策略各自的原理、代价与适用场景。

07. Scaling Laws 与算力最优配比预测

给定固定算力预算，模型该做多大、该喂多少数据？讲解 Chinchilla 式 IsoFLOPs 方法如何从小规模实验外推出大规模最优配置，这也是一次真实、要花钱下注的工程决策。

08. 推理系统与模型评估方法论

为什么"生成"比"训练"更受显存带宽限制。讲解 KV Cache、GQA/MLA、推测采样、PagedAttention 等推理加速技术，以及如何合理定义和选择模型评估指标。

09. 预训练数据工程的全流程剖析

从 Common Crawl 原始网页到可用训练语料的完整流水线：HTML 文本提取、语言过滤、隐私信息脱敏、有害内容过滤、质量规则，以及 MinHash+LSH 模糊去重算法的完整推导。

10. 对齐三部曲，SFT、RLHF 与强化学习

把语言模型看作强化学习里的"策略"，从最基础的 REINFORCE 梯度估计，一步步推导出 GRPO 算法的每一层改进：组内基线、优势归一化、序列长度归一化。

特辑：业界嘉宾，从 Qwen 到 LLaMA 的开源模型体系建设者

收录通义千问团队负责人 Junyang Lin 与 Meta AI 研究科学家 Mike Lewis 的客座讲座整理，从真实的开源模型工程实践回望课程十讲的每一个技术模块。
