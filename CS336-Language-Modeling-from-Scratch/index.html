CS336: Language Modeling from Scratch

Stanford 2026 年春季学期：从分词器到 RLVR，亲手实现训练语言模型需要的每一个部分

主讲：Percy Liang、Tatsunori Hashimoto（Stanford 计算机系）
整理：Joyce（@JOYCE9896）

这门课讲什么

CS336 要求学生从零实现训练语言模型的整条流水线，而不是调用现成框架：分词器、Transformer、优化器和训练循环，GPU 内核和多卡并行，缩放规律实验，数据处理，最后是 SFT 和强化学习。两位老师的说法是，只有亲手做过、算过每一步的算力和内存，才能真正理解这些模型为什么这样设计。贯穿全课的主线是效率：给定算力和数据，怎样得到最好的模型。

课程大致分几块：基础（分词、资源核算、架构）、系统（GPU、内核、并行、推理）、缩放规律、评估与数据、后训练（SFT、RLHF、RLVR），最后一讲是多模态，另有一场嘉宾讲座。需要会 Python 和 PyTorch，懂一点线性代数和概率。没有基础的话，可以先读本站的 AI 基础。

笔记依据 Stanford Online 公开的 2026 年春季课堂录像字幕整理，共 17 讲加 1 场客座讲座，每篇开头有录像链接。

笔记目录（17 讲 + 客座讲座）

01. 课程概览与分词

为什么要从零构建语言模型，效率为什么是全课主线，五个作业讲什么，BPE 分词器怎样工作。

02. PyTorch 与资源核算

张量和浮点格式占多少内存，FLOP 怎么数，MFU、算术强度和屋顶线分析，训练一个模型需要多少算力和显存。

03. 架构与超参数

近几年开源模型在归一化、激活函数、位置编码上的共识，超参数怎样选，z-loss、QK 归一化等稳定训练的技巧。

04. 注意力的替代方案与混合专家模型

线性注意力、Mamba 2、Gated DeltaNet 与稀疏注意力，MoE 为什么流行，路由和负载均衡怎样设计。

05. GPU 与 TPU

SM、warp 和内存层级，TPU 与 GPU 的异同，让 GPU 变快的几个技巧，FlashAttention 怎样把它们组合起来。

06. 内核、Triton 与性能剖析

GPU 编程模型和硬件细节，怎样做基准测试和剖析，用 Triton 写 GELU、softmax 等内核。

07. 并行（一）：集合通信与三种基本并行

集合通信原语，数据并行、张量并行、流水线并行的实现与通信量。

08. 并行（二）：大规模训练的并行策略

ZeRO 与 FSDP，零气泡流水线，序列并行与激活内存，专家并行，怎样组合，以及 Llama 3、DeepSeek 等的实际配置。

09. 缩放规律（一）：基础

缩放规律的历史和统计学解释，用它比较架构与优化器，临界批大小，Kaplan 与 Chinchilla 为什么得出不同结论。

10. 推理

推理为什么受内存限制，延迟与吞吐量，GQA、MLA 等缩小 KV 缓存的方法，量化、剪枝、推测解码和 PagedAttention。

11. 缩放规律（二）：实践中的缩放

MiniCPM 与 DeepSeek 的两种思路，WSD 学习率，学习率和批大小的缩放规律，Muon，μP 的推导与局限。

12. 评估

困惑度，考试类、对话类、Agent 类基准，ARC-AGI 与安全评估，训练集污染和数据集质量问题。

13. 数据（一）：数据从哪里来

抓取的技术和法律限制，版权与合理使用，从 BERT 到 Nemotron-CC 的预训练数据集演变。

14. 数据（二）：转换、过滤、去重与配比

分类器过滤，MinHash 与 LSH 去重，数据配比与 epoch 陷阱，推理与编程 Agent 的后训练数据。

15. 后训练：SFT 与 RLHF

指令数据的演变，知识与幻觉，安全微调，标注者与模型标注，PPO 与 DPO，过度优化。

16. 可验证奖励的强化学习（RLVR）

GRPO 及其问题，DeepSeek R1、Kimi k1.5、Qwen 3 的推理训练配方，编程 Agent 的 RL 与奖励被钻空子。

17. 多模态模型

CLIP 与 SigLIP，LLaVA 和 Qwen-VL 系列的视觉语言模型，把一切离散化的 Chameleon。

客座讲座：从推理服务看系统研究（Dan Fu）

一个 token 在推理服务中的一生，mega kernel，稳定化的循环 Transformer Parcae。
