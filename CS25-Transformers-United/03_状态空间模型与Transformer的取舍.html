第三讲：状态空间模型与 Transformer 的取舍

现代循环模型的三个关键要素，自回归状态决定了模型的取舍：Transformer 像数据库，SSM 像大脑；为什么注意力依赖于数据是否已被切分到合适的层级，以及在模型内部学习分块、不需要分词器的 H-Net

主讲：Albert Gu（CMU 机器学习系助理教授，Cartesia AI 首席科学家）
资料来源：课堂录像（Stanford Online 公开，2026 年春季，本文依据录像字幕整理）

一、背景

Albert Gu 是 CMU 机器学习系助理教授、Cartesia AI 首席科学家，研究深度学习的理论和经验基础，以新的深度序列建模方法和神经网络架构闻名，2024 年入选《时代》AI 100 人，在 Stanford 读的博士。他说这个报告过去一年讲过几个版本，也写成了博客，看过的话不会有太多新东西，博客可以作为补充。

过去两三年，Transformer 的替代架构很流行，特别是所谓"次平方"或线性复杂度的模型。比如两年多前的 Mamba，它带动了后来的很多工作，之后有 Mamba 2，一个月前他们刚发布了 Mamba 3；xLSTM 是对 LSTM 的改进，LSTM 某种意义上是 Transformer 之前最流行的标准序列模型；DeltaNet 和把 DeltaNet 与 Mamba 2 结合的 Gated DeltaNet 现在用得很广；还有"测试时训练"范式，把循环看作在测试时优化某个目标的更新。这些模型越来越多地用于大规模的生产级模型：Mamba 出来后被用在很多把线性层和注意力层结合的混合模型里，包括 AI21 的 Jamba、Zyphra 的 Zamba、Microsoft 的 Samba；最近有腾讯的混元（几千亿参数）；最新的 Qwen 模型基于 Gated DeltaNet；Kimi Linear 也是基于 Gated DeltaNet 后续变体的混合模型；AI2 最近发布的 OLMo 也是 Gated DeltaNet 加注意力的混合模型；NVIDIA 的 Nemotron 3 用 Mamba 2，也扩展到几千亿参数。

他不讲某个具体模型，而是退一步讲这些模型的一般特点、他怎样看待它们和 Transformer、它们之间的关系。这一讲统称它们为状态空间模型（SSM），这是 Mamba 被归入的类别；也有很多平行的研究脉络和名字，在本讲中基本可以互换：线性注意力、循环模型、"现代循环模型"（相对于 LSTM 这样的老模型）、线性 RNN、线性模型。"混合模型"指这些模型加上平方复杂度的注意力。这些是通用架构，几乎可以用在任何地方，但本讲主要讨论自回归建模：一是它可以说是现在最重要的建模范式，尤其是语言模型；二是理解这些序列模型的取舍时，从自回归的角度想很有帮助。

二、两类模型怎样推理

从高层看，注意力在推理时拿到一组 token 的提示，预测下一个 token 时要和之前见过的每一个 token 做两两比较，算出结果，预测下一个词，放回提示里，重复。注意力的特点就是能回看上下文中的每一个 token。即使不精确定义注意力，这也是很有用的刻画：Transformer 是会缓存每个过去 token 的标准模型，因为要做这些比较就必须缓存。具体说就是 KV 缓存，很多围绕 Transformer 的工作都在处理 KV 缓存，比如压缩它。叫不叫 KV 缓存无所谓，那是 Transformer 定义方式的产物，从更高层看，Transformer 就是一个存着这个缓存的模型，这决定了它的计算特性：内存和计算随上下文长度增长，分摊到整个推理过程就是平方级的计算，所以注意力被称为平方模型。

SSM 在推理时，token 流进来，不显式存下每一个，而是把它们都"挤"进一个状态（幻灯片上的蓝色小球），单个 token 被丢掉，模型只通过状态与数据交互，在线反复进行：生成新 token，再放进状态。状态高度压缩，所以推理的每一步是常数时间，整个序列是线性时间，这就是"线性模型"的由来。

三、现代 SSM 的三个要素

SSM 由下面的递推定义：

$$h_t = A_t\, h_{t-1} + B_t\, x_t,\qquad y_t = C_t^\top h_t$$

可以看作从输入 $x$ 到输出的序列映射。沿序列长度展开时，可以把 $x$ 看成一维标量，用向量 $B$ 放大后加到对隐藏状态的某种变换上，每一步像普通循环一样更新隐藏状态、并入输入，$h$ 就是刻画循环模型的隐藏状态。和老的 RNN 的区别之一是这个递推是线性的，后面不像 GRU、LSTM 那样接非线性。他认为最重要的三个要素：

  1. 状态大得多：一维输入对应的隐藏状态是 $N$ 维，$N$ 通常是 64 或 128 左右，状态比输入大约 100 倍，这和 LSTM 的定义很不一样。重要性在于自回归状态是上下文的瓶颈，所有上下文都压缩在里面，状态越大能记住的越多，这对语言这种信息密集的模态很重要。
  2. 状态更新要足够有表达力，能精确记住模型想记住的东西。抽象地说，任何 RNN 都是把前一个隐藏状态和新输入结合起来的函数，不同的参数化定义不同的 RNN，更有表达力的函数让模型更精确。Mamba 等较新的 SSM 的一个关键区别是参数是输入本身的函数，他们称之为"选择性"：模型可以根据输入控制递推，更精确地选择要记住什么。比如 $A$ 是输入的函数，不想记住这个输入，就看一眼输入，把 $A$ 设为 1、$B$ 设为 0；很想记住这个输入、丢掉之前的上下文，就把 $A$ 设为 0。这让状态更新函数的表达力大大增强，是这些模型奏效的关键。
  3. 高效计算：前两点让模型容量大得多，但也难算得多，和传统 RNN 不同，直接按递推计算基本不可能。这一系列工作很大一部分是找巧妙的办法重写训练时的计算，让它快得多。原版 Mamba 用关联扫描（associative scan），利用递推是线性的特点，用特定算法并行化；后来的 Mamba 2 和 Gated DeltaNet 等许多变体，把它完全改写成分块矩阵乘法。

这三个要素以前都有：线性注意力大约 2020 年发表，已经有类似的状态扩展；经典 RNN 的门控可以看作某种选择性；很多老的线性 RNN 已经用这些想法提高计算效率。Mamba 可以看作第一个把三者结合起来的模型，这对它真正奏效很关键；它也许是第一个显示循环模型在语言这种信息密集的模态上能和 Transformer 竞争的模型。现在知道这个说法要加个注脚，建模不只是困惑度，但至少从困惑度这种粗粒度的角度看，完全不同的架构可以有竞争力。

之后有很多变体（DeltaNet 论文里有一张很好的表，现在更多了），他认为它们都很相似，都包含这三个要素，只是调整了定义：有的改状态更新，有的改计算方式，都很在意效率。他私下的看法：目前最经过检验的是 Mamba 2 和 Gated DeltaNet，也是大规模混合模型里用得最多的；Gated DeltaNet 比 Mamba 2 稍强一点、稍慢一点，看需要选；Mamba 3 刚出来，大规模检验还少，但大概也会是其中之一。更重要的是，这些模型彼此之间的相似远大于它们和注意力的相似，与其讨论它们之间的细节差别，不如想它们与注意力之间更高层的取舍。

四、自回归状态决定取舍

他的核心论点：序列模型的取舍可以通过它的自回归状态来理解。每个自回归模型都隐含地携带一个状态，可以直接定义为生成时每一步之间模型存在内存里的东西：SSM 的状态是固定大小的矩阵状态，注意力的状态是 KV 缓存。这些状态的定义决定了模型的取舍和归纳偏置。

他喜欢的类比：Transformer 像数据库，KV 缓存存下见过的每个 token 的表示，相当于记到数据库里，序列越长数据库越大，能精确回看任何一条记录；SSM 像大脑，大小固定，把见过的所有信息压缩进一个固定大小的状态。很多取舍可以从这个类比推出来。SSM 的弱点是不太擅长检索，大脑也是这样，人出了名地记不住一长串精确的数字。但也有优点：SSM 是典型的有状态、压缩式模型。有状态让它们在在线场景中很高效，像大脑一样一直在线，以恒定速率接收信息，实时与世界交互；压缩还有一些微妙的好处，后面会讲。缺点是固定大小的状态让它们缺乏细粒度的回忆和检索能力，大海捞针、关联回忆这类要从上下文中精确挖出某条信息的合成任务，它们做得不好，就像大脑一样。

类比还有更多含义：人的智能不只是大脑，人用大量外部工具来增强处理能力。如果把类人的智能看作处理单元加外部草稿纸，这个类比也能预测模型的行为，这是混合模型的一个高层灵感。SSM 出现后就被用于混合模型，现在有很多，有些规模很大。值得一提的是许多组独立验证的最佳混合比例出奇地一致：最简单的混合是线性层和注意力层交错，问题是比例多少？早期很多论文发现大约 10:1（SSM 层比注意力层）最好，至少从困惑度看如此；现在随着模型变好比例有些变化，但大家通常至少用 3:1 或 4:1 的线性层比平方层。有意思的是，从人的智能类比也能预测这一点：大脑是主要的处理单元，外部数据库、草稿纸是辅助，帮你存信息，但不是主要的计算者；仔细做消融后，即使不考虑计算量，只看什么表现最好，也是线性层多于平方层。线性模型常被认为有致命缺点，有限状态记不住一切，压缩看起来是弱点；但即使只看效果不看速度，你也想要很多线性层。所以一个贯穿的问题是：压缩对智能是不是根本上很重要？它起什么作用？

五、注意力最适合什么数据

虽然有很多替代方案，Transformer 仍是很多任务（尤其语言）的首选，而且有充分理由。流行的看法是它在什么上面都能用，把数据放进去就行。这基本是对的，但有细节。他的看法是：数据处于合适的抽象层级时，注意力最有效。在任何实际使用 Transformer 的流水线里，都有相当重的编码和解码层，把数据转换成适合 Transformer 处理的形式。视觉中，ViT 把图像切成小块（视觉 token），稍微编码后送进 Transformer，相当于把数据变得粗粒度、适合 Transformer。语言中这个编码器就是分词器：理论上可以把字符串直接送进模型，但我们先分成较粗的块。很多人不太想这一步，用现成的分词器就行，但他认为这一步对 Transformer 好用很关键，不只是为了效率，也是从建模的角度决定 Transformer 能捕捉什么特征和变换。

分词有很多出名的问题。Andrej Karpathy 有一条推文列举了很多分词的边缘情况：拼写问题；提示以空格结尾或不以空格结尾，其中一种会把模型搞坏；等等。这些边缘情况大多已经清楚，可以用好的数据或其他技巧绕过，所以很多人认为这不是真问题。但如果能去掉分词，这些问题就免费解决了。他认为即使工程方案能用，这个问题仍值得解决，理由是哲学上的：AI 一直追求从原始数据自动学习，越端到端的模型往往越好，这也是"苦涩的教训"：更通用、更少特征工程、更能从规模中获益的模型，最终会从数据中学到更好的特征。

不分词直接训练会怎样？最早是 MambaByte 论文在字节级建模上比较 Mamba 和 Transformer，他们最近的论文也有类似的图：模型大小匹配，训练更久，SSM 比 Transformer 好得多。紫线是滑动窗口注意力，蓝线是 Mamba，两者在各方面等价，差距很大，画一条水平线看数据效率，大约差 2 倍。即使让注意力看全局（字节序列很长，计算量大增，全局注意力的计算量是 Mamba 的 2 倍），仍然不如 Mamba。这说明差别是根本性的，不只是因为注意力更慢：模型大小、数据、序列长度都相同，让注意力做它平方级的计算、用多得多的算力，还是差一些。DNA 上也一样：原版 Mamba 论文对 DNA 序列做自回归建模，Mamba 和 Transformer 差距很大，匹配计算量或参数量的话，Mamba 效率大约高 3 倍。这些都是没有分词的场景。

他用两个启发式来理解注意力擅长什么：

  • 再看自回归状态：注意力存下每个见过的 token，那么只有当缓存每个 token 有意义时才合理。很多数据并不需要缓存每个 token，比如有噪声、有无用 token 的数据；读英语时去掉很多字母也常能认出单词。这粗略地说明，不是每个 token 都有意义，没必要花内存和计算去缓存每个 token 的表示。
  • softmax 注意力某种程度上是作为硬注意力的替代而提出的：softmax 注意力对上下文中所有 token 加权组合；硬注意力每次只能看一个 token。这也是理解注意力的有用代理：在适合用硬注意力的数据上，注意力表现出色。所以把注意力用于字符级数据效果差得多：人处理文本时从不会只看单个字符，关注的是词或更粗的语义层级。

按数据类型看：词或子词是 Transformer 通常处理的东西，这些 token 本身有语义，模块化、可组合，看单个词、存一个词的表示是有意义的，所以 Transformer 表现很好；字符或 DNA 碱基对单个没有意义，这是注意力在这里差得多的一个解释；很多情况不这么清楚，比如视觉中图像的一个小块，有的信息很多，有的很少（一块天空对模型几乎没用），取舍就不那么明确。这说明为什么离开分好词的纯语言后，这些替代模型越来越流行：没有定义良好的分词器时，Transformer 的优势下降，而做隐式压缩的模型（在某种意义上可以看作承担了类似分词的角色）变得更好。Mamba 论文出来后不久有人统计了它最常被用在哪里：虽然是作为语言模型提出的，语言只占约 10%，更多是作为通用序列模型用于时间序列、音频，尤其是视觉。

六、H-Net：在模型内部学习分块

他的组最近发表了 H-Net，这项工作主要由他的学生 Sukjun Hwang 主导，可能是目前最新的真正不需要分词器的语言建模尝试。简单说，H-Net 是端到端的分层网络（H 代表 hierarchical），直接处理原始数据，通过依赖数据的分块过程进行压缩，可以看作一个在内部隐式地给原始数据分词的模型。这是围绕"压缩"思想的很通用的神经网络架构，最直接的用途是无分词器的语言建模。

现在所有语言模型都有显式的分词步骤，最常见的是 BPE（字节对编码），用启发式的合并规则把字符等底层数据组合成更大的块（通常叫 token）。H-Net 不做这个离线步骤，只看原始字符，比如处理字节时词表就是 256；模型在内部寻找类似的边界。训练过程的动画中，绿色表示模型想放边界的地方：训练初期模型在大量探索，后来稳定在和好的分词器很接近的边界上。英语里 token 边界多半在空格处，但仔细看会发现模型也找到了有语义的子词，组合起来还能找到有语义的词组。这是向真正无分词器建模迈出的一大步。

结构（模型挺复杂，只讲高层）：两个主要阶段，所以叫分层。直接处理字节或字符的部分：序列先经过一个轻量的编码器（几层通用序列模型）；然后有一个路由机制，对每个字符预测它是不是边界（一个块的结尾）；对被选为边界的位置，把每个块汇总、压缩成一个表示。编码器加分块起到和 BPE 分词器相同的作用。压缩后序列短得多，送进"主模型"，它可以是任何在块上有效的通用序列模型，默认用 Transformer，因为它在词、块、token 上表现可靠。主模型输出后，把表示展开回原始分辨率，经过解码器做自回归预测。粗略地说，它和现有的"分词器加 Transformer"流程很像，只是分词在模型内部通过编码器和预测边界的路由机制完成。

这一讲要强调的一点是：外层（与字节级数据打交道的部分）用 SSM 获益很大。和前面字符级实验一样，模型中凡是接触字节级数据的部分，用 SSM 都好得多。分块机制等还有很多细节需要优化，这是很难的问题，相当于不稳定、困难的离散优化，但全部做对了，确实能训练出完全在未分词数据上运行的模型，扩展得也不错，还能胜过标准的分词流程。

主阶段本身可以是另一个 H-Net，所以可以嵌套多层分块。H-Net 的本质不是无分词建模，而是动态分块：把任何数据压缩成更大的、理想情况下代表更高层语义的块；因为完全端到端，它是第一个不仅能分块、还能多次分块得到越来越高层抽象的模型。结果：固定模型大小，看验证集上每字节比特数随数据量的变化，黑线是 Transformer 基线；单阶段分块的 H-Net 开始比 Transformer 差，看到足够多数据后反超，扩展得更好。原因是特征工程是一种归纳偏置，在数据受限时有帮助，但从规模中获益较少，这就是苦涩的教训：加一个分块阶段，模型要先看一定量的数据才学会好的分块（如动画所示），学会后理论上能比硬编码的 BPE 分得更好；嵌套两阶段分块扩展得更好，虽然参数更多、更难训练等问题也随之而来。把 H-Net 直接用在 BPE token 上，行为也符合预期：BPE 相比字节级 H-Net 带来免费的提升，因为有了基于硬编码特征的分块；但在字节级 H-Net 上再加一个分块阶段，模型学到的特征就比 BPE 更好。无论什么设置，用 BPE token 训练效果不错，但如果能扔掉 BPE、端到端学分块，效果更好。

一个特别有意思的变体和前面的压缩论点有关：把单阶段 H-Net 用在 BPE token 上，改变编码器和解码器的架构，从全是 Transformer 层到全是 Mamba 层以及中间的各种组合。全是 Transformer 层时明显更差，一旦在编码器和解码器中放入 Mamba 层就好得多。前面说 Transformer 在数据已经压缩好（如 BPE token）时很好、未压缩时较差，字符上 Mamba 好得多；但这个实验完全在 BPE token 上，连外层也是，按理在外层放 Transformer 完全没问题甚至更好，因为它们只看到 BPE token。结果显示，即使计算量全部匹配，外层放 Mamba 也更好。他的结论是 SSM 的好处不只在于它看到的数据分辨率，还在于一种隐含的、倾向于压缩的归纳偏置：编码器层不仅要对接给定分辨率的数据，还要把表示交给分块层决定怎样分块，所以编码器也在起某种压缩作用，它的目标就是在时间维度上真正压缩数据。即使数据是 BPE 而不是字符，使用线性模型（也可以叫压缩式模型，因为状态大小固定）也很关键。他说这是他目前见过的最好证据，说明循环模型的有限状态不只是为了效率，而是有根本不同的归纳偏置；H-Net 的目标是创造更好的抽象（把字符分块成词，把词组成有意义的短语），这和压缩根本相关，而这些模型在经验上对此很重要。

最后一个结果来自一个月前刚放到 arXiv 上的论文：把几种架构用于 DNA 建模。DNA 有意思在于：语言中字符级建模有点像学术练习、长期方向，因为我们已经有分词器，很多人会问为什么不直接用；DNA 很难定义有语义的分词器。这里画的是正式的缩放规律，每个点是一个 FLOP 预算，扫描模型大小和数据量的比例，趋势很线性。和语言不同，语言中这些线通常只是平移，带来恒定的提升；DNA 上 H-Net 发现了现成分词器找不到的模式，扩展得从根本上更好。

七、总结

不同类型的模型做的事情很不一样，归纳偏置很不一样。Transformer 很好用，但在数据已经被恰当编码时特别有效；数据未编码或很难编码时，往往需要不同的模型。他认为未来的建模不只靠 Transformer。现在大多数人把 Transformer 当作很强的工具，不去碰它，而是通过大量特征工程、数据处理方式来围绕它设计整个流程；他相信架构设计还有很大的改进空间。

  • SSM 通常被看作比 Transformer 更高效但可能更弱的替代，常被指出检索能力有问题。但他认为效率有点转移视线，它们不只是更高效，而是在做不同形式的建模：有状态、压缩式，带来状态追踪（这次没讲）、构建抽象（H-Net 中看到的）等好处。优缺点是同一枚硬币的两面，都来自它类似大脑的自回归状态。
  • 注意力的长处是能关注上下文中很具体的细节，回忆和检索特别强，这是 SSM 的弱项。人们通常认为它的缺点是平方级的效率，但他认为真正的缺点是高度依赖数据的分辨率和语义：即使在语言建模中，把 BPE token 换成字节，注意力的表现就大变。也就是说，注意力受制于给它的 token：它缓存每个 token，所以对 token 的分辨率很敏感，又没有能力改变一个 token 对它意味着什么。这同样来自它类似数据库的缓存。
  • 两种模型的效率之争都有点偏题：最终我们只想让模型学到我们想要的东西。也许有些任务真的需要平方级注意力，必须缓存、记住上下文中的每一样东西，这时争论平方复杂度不好就没意义。

他给的整体图景：训练时给模型算力和数据，得到有广泛能力的智能模型，模型训练是把 FLOP 转换成能力的载体，目标是找到最高效的载体。核心问题是：模型是否明智地用了它得到的每一个 FLOP？有些能力确实需要大量计算，但也有模型在做不合理的计算，比如给 Transformer 字符级数据，它没必要把每个字符都缓存进 KV 缓存。架构设计的核心就是设计更好的"黑箱"来完成这种转换，他认为还有很大空间。

八、问答

  • 一位来自 Chris Ré 实验室的博士生问：现在的 SSM 是为了在反向传播（或沿时间反向传播）下可训练而牺牲了一些循环的表达力，但大脑几乎不可能存多份副本做沿时间反向传播，大脑里一定有别的求解器，怎么看？他说他很喜欢尝试完全不同计算范式的工作，驱动他研究的一个想法是我们可能处在某个局部最优，从架构到反向传播等整个训练设置都是，反向传播未必是最好的。模型设计和现有的物理硬件之间有很多相互依赖。他没怎么想过反向传播本身，但想过它可能带来严重问题：比如它给长距离依赖加上了物理内存的限制，整个序列放不进内存，就学不到那么长的依赖，可以构造出永远学不到的病态例子。也可能对所有我们关心的现实任务，都能工程化地做到足够好，这也是世界目前的方向。另外，这方面很多工作是为了在 GPU 等现有硬件上高效，牺牲了一些表达力，加入真正的循环可以拿回来，有一条研究线在尝试，但很难计算；他认为这条线很有前景，自己也有一些想法，重新想象现有约束也许能得到根本上更好的模型。
  • 动态分块机制会在未来模型中起重要作用吗？很难说。他们做这个花了很久，因为他从根本上相信分块是能带来更好模型的关键原语。发表的版本只是第一步，是第一个真正端到端可用的模型，远不是终点，包括分块机制本身在内的各部分都还能改进，也还没在更大规模上验证。但从哲学上讲，从零学到这些东西太重要了，他认为更好的分块机制可能对未来模型很重要。
  • 分隔点是任意的，分词器有固定词典，动态变化的块怎样送进模型？这是这个模型的一个关键优点。无分词器模型的一个难点是词表无限大，就没法有无限多个嵌入；H-Net 端到端在内部完成，过了最开始的编码阶段就没有查找表了。模型的词表就是最细粒度的单位，比如字节就是 256，之后每个阶段都在嵌入空间中工作。最简单的做法是：块对应的嵌入，直接取编码器输出中那个位置的嵌入，忽略中间的；或者对这个块做池化。
  • （同一位学生）能否用 SSM 来整理记忆，为基于注意力或查找的模型提供更高效的记忆，以扩展持续交互中能记住的东西？他说这些和大脑的类比很粗糙，他不是神经科学家，神经科学家听到可能会骂他；他更多把人当作概念验证：智能应该能做到什么、大致可能怎样做到。分块这个概念直接受认知心理学启发。他认为分块的一个用途是作为更聪明地构建数据库或缓存的方式，长上下文的一个关键难点是知道存什么、不存什么。H-Net 的一个潜在用途是长上下文建模：不断迭代，把上下文压缩成越来越高层的抽象或记忆，像是粗略的摘要，让内层模型关注少得多、层级更高的东西。这个具体想法他还没有进一步的进展，但和做这件事的整体理念直接相关。
  • 在数据受限或小模型场景下，SSM 和 Transformer 谁更好？他不确定，语言建模中很多人关心扩展。他提到前一天看到的一点信息：OpenAI 最近发布了一个参数高尔夫挑战（训练很小的模型），有人提交了基于 Mamba 3 的模型，效果不错，但他们的消融显示，加入少量注意力很关键。这是他以前不知道的。
  • Transformer 可以看注意力图做可解释性，SSM 有类似的东西吗？更难一些，但某些 SSM 和注意力之间有对应关系，SSM 的另一个名字就是线性注意力，它们和线性注意力有更深的联系，进而和注意力相关。可以可视化一种类似注意力的图（不是真正的注意力矩阵，但能显示每个 token 对其他每个 token 的依赖），做类似的比较，也很能说明行为：比如注意力有时真的像硬注意力，只关注特定 token；SSM 通常会把所有东西揉在一起，比较弥散。这大概不是唯一相关的可视化，对这些模型做更多机制可解释性的研究还在进行中。
