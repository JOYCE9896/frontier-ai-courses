第八讲：从语言模型到原生多模态智能

原生多模态模型的"一切皆 token"思路，只输出文本的模型与全模态模型，把图像离散化的 Chameleon，把自回归和扩散放进同一个 Transformer 的 Transfusion，按模态分开参数的 Mixture-of-Transformers，以及理解与生成之间为什么迁移不对称

主讲：Victoria Lin（Thinking Machines Lab，曾任 Meta AI 和 Salesforce AI Research 研究科学家）
资料来源：课堂录像（Stanford Online 公开，2026 年春季，本文依据录像字幕整理）

一、为什么要多模态

Victoria Lin 是 Thinking Machines Lab 的技术人员，专注原生多模态智能，此前在 Meta AI 和 Salesforce AI Research 做研究科学家，在华盛顿大学读的博士。她声明这次只讲公开材料，代表个人观点，不代表雇主。

大语言模型是过去几年最令人兴奋的突破之一，在座的人大概每天都会用，问 ChatGPT，用 Claude Code 或 Codex 写代码。这些模型基于对符号信息的下一个 token 预测，规模扩大后展现出惊人的涌现能力。回顾一下：Transformer 做下一个 token 预测，输出词表上的概率分布，用各领域的大量语料训练；随着数据和模型扩大，它们获得大量知识，可以后训练成遵循指令，能做思维链推理，最近还发现它们能规划、解决复杂任务。

但她认为只有语言建模不够：我们每天面对的数字世界和生活的物理世界都充满了不同模态的信息，图像、音频、视频，上网就能体会到；如果要构建实时和我们在物理世界交互的 AI 系统，必须处理多模态信息。目标是构建不仅处理符号知识、还能无缝处理视觉和听觉信息的系统。看现在最先进的模型，很多新发布的模型都声称是原生多模态的，能处理大量多模态信息，这是真的，它们在图像、视频理解等方面能力惊人。

二、什么是原生多模态语言模型

她觉得用语言模型来类比最容易理解：最先进的多模态架构就是全面的 token 化，不管输入是图像、视频还是音频，都设法转换成 Transformer 能处理的 token，再像语言模型一样做全局的自回归生成建模。

  • 文本：和大语言模型一样，通常用字节对编码切成小块 token。
  • 图像：做"分块"（patchify），把图像分成预先定义大小的小块，比如 16×16 像素；标准化后，对这些块运行编码器得到向量表示，再排成序列，就是图像 token。
  • 音频：对波形做变换，再用一些操作把得到的表示 token 化。
  • 视频：可以看作图像序列，对每一帧分块，把视频中所有帧的块拼接起来，仍然表示成 token 序列。

这里的 token 不一定是离散的，编码成稠密向量也叫 token。全面 token 化后得到多模态序列，就能像训练大语言模型一样训练。最先进的多模态模型大致分两类：

  • 多模态输入、只输出文本：输入多模态序列，只在文本 token 上计算损失，能产生很强的理解能力，输入图像或视频，模型用文本回答问题。今天熟悉的很多多模态模型，比如 Gemini、Qwen、Kimi，核心产品都是这种模式（这些公司也开发了能生成多模态信息的其他模型）。
  • 全模态模型（omni）：不仅输入多模态，也输出多模态，能生成文本、图像、音频，比如 GPT-4o，名字里的 o 就是 omni，它也能生成图像。

她认为这一页很重要：用 token 化的视角，很多语言建模的架构和训练原则可以迁移到多模态。好处有：可以用混合模态的提示来提示模型、让它遵循指令，解决需要多模态的复杂任务；模型能获得规划和推理能力，而且能用多模态信息规划和推理；语言建模中的一些经验，比如扩大数据和模型规模带来性能提升，也能迁移到多模态，继续扩大参数和训练数据，表现会越来越好，也会出现更多涌现能力。和文本建模不同，文本有很精确的缩放规律，可以推导幂律方程、拟合系数，多模态的精确缩放规律研究还不充分，但大致趋势仍在，她认为找出多模态缩放规律的精确拟合可以是很有意思的研究课题；MoE 等架构扩展和效率技术也能直接用于多模态模型。

三、全模态模型的几种做法

她以前的研究组一直在开发全模态模型。关键研究问题：怎样让模型生成非文本模态？非文本模态的理解和生成之间有没有正向迁移？

Chameleon：把一切离散化

Chameleon 系列的假设很简单：能否把每种模态都 token 化成离散 token？如果成功，就能把多模态世界建模成离散 token 序列，语言模型的很多性质都可能迁移过来。关键是怎样离散化图像，其实不难：在分块之后再加一步向量量化，对图像块运行连续编码器得到嵌入，再用一个学到的码本，把嵌入匹配到最近的离散码字，图像就变成离散表示的序列，也就是用 VQ-VAE 技术离散化图像。然后把图像和文本放在一个交错序列里，用交叉熵语言模型目标训练。结果模型能按原本的顺序生成交错的文本和图像，直接生成混合模态的文档；也能像语言模型一样做多任务，给混合模态的提示，可以聊天、头脑风暴、比较图像等。它是最早显示从零开始在交错的文本和图像序列上训练、能产生多模态能力同时保持很强纯文本能力的模型之一。

局限：图像理解任务中，离散化常常造成严重的信息损失，所以和现在用 SigLIP 这类连续图像编码的最先进多模态模型比，图像理解有明显差距；生成方面，离散化后生成图像在 token 效率上也有挑战，这类模型通常要在大量数据上训练才能采样出成形的图像。总之 Chameleon 展示了从零交错训练文本和图像的有趣范式，但"图像信息可以离散化"这个假设也许太强了。

Transfusion：自回归加扩散

Transfusion 与 Chameleon 差不多同时提出，想克服 Chameleon 的局限：用连续表示作为图像输入，也直接预测图像的连续表示。怎样预测连续表示？扩散模型是很成功的图像生成方法：从噪声开始，不断预测要去掉的噪声，直到得到清晰的图片。Transfusion 在单个 Transformer 中结合自回归语言建模和基于扩散的图像生成：输入仍是交错的文本和图像序列，文本做标准的自回归建模；图像部分不做自回归预测，而是对一段图像表示做扩散，模型做多步扩散得到清晰图像，再以它为输入继续自回归。架构上，文本继续用因果注意力，图像部分为了更好的表现用双向注意力。论文显示，它能用少得多的 token 预算，快速生成比基于离散 token 的方法好得多的图像。

Transfusion 是第一个把自回归下一个 token 预测和扩散目标无缝统一起来做多模态建模的方法，图像生成质量和 token 效率都好得多。但仍有开放问题：它对图像用 VAE 表示，对生成图像很高效，但对图像理解任务不是高效的表示，这造成两难，她认为至今仍是开放问题：领域发现图像生成和理解有时需要两种不同的编码，所以现在最先进的全模态模型常用两种图像编码来克服这个缺点。

Mixture-of-Transformers：按模态分开参数

还能怎样改进架构让它更高效？动机是：现在用 Transformer 处理多模态信息，但不同模态的信息密度不同，文本和图像的数据性质也很不一样，是否必须用统一的 Transformer 参数处理所有模态，还是可以给每种模态引入专门的东西？这就引出了 Mixture-of-Transformers（MoT）：给每种模态一套独立的 Transformer 参数，比如注意力层的 QKV 投影矩阵和前馈层。输入交错模态的序列时，根据模态确定性地选择激活哪套参数：文本 token 激活文本参数，图像 token 激活图像参数，音频 token 激活语音参数。在注意力层中各自得到 QKV 投影后，对所有模态的 token 做联合注意力，让它们统一起来；注意力层的统一输出再进入前馈层，前馈层也按模态分开，每种模态有自己的前馈参数。从外面看仍是 Transformer 单元，输入输出 token；内部各模态用不同的参数处理。这个技术可以和前两种模型结合：和 Chameleon 结合，每种模态都用自回归交叉熵目标；和 Transfusion 结合，文本用自回归目标、图像用扩散目标。

实验：做了从 1.63 亿到 70 亿参数的缩放阶梯，总是和稠密基线比较。直接和稠密基线比，MoT 有优势，因为参数多一倍，所以还和总参数量大致相同的 4 专家 MoE 模型比较。结果显示 MoT 在改善非文本模态的生成上特别有效；文本生成表现与稠密版本相当（详见论文）。它的长处是不牺牲文本表现，在生成图像等非文本模态上好得多：图像生成损失低得多，基于采样的图像生成评估也好得多。一个解释是非文本模态的生成和文本生成可能有很不同的地方，全部放在一个 Transformer 里可能有严重的容量竞争，用不同的参数分开这些能力，就能扩展得更好。定性结果上，MoT 在很多例子中更能遵循细粒度的指令，生成更细致的物体。MoT 也可以和 MoE 结合：每种模态不只一份参数，而是用 MoE 扩展，可以给不同模态分配不同数量的专家；他们发现分配更多专家对文本表现特别有帮助，而图像生成等能力随专家数增加扩展得没那么快，所以可以给不同模态定制专家数。

总结 MoT：用模态专属的参数，确定性地路由 token，显著提高图像、语音等非文本模态的生成质量；也有助于混合模态训练的整体稳定性和可控性，因为不同模态有不同参数，可以异步训练。一个常见场景：已有一个文本能力很强的现成模型，想加上图像或语音生成，不必对它做全量微调或继续训练，而是给它加一套图像或语音参数，冻结文本模型保持文本能力不变，只训练新参数，这样就能给现有模型扩展新模态的生成能力。

学生问：图像理解（图像到文本，更像大语言模型）和图像生成（文本到图像，更像扩散模型）看起来是不同的能力，多模态是要一个模型在两个方向都做到最好吗？她说在 MoT 的语境中，"图像模态"指的是图像生成；他们没发现按模态分开参数对图像理解有帮助。能力似乎以输出的是文本还是图像为界：如果输出文本，输入 token 不管是文本还是图像，最好走同一套参数。

MoT 发表后启发了一系列"模态感知"架构的后续工作：

  • BAGEL（去年一个很强的全模态模型）：架构和 MoT 很接近，有一套单独的图像生成参数，但基座是多模态语言模型，理解部分同时接收文本和图像，图像理解用另一种编码表示，图像理解和图像生成走不同的参数。这也呼应了前面说的，领域还没有找到统一图像生成和理解的有效办法。BAGEL 论文展示的一个能力是：因为把混合模态序列当作自回归生成来建模，模型可以在生成图像前先规划，先生成文本思考过程，再生成最终图像，这让生成的图像细节好得多。她认为"先思考再生成"也是现在很多最先进图像生成模型采用的技术。
  • 具身智能：原论文没有包括，但他们发现机器人领域现在很多架构用 MoT 式的结构预测动作向量，动作是另一种模态，用一套专门的参数预测动作，而整体的语言建模结构和 Transformer 中的自注意力让基座语言模型的世界知识等迁移到动作预测上，让预测好得多。

理解与生成之间的迁移

非文本模态的理解和生成之间有没有正向迁移？要分两个方向看。理解能否帮助生成？答案是肯定的：基座模型的理解能力更强，信息处理、规划、推理能力就更好，能生成细节更丰富的图像，生成的信息图更准确、幻觉更少。反过来，拿一个全模态模型继续针对非文本模态的生成训练，很少有工作显示这对理解有正向迁移：用大量 token 训练图像生成，不一定提高图像理解。她提到去年 Berkeley 的 Sergey Levine 发推说：语言模型通过下一个 token 预测获得惊人能力，而视频模型做下一帧预测却没变得强很多，这很令人困惑。

有几种解释，都有点粗略，有些也在那条推文里：一是语言和其他模态有根本区别，它是人类认知的高度压缩的抽象，训练语言的下一个 token 预测，等于在人的推理过程上训练，我们说的一些话也蕴含我们要采取的行动；图像和视频是感官数据，不是我们对世界的主观解读，而是对世界的被动观察，训练它们的后果会很不同。二是图像和视频的损失地形更复杂，有实验显示，即使图像和视频生成在人看来还不好，损失可能已经看起来不错了，为它们设计损失地形更难。三是现实中的下一帧预测很冗余，视频帧之间有大量重复信息。她认为这个现象值得记住：把语言建模的经验用于多模态建模虽然很成功，但大概不是终点，多模态还有更根本的问题要解决。

四、总结

她讲的这些全模态语言模型（Chameleon、Transfusion、MoT）只解决了今天多模态智能问题的一小部分，特别擅长多模态信息处理；但在真实的物理世界中，时空理解、实时理解、机器人控制等还有很多问题没解决，人们还在研究怎样为现实世界的多模态信息找到更好的表示。原生多模态是很活跃的研究领域，有大量开放问题，远不像语言模型那样已经弄清楚。今天的多模态语言模型擅长数字信息处理，离强大的物理世界多模态智能还很远。多模态模型比文本模型计算更重，训练和推理的基础设施有更多挑战。多模态本身是很复杂、很有意思的问题空间：数字信息理解、物理智能、机器人都需要多模态处理，短期内大概会看到越来越多针对特定能力定制的多模态模型，怎样把它们统一成一个连贯的系统，也是很有意思的未来研究方向。

五、问答

  • 人有些信息通过视觉理解、有些通过语言，设计这些架构时怎样考虑不同的信息流、怎样在它们之间交换信息，尤其是 MoT 把各模态的学习分开了？她说这些模型仍有自注意力，各 token 用各自的投影后仍经过自注意力，这是跨模态传递信息的一种方式；另一种是因果条件：仍然是"给定图像输入，预测文本"的结构，即使参数分开，自回归的顺序仍在，所以仍能以文本为条件生成图像、以图像为条件生成文本。
  • 怎么看 JEPA 这类世界模型对解决现实世界交互、多模态等问题的作用？她说 JEPA 是很有意思的架构（这个系列开头也有一讲）。她认为多模态空间很丰富，不同问题可能需要不同流派的表示：在信息图理解、PDF 理解、编程等方面，现在的分块加编码器范式效果很好，但信息图和真实世界的图像很不同，尤其是需要物理空间理解的场景；JEPA 就是为更高效地建模某些这类关系而设计的，值得探索不同的架构，尤其是在现实世界的物理理解方面。
  • 训练原生多模态和全模态模型，能否让它们在一般知识工作上也更好，就像人从现实世界学到很多？简短的回答是：目前还没发现做视频生成能有效迁移回知识工作。但现在有更有希望的信号，比如很多机器人任务的训练需要视频模型辅助，预测未来状态、获得反馈等。所以可能有办法，但还没看到单纯训练视频生成就让模型在通用任务上大幅变好；目前视频生成能力更多是作为下一步动作预测的反馈。
  • 能否把文本渲染成图像，用统一的图像方式处理所有模态？她自己没做过这类实验，但记得今年早些时候有篇论文，训练语言模型时只给图像输入，结果相当好，之后可以给它看 OCR 图像来提示。她预测这比在原始文本上训练效率低，因为文本已经有很好的符号结构，大规模下这个差别是否会消失是个问题，她主观认为仍然低效，比如文本的外观怎样选、段落怎样建模，可能有被忽略的低效；支持 OCR 的一个论点是图像输入能用更短的上下文表示更多文本，截一张段落的图就行，不用把整段分词。提问者认为文本渲染后，加粗、斜体等格式模型自然就能理解，训练动态上可能更简单。她说应该有人研究这个，但至少从目前看到的，统一模态时把其他模态对齐到文本上比把文本对齐到其他模态更好，因为文本往往驱动着底层的推理和 Agent 能力，把文本表示成 OCR 图像可能会让这些能力扩展得慢得多。
  • （线上）能否为视觉元素开发更高层、更以物体为中心的嵌入？婴儿和人天然把一起移动的部分看作一个东西。她认为可以，这也是 JEPA 的研究主题之一，即对各种东西有更语义化的表示，值得探索。
  • （线上）一个表示能否同时满足感知、生成和推理，还是需要像人一样的不同层级？已经有研究开始做了，今年有论文（她一时想不起名字）研究能否统一图像生成和理解的表示，结果有希望：比如用标准的图像编码表示做生成，能生成好的图像，有时甚至胜过 VAE 表示。哲学上，如果这个方向搞清楚了，会让图像建模向语言建模更进一步，因为语言模型有统一的文本输入和输出，她认为这条路说得通，领域也在进展。
  • （主持人 Steven）是不是所有东西都该像大语言模型那样做成自回归的？从认知角度看，人以更结构化、分层的方式学习，不是只根据前面的预测下一个 token；那更像统计学习，在数据极多时效果很好，但他觉得只靠下一个 token 预测也许不够。她说也有人在尝试别的方式，比如离散扩散语言模型；她个人认为下一个 token 预测已经证明很有效，而且表面上是下一个 token 预测，网络的连接很复杂，潜在空间里可能已经涌现了结构化的学习，我们还不太理解，下一个 token 预测可能只是表面形式，网络做的不止这些。Steven 也同意，因为 Transformer 和注意力的工作方式，模型可能学到了很多隐藏的抽象和结构，训练目标看起来是下一个 token 预测，实际学到的更多。
  • 空间推理（物理环境）的最新进展怎样？她说自己不是空间推理方面的专家。机器人实验室在视觉语言动作模型上进展很多，一个有意思的观察是其中一些进展是由多模态语言模型加速的，比如 Physical Intelligence 出来的模型，用视觉语言模型作为骨干而不是从零训练，似乎有从多模态语言建模到空间理解的正向迁移；也有一些实验室走更不同的路，更少依赖语言、更关注视觉信号，她对那些不太熟悉。
  • 推理在文本空间里比在视频空间里有效得多，这有多少是视频数据的问题？文本里充满推理、独白、停顿，视频里没有；如果在视频中穿插文本帧，推理问题似乎就解决了，这是否说明需要推理时最终总得回到文本？她同意以语言为骨干进行推理被证明很有效，合成数据现在对视觉任务也很重要；但这不排除纯视觉模型也能推理：比如有很好的视频下一帧预测，只用视频中发生的事提示它，如果它能准确预测未来会发生什么，她会把这叫一种推理。提问者说视频推理数据会很缺，而且文本聊天可以把推理过程剪掉，视频生成直接给用户看，每一帧都必须有意义，出于用户体验没法在视频空间里做专门的推理帧。她同意效率上是这样，以语言为骨架现在对视觉推理帮助更大，部分因为语言比视觉信息抽象得多；现在训练模型（通过图像描述等）在视觉信号和抽象空间之间来回，这被证明有用；也许将来计算足够强时，可以只在纯视觉空间里推理，这仍是开放问题。
