第二讲：从表示学习到世界模型

什么是世界模型，JEPA 与生成式世界模型的区别，怎样防止表示坍缩；用以物体为中心的表示和物体遮盖学习交互的 C-JEPA；只有一个超参数、可端到端训练的 LeWorldModel

主讲：Hazel Nam（Heejung Nam，Brown University 硕士生）、Lucas Maes（Mila 与蒙特利尔大学博士生）
资料来源：课堂录像（Stanford Online 公开，2026 年春季，本文依据录像字幕整理）

一、世界模型与 JEPA

这一讲有两位讲者。Hazel 在 Brown 大学读硕士，导师是 Randall Balestriero，研究表示学习、因果和自监督学习，实验室做 JEPA、自监督学习和一些理论；她说这是第一次用英语做报告，有点紧张。Lucas 在 Mila 读博，通过 Zoom 远程讲，研究 JEPA 和规划。Hazel 先讲 JEPA 和世界模型的概念，再讲她的 C-JEPA（怎样让模型理解物体之间的交互）；Lucas 讲 LeWorldModel（怎样端到端训练 JEPA 而不坍缩）。

自回归模型由前一个状态预测下一个状态，但这不足以描述世界，因为世界有不确定性：你观察的时候，别人可能正好做了什么，比如扔了个东西。要处理这一点就需要动作，于是有了世界模型：一个由前一个状态和动作预测下一个状态的函数。Hazel 把"世界模型"理解为模拟器。要让世界模型更好，她认为有三个设计要点：

  1. 好的状态表示：你大概不会把原始像素直接交给预测器，需要能如实反映世界的表示。
  2. 好的转移模型：环境背后有基本规则，比如重力，要理解这些规则才能预测和模拟世界。
  3. 好的动力学模型：你做一个动作，模型要做出恰当的反应。

这一讲不讲生成式世界模型。业界有很多：GAIA 是自动驾驶模型，用动作和前一状态预测下一个驾驶场景；Genie 想扩大世界模型的规模，因为网上的数据通常没有逐帧的动作标注，所以学一种"潜在动作"作为动作的替代；Sora 严格说是视频生成模型，但生成场景的逼真度很高，引起很多关注；Stanford 李飞飞教授的 Marble 做三维可交互环境，可以在里面探索。

JEPA（联合嵌入预测架构）不同。生成式世界模型把当前状态 $x$ 编码后交给预测器，直接和要预测的未来状态 $y$ 比较，所以模型要在和目标相同的像素空间里输出。JEPA 中 $x$ 和 $y$ 都经过编码器，在潜在空间里比较预测和真实目标。重点不只是没有解码器，而在于世界的不确定性：人想下一刻会发生什么时，不会在像素级预测，有些不确定的东西预测不了，人也有自己关心的部分。JEPA 试图只在潜在空间里保留可预测的信息，让预测更有意义、更像人。从另一个角度看，生成式世界模型学的是未来帧上归一化的似然；JEPA 可以理解为基于能量的模型，Yann LeCun 的原始论文就是这样表述的：学一个打分函数，$x$ 和 $y$ 不相容时给高分，相容时给低分，在世界模型里"相容"指 $y$ 是 $x$ 可能的未来。

基于能量的模型可能坍缩。防止坍缩有两类方法：对比学习，以及基于正则化的方法，后者会塑造出丰富、良定义的能量地形，JEPA 走的是这条路。例子：

  • V-JEPA（视频 JEPA）：输入连续帧，做时空遮盖，经编码器得到表示，预测看不见区域里发生了什么，目标编码器拿到全部信息。防坍缩的手段有：用指数移动平均（EMA）的目标编码器，防止很平凡的坍缩；对目标编码器停止梯度；用遮盖给模型更难的任务。
  • V-JEPA 2：架构基本相同，但规模更大，并做了一些有意思的后训练，其中之一是动作条件控制：预测器还接收机器人动作，这就更像世界模型了。
  • DINO-WM：结构和这种动作条件后训练一样。他们的观点是：要得到对规划有意义的抽象，真的需要训练编码器吗？他们认为不需要，冻结的预训练 DINOv2 编码器就能胜任。用它得到过去的图块表示，加上动作、本体感受信号等辅助变量，预测未来状态的表示再比较；预测器就是一个简单的因果 Transformer，自回归地预测未来。

Hazel 请大家想一想：人真的是把图像切成小块来预测下一步的吗？大概不是。

二、C-JEPA：通过以物体为中心的潜在干预学习世界模型

合作者是 Quentin、Lucas、Yann LeCun 和 Randall Balestriero。目标是理解物体之间的交互和动力学。她用了三个数据集：

  • PushT：控制实验中的经典例子，对蓝色的球施加动作，把灰色的 T 形块推到和绿色 T 完全重合。
  • CLEVRER：视频加问答，问题可以是预测性的（下一帧会发生什么）、反事实的（如果蓝色圆柱不存在会怎样）、解释性的，基本是视频问答基准。
  • PHYRE：很多物体在重力等基本规则下相互作用，质量也有影响。

现有模型把图像切成小块，预测每个小块里会发生什么。但要理解这些机制，你希望的是看到每个物体，知道一个物体怎样影响另一个。如果在 DINO-WM 中把表示换成以物体为中心的表示，就更接近人的思考方式，但这需要先学以物体为中心的表示。

以物体为中心的学习中有一个基础方法：Locatello 等人的 slot attention。它基本是编码器加解码器，在编码器和解码器之间的特征空间里，拿来一些"篮子"（槽，slot），每个篮子装一个物体的特征。slot attention 把特征分配到各个槽：做注意力，键是输入特征（比如 DINOv2 的图块嵌入），值也是输入特征，把每个图块嵌入分配给槽，再用 GRU 更新槽，迭代多次后，每个槽就有了与物体对齐的表示，再用这些篮子解码。这是很朴素的方法，还有很多更先进的，也有处理视频的 slot attention 模型。

如果模型完全理解了动力学，会怎样表现？假设模型学到了猴子吃香蕉。如果真的理解"吃"这个机制，用隐形布把香蕉盖住，看不见香蕉，但看到猴子嘴一直在动，就能推断香蕉大概在变短；反过来，让猴子隐形，看到香蕉在消失，也能推断有什么在吃它。这就是 C-JEPA 最核心的动机。

既然只看历史，预测器不必是因果 Transformer，可以用多个时间步的历史，所以他们用双向 Transformer（ViT 风格）。假设有很好的物体对齐表示，回看历史为四帧，预测下一帧；因为是双向的，未来的 token 需要占位，用遮盖 token 表示，目标是正确预测它们。每一行是一个物体随时间的演化。如果只遮住某个中间时刻的一个槽，模型最容易的办法是对前后两个 token 取平均，相当于插值，这不是我们想要的。像猴子的例子那样，把一个物体在所有时刻都遮住，这种遮盖很激进，但模型没有捷径，必须借助其他槽来推断被遮住的状态。

同时遮住两个物体会遇到问题：slot attention 必须固定最大槽数，训练中不变，通常给足够多的槽让模型自己决定什么信息构成一个槽，比如定义 8 个槽，场景里可能只有 3 个物体，只遮一个槽可能不够。送进 Transformer 前要展平并加位置编码，时间轴的位置编码没问题，但槽轴有问题：以物体为中心的模型不规定物体的顺序，对物体顺序是置换等变的，它是物体的集合而不是列表。遮住多个物体时，模型可能不知道要预测哪个，因为槽没有物体身份。视频 slot attention 能在一个视频内部保持物体顺序的一致，但不能保证视频 A 和视频 B 的物体顺序相同。他们的做法：不遮最早的时间步（这里是 $t-3$），用它作为槽的身份；每个遮盖 token 定义为身份 token 加可学习的遮盖 token 加位置编码。这样没那么激进，因为有每个物体的初始状态，预测遮盖 token 更合理。

动作条件：DINO-WM 把动作嵌入拼接在图块嵌入后面，比如 DINOv2-small 的特征是 384 维，动作嵌入 10 维，复制到每个图块，接在图块表示后面。她认为这不是最好的方式。C-JEPA 的动机来自因果图（它并不恢复真正的因果图）：既然每个物体的表示相当于图中的节点，为什么不把动作也当作一个节点，而不是特征表示的一部分？

整体架构：历史帧进入以物体为中心的编码器得到物体表示，选一些物体遮住，连同动作送进双向 Transformer 预测器，预测所有被遮盖的 token。

实验

  • CLEVRER 反事实推理：她强调的是不带遮盖的模型，说明性能提升不是因为用了以物体为中心的表示，核心是遮盖，正如香蕉的例子。C-JEPA 的平均准确率更高，在反事实问题上提升明显，这和最初的动机吻合，因为反事实问题问的是"如果这个物体不存在会怎样"，必须理解物体之间怎样相互作用。
  • PushT 规划：强调效率。DINO-WM 有 196 个图块，每个 384 维；以物体为中心的表示 token 数少得多，每个 token 语义清晰，特征也不必很大，一个物体要包含的信息不多：纹理、颜色、形状、旋转状态、位置。只把 DINO-WM 的图块表示换成物体表示，性能大幅下降，因为 DINO-WM 用因果 Transformer，而静态的物体表示不包含速度、加速度这类单张图片定义不了的属性。把动作改为单独节点、换成双向 Transformer 后，绝对成功率提高约 15 个百分点；再加上遮盖，相对以物体为中心的 DINO-WM 提高约 28 个百分点。和 OC-JEPA 相比，唯一的区别是物体遮盖，它帮助模型理解动力学。把动作当作单独节点，也明显好于 DINO-WM 那样在潜在空间拼接。
  • PHYRE：三个数据集中动力学最复杂，配置很多，必须精确学到场景中发生了什么。OC-JEPA 常常生成物理上不可能的场景，比如一根杆浮在固定杆下面。只学相关性就会这样：两根杆靠近时就待在那里，但物理不是这样。用物体遮盖训练，不断问模型"如果这个不存在会怎样""要预测被遮住的 token 应该考虑什么"，它能学到真正的动力学。注意力探测显示失败来自关注了错误的无关物体：OC-JEPA 依赖装着蓝球的杯子，C-JEPA 依据右边的杆来预测轨迹。

"因果"指什么

C-JEPA 的"因果"指时间上有方向的预测依赖：从历史预测未来，边是有方向的；要预测遮盖 token 就要关注相关的物体。这不是传统的因果定义，但现代因果机器学习中也有这样的用法。物体遮盖让预测器找到所谓"影响邻域"，也就是预测遮盖 token 所需的最小充分集合。形式上需要四个假设：没有瞬时关系；所有训练样本共享同一机制（比如重力在各视频中不变）；物体对齐的表示（实践中最棘手：物体表示在整个视频中要保持一致，不能互换，物体不能被拆到不同槽里，表示要如实反映场景）；历史充分性（用有限的历史，比如前四帧，要足以预测未来）。为了实用，他们不假设一阶马尔可夫过程（以物体为中心的表示通常不满足），并允许混杂因素存在，这让恢复真实因果图很难，但在真实世界的物体表示中几乎无法避免。

  • 物体表示不忠实怎么办？轻微的问题没关系，遮盖物体槽仍是一种归纳偏置；但如果很差就不行。
  • 能恢复真实的因果图吗？用这个方法不能，因为有混杂因素；而且很多场景下很难定义什么是真实的因果图。
  • 遮几个物体？槽数固定，实际物体数随帧变化。理想是只遮一个前景物体、不遮背景槽，但常常控制不好，所以根据数据统计估计，再扫描找最佳值。
  • 最大的局限来自以物体为中心的编码器：遮挡时效果不好，视频中途出现或消失的物体，slot attention 也处理不好。

回到开头的三个要点：好的状态表示，用物体表示；好的转移模型，用物体遮盖让模型学到预测充分性；动力学模型，把动作当作单独节点来做条件。

三、LeWorldModel：不用技巧的端到端 JEPA

Lucas 在 Mila 读博三年级，导师是三星的研究科学家 Damien，和 Brown 的 Randall 合作密切；这项工作的合作者包括 Quentin（NYU Yann LeCun 组的博士后）、Damien、Yann LeCun 和 Randall。他讲怎样让世界模型和 JEPA 变得容易训练。

JEPA 要在抽象空间里学表示，和生成式建模相反：生成式建模要对输入空间建模，所以损失函数会逼着模型建模所有细节。比如自动驾驶，你大概不关心路边树叶怎么动，但生成式模型按定义必须建模它。JEPA 先用编码器把输入编码到抽象空间，再在潜在空间里建模动力学。但如果只做这些就会坍缩：不约束嵌入的分布，模型可以忽略输入，总输出一个常向量（比如全零），潜在空间里的预测损失就被轻易最小化了，下一个状态也是零。JEPA 的很大一部分研究就是怎样避免坍缩：V-JEPA（以及 C-JEPA）用 EMA；DINO-WM 用冻结的预训练编码器产生非平凡嵌入，在嵌入上学动力学，基本就是监督学习；PLDM 端到端训练编码器和预测器，也是动作条件模型，用 VICReg 防坍缩，这是一种让潜在特征的协方差矩阵接近单位阵的正则项，即各维度互不相关。PLDM 的问题是方差项、协方差项要在空间和时间上各做一次，共四项，再加一个逆动力学损失来获取更多动作信息，再加潜在空间中预测未来的 L2 损失，一共六项，有六个超参数要调，很难调。

LeWorldModel 是一个不用任何技巧的简单 JEPA：没有 EMA、没有遮盖、没有停止梯度、没有预训练编码器，损失也稳定，只有一个超参数；模型只有 1500 万参数，单卡就能训练；完全从原始像素端到端训练，不用本体感受等辅助信息；规划速度比 DINO-WM 快约 50 倍。做法就是 JEPA 最本来的样子：取观测 $o_t$ 和下一个观测 $o_{t+1}$，用共享编码器得到 $z_t$ 和 $z_{t+1}$；用 $z_t$ 和动作 $a_t$ 训练预测器，估计未来 $\hat z_{t+1}$；与编码器给出的 $z_{t+1}$ 比较，用均方误差，再加 SIGReg 防坍缩：

$$\mathcal{L} = \left\|\hat z_{t+1} - z_{t+1}\right\|^2 + \lambda\,\mathrm{SIGReg}(Z)$$

伪代码几乎就是真代码：编码、预测、算预测误差、加 SIGReg。唯一要调的是 $\lambda$，只有一个超参数，可以用二分法，$O(\log n)$ 次就能找到最优值。

SIGReg（sketched isotropic Gaussian regularizer）是 Randall 和 Yann LeCun 去年 11 月左右提出的。$z_t$ 可以看作学到的世界抽象，或者对真实状态的估计。想法很简单（数学有点复杂，他推荐去读论文）：看一个批次里嵌入的分布，优化它使其接近各向同性高斯分布。可以用生成式建模和 KL 散度（像变分自编码器那样），但他们不想用生成模型，而是用统计检验：统计学里有检验可以判断一个经验分布离高斯有多近。问题是嵌入空间维度很高，统计检验受维度灾难影响，很难直接用。Randall 的想法是在潜在空间里随机采样很多方向，把所有嵌入投影到每个方向上，得到一维的经验分布，就可以优化它接近高斯。Cramér-Wold 定理说，如果所有一维投影都是高斯，联合分布就是高斯，所以在大量随机方向上这样做，就能让潜在嵌入整体接近高斯，保证嵌入有信息量。

评估一：在线控制

怎样确认学到了好的世界模型？他知道两种办法。第一种是在线控制：用学到的动作条件世界模型在线优化动作序列。给定目标帧 $o_g$ 和当前帧 $o_1$，都经编码器得到 $z_1$ 和 $z_g$；采样一个初始动作序列，用第一个动作和 $z_1$ 预测 $z_2$，再用第二个动作，依此类推，$H$ 步后在潜在空间里用均方误差衡量离目标表示多远；预测器可微，可以一直反向传播到动作，优化动作序列来减小距离。

四个任务：Two-Room，简单的二维导航，穿过门从房间一侧走到另一侧；Reacher，来自 DeepMind Control Suite，两关节手臂要到达目标位置；PushT，把 T 推到绿色区域，只能推不能拉；OGBench Cube，三维机械臂操作，把方块移到目标位置。结果：

  • PushT 最有意思：DINO-WM 训练时用了本体感受，不用本体感受的 LeWorldModel 以一半的参数胜过了它；去掉 DINO-WM 的本体感受，性能下降，LeWorldModel 大幅领先；另一个不用本体感受、完全端到端训练的 PLDM 在 PushT 上表现很差。
  • Reacher 上胜过 PLDM 和 DINO-WM。
  • OGBench Cube 上胜过 PLDM，但不如 DINO-WM。最可能的解释是 LeWorldModel 只在数据集中的轨迹上训练，而 DINO-WM 的编码器在 1.24 亿张自然图像上预训练过，对物体和三维的理解更好。
  • Two-Room 最简单，几乎所有基线都完全解决了，LeWorldModel 却没有。这是 SIGReg 目前的局限：如果问题的内在维度（真正需要的维度，Two-Room 只需要智能体的 x、y 坐标，知道它们再给定目标位置就能解决）远小于嵌入维度，就没办法产生高斯嵌入，优化 SIGReg 时得造出一些"假"信息来让潜在空间看起来是高斯的，这没有帮助。有研究在尝试解决；仔细调超参数也能部分克服，但为了公平，他们没有逐个环境调，所有环境用同样的超参数。

最吸引人的是规划时间。他们尽力优化了 DINO-WM 的速度，一次完整规划最快也要 47 秒，因为预测器要处理并预测所有图块，注意力有平方代价。LeWorldModel 只用编码器的 CLS token 表示潜在状态，加上一些其他技巧（他们没怎么专门优化），完整规划不到 1 秒，快了将近 50 倍。如果把规划的 FLOP 固定为 LeWorldModel 的水平，通过调规划超参数让 DINO-WM 也在 1 秒内完成规划，它在 PushT 和 OGBench Cube 上的成功率大幅下降，在相同预算下 LeWorldModel 连 OGBench Cube 都胜过 DINO-WM。

评估二：直觉物理

  • 探测：冻结 LeWorldModel 的编码器，训练线性探针和 MLP 探针从潜在表示预测仿真中的物理参数。在 OGBench Cube 上，线性探针几乎总是 LeWorldModel 的均方误差更低；MLP 探针则几乎总是 DINO-WM 更低。这说明 LeWorldModel 的潜在空间比 DINO-WM 的更解耦，更容易直接线性地恢复参数。他认为这说得通，SIGReg 会推动每个维度各有意义，不是完全解耦，但比 DINO-WM 更好。
  • 违反预期：动力学突然改变时，世界模型能否察觉？正常轨迹中机械臂拿起方块向右移动；两种扰动：在某一帧突然改变方块颜色，或者方块突然瞬移。横轴是时间步，纵轴是预测误差（预测器预测的与下一状态实际嵌入之差）。没有扰动时误差平稳；颜色改变时略高，但可以忽略，说明世界模型不太在意颜色，而颜色本来就和动力学无关；方块瞬移时误差骤升，说明模型没有预测到。常有人说这只是分布外，他承认，但认为这么说意义不大：人的世界模型被违反时也是分布外的，所以有人在你面前把硬币变没了，你会很惊讶、甚至有点恼火，这里也是预测误差很高。
  • 他们把智能体和 T 的位置嵌入后让它们移动，用 t-SNE 投影嵌入空间，除了坐标轴的置换、旋转和反射，基本恢复了原始空间中各位置之间的相对距离。
  • 冻结世界模型，训练一个解码器来看它"想象"的未来：给模型前三帧作为上下文，第一行是轨迹中真实发生的，第二行是给同样的动作序列时模型想象的，模型大致预测出了真实情况；方块那个例子中，第 15 帧和第 20 帧夹爪的角度是相反的，说明模型没有学到夹爪的旋转，但仍能在一定程度上解决任务。

局限（他称之为研究机会）

  • 目前只能做短期规划。
  • 只在单一时间层级上推理，需要层级结构：你想"我要去机场"时，在另一个层级上思考：先去开车，再去机场，最后才落实到肌肉动作，不会一直以肌肉动作为单位思考。
  • 他同意这些实验很"玩具"，能否走向真实机器人，或者 Minecraft 这样高度随机、部分可观测的环境？
  • 怎样指定目标：现在要给一张目标图像，但不总能拿到，而且它不说明该怎样完成任务。比如飞机降落，你不想只给一张飞机落地的照片，而是想规定降落要多平稳等，现在这类方法还做不到。

他还介绍了和 Randall 的很多学生一起做的开源库 stable-worldmodel：实现了上面提到的各种基线并经过充分测试，有各种规划求解器和很多环境，最近加入了 DeepMind Control 和 Minecraft，正在讨论支持真实机器人数据，有文档，欢迎试用、反馈和贡献。

四、问答

  • 世界模型怎样用于物理 AI 和机器人？已经有基于视觉的基础模型，比如 VLA。Lucas 说他很怀疑现在的 VLA 对世界有好的理解，没有理由有，它们没被训练去预测动作的后果。人擅长做事是因为能预测自己的动作在现实世界中的后果，世界模型做的就是这个，所以要做物理 AI 就需要世界模型，绕不过去。他转述 Yann LeCun 常说的话：VLA 对不需要预测动作后果的简单任务可能很有用，比如让机器人跳舞，只需要了解自身的动力学；要和现实世界交互，就要预测动作的结果。Hazel 补充，NYU 的一位教授认为世界模型可以用来评估策略。
  • 遮盖能提升预测，但学世界模型真的需要它吗？只用预测损失不够吗？Hazel：对以物体为中心的表示，只用预测损失，模型学到的可能只是每个物体自身的动力学，不能保证学到基于交互的动力学，所以不是说不够，而是遮盖能促使模型学到物体之间的动力学。
  • C-JEPA 怎样规划下一帧之后？完全按 DINO-WM 的规划评估方法，用预测出的未来帧自回归地做长时程规划，规划参数也相同。
  • 原生基于 JEPA 的 Agent 和现在基于 LLM 的 Agent 有什么不同？Lucas：世界模型学的是动作条件模型，"我在当前状态，采取这个动作，未来会怎样"，LLM 不是这样训练的（他说自己不是 LLM 专家），LLM Agent 学的是用工具、调用工具。另外，世界模型学会建模未来后，可以直接用控制论中的模型预测控制等方法变成 Agent，不需要后训练，零样本就能做。
  • JEPA 模型是否比 Transformer 模型更少幻觉？Hazel：JEPA 是基于能量的模型，评估的是"预测的未来是否合理、是否可能"，从表示的角度看更适合做世界模型。Lucas 强调 JEPA 不是一种新架构，比如 LeWorldModel 的编码器和预测器都是 Transformer，JEPA 是学世界模型的一种框架；如果模型学得不好当然会有幻觉，但和 LLM 的幻觉不同，LLM 幻觉的来源之一是没有锚定在现实世界上，世界模型可以比较容易地解决这一点；世界模型也有另一种幻觉来源：规划时优化出的动作在现实中没有意义，比如动作范围是 -1 到 1，优化器却给出 -2。其余就看学到的模型质量，这取决于数据和容量。
  • 世界模型比基于扩散的模型更适合机器人控制吗？世界模型也可以用扩散模型，有人用扩散模型生成训练数据，它有优点也有局限。
  • 能否用模型预测控制等方法长时间大量计算，再蒸馏成策略，以获得长时程行为？Lucas：可以。有了世界模型可以做两件事：直接优化动作序列得到零样本策略；或者像 Dreamer 那样在预训练世界模型上训练强化学习策略，定期去环境里收集更好的数据、微调世界模型、改进策略。他认为将来会有类似人的"系统一"和"系统二"：一个浓缩的、直接由状态和目标给出动作的反应式策略；遇到困难、没把握的任务时，再用规划和模型预测控制更仔细地计划。比如学开车，头 20 个小时用模型预测控制保证不撞人，20 小时后觉得自己是专家了，就把规划的结果蒸馏成直接输出动作的策略。
