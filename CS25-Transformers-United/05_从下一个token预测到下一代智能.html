第五讲：从下一个 token 预测到下一代智能

预训练的三种学习策略：两阶段预训练的数据配比与课程，把推理数据前置到预训练，以及把强化学习作为预训练目标的 RLP

主讲：Shrimai Prabhumoye（Mistral AI，Boston University 兼职教授，曾为 NVIDIA Nemotron 系列模型的主要贡献者）
资料来源：课堂录像（Stanford Online 公开，2026 年春季，本文依据录像字幕整理）

一、开场

Shrimai 是 Mistral AI 的 AI 科学家、Boston University 的兼职教授，研究提升大语言模型的推理能力；此前是 NVIDIA Nemotron 系列模型的主要贡献者，做数据整理、预训练和扩展，关注优化预训练流程，包括数据选择、配比和排序。她说自己这周一刚加入 Mistral，今天讲的主要是在 NVIDIA 期间的工作，题目是"从下一个 token 预测到下一代智能"，以及预训练的未来。

她认为做出最先进的 LLM 有四个要素：聪明的数据（大量高质量、多样的数据，做好过滤、去重等）；聪明的架构（架构在从 Transformer 演变，现在有 Mamba 2 混合架构等）；聪明的算法（怎样设计先进的训练配方）；以及预训练和后训练团队、研究和工程之间聪明的协作。数据方面她在 NVIDIA 参与的工作有：MIND（与数学相关的合成对话）、Nemotron-CC、Nemotron-CC-Math（从 Common Crawl 文档中解析出的数学数据），这些数据连同 Nemotron Nano 2 的数据集都在 Hugging Face 上开源；Prismatic Synthesis，鼓励合成数据生成的多样性；Nemotron-CrossThink，面向数学和代码之外的推理，发布那周成了 NVIDIA 在 Hugging Face 上最热门的数据集之一。这一讲讲算法，三项工作：最大化数据的潜力、前置推理、RLP。

她用一个比喻贯穿全讲：四个孩子 Pascal、Volta、Ampere、Hopper（都是 NVIDIA GPU 架构的名字），拿到的数据完全一样，数量、质量都相同，不同的是怎样从数据中学习。三个关键策略：

  1. 课程：看数据的顺序。
  2. 前置推理：四个孩子都能拿到高质量推理数据，是早用还是等以后再用？她用美国教育中的 AP 课类比：中学阶段就修大学水平的课，不仅中学会学得好，上大学也会学得好。
  3. 通过思考学习，而不只是观察。

Pascal 不按课程学，随机读手头的数据，一篇历史、一篇很难的数学、一篇很基础的数学；从不读高质量推理数据；也不通过思考学习。Volta 按课程学，按某种顺序读文档并发现有好处，但不读高质量推理文档，也不通过思考学习。Ampere 按课程学，也用了推理文档，但不通过思考学习。Hopper 三样都做到了：按课程学，用好高质量文档，并且通过思考、与材料互动来学习，而不只是读。全讲就比较这四个孩子。

二、最大化数据的潜力：两阶段预训练

LLM 用数万亿 token 训练，来源五花八门：法律文件、书、论文、包罗万象的网页抓取、数学文档等。Epoch AI 的分析显示，按目前 LLM 消耗数据的速度，大约到 2030 年会用掉超过 95% 的人类生成数据：2021 年左右的 GPT-3 用了几千亿 token，2024 年底的 Llama 3 用了几十万亿 token，很快就会用完人类生成的数据。有这么多来源，要回答两个问题：怎样给各来源加权（怎样判断哪个文档质量高）？怎样给各来源排序（课程：先读什么后读什么）？

构建最优配比的流程：先做质量估计，训练质量分类器估计每个来源的质量，质量相同的来源在配比中权重相近，高质量来源的权重高于中低质量来源；再做 epoch 估计，即某个来源重复看几遍最好，尤其要从高质量来源中榨出最多价值，估计重复多少次之后下游任务开始收益递减；据此得到最优配比。课程上用两阶段预训练：第一阶段鼓励多样性，让模型接触尽量多、尽量多样的数据，配比中有大量网页抓取，包括中低质量的，高质量来源的 epoch 较少；第二阶段只强调高质量数据，高质量来源（数学、维基百科、代码等）的 epoch 更多。

基线：一是自然分布，不管质量和重复次数，按各来源的 token 数采样，一个质量低但很大的来源会被看得更多，也没有排序；二是最优配比，用了质量和重复次数的信息，但以随机顺序给模型看；三是两阶段方法，既有最优配比，也有顺序，第二阶段多看高质量来源，兼顾质量、epoch 和顺序。这就是 Pascal 和 Volta 的区别：Pascal 不估计质量和 epoch，也不按顺序学；Volta 用两阶段方法和最优配比。直接比较，Volta 平均比 Pascal 好 17%，比最优配比但随机顺序的版本好 3.4%。

三、前置推理：预训练与后训练数据的协同

现在的 LLM 流程是：预训练学世界知识和事实；SFT 学模仿推理式的回答，也就是学推理的格式；最后 RL 才真正学推理。她们认为预训练只学一般知识、后训练才事后加上推理技能，会造成不善推理的基础、弱的基础。她们主张前置推理：预训练中不仅学一般知识，也学推理技能，后训练再放大和完善，这样能给推理模型打下更强的基础。

研究方法：系统地在训练的不同阶段（预训练、SFT 等）注入推理类数据，研究影响。推理数据按三个维度分类：多样性、质量、数量，研究在预训练和 SFT 中加入不同多样性、质量、数量的推理数据有什么影响。两种条件：预训练中不加推理数据，叫"无推理基座"（no-reason base）；预训练中加了一定数量、质量或多样性的推理数据，叫"推理基座"（reason base）。评估基座模型和经过 SFT、RL 的模型用的基准不同，所以后面预训练和后训练的数字不能直接比。五条结论：

  1. 预训练中加入推理数据有益：预训练结束时，见过推理数据的 Ampere 平均比 Volta 好 16%。
  2. 收益在 SFT 后不会被冲掉：预训练和 SFT 都用了推理数据，SFT 之后 Ampere 仍比 Volta 好 9.3%，预训练加推理数据的优势不会因为 SFT 而消失。
  3. 高质量数据的收益可能在 SFT 后才显现：三个数据集，SHQ 数量和多样性小但质量高；LDQ 多样性和数量大但质量低；LMQ 是两者合并。预训练刚结束时 LMQ 和 LDQ 平均表现相同，看起来往 LDQ 里加高质量的 SHQ 没有好处；但同样的模型做后训练后，LMQ 比 LDQ 高 4.25%。预训练中的高质量数据能在 SFT 后解锁隐藏的收益，而且不一定导致过拟合。
  4. 早期推理打下很强的基础，后面补不回来：有人会问，无推理基座做两倍的 SFT 能追上吗？用更多 SFT 数据呢？一种情况是无推理基座 SFT 做 2 倍 epoch，推理基座只做 1 个 epoch，推理基座仍高 3%；另一种是推理数据总量固定，全留给 SFT，还是一部分用于预训练、一部分用于后训练（SFT 阶段用质量最高的数据），推理基座平均仍高 12%。不用推理数据的预训练，靠增加 SFT 算力追不上；即使推理数据预算固定，也最好在预训练中用一部分。
  5. 前置推理带来持久的优势：经过预训练、SFT、RL（这里是 RLHF）全部阶段后，Ampere 平均仍比 Volta 好 19%，在 AIME 这类很难的数学基准上优势扩大到 39%。

学生问怎样区分小规模高质量和大规模低质量的数据。她说用的都是开源数据集：OpenThoughts，以及 NVIDIA 发布的 Nemotron SFT 数据集。后者混合了很多数据集，领域多（不只数学和代码），没有经过像 OpenThoughts 那样严格的过滤，所以在某种意义上质量较低，但 token 多得多、规模更大。也可以按复杂度过滤，比如按长度或已有的难度标签挑更难的题，用不同的指标定义质量。

学生问怎样判断数据是推理数据，推理是否与领域无关（律师和数学家、工程师推理的方式可能不同）。她说用的是社区通用的定义，以及社区已发布的推理数据集；这类数据通常是问题、长推理过程、最终答案，数学奥赛题是很好的例子。Nemotron SFT 数据没有做领域过滤，但大概没有法律领域的数据，大部分集中在数学、代码和其他与 MMLU 等基准相关的 STEM 领域。

学生问数据配比是自动优化还是手工设计。她说两者都有：质量估计和 epoch 估计是自动的，据此构建配比的部分不完全自动。epoch 估计指一个来源重复几遍之后开始收益递减，有的数据集超过两遍就收益递减，有的可以四遍、六遍。估计方法是做消融：基础配比中这个来源只看一遍，然后增加到两遍、四遍，它的权重随之增加，就要从别的来源（通常是低质量抓取）那里拿走相应的权重，看两遍、四遍的影响。她们是按领域类别做，而不是按单个来源，比如数学整体做一次，而不是数学里的每个来源。

学生问有没有试过反过来，先质量后多样性。她说做过消融，先多样性后质量的效果更好，交换顺序不如原来好。提问者说这和人相反，人小时候先教好，之后才能应对各种情况，这里像是先探索效果更好。

四、RLP：把强化学习作为预训练目标

动机是两个学习者的故事：Leo 通过动手学，Bolt 通过观察学。有一天要搭一座桥，让玩具车能开过去。Leo 很快抓了几堆积木搭了一座很简单、一点也不花哨的桥，但车能开过去。Bolt 分析了历史上所有的桥，造了一座设计花哨、精度无瑕的悬索桥，但太小，车过不去。教训是要通过做来学，而不只是看。现在的模型通过看文本学习，也就是预测下一个 token；RLP 的动机是教模型通过自己的思考来推理，而不只是观察文本。

标准流程中，预训练收集世界知识，SFT 模仿推理格式，实际是模仿学习：预测对下一个 token 就得到某种"是或否"（不是 RL 的奖励），是在做模式匹配；直到 RLHF 和 RLVR 阶段，模型才真正推理、才有机会探索，推理成了事后附加的东西。她们想回答：推理能不能在预训练中就建立起来？收益能否持续，还是后训练后被冲掉？这也很重要，因为前面说过模型已经消耗了数万亿 token，基本撞墙了，问题变成怎样更有效地使用这些数据，RLP 是一种解决方案，也许需要开发数据效率高的算法。

区别：上下文是"光合作用是植物、藻类和一些细菌利用……制造自己食物的过程"，下一个 token 是什么？标准预训练直接根据上下文预测"阳光"。RLP 给模型机会先思考、探索："光合作用依赖太阳能，所以下一个 token 应该是阳光"，下一个 token 的概率不仅以上下文为条件，还以模型自己生成的思考为条件，是由推理驱动的预测。关键区别在于 RLP 在预测下一个 token 之前产生显式的推理过程，让"为什么"变得可见、可训练，而不只是最终答案。

生成思考的提示要求模型关注接下来的步骤，而不是直接跳到最终的 boxed 答案，也不要复述问题或写元评论。各组成部分：

  • 思考策略：输入（上下文加提示）进入思考策略，它做 rollout，在预测下一个 token 之前探索不同的思考，既生成思考也生成下一个 token，给出 $p_\theta$：在上下文和模型生成的思考 token 条件下下一个 token 的概率。
  • 无思考基线：同样的上下文（不加提示）送入标准的下一个 token 预测模型，算出词表上的概率分布，给出 $p_\phi$：只在上下文条件下下一个 token 的概率。
  • 基于信息增益的奖励：

    $$r = \log p_\theta(x_t \mid x_{<t}, c) - \log p_\phi(x_t \mid x_{<t})$$

    $c$ 是思考。只有当思考真的有助于预测下一个 token 时它才为正，思考是垃圾或没帮助时可能为负或为零。它不像 RLVR 那样最后给 0 或 1，而是稠密的，可以取任何值，可以用在文档的每个位置，不需要外部的选择过程。每个 rollout 都得到这样的稠密奖励。
  • 指数移动平均：无思考基线和思考策略是同一个模型，但用 EMA 延迟更新。这样它足够新，能在训练中提供有信息量的比较，又故意滞后，以减少奖励被钻空子。

实验

问题：不做任何针对任务的调优，能否提高基座模型的推理能力？用 Qwen3-1.7B 基座模型的最终检查点，做 10 亿 token 的 RLP 训练，用的是一般预训练语料，没有专门的推理数据，网页抓取、书、论文都可以。比较对象：基座模型；后训练（SFT 和 RLVR）之后的结果；以及另一个基线：同样 10 亿 token 用下一个 token 预测损失继续预训练。结果：

  • 基座比较：RLP 比基座模型平均好 19%，比用同样 token 继续做下一个 token 预测好 17%。
  • 相同的后训练（SFT 和 RL）之后，收益叠加，Hopper 比 Ampere 相对好 8%。RLP 在预训练中建立的推理基础不会被下游对齐冲掉。
  • 计算量匹配：RL 通常比下一个 token 预测更费算力，要做多次 rollout、生成思考等。按 FLOP 换算，RLP 用 1.7 亿 token 时，对应的下一个 token 预测要用 60 亿 token。即使在 FLOP 匹配的情况下，RLP 仍比下一个 token 预测平均好 14%，尽管后者看到的数据多 35 倍。
  • 中间检查点：Nemotron Nano 12B v2 有中间检查点，取训练到 19.8 万亿 token 的检查点，只用 2.5 亿 token（一般预训练语料）做 RLP，与训练到 20 万亿 token 的基座比较，RLP 少看了约 2000 亿 token。这是更大的模型，也是不同的架构（Nano v2 是基于 Mamba 2 的混合模型，Qwen 是 Transformer）。尽管少训练了 2000 亿 token，Hopper 仍比 Ampere 平均好 35%，科学领域提升最大；相同的后训练之后，RLP 仍比基座高 3 个百分点。RLP 的收益在更大的模型和不同架构上仍然存在，甚至放大。

相关工作：在 RLP 发表时，这方面至少有三篇论文，Quiet-STaR、强化预训练（RPT）、预训练数据上的强化学习（RLPT）。定性比较：奖励来源上，下一个 token 预测没有奖励，RPT 和 RLPT 需要外部验证器（另一个模型来算奖励），RLP 不需要验证器，奖励是内在的；奖励粒度上，RPT 和 RLPT 用 RLVR 式的奖励，是稀疏、二元的，RLP 是稠密的；推理的显现上，RPT 和 RLPT 是显式但弱的，RLP 是显式且强的。定量比较：用和 RPT 论文类似的设置，Qwen3-1.7B 基座模型、Omni-MATH 数据集，两种方法各训练 1.7 亿 token，RLP 平均比 RPT 好 4%。她们认为原因是：RPT 用外部过滤器（另一个模型先过一遍预训练数据，挑出可以用 RPT 奖励的 token），RLP 不做选择，任何 token 都可以用；RPT 用稀疏的二元奖励，只强化挑出的 token，忽略推理步骤本身，RLP 用基于信息增益的逐 token 稠密奖励，计算奖励时考虑了推理过程，捕捉了完整的推理信号。

要点：预训练中让模型自己探索和思考，并为此给予奖励（对中间思考的信息增益奖励），效果胜过单纯的下一个 token 预测；奖励稠密，可以用在文档的任何位置；token 效率高，用 2.5 亿 token 就让 Nemotron 12B 比 20 万亿 token 的基线好 35%。

五、总结

四个孩子数据相同、策略不同，粗略的相对提升：三种策略都用上的 Hopper（课程、前置推理、通过思考学习）比 Pascal 最多可以高约 60%。具体的结论：两阶段预训练很有效，第一阶段重多样性，第二阶段重高质量数据；前置推理带来持久且会叠加的优势，有时收益在 SFT 之后才显现；RLP 把用于推理的 RL 重新表述为预训练目标，想弥合下一个 token 预测和有用的思维链推理之间的差距。论文中还有消融：只用网页抓取、只用学术数据等，通常都有 7% 到 9% 的提升，所以即使用未标注的文本流（比如网页抓取），也能教出类似推理的行为，同时打牢基础，后训练再在此之上建立更深的专长、放大推理技能。RLP 把探索和推理的激励带进预训练，让模型一边建立对世界的知识和理解，一边学会思考问题。她们认为这开辟了模型学习推理的一个新的扩展维度。最后回到四个要素：聪明的数据、聪明的架构、聪明的算法、聪明的协作。

六、问答

  • RLP 生成多个样本、计算信息增益，这和后训练中 GRPO 的优势有什么异同？她们实际就是用 GRPO：GRPO 里奖励是 0 或 1，现在改用基于信息增益的奖励，其余优势计算和后训练中的 GRPO 一样，也基于推理 token 的概率等，只是奖励的算法变了。
  • 有没有把 RLP 等方法用在视觉语言对齐上？还没有。
  • RLHF 有让人觉得舒服的偏差，现在还用吗？怎样减少这种讨好用户的偏差？她说据她理解，RLHF 数据仍会少量混入 RLVR 等阶段，各模型家族用法不同，但它在后训练中占的比重小多了；减少幻觉和偏差是正在进行的研究，她不做这个方向，据她了解大家在构建判断回答是否有帮助、是否安全的分类器，而且总能找到对抗数据，所以要不断更新这些分类器。主持人补充，这和对齐研究很相关，Anthropic 等在做；RLHF 确实容易被钻空子，有很多工作在减少这一点，比如用 AI 代替人的 RLAIF 可能主观性和偏差少一些。
  • 网页抓取这类一般数据怎样量化质量？有很多方法，最流行的是 FineWeb-Edu 的分类：Hugging Face 训练了分类器，给网页文档的教育价值按 1 到 5 打分，NVIDIA 也采用了这种做法。Essential Web 做了更多类型的分类，不只是教育质量，还有领域（科学、数学等），以及教育中的程度（初级、高中、大学等）。看你想提取什么，可以基于评分细则用 LLM 构建分类器。FineWeb-Edu 是最流行、某种意义上最基本需要的。
  • RLP 选哪些前缀开始？是不是用最高质量的数据，挑特定 token？理论上 RLP 可以用在文档的任何 token 上。实验中取一个文档，随机选一个 token（没有按熵等方法挑），用 RLP，反向传播奖励，然后丢掉这个文档，换一个新文档。她也纠正说，RLP 不是在最高质量的数据上做的，而是在预训练数据配比上做的，里面有大量网页抓取等，不只是推理数据。
  • （线上提问）19.8 万亿 token 的检查点已经是数据量与参数量之比超过 1000，往前推多早的检查点做 RLP 仍能胜过继续预训练？论文中给的是 19.8 万亿 token 的结果，但她们也在预训练的 20% 处做过实验：如果 20 万亿是 100%，就在 4 万亿 token 的检查点上做 RLP，仍比基线有提升。
