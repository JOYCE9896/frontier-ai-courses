第七讲：用协作式 AI Agent 推进科学和医学

Google DeepMind 的 AI co-scientist：为什么科学发现需要"系统二"式的思考，怎样把 AlphaGo 的自我对弈推广为科学辩论，生成、评审、排序、进化四类 Agent 的循环，以及抗菌素耐药、白血病药物再利用、肝纤维化、阿尔茨海默病等实验验证

主讲：Vivek Natarajan（Google DeepMind 研究科学家，Med-PaLM 与 Med-PaLM 2 的主要研究者）
资料来源：课堂录像（Stanford Online 公开，2026 年春季，本文依据录像字幕整理）

一、缘起

Vivek Natarajan 是 Google DeepMind 的研究科学家，领导 AI、科学与医学交叉方向的研究。他是 Med-PaLM 和 Med-PaLM 2 的主要研究者，这两个系统分别是最早在美国医师执照考试类题目上达到及格和专家水平的 AI 系统；他还共同领导 AMIE 项目，目标是构建医学超级智能并让更多人用上；此前在 Facebook AI Research 做多模态助手，也是哈佛公共卫生学院高管教育的教员。这一讲的主题是过去几年在 Agent 式 AI 系统与科学、医学交叉方向的工作，主线是构建通用的 AI 系统，作为科学家和医生的协作伙伴。他主要讲 AI co-scientist，目标是给科学家一个协作伙伴，加快科学和生物医学发现的"时钟速度"，给科学家超能力。

这项工作起源于他几年前在 Stanford 的一次报告。2023 年他们在《自然》上发表了 Med-PaLM，最早的医学调优大语言模型之一，用于医学问答和摘要，在反映美国医师执照考试风格的基准上最早达到及格，后续版本达到专家水平，上了新闻头条。2023 年 10 月左右他在 Stanford 讲这个系统，结束后 Stanford 的 Gary Peltz 教授走过来，后来又发邮件说：你们用它做医学问答和摘要，但大语言模型在大量科学和医学 token 上训练过，也许可以提示它生成假设，比如找出罕见病的致病基因。想法很有意思，但当时他们还在用 PaLM 这一代模型（Gemini 的前身，Gemini 现在已经出到第三代；他开玩笑说希望大家在用 Gemini，可能没 ChatGPT 好，然后说是开玩笑），很难得到可靠的回答，到处是幻觉。生成假设、提出新颖有创造性的科学想法，是专家科学家的领域，用 AI 系统做这件事感觉还要很多年。他回去问团队要不要现在做，压倒性的反馈是还没准备好。

但他说自己做过的最好的项目，往往是不知道怎样到达终点、却仍然决定去做的项目，像是跳下悬崖，在下落途中造飞机。于是他们决定做：构建评估，取得一些进展，看能推多远。最初用 PaLM 搭了一个 Agent 式脚手架（那是 2023 年，还没人用"Agent"这个词），能访问一些数据库和工具，检索信息、读文献，再让它预测最可能导致某种罕见病变异的基因等。结果有一些希望：系统提出的一个假设，Gary 在实验室用小鼠的 CRISPR 敲除实验验证成功，几个月前作为同行评审论文发表在《Advanced Science》上。

二、科学需要怎样的思考

这个过程也让他们看到朴素使用 LLM 做假设生成的局限。他认为平常用 Gemini、ChatGPT、Claude 时，这些模型主要在做"系统一"式的思考：很快给出直觉式的回答，没有深入思考，多是表面的相关性和模式匹配。这有用，但科学发现需要的思考很不同：更慢、更审慎、更严谨。和顶尖科学家聊会发现，他们最好的想法往往是在一个问题上想了几周、几个月甚至几年后才有的，一直在脑子后面转，突然有了创造性的顿悟。这更像"系统二"式的思考，是科学发现的标志。核心研究问题就是：怎样构建能做这种结构化、严谨科学思考的 AI 系统？

另一种表述：要构建真正的科学超级智能，怎样衡量进展？他画了一张图，纵轴是按复杂度排列的科学任务，从文献综述、假设生成，到写研究论文、做博士论文，最高是提出改变范式的理论和突破（比如广义相对论）；横轴是普通科学家完成这些任务需要的时间，从几分钟几小时到几天、几周、几年，有时是几十年甚至一生。

AlphaFold 在哪里？他把它放在横轴的最右端：它在某种意义上已经完成了相当于数百万科学家年的工作。在它之前，得到一个蛋白质的结构往往要一个博士生 3 到 5 年的专门工作；AlphaFold 上线后，一夜之间就有了数百万个蛋白质的预测，因此获得了诺贝尔奖。但他把 AlphaFold 画在图外，因为他认为科学超级智能的一个重要性质是通用性，而 AlphaFold 没有：它很专门，只认蛋白质序列输入，只输出蛋白质结构，给它别的科学问题它就无法理解。它很有用，也解决了几十年的重大挑战，但它是能力很强、很专门的系统。通用性指的是：拿到几乎任何问题，都能想办法取得进展，不一定解决，但能理解它、拆成步骤、做出合理的尝试。

他推荐纪录片《The Thinking Game》，讲 DeepMind 从创立到 AlphaGo 再到 AlphaFold 的历史。片中有 IBM 深蓝对战卡斯帕罗夫的片段，深蓝赢了，但 Demis Hassabis 说他对卡斯帕罗夫的印象比对深蓝更深，因为卡斯帕罗夫的大脑很通用：不仅能在国际象棋这样复杂的游戏中和一台巨大的黑箱机器抗衡，还能做人类能做的其他一切，说多种语言，欣赏艺术，思考物理、哲学、诗歌。人脑的通用性让我们能做科学，为复杂的科学问题提出有创造性的假设。到目前为止，全宇宙中唯一能证明这种通用性和假设生成能力存在的"机器"就是人脑，问题是能否构建出模仿这种能力的 AI 系统。

他认为通用性的关键构件是自然语言：以自然语言作为输入输出接口，就像人一样，可能就能理解不同的概念、解决不同的问题。现在的大语言模型都建立在自然语言输入输出的范式上，大家和它们聊各种话题，它们能理解，所以有这种通用性，可以向它提出任何科学问题。但至少到几个月前，LLM 系统能做的科学任务还很初级，深度研究模式能做证据综合、文献摘要等，但假设生成、写研究论文这类更复杂的任务还没看到证据，图上还有大片空白，有很大空间向右上方推进。co-scientist 的目标就是在这张图上向右上推进：在更长的时间跨度上完成更复杂的科学任务。

三、方法：把自我对弈推广为科学辩论

为了构建这个结构化的科学思考引擎，他们借鉴了 Google DeepMind 的传统。今年是 AlphaGo 十周年，AlphaGo 的关键原理是自我对弈：简单说，Agent 在环境中相互对弈，根据棋局结果得到奖励，导致胜利的走法和策略在网络权重中被强化，导致失败的被降低优先级，是自我对弈、强化学习和搜索的结合。AlphaGo（更准确说是 AlphaZero）的美妙之处在于：搭好环境，让 Agent 自我对弈，没有人类干预，从零开始，只要在正确的时间给出正确的奖励，Agent 会不断进步，AlphaZero 训练了约 3 个月就成了超人水平，这个设置随计算量扩展得很好。2019、2020 年有人显示类似方法在 AlphaStar 等更复杂的环境中也行。游戏是开发学习策略和算法的好试验场，但我们想把这些系统用于科学发现、医学等更复杂的现实任务，过去几年他们所处理的"棋盘和环境"越来越复杂。

他们把自我对弈推广到科学推理的方式是科学辩论、自我辩论：系统里有一队 Agent，不断互相辩论，持续生成科学假设，也互相完善、评审、批评；让这个过程持续一段时间，不断引入新知识和奖励信号，系统就能自我改进，得到质量更高的科学假设。从这个多 Agent 设置中涌现出的复合 AI 系统，能生成科学假设，在长时间跨度上解决复杂的科学任务。他说 co-scientist 是最早的通用科学发现多 Agent 系统之一。

输入与输出

他们设想人类科学家始终坐在驾驶座上引导系统，接口都是自然语言，可以提出任何科学问题。科学家给出研究目标，可长可短，可以写上想解决的科学问题的所有细节，让系统能提出合适的假设和方案。除了目标，科学家还可以给出解必须满足的约束、比较不同假设时用的维度或评分细则、自己的偏好；也可以像导师告诉博士生"先去探索这个方向"那样，给出初始的探索方向；还可以提供多模态数据，比如相关论文的 PDF、实验室产生的实验数据。这些构成研究目标，作为系统的输入。系统做大量计算，时长是动态的，从几分钟、几小时到几天、几周，取决于问题的复杂度，最后输出一份研究报告，包含一批解决问题的假设或方案。

系统内部

系统内部是多 Agent 系统，Agent 被配置成持续生成各种科学假设，同时评审、批评、排序、确定优先级。这些 Agent 都是最新的 Gemini 模型，用不同的策略和系统提示让它们在多 Agent 设置中承担特定的专门任务。最简单的理解是一个带 while 循环的程序，有四个函数异步、持续地运行，都用 Agent 式 LLM 方法实现：一个持续生成科学想法和假设；一个评审和批评假设；一个对假设排序、定优先级；一个改进和进化假设。

每个 Agent 有一个"策略库"，从中选择策略完成任务。比如生成想法的一种策略是读完与目标相关的所有论文，建立知识基础，再据此提出想法；另一种是模拟辩论：很多人有过和朋友聊天时想到最好主意的经历，两人各有初步想法，来回讨论后得到比最初都好得多的想法，所以让 Agent 模拟两位专家对话几轮，最后提出科学想法或假设。每个 Agent（包括生成 Agent）有几百种策略。团队成员很喜欢做的一件事是听陶哲轩、David Deutsch 等人的播客，看他们怎样抽象地思考、怎样提出新的科学想法，再把这些概括成提示放进策略库，这是不断增长的知识库，测试时采样一个策略来生成假设。负责评审的反思 Agent 也有一批策略。

他重点讲排序 Agent：它拿到目前生成的假设和想法，用前面说的辩论机制排序，组织想法之间的"辩论比赛"，模拟几轮对话，按科学家在研究目标中给出的标准判断哪个更好。辩论多了，就可以算 Elo 分，像围棋或国际象棋比赛那样给选手排名，用来对假设排序。它有两个作用。第一，如果系统里只有生成和评审 Agent，得到的会是一个产生很多好想法或还行的想法的系统，他认为这不足以推动科学发现：顶尖科学家并不缺想法，他们的想法比时间和资源多。真正做科学家的协作伙伴，就要尊重他们的时间和注意力，只呈现真正值得的想法，做好优先级排序和总结，还要有"认知上的谦逊"：系统要能清楚说明自己什么时候不知道，说明对某个假设有多大把握、有哪些关键的不确定性需要解决。排序 Agent 就在做这些，还会计算每个想法的不确定性并传达给科学家。第二，辩论都用自然语言进行，可以把它们总结成摘要放进系统的整体记忆，下次各 Agent 工作时读取这些摘要，提出更好的假设、写出更好的评审，形成反馈回路，带来自我改进的循环。

他说整体上很简单，就是带四个方法的 while 循环，从高处看，几乎是对科学家提出新想法时脑中思考过程的 Agent 式"计算机内"实现。计算持续一段时间直到终止状态，比如生成了 X 个想法，或者系统卡住、解决不了问题时停止。之后系统把探索过的想法聚类，汇总成一份文档返回给科学家。所有 Agent 都是最新的 Gemini 模型，有长上下文、多模态、Agent 式工具使用等能力。

中途问答

  • 奖励怎样扩展，怎样评估假设好不好？他说这是后半部分要讲的。
  • （关于多 Agent 系统在更多 token 上是否出现性能饱和，问题在录像中不完整）他说取决于问题的类别。有一类问题搜索空间极大，不断投入计算、让系统聪明地探索，很可能得到更好的解，比如要优化某个东西，只要有明确的适应度函数，计算越多就能优化得越好，这类问题基本看不到饱和。两个极端：问题太简单（比如检索），没必要花几百万 token；问题超出现有知识（比如造时间机器），投多少计算都没用。好在中间有一大类问题，投入更多计算、引入新信息，系统能随时间提出越来越好的假设，有很好的扩展性质。
  • （关于能否用于不同学科）后面会展示一些验证例子。
  • 提出假设是一种很线性的科学进步方式，这样的系统像是有一堆自动化的博士在填补研究空白，但永远到不了突破的下一层，怎样让人留在回路中、知情到足以做出突破？他说目标之一是生成足够有说服力的想法和假设，让回路中的专家愿意放下自己所有的想法来做这一个；如果能做到足够多次，就说明系统有效，希望由此带来更多发现和突破，也就是去开发科学家没想到的东西，不一定都能成功，科学本来如此。他同意提问者的判断：我们很快会、或许已经进入这样的时代：有说服力的假设太多，瓶颈变成验证，下一步是怎样排优先级、怎样分配资源挑出最好的去验证。
  • 用的模型有没有专门针对科学？没有专门化，都是 Gemini，视任务用 Flash 或 Pro 版本：评审、验证这类任务用推理更好的 Pro，较简单的任务用 Flash 节省 token 和成本。

四、实验验证

要说系统能做科学发现，真正的证明是在实验室里验证假设。他举了一系列例子：

  • 抗菌素耐药（复现）：2024 年感恩节假期期间开发系统时，他们联系了帝国理工研究抗菌素耐药的研究者，问有没有应用场景。对方说他们已经有一个重要的发现，与细菌中一种很新的水平基因转移机制有关，而这种机制导致抗菌素耐药；关键是还没在任何地方发表，有数据，正在写论文，外界都不知道。对方建议：把他们研究了 8 到 10 年的同一个研究目标交给系统，看会给出什么。系统运行了几天，把结果发给主要负责人 José 和 Tiago。半小时后 José 发邮件说"我现在就要跟你谈"，电话一接通，没有寒暄，直接问"你能看到我的邮箱吗？"，他以为他们作弊、读了他的邮件来猜假设。他们说 Google 做很多事，但不读你的邮件。他又问"你能看到我的 ChatGPT 吗？"，因为他在用 ChatGPT 帮忙写论文。Vivek 说 José 是很资深的研究者，不容易激动，他有这么本能的反应，是团队第一次觉得这个系统真有点东西。之后他们向全世界越来越多的科学家开放系统，看到一种新的 AI 与人类科学家协作的形式正在出现，带来新的洞见和发现。
  • 急性髓系白血病的药物再利用：休斯顿卫理公会医院的医生科学家用系统为急性髓系白血病（AML）这类复杂癌症找到新的可再利用药物和联合疗法。IC50 曲线验证了系统对一些药物的预测：在多个细胞系上测试，看药物在什么浓度开始抑制肿瘤、杀死癌细胞，浓度越低越好，这些药物在合理的浓度下有效。系统对自己假设的新颖性评审也很有分寸：它建议试 KIRA6，并说明这不完全是突破，因为作用于同一通路或靶点的其他药物已经在 AML 中试过，这让它相信 KIRA6 也会有效；但 KIRA6 没有被深入研究、也没有临床试验，所以值得一试。它的建议以证据和以往文献为基础，这也是医生科学家愿意拿去做实验的原因。
  • 肝纤维化：Gary Peltz 先用系统找到肝纤维化的新表观基因组靶点，又让系统给出在他实验室的类器官中验证的实验方案，并推荐能用于验证这个靶点的药物。他在人肝类器官中测试了系统推荐的四种药物，都显示出很有希望的抗纤维化活性。其中一种是广为人知、安全、经 FDA 批准的抗癌药伏立诺他（vorinostat）。他认为这体现了人类智能和 AI 的互补：肝纤维化专家不一定了解癌症领域的疗法、进展和通路，AI 能广泛涉猎、建立意想不到的联系，把这些不同的视角呈现给科学家，科学家再用自己的判断和深厚专长决定是否合理。人有深度，AI 有广度，聪明地结合起来，整体可能远大于各部分之和。
  • 马铃薯免疫蛋白：英国 Sainsbury 实验室的研究者有一批 AlphaFold 预测的结构，想知道怎样分析、怎样发现数据中的异常、哪些结构值得关注。他们用 co-scientist 构建了一个"结构新颖性指数"（一组特征），用它重新分析 AlphaFold 的结构预测，发现了一种此前未知的、巨大的马铃薯免疫蛋白。植物生物学家通常认为这类免疫蛋白复合体（resistosome）是六边形的，新分析揭示了大得多、新颖得多的结构。这是几周前发布的预印本，他认为对理解植物免疫、对农业和全球粮食安全可能有很大意义。
  • 设计更好的 Oct4 蛋白：Oct4 是经典的山中因子之一，山中伸弥因这组转录因子获得诺贝尔奖。这些转录因子能让细胞年轻化，但也可能引起肿瘤，所以想要活性相同但更安全的版本。他们让系统在回路中使用 AlphaFold：预测一个序列，用 AlphaFold 看结构稳定性，据此改进假设，在计算机中反复多次，最终得到的序列有想要的活性和递送性质。他们正在实验室测试这些新蛋白设计，目前看都很有希望。
  • 细胞衰老（未发表）：让系统读文献、看数据，预测能让细胞年轻化或减少衰老细胞数量的新遗传因子或分泌蛋白。衰老指细胞炎症严重到不再分裂并导致疾病，希望减少这类细胞，甚至让它们恢复年轻。系统运行几天给出一个名单，他们测了几个，与研究得很充分的阳性对照 Klotho 比较，AI 提名的因子减少衰老细胞比例的倍数与阳性对照相当。还需要更多实验，如果成立，可能得到全新的年轻化因子。
  • 阿尔茨海默病（复现并补全）：麻省总医院的研究者发现，服用 ACE 抑制剂（常用于治疗高血压和心脏病）的人患阿尔茨海默病的风险升高，想弄清原因。他们经过多年实验，提出了一个包含九个步骤的复杂级联机制。他们把同一个问题交给 AI，它复现了整个九步机制，还预测出科学家漏掉的一个关键步骤：大大简化地说，ACE 抑制剂会调节一种叫缓激肽的化学信号，进而触发脑细胞表面的 B2R 受体，导致神经退行；AI 说缺失的环节是缓激肽和 B2R 受体之间的联系。研究者回到实验室做了蛋白稳定性实验（chase assay），验证了这一步。他说这个例子也说明 Agent 式脚手架比基础 LLM 好：同样的问题交给 Claude 和 GPT-5，它们能得到第一步和高层假设，但得不到完整的细节，需要这个 Agent 框架花时间在验证上、提出合适的假设，才能得到关键细节和真正新颖的洞见。
  • 反向共病：他自己也会问系统有意思的问题。阿尔茨海默病患者患癌的风险低得多，这是已知的，但研究不多。他让系统读文献，找出神经疾病中常见、研究不足、可能也与癌症有关的通路和基因，并告诉他应该看哪些基因和哪种癌症。找到足够多这样的通路，它们也可能成为针对这些适应症开发药物的靶点。系统给出一对常见的神经基因 DHX9 和 SRRM4，还建议他联系德国的一位教授来验证。他给这位教授写了封冷邮件，教授有一批全基因组 CRISPR 筛选数据，回头一看，在系统预测的小细胞肺癌中，这两个基因的表达远高于其他癌症，所以假设是对的。这还没有得到验证，但这是系统建立联系、提出线索，可能带来新的洞见和发现的例子。

系统生成的报告很详细，100 多页，有图有解释，会告诉你想验证这个假设可以联系哪些人，以及它发现了哪些意外的东西。

五、问答

  • 有人在只用 1931 年以前文本训练的 130 亿参数模型上研究知识截止，能否预测截止之后发生的事？他说帝国理工的例子就是这样，阿尔茨海默病的例子也是。提问者指出很难隔离语料，泄漏太多，他同意。他们很兴奋的一件事是用系统预测未来事件，比如正在进行的临床试验的结果，目前有一定的成功率，但系统没有全部信息，因为很多信息是专有的。他的直觉是，有合适的知识但不透露全部细节，这类系统在预测临床试验等方面可能很强大、很有用。
  • 论文越来越多，同行评审要很久之后才有结论，最终论文可能主要由别的 Agent 来读，有没有更好的同行评审系统、能让其他 Agent 在此基础上工作，而不用等 9 个月？他说这是很好的问题，他没有好答案。论文中 AI 的使用越来越多，就在当天早上 arXiv 出了新政策：论文中如果有幻觉出的参考文献，会被禁止使用 arXiv 一年，他认为这不太有建设性，需要更好的机制。人们在同行评审中使用 AI，这可能有帮助，但如果用得不审慎，就会只偏向通过 AI 过滤的某类论文，让其他课题无人探索，这是一个重要挑战。也可以做些事让 Agent 分享发现和信息，也许需要一个"科学上下文协议"，需要统一科学数据的生成、共享和去中心化的格式。有很多很酷的工程工作可做，但随着论文洪流到来，人类跟不上，也有一些棘手的问题必须解决。
  • 报告有 100 多页，人怎样知道该信任哪些内容？他们希望报告包含所有细节，但也告诉科学家该把时间和注意力花在哪里，比如这些是最有说服力或最有意思的假设，建议先读。系统也可能太保守，即使认为某些假设不可行，里面可能也有对科学家有用的线索或洞见，所以仍保留在报告里，但会明确说该把精力放在哪一部分或哪条路径上。反过来，有时系统会说目前所有想法都行不通，建议重新表述问题或聚焦某个子问题。这在数学问题中常见：让它一次给出完整证明就会崩溃，拆成合适的步骤和块、让人反复和它交互，就能取得进展，系统里有这些机制。
  • （关于安全，问题在录像中听不清）他说有多层安全检查：科学家提出研究目标时，检查是否有恶意，但这常常可以换个说法绕过去；所以还会监控系统持续生成的想法和探索，如果一定比例（目前设为 10%）的想法进入不安全的领域，就停止计算，告诉科学家这是不安全的研究目标；Agent 都基于 Gemini，Gemini 本身做过 CBRN（化学、生物、放射、核）测试，基础模型带来一些安全性质。但多 Agent 系统中，可能出错和被不当使用的面也大了很多，所以需要多层的安全方法。
