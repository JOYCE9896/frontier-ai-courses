第一讲：Transformer 概览

两位课程负责人介绍课程安排，回顾从手工特征到 Transformer 的演变，讲预训练数据的几项小规模研究、后训练方法、Agent、视觉 Transformer 与脑成像，以及幻觉、持续学习、对齐和 Transformer 之后的架构

主讲：Steven Feng（Stanford 计算机系博士生）、Karan Singh（Stanford 电子工程系博士生）
资料来源：课堂录像（Stanford Online 公开，2026 年春季，本文依据录像字幕整理）

一、课程安排

CS25 已经是第六次开课（V6）。这门课最早由 Div Garg 发起，他在 Steven 读博第一年就请他加入。课程形式是：从第二周开始，每周请一位学界或业界的讲者来讲自己用 Transformer 做的工作，领域很杂，有视觉、文本、语言模型、生物、神经科学等。第一讲是导论，讲课程安排、Transformer 的背景和可能的发展方向。

Steven 是计算机系四年级博士生，此前在 CMU 和滑铁卢大学，研究自然语言处理，近来也做和认知科学、心理学交叉的工作，比如数据有限时小语言模型的高效推理、受人类认知启发的学习信号、评估方法。Karan 是电子工程系三年级博士生，也做语言模型效率方面的工作（课程学习、RAG），但这几年主要研究计算机视觉，最近转向神经科学，做 fMRI 等脑成像的基础模型。

课程每周四上课，也可以在 Zoom 上听。唯一的作业是出勤：讲者来现场时要求现场出席，否则至少在 Zoom 上参加，允许三次无故缺勤，用 Google 表单签到。所有讲座都录像，大约两三周后发布在 YouTube 上。他们希望大家从课上学到 Transformer 具体怎样工作（从注意力到扩展），了解它在各领域的前沿应用，接触正在塑造这个领域的研究者，并了解还有哪些局限和开放问题。

二、从手工特征到 Transformer

Karan 先回顾机器学习的演变：

  • 2012 年以前，主要是针对任务手工设计特征，送进浅层模型，用少量人工收集、很贵的标签训练。
  • 监督深度学习：模型变大后，用原始数据代替手工特征，从原始数据直接到预测，去掉了手工设计这个中间步骤。
  • 自监督学习：连昂贵的标签也不要了，用某种方式破坏原始数据（加噪声、遮盖），训练模型还原，学到通用的表示，再微调到各种下游任务。

以语言为例，早期很多工作是情感分析：输入一段评论，分成正面、中性、负面。后来转向更贴近语言本身的任务：语言是序列，依赖上下文，"the quick brown fox jumps over the" 后面是什么你一看就知道，于是训练语言模型预测下一个 token，这也能最大限度利用原始文本，因为可以构造大量这样的样本对。视觉的方向类似：自编码器、对比学习，比较新的是掩码自编码器（MAE），遮住图像的一部分让模型重建。一个问题是怎样遮盖：通常随机遮，但随机的遮盖可能留下三个让问题很容易的块，也可能留下三个让问题很难的块，找到更好的平衡是一个方向。

词嵌入：人理解语言很自然，模型处理的是数字，所以要把词表中的每个词表示成高维空间里的稠密向量，常见方法有 word2vec、GloVe、fastText。它们支持向量运算，比如"国王 - 男人 + 女人"大致得到"女王"。但静态嵌入给每个词一个向量，"bank"作为银行和作为河岸会得到同一个向量；上下文嵌入根据上下文给同一个词不同的向量来解决这个问题。

循环神经网络（RNN）逐步处理输入，同时维护一个记忆（隐藏状态），但序列很长时会忘掉最早学到的东西。LSTM 是带门控的 RNN，多了几组参数控制什么时候记住、什么时候忘记、什么时候输出，更好地保留长距离依赖。

然后是 Transformer。自注意力学习每个 token 应该关注什么：学习查询、键、值三个矩阵。Karan 用图书馆找书作比喻：每本书有一段摘要（键），你要找的东西是查询，查询和摘要匹配，就去读那本书的内容（值）；注意力对所有书做"软匹配"，给每本书一个相关度分数。自注意力就是在一个序列内部这样做，学习每个词和其他每个词之间的联系。只做这个，模型不知道顺序，所以要加位置编码，最简单的就是给第一个词 1、第二个词 2，模型在训练中学会把它们和顺序对应起来。多头注意力在同一序列上学多个不同的注意力，合起来给出更细的表示。

为什么最新的模型不用 RNN？Transformer 可以并行：RNN 必须一步一步按顺序处理，注意力可以一步处理整个序列，在 GPU 上快得多；LSTM 部分缓解了梯度消失和遗忘，但 Transformer 处理长上下文好得多，也更容易扩大，现在有能处理百万 token 级上下文的模型；注意力可以访问之前所有的 token 并建立联系，RNN 和 LSTM 只能依赖隐藏状态里存下的东西。

现在 Transformer 已经扩展到科学技术的各个领域：大家每天用的 GPT-5、Claude 等大语言模型，越来越好的视觉模型（有的已经能在手机上跑），语音、生物、视频、机器人等。大语言模型就是放大的 Transformer，数十亿参数，计算代价很高，在海量通用文本上用下一个 token 预测做预训练。规模变大后会出现"涌现能力"（有一篇很有影响的论文专门讲这个）：只用通用文本训练，模型开始能做数学、推理等。它们也很擅长少样本和零样本学习，给一个从没见过的任务，因为见过的数据多，也能很快理解你要做什么。

三、预训练与数据：四个研究

Steven 接着讲预训练和数据的重要性。预训练是训练的第一阶段，从随机初始化的模型出发，尽可能多地灌进知识和基本能力，通常用大量多样的互联网文本，希望模型学到接近人类语言自然分布的统计分布。数据是机器学习和 AI 的燃料，对在大量文本上训练的 LLM 尤其如此。他们讲了自己的四个项目，前两个是儿童规模的语言学习，后两个规模大一些。

人和语言模型学语言的方式很不同：模型在大量网络文本上预测概率最高的下一个 token；人可能以更结构化、分层的方式学习，有目标驱动，在和别人的互动中学（孩子和别的孩子、妈妈、保姆说话），而且是多模态的，不断从世界吸收信息，语言学习有所依托，而多数语言模型只有文本。这两个项目主要关注人和模型在语言数据上的差别。为什么研究小模型和小数据？一是成本，不是谁都能花几百万美元训练 GPT-5 这样的模型；二是小模型有更多用途，比如在手机上做和你日常目标更贴合的事；三是小规模上发现的技术可能用到大规模上提高效率；四是弄清怎样让小模型更有效，也许能帮助理解人类为什么学语言这么高效。

BabyLM：用单个孩子的语言输入训练

孩子学语言用的数据比大语言模型少几个数量级：0 到 13 岁大约接触 1000 万到 1 亿个词，却能达到相似的泛化、抽象和推理能力。他们有一个数据集，包含单个孩子接触到和说出的语言的转录文本，于是问：用这些转录训练语言模型会怎样？随数据量怎样扩展？不同家庭之间差别多大？什么样的数据特征让孩子学得更好？

在四个基准上测（BLiMP 测语法和语言能力，词相似度和另一个基准测语义理解，EWoK 测基本世界知识）：用各家庭数据训练的模型差异很大，但即使在这么小的数据量上，也有随数据量正向扩展的趋势，只是信号很嘈杂；用更大（最多 2 亿 token）、更干净的合成对话数据 TinyDialogues 训练，缩放规律更干净。外推到在约两三百亿 token 上预训练的 RoBERTa-base，他们的小实验基本落在更大范围的缩放曲线上。扩展效果因任务而异，语法扩展得比世界知识好，说明单个孩子的语言环境可能不足以让语言模型获得基本的世界理解，需要额外的数据。他们还做了全面的语言学分析，把各家庭训练数据的特征和模型最终表现关联起来，发现不仅数据量重要：语义多样性、对话数量、各家庭数据集之间的分布差异等都有关系，表现好的数据集往往更有结构、更多样、互动更丰富、覆盖更广。这和儿童语言研究的观点一致：在这么小的规模上，质量比数量更重要。

双语小模型

有一种针对人的"混淆假说"：在多语言环境中长大的孩子要同时处理来自不同语言的冲突信息，可能学得更困难，主要语言的能力也可能下降。他们问三个问题：这对语言模型成立吗？双语输入的具体方式影响表现吗？这些效应随模型和数据规模怎样变化？数据集设计：上限是 1 亿 token 的英语和西班牙语数据；基线是一半量的纯英语；多语言版本是 1 亿 token 混合，5000 万英语加 5000 万西班牙语，同时学，而不是先学一种再学另一种；还研究了在句子级和词级交替两种语言的语码转换。

结果：多语言模型在两种语言上的困惑度都很低，彼此相当，甚至略低于英语基线，加入第二种语言基本不影响第一种语言的学习，基准表现在不同随机种子下也和纯英语模型持平。不同的接触方式（妈妈总说英语、爸爸总说西班牙语，还是按说话人随机；句子级还是词级语码转换）没有显著差别。规模上，用更小的模型影响不大，但把数据从 1 亿词降到 2000 万词会明显影响表现，不过总体趋势仍然成立。结论：没有干扰；接触方式出人意料地无关紧要；在这个规模上，多语言学习中数据规模比模型规模更重要。

RAG 与预训练的分配

Karan 讲检索增强生成（RAG）：通常的语言模型在大量网络数据上训练，从用户查询直接到输出；RAG 加上一批特定领域的文档和一个检索器，用户查询进来，检索器挑出最相关的文档放进 LLM 的上下文，帮助改进输出。他们研究 RAG 的缩放：假如总共有 1000 亿 token，应该怎样在预训练和检索之间分配？对每个预算有一个最优点，连起来是一条最优前沿。结果是小模型从 RAG 中获益多得多，规模大的模型很快饱和。以"每个检索 token 相当于省下多少预训练 token"来看，有一个交叉点：模型至少要预训练到一定程度才能有效利用 RAG，他们这里大约是每个参数 4 个预训练 token，10 亿参数的模型大约需要 40 亿 token。每增加 10 亿检索 token 带来的提升也随模型规模变化：3000 万参数的小模型获益很多，30 亿参数的模型在充分预训练后几乎没有收益。这说得通，大模型已经记住了大量信息，用一般的网络数据做 RAG 用处不大；如果加的是特定领域的文档，就是另一回事了。

课程学习与模型生长

预训练成本越来越高，大家希望提高学习效率，用少于万亿 token 训练模型；而且常规预训练和人的学习方式差别很大，小模型推理能力往往较弱。人在学校按课程学习，同时大脑在生理上也在长大，语言模型能不能也这样：从小模型和简单数据开始，两者一起变大，模型随数据变难而生长？

相关工作：数据方面，有 TinyDialogues、TinyStories（5 岁孩子水平的简单故事）这类合成数据，也有做去重、清洗的数据过滤；模型生长方面，有"堆叠"：先训练小模型，再复制层继续训练。2024 年的 MIDAS 论文发现，堆叠后相邻的层基本学到相同的东西，用处不大，这推动了更好的模型生长方法。他们的方法叫 CGLS（curriculum guided layer scaling，课程引导的层扩展）：从比如一半大小的模型和比较简单的数据开始，训练一段，随训练逐步加层，直到达到最终大小，再用最难的数据训练。结果比在所有数据上直接随机训练最大的模型更好，也比在最大模型上用同样的由易到难课程训练一次更好；数据从 20 亿 token 增加到 200 亿 token，差距更大。在 1.24 亿和 10 亿参数规模上，结合模型生长和结构化课程能发挥堆叠技术的好处；但不是所有任务都同样受益，在 10 亿参数规模上，随机基线的困惑度反而比 CGLS 好，虽然 CGLS 在推理任务上更好。未来方向包括进一步调超参数、探索别的课程定义（我们认为的难易对模型不一定是难易）、用到图像和医学影像等领域。

四个项目合起来的结论：数据的效果不只取决于数量，还取决于质量、结构和使用方式，怎样选择和策略性地使用数据很重要。

四、后训练

预训练让随机初始化的模型有了基本能力，后训练要把它适配到具体任务、用户和领域，方法包括微调、基于提示的技术、前面讲的 RAG 等检索方法。

  • 思维链提示：不让模型直接输出答案，而是像人一样一步一步想，再给答案。人做数学题会把难题拆成小步骤，这篇论文发现语言模型也能这样，说明模型权重里对问题的了解比直接回答时表现出来的多。
  • 扩展：思维树让模型考虑多条推理路径，用多数投票等方法评估哪条更好；把中间推理交给工具或程序，比如生成代码作为中间步骤，用 Python 解释器执行，步骤和答案都更精确，在数学上表现更好；Socratic questioning 用一个自我提问模块让模型提出和原问题相关的子问题，用分治法递归解决；还有把组合任务表示成计算图的工作。
  • RLHF：从人类反馈训练奖励模型，比如给人看两个回答，让人选更喜欢哪个，用作奖励来后训练模型。
  • DPO（直接偏好优化）：不用强化学习、不需要单独的奖励模型，直接训练模型让人类更喜欢的输出排得更高，现在很流行。
  • 人有主观性和偏差，而且很贵，要人排几千、几百万个输出可能做不到，于是有用 AI 反馈的方法：让现成的 LLM 给出偏好，用来调整输出。
  • DeepSeek 的 GRPO（组相对策略优化）：不是两两比较，而是在一组多个回答内部排序，反馈更丰富、更细，在数学等任务上提高了表现。
  • 过程监督（过程奖励）：很多任务涉及多个步骤，与其只在最后给奖励，不如给中间步骤打分，训练模型产生更好的推理过程，不仅最终答案更好，整体推理行为也更好，还能减少奖励被钻空子。

AI Agent 是能感知环境、做决策（比如思维链）、采取行动去完成目标（通常由人给出）的系统，比如你让 Claude Code 去做一个应用。Agent 的一大好处是能反思和改进自己：拿到查询后收集输入和需要考虑的环境因素，推理、规划，采取行动，观察结果；用过 Claude Code 会发现它会运行脚本看能不能编译通过，再反思，必要时重复这个循环更新输出。模型可以这样从过去的错误中学习、调整之后的回答。还可以加记忆库（现在 GPT 也会存一些记忆），存下过去的错误；也可以结合工具使用、API 调用和检索，生成可能需要调用外部工具、上网搜索、查数据库的推理计划，把结果并入最终回答。

五、语言之外的应用

Transformer 的应用已经遍及各领域：DeepMind 的 AlphaFold、各种医学语言模型、AlphaGo、图像生成等。Karan 简要讲了视觉 Transformer（ViT）：之前是卷积神经网络（CNN）。Transformer 在语言上表现很好后，大家想把它用到图像上。如果把每个像素当一个 token，即使 28×28 的小图展平后也有将近 1000 个 token，对今天的硬件也很贵。ViT 把图像切成小块，编码成更短的序列让 Transformer 学习，在很多任务上效果很好，也是很好的表示学习方法。

既然 CNN 多年来效果很好，为什么用 Transformer？Transformer 是很灵活的架构，归纳偏置很少，对输入数据几乎不做假设；CNN 假设相邻像素相关（局部性），用滤波器处理图像，比如 4×4 的滤波器就假设这个尺度内有关联。这些假设让 CNN 在训练数据有限时学得好，但也限制了它的上限。Transformer 需要很大的数据集，在 CNN 那样的数据规模上训练不好；但它不做假设，在更大的数据集上能学得更好。另一个重要转变是 CLIP：用两个模型分别把文本和图像编码成向量，用配对的图文数据训练，让两者对齐。

脑成像中的 Transformer

Karan 自己的研究是用 Transformer 处理 fMRI 数据。fMRI 能捕捉大脑各处血氧的变化，但信号嘈杂、维度很高，更多是相关的波动，而不像深部脑电极那样是稳定的激活，所以重要的往往不是信号的绝对值，而是信号之间的相关性。有一类工作把大脑各部分聚类成网络，发现某些网络数量更稳定，最后定为 7 个和 17 个。分成 7 个大网络时，有视觉中枢、调节注意和感觉的显著性网络，以及默认模式网络（DMN，和走神有关）等。

最简单的做法是在这类数据上用随机遮盖训练，在大规模上效果还行。但他们想要更可解释、更好的架构，于是把"大脑分成网络"作为先验交给模型：不是随机遮住大脑各处的小块，而是遮住整个网络，比如整个视觉中枢的信息，看能否从大脑其余部分预测出来。这样学到的嵌入更稳健，能帮助理解阿尔茨海默病等疾病：嵌入按疾病状态聚类，CN 是对照组，MCI 是轻度认知障碍（易感的人年老后通常会发展为阿尔茨海默病）。这个架构还能探测大脑不同部分之间的依赖，比如视觉系统和走神网络有多大关联，以及每个网络能多大程度从其余部分预测：视觉中枢很容易从大脑其他部分预测，参与记忆的皮层下区域等则比较独立。因为有包括阿尔茨海默病患者在内的多组数据，还能看到大脑哪里发生了变化：默认模式网络受到的影响明显大于其他部分，这也许能为药物研发提供参考，或帮助理解疾病进展的机制。

六、还缺什么

Transformer 已经渗透到生活的方方面面，还能支撑更多应用：医学、法律等领域的基础模型，一些国家的个性化教育，减轻医生负担，还有交互娱乐和游戏（让 NPC 用 AI 和你对话）。但离大家追求的 AGI 还缺很多：

  • 记忆：现在的模型记忆很有限，而人能快速回忆、存储量很大。
  • 降低计算复杂度：用万亿参数在万亿 token 上训练难以持续。
  • 超越现在 Agent 的自我改进：在遇到任务时真正更新参数、变得更好。
  • 更强的自主性和长周期决策。
  • 对齐：让模型具备情感智能和社会理解，符合人类价值观，不把人当对手。
  • 小模型和端侧 LLM：如果小模型能做得好得多，就能在手机上跑出类似的表现，将来甚至可能在本地微调。
  • 扩展的极限：只增加数据或模型规模已经有收益递减，在网络数据上训练大概到不了 AGI，所以大家转向 RLHF、RLAIF 等后训练、提高数据质量、课程学习、借鉴人类学习方式。后训练的风险是训练过度可能让模型忘掉预训练学到的东西，任务表现反而变差。突破可能来自新架构、更高质量的数据、改进的训练流程。

幻觉：一个统一定义

Steven 讲幻觉：模型给出虚假或不正确的信息，编造不存在的事实、引用、细节，而且通常说得很自信，在缺乏知识时不会表达不确定性，不知道说"我不知道"。可能的原因：模型优化的是"像真的"而不是"真的"，训练目标是生成概率最高的下一个 token，最可能的文本不一定是真的；缺少依托，模型对世界没有外部的锚定；用户的提示常常含糊或信息不足，让模型困惑，促使它编造。幻觉损害信任和可靠性，在法律、医疗等高风险领域尤其不能接受，而且模型说得很自信，很难发现。但不是所有错误都是幻觉，什么是"真"也取决于语境，至今没有统一的定义。

现有定义因领域和任务而异：摘要中，幻觉指输出不忠于源文档；开放域问答中，指回答与现实不符；Agent 中，指比如幻想出网页上不存在的按钮而采取错误行动。同一个输出在一个场景是幻觉，在另一个场景可能是对的。他们的核心观点是幻觉关乎世界模型：模型通过预训练等学到一个内部世界模型；手头的任务有一个外部的参照世界模型，摘要中是源文档描述的世界，开放域问答中是真实世界。模型学到的世界与参照世界矛盾时就是幻觉，它不只是答错，而是对世界本身的信念错了。

他们把它形式化为三个要素：参照世界模型，规定什么是真的（文档、数据库、真实世界等）；视图，模型实际能看到的东西，比如从数据库检索到的信息；冲突策略，不同信息来源矛盾时怎样解决。比如现实中哈利·波特是男孩，但用户在角色扮演、自己编故事时说哈利·波特是女孩，模型应该跟随用户。幻觉就是在这三者给定时，模型输出了包含错误断言的内容。几乎所有已有的幻觉定义都能纳入这个框架：摘要中，参照世界和视图都是源文档，冲突策略是以文档为准，现实中是什么不重要，输出与文档矛盾就是内在矛盾型幻觉；Agent 中，环境（网页）是真相，Agent 以为环境和实际不同就是幻觉。这个定义还能把幻觉和其他错误区分开：幻觉是对世界的信念错了，规划错误是信念对了但行动错了；点击不存在的按钮是幻觉，选了一个糟糕的策略是规划错误。

这个定义的意义在于让假设变得明确：以后研究幻觉或幻觉缓解技术，应该说明参照世界模型、模型的视图和冲突解决策略分别是什么，这样基准之间才能比较、定义才能一致。有了数学上明确的定义，还能通过在合成环境中操纵这三个要素，大规模生成各种幻觉样本，他们正在做一个叫 HalluWorld 的基准，可用于评估幻觉，也可用于训练更好的缓解方法。

记忆与持续学习

现在很多模型是无状态的，交互之间没有持久的学习。我们想要像人脑一样能跨会话存储信息、取回和复用过去的经验、随时间更新知识，以便个性化、适应变化，支持持续学习和长周期的推理规划。现在的记忆多存在向量数据库等外部系统里检索，或者把过去的信息摘要后压缩进上下文，或者用列表、图等结构化记忆。缺的是可靠的记忆更新：新信息和旧信息矛盾时，覆盖旧的，还是分开存？记忆太多时怎样修剪，删最旧的、最不重要的？什么算最重要？

这引出终身学习或持续学习：希望 AI 系统部署后能通过隐式反馈和真实交互持续学习，而且最好是永久的，更新模型权重，相当于更新大脑。现在很多推理时的学习只在上下文里，不是永久的。这引出一个争论（他没有展开）：真正的持续学习是否需要更新参数，还是上下文学习就够了？Steven 认为真正的持续学习应该更新权重。现在的工作很多是模型蒸馏、自我改进和反思，都只是推理时的增强。他说自己此刻边讲课就在持续学习，不需要每个月坐下来让人把整个互联网念给他听。模型编辑想针对新事实修改模型的特定部分，比如 ROME（秩一模型编辑），但有固有弱点：只对简单事实有效，很难把改动传播到相关事实。比如把"Bob 的爸爸是 Jason"改成"Bob 的爸爸是 Justin"，而 Bob 有个妹妹，妹妹的爸爸也应该改，但可能有成百上千个相关事实要更新，模型编辑做不到。

可解释性与对齐

数十亿甚至万亿参数、在海量数据上训练的模型是很大的黑箱，难以理解。可解释性研究试图弄清这些模型怎样学习和思考，理解它们的内部表示，而不只是输出；机制可解释性用回路、特征等技术打开黑箱。模型越大越强，越会被用在与现实世界交互的地方，所以必须对齐，按我们的意图行事、保证安全。常见问题：为达成目标走捷径，而捷径可能不安全或不合意；换到新领域泛化不好，训练时对齐了，部署到不同场景可能出现异常或不安全的行为。具体的失败模式有：奖励被钻空子，不优化真正的目标，而是找到办法只优化奖励；学会优化训练者或使用者不知道的隐藏目标；思维链的忠实性问题，模型写出的推理步骤是否真是它用来得出答案的依据，还是事后编的解释？可以用因果干预来评估。

对齐方法：人类和 AI 反馈，但 RLHF 容易被钻空子；可解释性；过程监督，检查推理的每一步而不只看最终结果；Anthropic 提出的 Constitutional AI，给模型一份写有行为规则和原则的"宪法"，用它来后训练模型；可扩展监督：模型可能变得很强、数量很多，让人去监督不现实，于是用模型监督模型。总的目标是让模型追求正确的目标，在各种条件下可靠地行事。

Transformer 之后

课程叫 Transformers United，但 Steven 认为应该跳出框框，不只研究 Transformer（现在大多数人都在研究它），因为没有保证 Transformer 和下一个 token 预测能通向 AGI 或超级智能。Transformer 有局限：序列越长效率越低，计算量是平方级的；长上下文推理常常失败；他还认为（这有争议）它没有很好地真正理解世界，多数情况下没有学到有效的世界模型。两个新方向：

  • 世界模型与 Yann LeCun 提出的 JEPA（联合嵌入预测架构）：世界模型是对环境（现实世界）的结构化表示，预测未来状态而不只是 token，有助于更有效、更贴合现实地规划和推理。JEPA 不预测下一个 token 这种原始输出，而是预测潜在表示，关注潜在结构而不是表面细节，避免对底层噪声建模，数据效率更高、抽象和泛化更好，也可以说更接近人的学习方式：预测世界的结构和状态，而不是像素或 token。
  • 状态空间模型（SSM）：用连续的状态更新为序列建模，随时间维护一个压缩的内部状态，有点像 RNN 的隐藏状态。计算随 token 数线性增长，而不是注意力那样的平方，所以对长序列更高效，在长上下文任务上更强，Mamba 就是一种选择性状态空间模型。但它也有取舍，在某些场景下不如注意力灵活，研究还比较早期。

下周 Hazel Nam 来讲 JEPA 和世界模型，再下周 Albert Gu 讲 Mamba 和状态空间模型。他们说有点讽刺，头两位讲者讲的都不是 Transformer，而是替代架构，但他们鼓励大家多了解、跳出框框思考。
