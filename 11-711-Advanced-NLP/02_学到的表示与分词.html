第二讲：分词、词嵌入与神经网络训练

子词与 BPE 分词，UTF-8 字节，词嵌入层，连续词袋与深度连续词袋，非线性激活，交叉熵损失与 KL 散度，手推梯度，SGD，计算图与反向传播

主讲：Sean Welleck · 2026 年 1 月 15 日
资料来源：课程幻灯片 · 课堂录像（本文依据录像字幕整理课堂口述内容） · 课堂代码 · 主要阅读：Cho 讲义第 2、3 章；Karpathy, Let's build the GPT Tokenizer（视频）
零基础读前预备：Softmax 与交叉熵 · 梯度下降与反向传播

一、本讲的位置

上一讲建立了框架：学一个打分函数 $s_\theta(x,y)$，由它可以得到概率模型 $p_\theta(y\mid x) \propto \exp s_\theta(x,y)$；系统由参数化、学习、推理三个要素决定。例子是最朴素的组合：独热向量相加的词袋模型、结构化感知机、看符号的推理。

这一讲仍然只做分类，但会讲任何先进 NLP 系统（包括大语言模型）都在用的基础：子词的连续表示，用神经网络做参数化，用反向传播和梯度下降优化损失。Sean 说如果这些内容大部分没见过，可以借此判断自己的先修知识够不够；分词部分则是 NLP 特有的，没接触过语言模型的人不太可能深入了解过。

词袋模型的毛病在这里多列了一条：组合特征。"I love this movie" 和 "I don't love this movie"，要判断对，必须把"否定"和"love"两个特征组合起来考虑。真正解决句子结构问题需要序列模型（循环神经网络和 Transformer），从第四讲开始。

二、分词

1. 子词

前面一直把整个词当作一个 token。子词模型把不常见的词拆成几个子词 token，比如 "the companies are expanding" 变成 "the compan _ies are expand _ing"。也可以反过来，让一个 token 覆盖好几个词。更一般地说，就是不再执着于"词"的概念，只问：把数据表示成离散单元序列的最好方式是什么。

Sean 让学生说说好处。一个学生说可以缩小词表：如果把互联网上每个词都当一个 token，词表会极大，拆开后小得多。另一个学生说到参数共享：-ing 是很常见的后缀，它的表示可以从所有以 -ing 结尾的词那里获得学习信号；如果 expanding 和 contracting 各是一个独立的 token，它们的表示就完全无关。

2. 分词的核心问题

分词（tokenization）是把原始数据（文本，也可以是图像）映射成一个离散 token 序列 $x_1, \dots, x_T$，每个 $x_t$ 来自词表 $\mathcal{V}$。比如可以按字符切（t, h, e, c, o, m, …），按词切（the, companies, …），或者按子词切。我们希望词表：

  • 有表达力：能表示任何文本，英文、日文、代码都行。如果词表只有英文字母，模型就只能处理英文。
  • 高效，这里有两头的取舍。词表不能太大：每个 token 都有一个要学的向量，词表太大参数就太多，而且很多罕见词的向量几乎得不到训练信号。词表也不能太小：按字符切的话，一句话的序列会非常长，计算代价高。

3. 看看真实模型怎么切

课上用 tiktokenizer 网站演示。GPT-4o 对 "the advanced NLP is cool" 的切分里，advanced 是一个完整的 token，" N" 和 "LP" 是另外的 token。输入一串随机字符，就会被切得很碎，原因看完算法就明白：词表是根据频率建的。

数字是各家差异很大的地方。GPT-4o 似乎把数字按最多三位一组切，这可能是写进分词器的规则；Code Llama 则总是把数字拆成单个数位。不加规则时会出现奇怪的现象：比如 123 有自己的 token，124 和 12 却没有，导致 "123" 是一个 token 而 "927" 被切成 "92" 和 "7"。所以模型开发者常常手动规定数字怎么切。

4. 思路一：UTF-8 字节

计算机用 Unicode 表示文字，约有 15 万个字符，覆盖各种语言和编程语言，而且还会随新字符的加入而变化。15 万太多，又在变。每个 Unicode 字符在计算机里用一小串 UTF-8 字节存储，每个字节只有 256 种取值。所以任何文本都可以写成一串 0 到 255 之间的数。拿这 256 个字节当基础词表，表达力没有问题；缺点是序列太长，"元気ですか。Hello!" 这么短的句子都要很多字节。

5. 思路二：字节对编码（BPE）

从一个表达力强的基础词表出发，再想办法压缩。最流行的算法是字节对编码（Byte Pair Encoding，BPE），思路很简单：

  1. 从一个基础词表（比如 UTF-8 字节）和一份训练文本开始。
  2. 统计训练文本里所有相邻 token 对出现的次数，找到最常出现的那一对。
  3. 新建一个 token 表示这对的拼接，并在文本里把所有这一对替换成新 token。
  4. 重复，直到词表达到预定大小。

课上以字符为基础词表举例：遍历文本，h-e 计一次，e-l 计一次，……统计完发现 "e" 加空格最常见，于是新增 token "e␣"。再统计，最常见的变成 "t␣"，然后是 "er"、"th"，依此类推。

课堂代码里用一段关于大阪马拉松的文本（混合了数字、日文和英文）做实验：用 UTF-8 字节表示需要约 3.9 万个 token；词表从 256 扩到 300，只需约 2.9 万个。可以试试 500 或 1000。

6. 实用工具

  • tiktoken：只能用已经训练好的分词器做切分和还原，不能训练。可以加载 OpenAI 的词表，比如 GPT-2、GPT-4（那时 OpenAI 还公开模型和分词器）。
  • SentencePiece：Google 发布，也能训练分词器。它诞生时用 UTF-8 字节当基础还不流行，所以默认以 Unicode 字符为基础词表，需要设置 byte_fallback=True：遇到词表里没有的字符时，退回按 UTF-8 字节切，否则词表就不是完全有表达力的。它还有拆分数字的选项。课上训练了一个 2048 大小的 BPE 词表，学到的 token 已经有些可解释：常见的英文前后缀，马拉松文本里的常见词，甚至 championships 这样很具体的词。

有学生问中文这种没有空格的语言，切完后怎么还原。这由分词器的实现负责：SentencePiece 会保存足够的信息，比如用一个特殊的下划线符号标记原来的空格，只要正确实现切分和还原，就能复原原句。另一个学生问 BPE 现在还用不用：还很常用，具体取决于数据和目标词表大小。

7. 实践中的考虑

  • 词表取决于训练语料。假设语言 A 只占你数据的 0.1%，但用户里 90% 讲语言 A。不做处理的话，语言 A 的 token 合并得少，大部分用户的序列都会很长。常用办法是在训练分词器时上采样这类数据。
  • 训练分词器的数据和实际使用的数据可能不匹配。比如训练数据里数学很少，上线后大家都在问数学，人们就是这样发现模型对数字的切分很怪的。大模型重训分词器是个大决定，但出新版本时会认真考虑训练集是否有代表性。有学生问出现新词（比如新的宝可梦名字）是否要重训：通常要等到下一个版本。
  • 词表大小主要受计算约束：词表越大，嵌入层越大。开发者会按目标参数量给嵌入层分配一定比例，各模型的词表大小一般落在某个范围里。

三、连续词嵌入

有了 token 序列，下一步是给每个 token 一个好的表示。以前用独热向量 $x_t \in \{0,1\}^V$，维度等于词表大小，只有一个位置为 1，是稀疏的。现在给每个 token 一个稠密向量 $x_t \in \mathbb{R}^{d_{\text{emb}}}$，比如 $[0.2, -1.3, \dots, 0.6]$。维度 $d_{\text{emb}}$ 叫嵌入维度，是一个超参数，和词表大小无关。更重要的区别是：这些向量的值是参数，放进神经网络里，随损失函数的梯度一起学。

1. 嵌入层

把所有 token 的向量排在一起，就是一个 $V\times d$（或转置成 $d\times V$）的矩阵，叫嵌入层（embedding layer）。它唯一的操作是查表：要 token 2 的向量，就取第 2 行。这等价于用独热向量去乘这个矩阵，独热向量的作用就是选出一行。所以独热向量其实还在，只是被用来索引。实际中用库里的实现，比如 PyTorch 的 nn.Embedding。

2. 连续词袋（CBoW）

把一句话里所有 token 的嵌入向量相加，得到 $h \in \mathbb{R}^d$，再经过一个线性层得到 $K$ 个类别的分数：

$$\text{scores} = W h + b, \qquad W \in \mathbb{R}^{K\times d}$$

线性层把 $d$ 维向量映射成 $K$ 维（$K$ 是类别数），再加上偏置 $b$（也可以把偏置并进矩阵）。要学的参数是嵌入向量、$W$ 和 $b$。

课堂代码的任务是推文情感分类（正面、中性、负面）。先在训练集上训练一个只有 2000 个 token 的分词器，学到的 token 里就有 "Twitter"、"?!" 这样的。

3. 向量代表什么

没有保证，但希望相似的词在向量空间里靠得近，并且向量的每个维度相当于一个特征。比如 great 和 excellent 常出现在相似的上下文里，为了降低损失，学习算法可能发现把它们放在相近的位置更有效。独热向量之间没有任何相似性的概念。实际学到的空间是什么样，取决于损失函数和学习算法；人们在一些情况下确实观察到了可解释的结构，甚至可以做向量运算。

四、神经网络特征

1. 为什么要组合特征

"There's nothing I don't love about this movie" 是非常正面的，"I don't love this movie" 是负面的。要分对，需要把否定、具体的词、句子成分等多个特征组合起来。深度神经网络可以把基础的嵌入特征做非平凡的变换，并在多次变换中把信息组合起来，最后得到复杂的表示。

2. 深度连续词袋

仍然把嵌入相加（结构仍然丢了），但不直接用来分类，而是先经过几层变换：

$$h^{(2)} = \tanh\!\big(W^{(1)} h^{(1)} + b^{(1)}\big), \qquad h^{(3)} = \tanh\!\big(W^{(2)} h^{(2)} + b^{(2)}\big), \qquad \text{scores} = W h^{(3)} + b$$

Sean 问 tanh 为什么关键。有学生提到它的取值范围（−1 到 1），有时确实有用，但他要的答案是：它引入了非线性。这类函数叫激活函数（activation function）。如果没有它，两个线性层叠在一起，$W_2(W_1 h) = (W_2 W_1) h$，还是一个线性变换，叠多少层都一样。有了非线性，网络才能表达更复杂的模式。

有学生问能不能用别的。可以。早年网络很难训练，tanh 有一些好的性质，人们用它让网络训练起来了；后来 ReLU 出现，效果更好；作业里会见到 LLaMA 等新模型用的激活函数。Sean 建议查看 PyTorch 的激活函数列表，大致能反映现在用的是哪些，要了解某个模型用的具体激活函数，就去读那篇论文。

直观理解：第二层的某个节点可以表示"特征 1 和特征 5 同时激活"，比如"出现了否定"和"出现了 hate"；同时网络还能学到对前一层特征的非线性变换。课堂代码显示，哪怕只加一个隐藏层，效果也比连续词袋好很多。

五、训练神经网络

用梯度下降的某个变体，分三步：写下损失函数；计算损失对参数的梯度；把参数往减小损失的方向移动。Sean 说即使见过也值得复习，交叉熵的多分类版本正是训练大语言模型用的损失。

1. 二元交叉熵

把推文分为正面（1）或负面（0）。让模型输出一个 0 到 1 之间的数，解释为正面的概率 $p_\theta(x)$。怎样保证输出在 0 到 1 之间？学生答：sigmoid。在网络最后加一层

$$\sigma(s) = \frac{1}{1 + \exp(-s)}$$

真实标签 $y\in\{0,1\}$，损失是：

$$L_{\text{BCE}}(\theta; x, y) = -y\log p_\theta(x) - (1-y)\log\big(1 - p_\theta(x)\big)$$

分情况看就很直观。$y = 1$ 时第二项为零，损失是 $-\log p_\theta(x)$。模型错了（$p\to 0$），$\log p$ 趋于负无穷，前面有负号，损失很大；模型对了（$p\to 1$），$\log p\to 0$，损失很小。$y = 0$ 时对称。

2. 多分类交叉熵

三类：正面（2）、中性（1）、负面（0）。模型输出一个概率向量，每个元素在 0 到 1 之间、总和为 1，比如 $p = [0.2, 0.5, 0.3]$。网络本身输出的 $K$ 维向量 $z$ 不一定是概率，在顶上加一层 softmax：

$$p_i = \frac{\exp(z_i)}{\sum_{j=1}^K \exp(z_j)}$$

softmax 非常常见，值得记住它的形式。真实标签写成独热向量，比如 $y = [0, 0, 1]$，损失是：

$$L_{\text{CE}} = -\sum_{i=1}^K y_i\log p_i$$

和二元情况一样，除了真实类别那一项，其余全部为零，损失就是真实类别概率的负对数。模型给真实类别高概率，损失小；给低概率，损失大。类别可以有很多，比如 5 万个，只是计算上要注意。

代码实现往往看不到求和：先算 log_softmax，再取出目标类别那个位置的值。因为其他项都是零。如果要训练很大的模型，应该用 PyTorch 等库里优化过的实现（nn.CrossEntropyLoss）。

3. 交叉熵从哪来

信息论里，KL 散度衡量两个概率分布有多不同（严格说不是距离）：

$$\text{KL}(p_1, p_2) = \sum_x p_1(x)\log\frac{p_1(x)}{p_2(x)} = \underbrace{-\sum_x p_1(x)\log p_2(x)}_{\text{交叉熵 } H(p_1,p_2)} \ \underbrace{+ \sum_x p_1(x)\log p_1(x)}_{\text{负熵 } -H(p_1)}$$

如果要调整 $p_2$ 让它尽量接近 $p_1$，熵 $H(p_1)$ 不含 $p_2$，可以丢掉，剩下的就是交叉熵。在上面的例子里，$p_1 = [0, 0, 1]$ 是真实标签，$p_2 = [0.2, 0.5, 0.3]$ 是模型输出。所以最小化交叉熵损失，等价于最小化 KL 散度，也就是让模型的分布尽量等于目标分布。讲语言模型拟合文本分布时还会再用到这个论证。有学生问这和热力学的熵是不是一回事，这里是信息论里的 Shannon 熵。

4. 手推一次梯度

模型：$z = wx + b$，$p = \sigma(z)$，损失是二元交叉熵。用链式法则分解：

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial p}\cdot\frac{\partial p}{\partial z}\cdot\frac{\partial z}{\partial w}, \qquad \frac{\partial L}{\partial p} = \frac{p - y}{p(1-p)}, \quad \frac{\partial p}{\partial z} = p(1-p), \quad \frac{\partial z}{\partial w} = x$$

中间一项需要自己推 sigmoid 的导数，是很好的练习。三项相乘后化简得到：

$$\frac{\partial L}{\partial w} = (p - y)\,x$$

结果简单又直观：预测和标签相差越大，梯度越大；两者一致时梯度为零。偏置 $b$ 同样推导。

5. 更新参数

最简单的是随机梯度下降（SGD）：

$$g_t = \nabla_\theta \ell(\theta_{t-1}), \qquad \theta_t = \theta_{t-1} - \eta\, g_t$$

$\eta$ 是学习率，控制每次更新的步子多大。最简单时它是常数，实际中通常有一个调度，比如开始大、逐渐衰减。还有更复杂的更新规则，作业里会详细实现 Adam 的一个变体，后面的课会讲。到这里，一个训练循环的零件就齐了：遍历训练样本，送进模型，算交叉熵损失，算梯度，用 SGD 更新。

六、计算图与反向传播

上面的训练循环里看不到任何求梯度的代码，因为现代库基于自动微分，会记录所有计算并自动求梯度。提到神经网络，人们可能想到大脑，但实际上它就是一张计算图。

1. 计算图

  • 节点是一个值：张量、矩阵、向量或标量。
  • 边是函数参数，指向别的节点。有入边的节点是入边另一端节点的函数。
  • 每个节点只需知道两件事：怎样算出自己的值，以及自己对每个输入的梯度（局部梯度）。这让整个系统可以模块化。
  • 计算图是有向无环的。

例子是表达式 $y = x^\top A x + b\cdot x + c$：先有 $x^\top$，再有 $x^\top A$，再有 $x^\top A x$，然后加上 $b\cdot x$ 和 $c$。只要实现了这些基本运算，就能拼出任意复杂的表达式。现在的库已经实现了构建神经网络所需的所有运算：ReLU、sigmoid、tanh、线性变换等。

2. 前向与反向

  • 前向传播：按拓扑顺序，用每个节点的输入算出它的值，直到图的末端，通常是损失函数。
  • 反向传播：按逆拓扑顺序，从最后的输出开始，依次算出输出（损失）对每个节点的梯度。关键是链式法则：某个节点的梯度 = 从上面传下来的梯度 × 该节点的局部梯度，$\frac{\partial F}{\partial u} = \frac{\partial F}{\partial f(u)}\cdot\frac{\partial f(u)}{\partial u}$。递归下去，就得到损失对每个参数的梯度。
  • 参数更新：沿梯度的反方向移动参数，W -= α * dL/dW。

框架里的基本流程是：建模型；对每个样本构建表示所需计算的图，算出结果；训练时做反向传播并更新。

3. 框架

PyTorch 是 NLP 里用得最多的（Meta 开发），偏动态执行，灵活。JAX 由 Google 开发，偏"定义再编译"，并行化在概念上简单。更早的 TensorFlow 要求预先声明静态的计算图，而 PyTorch、JAX 是动态构建的。

课堂代码实现了词袋、连续词袋、深度连续词袋三种模型和完整的训练循环。最后的结果是，深度学习模型比非深度学习模型好很多。

  • tiktoken、SentencePiece：两个常用的分词库。

八、小结

分词把文本变成 token 序列，词表要在表达力和效率之间取舍。以 UTF-8 字节为基础词表能表示任何文本，BPE 反复合并最常见的相邻对来缩短序列；词表取决于训练语料，低资源语言和数字需要特别处理。词嵌入给每个 token 一个可学习的稠密向量，嵌入层就是查表。连续词袋把嵌入相加再接线性层，深度连续词袋加上带非线性激活的隐藏层，从而能组合特征。训练用交叉熵损失，它等价于最小化模型分布与目标分布的 KL 散度；梯度由链式法则得到，在 sigmoid 加交叉熵的情况下化简为 $(p-y)x$；参数用 SGD 等方法更新。现代框架把模型表示成计算图，自动做前向和反向传播。
