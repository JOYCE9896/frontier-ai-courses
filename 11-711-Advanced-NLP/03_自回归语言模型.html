第三讲：自回归语言模型的基础

结构化预测，语言模型是序列上的概率分布，链式法则，二元与 n 元模型，最大似然与 KL 散度，对数似然与困惑度，平滑，前馈神经语言模型，以及训练深度模型的几条实践经验

主讲：Sean Welleck · 2026 年 1 月 20 日
资料来源：课程幻灯片 · 课堂录像（本文依据录像字幕整理课堂口述内容） · 课堂代码 · 主要阅读：Cho 讲义第 5 章（至 5.4.2）；Bengio 等 2003

一、三类预测问题

这一讲开始向大语言模型靠近，但讲的是最简单的语言模型。Sean 说，这些简单模型足以引出很多重要的概念，而且这些概念会一直沿用到最新的大模型。

传统 NLP 按要预测的东西把任务分成几类：二分类（正面或负面），多分类（很好到很差五档），以及结构化预测（structured prediction）：标签的数量是指数级甚至无穷的。经典例子是词性标注，给 "I hate this movie" 的每个词标上 PRP、VBP、DT、NN 这样的标签。每个位置有 $n$ 种选择，长度为 4 的句子就有 $n^4$ 种可能的输出，随长度指数增长。翻译也一样：把 "I hate this movie" 译成日文 "kono eiga ga kirai"，每个位置有词表大小 $V$ 种选择，输出空间随长度指数增长。可以把翻译看成一个疯狂的分类任务：在一个极大的输出空间里挑一个好的点。语言模型提供了一种处理这种问题的方式。

二、什么是语言模型

一个语言模型就是所有序列上的一个概率分布 $P(X)$。$X$ 的取值空间可以是所有英文句子，或者互联网上所有文本序列。概率分布的意思是：每个元素对应一个 0 到 1 之间的数，所有元素的数加起来为 1。最简单的例子是一枚不均匀的硬币：$P(X=0) = 0.4$，$P(X=1) = 0.6$。语言模型也给出这样的分布，只是元素换成了序列：比如 "a." 的概率是 0.000013，"aa." 是 0.000001，"a cat sat." 是 0.0191。可以想象成一张巨大的网格，每格是一个序列，序列的数量多得惊人。

语言模型能做什么

  • 给序列打分：$P(\text{Jane went to the store .})$ 高，$P(\text{store to Jane went the .})$ 低。在大型预训练模型出现之前，语言模型主要就是这么用的：比如一个基于规则的翻译系统给出几个候选译文，用语言模型打分重新排序。
  • 生成序列：从分布里采样一个序列 $\hat x \sim P(X)$，就像抛硬币得到一个结果。
  • 条件生成：把前 $t$ 个 token 当作上下文（也叫提示，prompt），采样它的续写 $\hat x_{t+1:T} \sim P(X_{t+1:T}\mid x_{1:t})$。上下文是英文句子、续写是日文句子，就是机器翻译。更一般地，上下文里可以放任务说明、示例和输出的开头，续写就是完成任务的输出。后面讲的指令遵循训练就建立在这个思路上。

很多任务都能这样做。回答选择题：给每个选项打分，或者直接续写答案。分类：比较"……This is positive"和"……This is negative"两个序列的概率，或者在提示里描述分类任务，让模型生成标签。改语法：给每个词打分、替换得分低的，或者直接生成语法正确的句子。

三、自回归分解

Sean 问这个等式叫什么，学生答：概率的链式法则。

$$P(X) = \prod_{t=1}^{T} P(x_t\mid x_1, \dots, x_{t-1})$$

这是一个等式，不是近似。展开就是 $P(x_1)P(x_2\mid x_1)P(x_3\mid x_1,x_2)\cdots$。读概率教材时这个公式常常一扫而过，但它对语言模型意义重大：它把序列建模分解成了下一个 token 的建模。只要能给出好的"下一个 token 分布"，把它们乘起来就是好的序列分布。

这为什么重要？结构化预测的输出空间是指数级的，直接对它建模不知从何下手。而下一个 token 的分布 $P(x_t\mid x_{<t})$ 只定义在词表 $\mathcal{V}$ 上，只是 $V$ 个数。于是问题变成：怎样学好下一个 token 的分布。所有最先进的大语言模型都基于这个自回归分解，训练目标都是预测下一个 token，而上面的等式说明了为什么这样做能得到对整段序列的好模型。

四、二元模型

二元模型（bigram model）假设每个 token 只依赖它前面一个 token：

$$P(X) \approx \prod_t p_\theta(x_t\mid x_{t-1})$$

很天真。比如 "The jacket is on the desk"，预测 desk 时只能看到 the，完全不知道前面说的是 jacket。但它很有启发性：我们能清楚地看到它怎么学，学到的东西也完全可以解读。有学生问，这里的 token 是字母吗？二元只是说"相邻两个 token"，用什么分词器都行；课上为了好解释用了字符，也可以在 BPE token 上训练二元模型。

1. 训练

先明确设定。我们想建模的分布叫数据分布 $p_{\text{data}}$，比如所有人名的分布，或者英文文本的分布。我们手里没有这个分布本身，只有一个数据集 $D = \{x_n\}_{n=1}^N$，把它看作从 $p_{\text{data}}$ 抽出的样本，再分成训练集、开发集和测试集。目标是用训练集学出 $p_\theta \approx p_{\text{data}}$。

二元模型的训练不用反向传播，只用数数：

$$p(x_t\mid x_{t-1}) = \frac{\text{count}(x_{t-1}, x_t)}{\sum_{x'}\text{count}(x_{t-1}, x')}$$

遍历训练集，统计 $x_t$ 跟在 $x_{t-1}$ 后面出现的次数，除以 $x_{t-1}$ 后面跟任何 token 的总次数。可以把它看成学参数：参数 $\theta_{i,j} = p(x_j\mid x_i)$，共 $V^2$ 个，数数就是估计这些参数的方法。

课堂代码（改编自 Karpathy 的 makemore 视频）用一个人名数据集，按字符切分。每个名字前后加上特殊的开始和结束 token，这样才能表示"第一个字符的概率"和"名字在这里结束的概率"。统计发现最常见的相邻对是 n 后面紧跟结束符，最常见的首字母是 a。归一化之后可以看到学到的每一个参数，比如 q 后面几乎全部概率都给了 u，和英文拼写一致。模型完全透明。

2. 为什么是数数：最大似然

数数恰好对应最大似然估计（maximum likelihood estimation，MLE），推导可以自己做练习。最大似然的意思是：选参数，让模型给训练数据分配尽可能高的概率：

$$\max_\theta \sum_{x\in D_{\text{train}}}\log p_\theta(x)$$

这会是训练大语言模型的方法，后面会反复出现。直觉上很合理：训练时我们只有训练集，那就让训练集里的序列更可能。Sean 问有什么潜在问题：如果模型只是给训练集很高的概率，遇到测试集里的新样本就不行了。我们真正想要的是泛化，学到底层的分布。

最大似然还有更有原则的依据，和上一讲分类时的论证一样。记 $p^* = p_{\text{data}}$，我们想让模型和数据分布的 KL 散度最小：

$$\min_\theta D_{KL}(p^*\,\|\,p_\theta) = \min_\theta \Big[-\sum_x p^*(x)\log p_\theta(x) + \sum_x p^*(x)\log p^*(x)\Big]$$

第二项（负熵）与 $\theta$ 无关，丢掉；第一项是交叉熵，写成期望形式 $-\mathbb{E}_{x\sim p^*}\log p_\theta(x)$。我们只有数据集，它是从 $p^*$ 来的样本，可以用样本平均近似期望：

$$\approx \min_\theta -\frac{1}{|D|}\sum_{x\in D}\log p_\theta(x) \ \equiv\ \max_\theta \sum_{x\in D}\log p_\theta(x)$$

就是最大似然。所以最大似然等价于让模型去匹配数据分布，唯一的误差来源是用有限样本近似期望，数据集太小时误差就大。数据无穷多时，最大似然会让模型等于数据分布。

3. 为什么用对数

序列越长，要相乘的小概率越多，结果小到计算机难以表示，出现下溢等数值问题。取对数后乘法变成加法，$\log\prod_i P(x_i) = \sum_i\log P(x_i)$，数值稳定，也方便。有学生问这是否假设样本相互独立：链式法则本身就是乘积，取对数变成和；如果把数据集里的多个序列视为独立，整个数据集的概率也是乘积，取对数后同样是和。

4. 生成

利用自回归的结构：从开始符出发，采样一个 token，接到上下文后面，再采样下一个，直到生成结束符。$\hat x_t \sim p_\theta(x_t\mid \hat x_{t-1})$。第 7 讲会讲到，这样逐个采样等价于从模型对整段序列的联合分布中采样。这是自回归模型的一大优点：采样一个完整序列，只需要反复从一个 $V$ 维的多项分布里抽样，PyTorch 里一行代码。后面讲扩散模型时会看到，非自回归模型需要另外设计采样过程，会更复杂。

生成的名字像 "mor"、"ch"、"anon"，每次运行都不一样。它们好不好？见仁见智。我们需要一种不看语义、只把模型当作概率分布来客观评价的方法。

5. 评估：对数似然与困惑度

把模型在一个数据集（训练集或测试集）上给出的概率直接当作评价指标。不需要生成，算得快，训练时广泛使用。

$$\text{NLL} = -\sum_{i=1}^N\sum_{t=1}^{T_i}\log p\big(x_t^{(i)}\mid x_{<t}^{(i)}\big) \in [0, \infty)$$

负对数似然越低越好，它就是后面用的损失函数。数据集有上万亿 token 时总和会大得难以解读，所以通常除以 token 总数，得到每个 token 的平均负对数似然 $\text{NLL}_{\text{avg}}$。困惑度（perplexity）来自信息论，是它的指数：

$$\text{PPL} = \exp\big(\text{NLL}_{\text{avg}}\big) \in [1, \infty)$$

最好是 1（模型给每个真实 token 的概率都是 1）。困惑度有一个直观解释。看例子："When a dog sees a squirrel it will usually ___"，模型给 bark 的概率是 0.0352，$e^{-\log 0.0352} \approx 28.4$。意思是，模型对这个位置的不确定程度，相当于在 28 个选项上均匀分配概率。可以验证：如果在 $k$ 个选项上均匀分配，每个概率 $1/k$，代进去恰好得到 $k$。困惑度越大，模型越不确定，概率摊得越开。对 jump、start、run、try 分别得到 29.6、34.6、36.1、45.7。

五、n 元模型

把上下文扩展到前面 $n-1$ 个 token，比如四元模型是给定前三个 token 预测第四个：

$$p(x_t\mid x_{t-n+1:t-1}) = \frac{\text{count}(x_{t-n+1:t-1}, x_t)}{\sum_{x'}\text{count}(x_{t-n+1:t-1}, x')}$$

Sean 问：用这种数数的方法训练一个十元模型会怎样？学生答：矩阵很稀疏。很多十元组在训练集里从没出现，概率为零，或者只出现过一次。概率为零尤其麻烦，评估时要算 $\log 0$。

平滑

办法是加"假计数"，把一部分概率分给没见过的组合，统称平滑（smoothing）。最简单的是给每个可能的 n 元组都加 1：

$$p(x_t\mid x_{t-n+1:t-1}) = \frac{1 + \text{count}(x_{t-n+1:t-1}, x_t)}{|V| + \sum_{x'}\text{count}(x_{t-n+1:t-1}, x')}$$

分母加上 $|V|$ 保证它仍是合法的概率分布。平滑方法曾经是一个大的研究方向，足够讲一两节课，现在只剩一张幻灯片。比较有名的是 Kneser-Ney 平滑。

根本局限

课上用 Slido 收集了学生的答案：低频词，相似词，过拟合，存储复杂度，语义相似性。幻灯片列了三条：

  • 不能在相似的词之间共享信息。"she bought a car" 和 "she purchased a car"，bought 和 purchased 的统计完全独立。解决办法：神经网络。
  • 不能跳过中间的词利用上下文。对 "Dr. Jane Smith" 估计得再好，换成 "Dr. Gertrude Smith" 就得完全重新数。
  • 处理不了长距离依赖。"for tennis class he wanted to buy his own racquet" 和 "for programming class he wanted to buy his own computer"，最后一个词取决于句首。解决办法要等到后面几讲的序列模型。即使对大语言模型，很长的依赖仍是开放问题，课程末尾会讲当前最好的长上下文方法。

n 元模型并非没用。神经模型效果更好，但 n 元模型估计和使用都极快，而且能完美地"记住"数据。面对 TB 级的预训练语料，可以用它快速查找某段文字是否出现过、做粗略估计、快速过滤数据。常用工具是 KenLM，里面实现了各种平滑方法。

六、前馈神经语言模型

用神经网络来参数化 n 元模型，出自 Bengio 等人 2003 年的论文《A Neural Probabilistic Language Model》。Sean 推荐读原文：当时人们都在研究平滑和计数模型，这篇论文为用神经网络给出了很好的动机，今天读来仍然易懂。

动机是相似性。训练时见到 "The cat was walking in the bedroom"，希望 "The dog was walking in the bedroom" 的概率也随之上升，因为 cat 和 dog 常常可以互换；同样希望 "The cat was running in a room" 也上升。办法是用学到的分布式表示。

结构是上一讲连续词袋的延伸，但保留了顺序信息：把上下文 $n-1$ 个 token 的嵌入拼接（而不是相加）起来，经过一个隐藏层 $h = \tanh(W_1 [\,e_{x_{t-2}}; e_{x_{t-1}}\,] + b_1)$，再乘以输出权重矩阵得到词表上每个 token 的分数 $s = Wh \in \mathbb{R}^V$，最后 softmax 得到 $p_\theta(x_t\mid \text{cat, was})$。拼接的缺点是 $n$ 很大时向量会很长，但这类模型用的 $n$ 都很小。说白了，就是把预测下一个 token 当作一个 $V$ 类的分类问题。

训练：还是交叉熵

用最大似然。按链式法则，序列的对数概率是各位置下一个 token 对数概率之和，于是每个位置的损失是：

$$L_t = -\log p_\theta(x_t\mid x_{1:t-1})$$

这就是上一讲的交叉熵损失 $-\sum_i y_i\log p_i$：类别就是词表里所有可能的下一个 token，$y$ 是训练数据里真实下一个 token 的独热向量，$p_i$ 是模型给它的概率。把这几讲的论证串起来，结论有点出人意料：只要学会给下一个 token 分类、用交叉熵训练，就得到了一个拟合数据分布的语言模型。训练大语言模型用的也是这个损失。课堂代码里，输入是上下文，标签是下一个 token，在人名数据上训练，效果比二元模型好得多。

它能学到什么

模型学的是任何能降低损失的东西，具体学到了什么很难说，但可以想象一些可能性。比如输出权重矩阵的第 34 行，可能在"前一个词是限定词、再前一个词是动词"时给出正数，这就是一种组合特征。

信息在哪里共享？相似的词可能得到相似的嵌入；于是相似的上下文得到相似的隐藏状态；相似的输出词得到相似的输出权重。课上给了一个简单论证。两个相似的上下文 "It's a great" 和 "It is a wonderful"，隐藏状态分别是 $h_j$、$h_k$，下一个词是 movie（输出权重 $w$）：

$$\frac{p(w\mid h_j)}{p(w\mid h_k)} = \frac{Z_k}{Z_j}\exp\big(w^\top(h_j - h_k)\big)$$

要让两个上下文预测 movie 的概率相同，一种方式是让 $w^\top(h_j - h_k) = 0$，比如让两个隐藏向量彼此接近。优化过程会推动相似的上下文得到相似的表示。阅读材料里有更详细的推导。

对照前面的三条局限：相似词之间共享信息，解决了；跳过中间词，也因此解决了，相似的上下文也能共享；长距离依赖，还没解决，要等下一讲的循环神经网络和再下一讲的 Transformer。

七、训练深度模型的实践经验

深度学习系统有很多活动部件：架构、优化器、权重、超参数。做实验时要保证结论可靠：如果声称效果差异来自新架构，就不能实际上是由优化器或批大小造成的。下面几条经验在大多数深度学习实验里都是默认的。

1. 训练集、验证集、测试集

  • 训练集：来自 $p^*$ 的样本，用来拟合模型。
  • 验证集：留出的另一批 $p^*$ 样本，检查泛化。模型可能把概率全压在训练数据上，如果它在验证集上也给出高概率，说明可能学到了底层分布。验证集用来设计系统：比较两种批大小、两种架构，选好的那个；也用来调超参数、做消融实验。
  • 测试集：既然用验证集设计了系统，系统可能对验证集过拟合，所以还需要再做一次泛化检查。只在开发完全结束、不再改动系统之后用一次，开发过程中不看它。当然测试集也不能混进训练集，这听起来是常识，但大语言模型时代，我们并不确定这一点是否总能保证。

课上给了三个模型的训练损失和验证准确率，全班一致选模型 3：它的验证准确率最高，按验证集选模型就该选它。

2. 过拟合

典型症状：训练损失一直下降，验证损失开始上升。应对办法：换超参数（比如数据很少而模型太大，就把模型变小）；加正则项；或者定期保存检查点，选验证损失开始上升前的那一个。

3. 初始化

从零训练时，权重的初始化方式对优化轨迹影响很大。课堂代码里如果去掉初始化那几行，效果明显变差。早年让深度网络能训练起来，初始化是关键问题之一。Xavier 初始化（Glorot 和 Bengio 2010）从零附近的均匀分布中取值，并按层的输入输出维度缩放，平衡各层之间的方差：

$$W \sim \mathcal{U}\!\left(-\sqrt{\frac{6}{n_{\text{in}} + n_{\text{out}}}},\ \sqrt{\frac{6}{n_{\text{in}} + n_{\text{out}}}}\right)$$

4. 学习率调度与预热

学习率通常不固定。常见的余弦调度先大后小：开始时大步更新，像在空间里四处探索；找到某个盆地（可能是局部最小，也可能是全局最小）之后小步收敛。一开始步子太大可能让训练不稳定，所以常配合预热（warmup）：前若干步把学习率从很小逐渐升上去。即使只写一个微调循环，也要考虑学习率调度。

5. 批处理

一次处理多个样本（一个批次），利用 GPU 的并行能力；每次梯度更新都是对全数据集梯度的有噪声估计，在批内平均可以平滑掉一部分噪声。序列长度不同时，批次必须是整齐的矩阵，所以用填充 token（pad）补齐短序列。涉及 pad 的运算可能需要屏蔽；输出长度不同时，要把 pad 位置的损失屏蔽掉，PyTorch 的损失函数有现成的选项可以忽略 pad 索引。下一讲会有具体例子，优化器 Adam 也在下一讲。

  • A Neural Probabilistic Language Model（Bengio 等，2003）：提出用词的分布式表示和神经网络建模 n 元语言模型，同时学习词向量和概率函数，比当时最好的平滑三元模型困惑度明显更低。
  • Understanding the difficulty of training deep feedforward neural networks（Glorot & Bengio，2010）：Xavier 初始化。
  • Karpathy 的 makemore 视频：二元模型人名生成的代码来源。
  • KenLM：n 元语言模型工具库。

九、小结

语言模型是序列上的概率分布，可以打分、生成和条件生成。链式法则把序列建模分解为下一个 token 的建模，这是所有自回归大语言模型的基础。二元和 n 元模型用计数训练，计数就是最大似然估计，而最大似然等价于最小化模型与数据分布的 KL 散度。模型用平均负对数似然和困惑度评估。n 元模型受困于稀疏、不能共享相似词的信息、处理不了长距离依赖；平滑能缓解零概率。前馈神经语言模型拼接上下文嵌入、用神经网络预测下一个 token，用交叉熵训练，解决了相似性的问题。训练深度模型时要正确划分数据、监控过拟合，注意初始化、学习率调度和批处理。
