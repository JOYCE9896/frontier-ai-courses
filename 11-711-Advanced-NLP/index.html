11-711: Advanced NLP

从词袋模型到推理模型：语言模型的表示、架构、预训练、微调、解码、检索、多模态、评估、强化学习、Agent 与规模化

主讲：Sean Welleck（CMU 语言技术研究所）
整理：Joyce（@JOYCE9896）

课程简介

11-711 Advanced NLP 是卡内基梅隆大学语言技术研究所（LTI）的研究生 NLP 核心课。这里整理的是 2026 年春季学期的版本，由 Sean Welleck 主讲，每周二、四下午上课，共 23 讲，4 月 16 日期末考试。不少幻灯片改编自 Graham Neubig 2024 年秋季的同名课程。考核包括 5 次小测、1 次考试和 4 次作业，后两次作业是先做文献综述并复现一个已有结果，再在此基础上做自己的课程项目。

课程从最基础的问题讲起：怎样把文本变成模型能处理的东西，语言模型是什么，怎样训练。然后依次讲 RNN 与 Transformer、预训练与缩放定律、微调与解码、检索增强、多模态（视觉理解、图像生成、扩散），接着是评估与实验方法、强化学习、Agent，最后几讲围绕效率与规模化：量化、并行训练、混合专家、长序列和推理时扩展。

课程网站：cmu-l3.github.io/anlp-spring2026，幻灯片公开；课堂代码在 cmu-l3/anlp-spring2026-code；课堂录像在 YouTube 上公开。每一讲的笔记依据幻灯片和录像字幕整理，保留了课上的问答。

读之前需要知道的几个概念

1. 语言模型就是给序列分配概率

第三讲会正式定义：语言模型是文本序列上的概率分布，用链式法则拆成"给定前文，下一个 token 的概率"的乘积。训练几乎都用最大似然，也就是让模型给训练数据里的序列分配高概率。课程后半段的强化学习，可以理解为把"数据里有什么就学什么"换成"按奖励的好坏来调整"。

2. 学习系统的三个要素

第一讲提出、整门课反复使用的框架：参数化（模型长什么样，比如 Transformer），学习（怎样从数据找到参数，比如梯度下降最小化交叉熵），推理（训练好之后怎样用它产生输出，比如解码算法）。后面每一讲基本都在改进其中一个要素。

3. 计算、内存与规模

训练一个模型大约要花 $6ND$ 次浮点运算（$N$ 是参数量，$D$ 是 token 数），这个近似在缩放定律、并行训练、混合专家几讲里都会用到。很多技术的取舍都能归结为在计算、内存和通信之间交换，读最后几讲时可以留意这一点。

课程目录（23 讲）

第 10 讲由 Akari Asai 主讲，第 18 讲由 Zora Wang 主讲，其余由 Sean Welleck 主讲。

01. NLP 是什么，学习系统的三个要素

规则、监督学习与强化学习，手写一个情感分类器，打分函数，参数化、学习与推理，词袋模型与感知机，从分数到概率再到生成与行动。

02. 分词、词嵌入与神经网络训练

子词与 BPE 分词，UTF-8 字节，词嵌入层，连续词袋与深度连续词袋，非线性激活，交叉熵损失与 KL 散度，手推梯度，SGD，计算图与反向传播。

03. 自回归语言模型的基础

结构化预测，语言模型是序列上的概率分布，链式法则，二元与 n 元模型，最大似然与 KL 散度，对数似然与困惑度，平滑，前馈神经语言模型，以及训练深度模型的几条实践经验。

04. 循环神经网络与注意力的起源

序列模型的三种做法，RNN 的结构、训练与推理，梯度消失的成因，门控与残差连接，GRU 与 LSTM，编码器-解码器，以及为翻译而发明的注意力。

05. 注意力与 Transformer

交叉注意力与自注意力，查询、键、值，缩放点积，位置编码，多头注意力，因果掩码，层归一化与残差，前馈层，以及 LLaMA 式改进：SwiGLU、RoPE、Pre-LN、RMSNorm、分组查询注意力。

06. 预训练

先预训练再适配，掩码语言模型与 BERT，自回归预训练为什么是在拟合分布、也是在学压缩，GPT-2 与 LLaMA，预训练中的评估，网页数据的抽取、过滤、去重与配比，以及 Adam 优化器。

07. 缩放定律与上下文学习

训练就是花计算量，C ≈ 6ND，幂律与双对数图，数据、模型规模与计算量的缩放定律，Chinchilla 的计算最优配比，用缩放定律选超参数；提示的三种方式，上下文学习的现象，对话格式与系统提示，思维链与提示链。

08. 微调、指令微调与知识蒸馏

监督微调的定义，分类与语言模型的微调代码，微调哪些参数，LoRA，微调让分布变窄，从 FLAN 到 Self-Instruct 的指令微调，对话微调，词元级与序列级知识蒸馏。

09. 解码算法

解码是在一棵树上做选择，作为优化的贪心与束搜索，MAP 解码的退化：重复、空序列与非典型，祖先采样与复合误差，top-k、top-p 与温度，KV 缓存，计算受限与访存受限，以及加速推理的三个层面和推测解码。

10. 检索、检索增强生成与深度研究（Akari Asai）

语言模型为什么会幻觉、知识会过时，检索增强的三个组件：数据存储、检索器、语言模型；TF-IDF 与 BM25，稠密检索与对比学习，重排序，评估与 MTEB；RAG 的训练与局限，Self-RAG，深度研究 Agent 的训练，以及 RETRO 与 kNN-LM。

11. 多模态大模型（一）：让语言模型看懂图像

多模态的几种设定，把图像变成向量序列，Vision Transformer 的切块与嵌入，表示学习与 CLIP 的对比损失，零样本分类，LLaVA 式视觉语言模型，以及 Molmo 和 PaliGemma 两个案例。

12. 多模态大模型（二）：图像 token 与自回归生成

四种生成建模范式，逐像素的自回归模型及其局限，VAE 与证据下界，VQ-VAE 把图像离散成 token，VQ-GAN，DALL-E 与 Chameleon 用一个自回归模型同时生成文本和图像。

13. 评估与基准

损失为什么不够，下游任务评估的形式化，MMLU、HumanEval、GSM8K 与 pass@k，好基准的性质：广度、难度、效用、鲁棒性、无污染、高效，ROUGE、LLM 作评委、清单式评估与 Chatbot Arena。

14. 研究能力与实验设计

基准分数的标准误与置信区间，聚类问题，非配对与配对检验，怎样找研究问题、读文献、提出可证伪的假设，找数据与标注，用功效分析估算需要多少测试数据，用 Cohen's kappa 衡量标注一致性。

15. 扩散与流（多模态大模型三）

前向加噪与反向去噪，噪声调度，从证据下界推出预测噪声的训练目标，DDPM 的采样，噪声与分数函数的联系，分类器引导与无分类器引导，潜空间扩散与 DiT，SDE 与概率流 ODE，流匹配与 Stable Diffusion 3。

16. 强化学习基础

最大似然的三个局限，智能体与环境，马尔可夫决策过程与策略，策略、价值、模型三类算法，得分函数估计与 REINFORCE，CartPole 示例，折扣、基线、优势与 GAE，PPO 的裁剪。

17. 大模型的强化学习

单步 MDP 与 token 级 MDP，RL 前要不要先做 SFT，可验证奖励（RLVR），组内相对优势与 GRPO，字符串反转示例，DeepSeek-R1，RLHF 三步走，Bradley-Terry 奖励模型，奖励投机与 KL 约束。

18. 基于语言模型的 Agent（Zora Wang（客座讲者））

什么算 Agent，观察空间（文本、可访问性树、截图与标记集），动作空间（原始动作、API、自己归纳的技能），工具的类别与学习，内部状态与记忆，基准与框架，训练 Agent 基座模型的数据，从独立自主到与人协作。

19. 量化

模型为什么放不进笔记本，计算机怎样表示整数和浮点数，FP32、FP16 与 BF16，absmax 与零点量化，离群值与 LLM.int8()，GGML、GGUF 与 llama.cpp，量化感知训练与 QLoRA。

20. 并行与规模化训练

单卡训练的计算量与 MFU，训练时的显存构成，批大小，激活重算与梯度累积，通信原语，数据并行及其重叠与分桶，张量并行，流水线并行与气泡，ZeRO 分片，怎样组合各种并行策略。

21. 混合专家模型

用稀疏激活在不增加每样本计算的前提下扩大参数量，专家放在哪、要多少、细粒度专家与共享专家，top-k 词元选择路由与专家选择路由，负载均衡损失与 z-loss，专家并行，稀疏升级，DeepSeekMoE 与 OLMoE。

22. 扩展序列长度

序列能有多长，长上下文的评测（迷失在中间、大海捞针、RULER、Oolong），注意力的平方复杂度与 GPU 存储层级，在线 softmax、FlashAttention 与环形注意力，位置编码的外推失败、长文档继续训练与 RoPE 缩放，Transformer 的改造与状态空间模型（Mamba）。

23. 推理时扩展

测试时计算这一新的扩展维度，生成器与元生成算法，Best-of-N 与奖励模型、过度优化与过程奖励，投票（自洽性）与加权投票，投票在极限下收敛到什么，带外部或内部反馈的迭代修正，推理缩放定律，长思维链模型与长度控制。
