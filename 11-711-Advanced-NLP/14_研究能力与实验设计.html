第十四讲：研究能力与实验设计

基准分数的标准误与置信区间，聚类问题，非配对与配对检验，怎样找研究问题、读文献、提出可证伪的假设，找数据与标注，用功效分析估算需要多少测试数据，用 Cohen's kappa 衡量标注一致性

主讲：Sean Welleck · 2026 年 2 月 26 日
资料来源：课程幻灯片（研究方法部分大量来自 Graham Neubig 2024 年秋的讲稿） · 课堂录像（本文依据录像字幕整理课堂口述内容） · 课堂代码 · 主要阅读：Adding Error Bars to Evals（Miller，2024）

一、从一张结果表说起

上一讲讲了怎样搭建评估各方面能力的基准。这一讲接着问两件事：拿到一组基准分数，能得出什么结论；以及怎样开展一项新研究，从选题、收集数据到做实验，最后拿出站得住的证据。前半部分基于主要阅读那篇论文，作者在（或曾在）Anthropic 工作，细节可以去读原文。

设想你的课程项目交上来这样一张表：三个基准，MATH、HumanEval（代码）和 MGSM（多语言 GSM，同一批小学数学题翻译成多种语言）；两个方法，Dreadnought 是已有方法（比如作业三复现的那个），Galleon 是你在作业四提出的新方法。不加思索的读法是：Galleon 数学更好，代码更差，多语言数学更差。下面用统计工具仔细看看能不能这么说。

二、基准分数背后的统计

1. 标准误

把一个评估集看作从一个题目总体里独立抽出的 $N$ 道题 $q_1, \dots, q_N$。模型在每题上得分 $s_i$，可以是 0/1（对或错），也可以是连续分数。观察到的平均分是

$$\bar s = \frac{1}{n}\sum_i s_i$$

0/1 的情况下就是准确率。假如能拿到整个题目总体，模型的真实分数是 $\mu = \mathbb{E}[s]$，我们观察不到它。大数定律告诉我们可以用 $\bar s$ 估计 $\mu$。中心极限定理告诉我们，样本够大时 $\bar s$ 近似服从正态分布，它的误差（标准误）可以这样估计：

$$\text{SE}_{\text{CLT}} = \sqrt{\text{Var}(s)/n} = \sqrt{\Big(\frac{1}{n-1}\sum_i (s_i - \bar s)^2\Big)\Big/ n}$$

如果得分是 0/1 的伯努利变量，有更简单的闭式：

$$\text{SE}_{\text{Bernoulli}} = \sqrt{\bar s(1-\bar s)/n}$$

题目数 $n$ 越大，误差越小。

2. 置信区间

报告结果时可以同时给出题目数 $N$ 和标准误，或者给出置信区间：

$$\text{CI}_{95\%} = \bar s \pm 1.96\times\text{SE}$$

1.96 是 z 分数：标准高斯分布 95% 的概率质量落在均值两侧 1.96 个标准差以内。想要 99% 的区间，就换成更大的 z 值，可以查表。回到那张表，小数据集上的误差明显大得多，有些区间已经重叠了，比如 83 加上 3.2 就到了 86。

3. 一个模拟

课堂代码（在第 13 讲的目录下）把这件事具体化。假设在 HumanEval 上（164 题）有两个系统，真实表现完全一样，在无穷多道题上会得到相同分数。从同一均值的二项分布各模拟一组得分，当作两个系统跑出来的结果：一个平均 0.84，一个 0.89。真实均值相同，观察到的结果却像是一个系统好了 5%。算出标准误和置信区间，两个区间是相交的。所以不能轻易下"系统 B 更好"的结论，在这里我们知道它们其实一样。

4. 聚类的题目

上面假设题目独立抽取，但常常不是。MGSM 里同一道数学题被翻译成多种语言，这些题之间相关性非常强。知道评估集有这种结构，可以换一个考虑"聚类"的标准误估计，多出一项按聚类求和的项，推导见论文。论文里给了三个有聚类结构的数据集，用聚类估计和不用时标准误差别不小。要点是：了解评估集的结构，就可以利用它得到更准确的误差估计。

三、比较两个模型

1. 非配对检验

要说系统 A 比 B 好，就是说 A 的平均分比 B 高，看两者之差：

$$\hat\mu_{A-B} = \hat\mu_A - \hat\mu_B$$

零假设是这个差为 0，也就是两个系统一样。假设两者独立，差的标准误和置信区间是：

$$\text{SE}_{A-B} = \sqrt{\text{SE}_A^2 + \text{SE}_B^2}, \qquad \text{CI}_{A-B, 95\%} = \hat\mu_{A-B}\pm 1.96\times\text{SE}_{A-B}$$

区间不包含 0，就说结果在 95% 水平上统计显著。另一种等价的做法是算 z 分数，把差标准化：

$$z_{A-B} = \hat\mu_{A-B}/\text{SE}_{A-B}$$

再查表得到对应的 p 值：在零假设成立时，观察到至少这么大差异的概率。低于阈值（比如 $p<0.01$）就拒绝零假设。不同领域标准不同，有的要求 $p<0.0001$。

接着模拟的例子：z 分数是 1.29，p 值约 0.19。意思是，如果两个模型真的一样，单纯因为抽样波动，大约有 19% 的机会看到这么大的差异。我们只跑了一次模拟，碰巧就落在了这大约五次里有一次的情况上。p 值这么高，没有理由拒绝零假设。即使记不住具体步骤，看到结果表时也要习惯问一句：真的能说这个系统更好吗？该怎么检验？

2. 配对检验

上面假设两个均值独立，相当于两个系统在两组不同的题上评估。实际上在同一个基准上，两个系统做的是同样的题，可以收集三元组 $(x, y_A, y_B)$，用配对检验。直觉是：数据集里可能有很多简单题，两个系统都做对，真正区分它们的是那些难题。配对检验通过协方差项利用这种相关：

$$\text{Var}(A - B) = \text{Var}(A) + \text{Var}(B) - 2\,\text{Cov}(A, B)$$

两个系统正相关时，差的方差变小，检验更灵敏。

3. 回到那张表

论文里对三个数据集都用了配对检验，MGSM 还用了聚类标准误，给出每个差值的置信区间。看区间是否包含 0：HumanEval 上和模拟例子类似，虽然差了 3%，置信区间却跨过 0，没有证据说两者有差别。

有学生问这里检验的到底是什么。Sean 解释：检验假设的是样本均值服从正态分布，这个均值本身有均值和标准差，标准差取决于样本量；样本很大时，样本均值方差很小，离真实均值很近。检验考虑的是两个系统的样本均值各有多少波动。这位学生又问：做实验时一般有一个自变量，看它对因变量有没有影响，比较两个 LLM 时自变量是什么？这是个好问题，研究和课程项目里经常出问题。上面的表里，我们根本不知道 Galleon 和 Dreadnought 之间改了什么。理想做法是有一个基线，只改你声称带来提升的那一处，别的都不变；这样统计显著的差异才能归因到那个改动。如果两个系统之间有一堆不同，你能说一个比另一个好，但说不清是哪个改动起的作用。比如你说新的激活函数很好，就应该只换激活函数。学生提到 ANOVA 这类多变量方法，Sean 说在 LLM 研究里用得少一些，但并非无效，只要实验设置符合检验的假设就可以用。

4. 降低方差

估计量是 $\hat\mu = \sum_{i=1}^n s_i/n$，方差是 $\text{Var}(\hat\mu) = \text{Var}(s)/n$。降低方差有两个办法：增加题目数 $n$；如果用随机解码，每题多采样几个输出，取平均作为该题得分。这印证了直觉：数据越多，估计越准，能做出更细的判断。

四、怎样开展一项研究

后半部分基于 Graham 为往年课程做的讲稿，从维基百科上的科学方法出发：观察或提出问题，确定研究主题，形成假设，用实验检验，分析数据，报告结论。

1. 为什么做研究

不谈为了找工作、申博这些理由，只看研究问题的类型。粗略分两类，彼此有重叠，同一篇论文里可能两种都有：

  • 应用驱动：想做一个有用的系统或者让它更好，比如聊天机器人、翻译、边说边翻的语音翻译。做的过程中碰到障碍，想办法解决，系统就变好了。例子：Pang 等（2002）提出情感分析任务，因为"给文章标注情感能为读者提供简洁的摘要"；Reddy 等（2019）提出对话式问答，因为虚拟助手无法建立和维持共同基础；Gehrmann 等（2018）提出自底向上的抽象式摘要，因为神经网络摘要流畅但内容选择差；Kudo 和 Richardson（2018）提出无监督分词（SentencePiece），因为依赖语言的预处理让多语言模型很难训练，每种语言都要小心管理前后处理器。可以想象他们在搭系统时越搭越复杂，只好发明新方法。
  • 好奇心驱动：想更多了解语言，或者通过语言了解世界。比如扩散模型适不适合文本，答案也许能催生应用，但也可能只是好奇。例子：Rankin 等（2017）问真实新闻和讽刺、恶作剧、宣传的语言有什么不同；Cotterell 等（2018）问"所有语言都同样难以做语言建模吗"；Tenney 等（2019）量化 BERT 的哪些层编码了哪些语言学信息。知道答案也许对各种应用有用，但问题本身并没有针对某个应用。

2. 研究点子从哪来

  • 自底向上：从现有研究或应用的具体失败出发，上升到一个更高层的实验问题。比如某个系统在某个稀有语言上不行，于是思考要开发什么方法解决。这是渐进式进步的好工具，但它是现有研究的函数，会把新想法绑在已有东西上，可能妨碍更大的跳跃。
  • 自顶向下：从一个高层问题或想法出发，再落到具体的检验。这门课几乎所有技术都基于深度学习，但在那之前 NLP 有大量非深度学习的研究；如果只是拿一个基于规则的系统想着怎么改进，大概永远发明不出深度学习。读深度学习的历史会发现，它有很长一段时间效果并不好，早期的研究者是凭着某种信念或初步证据一直推下去的。这种方式容易出大想法，但可能脱离现实：解决一个其实不存在的问题，或者先选好了方法、结果并不适合，甚至简单得多的方法效果更好，无法说服别人它比替代方案强。

实际中两者会混在一起。

3. 文献调研

经典步骤：关键词搜索，找更早和更新的论文，读摘要、引言和主要结果，再细读最相关的几篇。Sean 的建议是准备快读和慢读两种方式：大量过论文时，只判断关键结果或想法是否和你的问题相关；确定重要、高度相关，再慢慢细读。

论文来源：如今 NLP 很大程度上是机器学习的一部分，尤其在大模型时代，很多课程话题可以在 NeurIPS、ICML、ICLR 这些机器学习会议上找；更专门的有 COLM（Conference on Language Modeling，比较新）和 ACL 旗下的一系列会议（ACL、NAACL、EMNLP、EACL 等，收录在 ACL Anthology，可以从几个顶会过去三到五年的论文看起）；期刊有 JMLR（论文较长，录用周期长）和 TMLR（论文风格接近 ICLR、NeurIPS）。arXiv 是预印本平台，能看到最新的、还没经过评审的工作，有人每天把新投稿全看一遍，有点疯狂。OpenReview 上，带星号的那些会议（NeurIPS、ICLR、COLM、TMLR）评审意见是公开的，读评审很有帮助，能看到论文的问题，或者好论文好在哪里。Google Scholar 可以按关键词搜，可以看引用某篇论文的所有论文并按日期排序。找更早的论文，往往跟着参考文献走就行：读了一个领域的若干论文后，某些论文会反复出现，那多半是基础性的工作。

有学生问怎样判断论文好坏、哪些必读。如果用了某个基准，就去读基准的原始论文；如果是小众应用，读该领域的早期论文，它会花力气论证这个应用为什么有意思；方法方面，比如扩散模型现在有几万篇论文，真要做就回去看它最初是怎么提出的，看哪些论文被引用最多，那多半是重要的跳跃。另一个学生问会不会被虚假或有偏的评审误导：可以看是否被会议录用、是否获得口头报告或最佳论文，以及评审意见的理由。

先广泛调研有利有弊：能避免重复工作，能扩充你的方法工具箱（比如读了扩散模型的论文，就多了一样可用的东西）；但也会束缚思路（Varian 1994）。Sean 说常有学生做项目时像没睡好一样，脑子里塞满了"这篇做了这个、那篇做了那个"，读得太多，反而没了自己的想法，他自己也经历过。所以要同时从第一性原理出发，想清楚自己感兴趣的问题；很实际的做法是先做个简单实验，有了具体结果再去查有没有人做过。这样做出来的东西可能和已有工作相关，但有点不同、有点意思；如果一开始就看到那篇相关论文，你可能根本不会去做这个实验。Varian 是一位经济学家，他说自己从报纸里找研究点子，不从别人的论文里找。

4. 研究问题与假设

最终要让别人和自己都信服某件事。可以想象成打官司：你对另一方提出主张，要拿出有力的证据，而主张首先得清楚，还得有望收集到证据。研究也一样，要把"我想做一个会推理的系统"这种模糊想法变得具体、可检验。

  • 研究问题：一个或几个明确的问题，关于你想知道的东西。"是不是"式的问题通常比"怎样做"式的好检验。
  • 假设：你事先认为答案可能是什么。它应该可证伪：得到某种结果就验证了假设，否则就推翻它。没有假设，问题可能就不那么有意思。

例子：Cotterell 等（2018）的问题是"所有语言都同样难以做语言建模吗"，假设是"尽管有粗略的跨语言能力，所有语言同样容易、或者我们的方法对所有语言同样好，都不太可能"。他们表明了立场，由此很容易想到实验。Reddy 等的论文把研究问题一条条列出来，每组实验直接检验一个问题；还要回头确认这些问题不是随便凑的，而是讲同一个故事、服务于更高层的研究目标。幻灯片上还有几篇应用驱动论文的问题和假设，有的假设是"大概有帮助吧"，有的是"不太有帮助"或"不清楚"。

要小心"X 能让 Y 更好吗？""能"这种问题和假设。它很自然，但很间接：实验后答案是"不能"，你怎么知道哪里出了问题？通常你对 X 为什么能让 Y 更好是有直觉的，不是随便猜的。能不能想出其他研究问题和假设，去证实或证伪这些背后的假设？观察到失败时，就能对照先前的信念去理解它。

五、做实验：数据

找到能回答研究问题的数据，跑实验算出数字，计算显著性并分析效果。数据要和问题相关，跑出的数字要能为你的主张辩护。拿垃圾证据上法庭，别人会直接无视；数字的差异不可信，论文就不扎实。

1. 找数据集

在已有工作基础上做，最稳妥的是用同样的数据集，比如做小学数学就用 GSM8K。回答新问题时，先看能不能改造别的数据集，比如研究监督微调的数据效率，未必有专门的数据集，但可以改造现有的。实在不行只能自己造，这是很大的工作量，也很难，但探索新领域时不得不做。数据集列表：Hugging Face datasets、LREC 的共享资源、Papers with Code（不确定是否还在）。

2. 标注数据

需要标注（得到解答、输出或类别标签）时就难了：决定标多少，抽取合适的数据，写标注指南，雇用并监督标注者，评估质量。现在有些事也可以试着让语言模型来做。例子：假设还没有情感分析数据集，要训练一个判断影评"正面"还是"非正面"的分类器，就得收集影评，雇人标注。

3. 需要多少测试数据：功效分析

要足够在方法之间得到统计显著的差异（比如 $p<0.05$）。怎样估计多少才够？用功效分析（power analysis）。先要假设一个效应大小：方法之间的差异如果只有 0.001，可能需要海量数据才能下结论；如果预期准确率差 10%，数据集就不必那么大。给定效应大小和显著性阈值，算出在大多数试验中得到显著结果所需的数据量。输入有：

  • 零假设：系统 A 和 B 表现相同。
  • 显著性水平 $\alpha$：错误地检测出差异的概率（第一类错误）。
  • 功效 $1-\beta$：差异真实存在时检测到它的概率（$\beta$ 是第二类错误）。
  • 最小可检测效应 $\delta$：你关心的最小差异，它对所需数据量影响很大。

假设已经在一小批"试点"数据上评估了 A 和 B，用试点数据的统计量估计所需题目数：

$$n = \frac{(z_{\alpha/2} + z_\beta)^2\big(\omega^2 + \sigma_A^2/K_A + \sigma_B^2/K_B\big)}{\delta^2}$$

$\omega^2$ 是 A 与 B 真实表现差异在题目之间的方差；$\sigma_A^2, \sigma_B^2$ 是每题在 $K$ 次采样下的平均方差，来自随机解码或随机的评估器（比如 LLM 作评委）。如果解码和评估都是确定性的（贪心解码、不用 LLM 评委），公式简化为：

$$n = \frac{(z_{\alpha/2} + z_\beta)^2\,\omega^2}{\delta^2}$$

例子：收集 156 题的试点集，模型 A 和 B 都得到 0.86，题目间方差 $\omega^2$ 为 0.077；第一类错误 $\alpha = 0.05$，功效 $1-\beta = 0.8$，最小可检测差异 $\delta = 0.03$，算出需要 674 题。和所有统计检验一样有一堆假设，但至少为"数据要多大才能下某种结论"提供了依据。

4. 需要多少训练数据

一般越多越好，但人力、时间总是有限。很实用的做法是分阶段收集：先用 500 条微调，再收 500 条再微调，看边际提升，开始出现收益递减就可以停。比如用 GPT-5 生成数据做蒸馏，可以在越来越大的数据上微调，收益变小就停。更进一步，可以用主动学习（active learning）聪明地挑选数据。

5. 标注指南与标注者

先自己试着标，写指南，再迭代。指南可能不清楚、有歧义，或者引导标出错误的东西，这本身就能讲一整讲。例子是 Penn Treebank 的词性标注指南（Santorini 1990），既说明标什么，也专门讨论困难的情况。

标注者来源：小项目可以自己标；同事、朋友、同学；网上的自由职业者（比如 UpWork）；众包工人（比如 Mechanical Turk）。先雇一个小活看看及时性和准确度，再派大活。可能需要 IRB（伦理审查）批准。所需专业程度有一个谱系：研究级数学证明的标注比情感标注贵得多，要看需要哪种标注、预算够不够。有学生问能不能先标一部分，训练模型来标剩下的。可以，这又能讲一整讲：用模型标注时，仍可以让人检查模型对不对，这比让人从头写完整的数学证明容易；也可以估计模型标注的噪声水平。

6. 评估标注质量：Cohen's kappa

多人标注同一批数据（比如把那 674 条标成正面或负面）时，人会有分歧，要衡量他们的一致程度超出偶然一致多少。最简单的是 Cohen's kappa（Cohen 1960），针对两个标注者。先做混淆矩阵：

B：负B：正
A：负$C_{00}$$C_{01}$
A：正$C_{10}$$C_{11}$

观察一致率是对角线占总数的比例，期望一致率是两人各自标签分布下偶然一致的概率：

$$p_o = \frac{C_{00} + C_{11}}{674}, \qquad p_e = p(A)_0\,p(B)_0 + p(A)_1\,p(B)_1, \qquad p(A)_0 = \frac{C_{00} + C_{01}}{674}$$ $$\kappa = \frac{p_o - p_e}{1 - p_e}$$

解读参考 Landis 和 Koch 的划分（比较主观）：小于 0 无一致，0 到 0.20 轻微，0.21 到 0.40 尚可，0.41 到 0.60 中等，0.61 到 0.80 相当，0.81 到 1.0 几乎完全一致。多于两个标注者用 Fleiss' kappa；Krippendorff's alpha 更灵活，支持有序和区间数据、标注者数量不定和缺失数据。一致率低时，可能要修改指南，换更好的标注者，或者重新想想这个任务是否可行。Sean 讲得很快，说不会考细节，真做人工标注时再查。

七、小结

基准分数是从题目总体里抽样得到的估计，有标准误，可以给出置信区间；题目有聚类结构时要用相应的估计。比较两个模型时看差值的置信区间是否包含 0，或者算 z 分数和 p 值；同一批题目上用配对检验能利用两者的相关、降低方差；增加题目数或每题多采样也能降低方差。可信的结论还需要好的实验设计：基线和新方法之间只改一处。开展研究时，问题可以来自应用或好奇心，点子可以自底向上或自顶向下得来；文献调研要有快读和慢读，但别读到失去自己的想法；研究问题最好是"是不是"式的，假设要可证伪。数据优先沿用已有数据集，自建时要决定规模（功效分析能估算测试集大小，训练集可以分阶段收集看边际收益）、写好指南、选好标注者，并用 Cohen's kappa 等指标检查标注一致性。
