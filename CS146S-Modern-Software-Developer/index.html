CS146S: The Modern Software Developer

斯坦福讲 AI 原生软件开发的课：编程 Agent 的内部结构，上下文工程和规格驱动开发，MCP、Skill、AGENTS.md、Hook、子 Agent，让代码库适合 Agent，Agent 代码审查，以及给真实开源项目提交代码

主讲：Mihail Eric（斯坦福兼职讲师，Monaco 的 AI 负责人）
整理：Joyce（@JOYCE9896）

这门课讲什么

课程介绍里说，大模型把软件开发从以手工编码为主，变成了开发者和越来越能干的编程 Agent 协作。这需要新的方法来表达意图、组织工作、协调工具，好让 Agent 能在复杂项目里出力。课程讲 AI 原生开发背后正在形成的做法和技术，包括 MCP、Agent Skill、规格驱动开发、循环工程和"软件工厂"：怎样给 Agent 对的上下文和能力，怎样把产品需求变成可执行的规格，怎样设计人和 Agent 一起计划、构建、评估、改进软件的迭代流程。主讲人反复强调一句话：这门课讲原则，不讲工具。

课程 3 学分，先修要求相当于 CS111 和 CS161 的编程经验，推荐修过 CS221 或 CS229。每周二、四下午 5:30 到 6:20 上课，周二是主讲人的课，周四多是客座讲座。成绩构成：期末项目 50%，每周作业 15%，给开源项目的贡献 30%，课堂参与 5%。这一期有 15 个开源合作伙伴（Anyscale、Arize Phoenix、Browserbase、cmux、CopilotKit、CrewAI、HeyGen、Marimo、Milvus、OpenHands、Pi、Semgrep、Unsloth、Vercel、Warp），每位学生学期中会换一次合作方，目标是至少四次贡献，合不进主分支的"AI 垃圾"PR 得零分。

怎样读：会写代码、用过 Claude Code 或 Cursor 就能读。建议按顺序读，第一讲写的那个两百行的 Agent，是后面所有内容的参照。想了解编程 Agent 背后的模型原理，可以先读本站的 AI 基础；从系统和推理服务角度讲 Agent 的，可以对照 Harvard CS2680。

资料说明：这门课没有公开的课堂录像，只有第六讲的客座 Lee Robinson 自己在 YouTube 上公开了讲座录像，第六讲据此补充了口述内容。笔记依据课程网站公开的课件、三讲的课堂转录（9 月 24 日、9 月 29 日、10 月 1 日）、课上的代码和 Skill 文件，以及 GitHub 作业仓库整理；没有转录的几讲只依据课件，讲者口头补充的内容这里没有。课程还在进行中，截至 2026 年 11 月 13 日公开了 11 次课的课件和第 1 到第 5 周的作业。10 月 15 日 Boris Cherny（Claude Code 的创造者）和 10 月 29 日 Silas Alberti（Cognition 首席研究官）、11 月 5 日 Isaac Evans（Semgrep CEO）、11 月 12 日 Rajesh Bhatia（Cloudflare 高级总监）四场客座讲座已经上过，但没有公开课件，公开后再补；11 月 3 日学校放假停课。期末项目说明发在课程内部平台上，没有公开。课程网站上还保留着 2025 年秋季第一期的课表，那一期的内容大部分已被替换，这里只整理 2026 年这一期。

笔记目录（11 讲加作业）

第 1 周：编程 Agent 的内部

01. 课程介绍，用两百行代码写一个 Claude Code（9 月 22 日）

2026 年的处境，讲原则不讲工具，课程安排与评分；从零写一个只有读文件、列目录、改文件三个工具的编程 Agent，逐块读课上写完的代码。

02. 现代编程 Agent 的解剖（9 月 24 日）

抓包拆开一次真实的 Claude Code 会话：约 40 个内置工具和 MCP 工具，系统提示词，CLAUDE.md / AGENTS.md，计划模式，Skill，子 Agent，Hook，上下文压缩，好外壳的原则是简单。

第 2 周：高级上下文工程

03. 复杂代码库的高级提示与上下文工程（9 月 29 日）

开源合作伙伴计划，规格驱动开发的 RePPIT 框架（研究、提议、计划、实现、测试）和给 Mint 克隆加功能的完整演示，课程公开的六个 RePPIT Skill，"聪明 token"与"笨区"，什么时候清空和压缩上下文，任务委派的分级，Superpowers 和 OpenSpec。

04. MCP、工具调用与更进一步（10 月 1 日）

从 M × N 到 M + N，主机、客户端、服务器、工具，一次调用的流程，好的 MCP 服务器怎样设计（面向结果、参数明确、说明即上下文），只暴露搜索和执行两个工具的 code mode，API、MCP、Skill 的区别。

第 3 周：Agent Skill 与命令行

05. Agent Skill（10 月 6 日）

为什么在 MCP 之外还要 Skill，四类常用 Skill，写好 Skill 的最佳实践：范围单一、从自己的对话记录里挖、带上触发措辞、渐进式披露、组合、配一个验证 Skill。

06. 常驻 Agent 怎样工作（10 月 8 日，客座：Lee Robinson）

一个一直在线、有自己的电脑和记忆的 Agent 怎样搭：触发与睡眠唤醒，每个用户一台虚拟机，持久化工作流，只用一个工具和用户说话，便宜的手段先试，安全措施，保持提示词前缀稳定以命中缓存，记忆分层，开放问题。依据课件和讲者公开的录像。

第 4 周：定制 Agent 和仓库

07. 定制你的 Agent 配置（10 月 13 日）

MCP 的额外好处，怎样写好 AGENTS.md，Hook 的事件和用途，子 Agent 适合的支线任务，常用 MCP 服务器，上下文是怎样一层层叠起来的。

第 5 周：让代码库适合 Agent

08. 让代码库适合 Agent（10 月 20 日）

人能绕过去而 Agent 绕不过去的缺口（没测试、文档过时、构建不稳、环境难搭），Agent 就绪检查清单和 Factory 的就绪度报告演示；后台编程 Agent 需要什么：Git 工作树隔离、多 Agent 编排器、从浏览器、Slack、手机、Linear 启动的云端 Agent。

09. 能验证，Agent 就能解决（10 月 22 日，客座：Eno Reyes）

Factory CTO 的讲座：Agent 失败多半是环境的问题；人类的进步来自让事情可检查；检查的精确度和频率，20 步任务每步检查后成功率从 12% 到 98%；九个支柱、五个等级的就绪度框架；一个下午的改造清单；数学和代码这类检查便宜的领域 Agent 先到。

第 6 周：Agent 代码审查

10. Agent 代码审查（10 月 27 日）

审查需求的层次，代码生成变快后审查成了瓶颈，AI 审查的三级成熟度，六层检查加快速回滚，按风险分流，多 Agent 审查架构和安全审查 Agent 的规则，怎样设计审查 Agent（换模型、给上下文、跑起来验证、按任务选模型、用历史 bug 做评测），现有工具。

第 8 周：后台 Agent

11. 后台 Agent（11 月 10 日）

编程 Agent 的三个阶段和效率提升，告别本地开发环境，后台 Agent 平台的三个组成部分和 LangChain Open SWE 的架构，沙盒服务商，一个 Slack 机器人的架构，子 Agent 和 Agent 团队，生成-验证和"主模型加聪明朋友"两种模式，管理多个 Agent 的元技能。

作业：第 1 到第 5 周

拆解一次真实的 Claude Code 会话，为一个第三方 API 写带 OAuth 的 MCP 服务器，写一个能可靠触发的 Skill，给一个陌生开源仓库写 AGENTS.md，用 Factory 的就绪度报告给三个开源仓库打分并分析它们差在哪里。

补充：讲者和讲师的公开访谈（11 篇）

这些都不是课堂内容。补一到补五：四场客座讲座没有公开课件和录像，这里换成同一位讲者在课外的公开访谈或演讲，内容和课上讲的不一定相同。补六到补十一：课程自己的 YouTube 频道 The Modern Software Developer 上的访谈节目 The Build System，由讲师 Mihail Eric 主持，嘉宾现场演示自己的开发流程。全部依据 YouTube 自动字幕整理，每篇开头注明来源、日期和对应哪一周的课。

补一：Boris Cherny 在 YC 的访谈（2026 年 7 月 27 日）

对应第 4 周客座。每代新模型删掉大半系统提示词再逐行加回，评测集也会过期，product overhang 与 hobbling，给略难的任务并让模型能自我验证，Bun 从 Zig 改写成 Rust、Electron 改写成 Swift 两个长任务，用动态工作流和 routine 一次调度成千上万个 Agent。

补二：Boris Cherny 在 Sequoia 的访谈（2026 年 5 月 4 日）

对应第 4 周客座。Claude Code 前六个月为什么不好用，"编程已经解决"对谁成立，他用手机管几百个 Agent 和几十个 loop，跨学科通才，AI 让哪些商业护城河变弱。

补三：Silas Alberti 在 CoreWeave 大会的访谈（2026 年 9 月 30 日）

对应第 6 周客座，内容偏训练基础设施。Devin 作为"同事式" Agent，跨三大洲的分布式 RL 训练，用 KL 散度控制异步训练的偏移，用长度惩罚让模型更快更便宜，Devin on call。

补四：Isaac Evans 谈 AI 时代的应用安全（2026 年 7 月 28 日，播客）

对应第 7 周安全主题。CI 不再是安全的中心关口：一头是大模型连续跑几天的后台漏洞挖掘，一头是嵌进编程 Agent 循环的快速确定性检查；用规则引导模型，安全工程师管理一批安全 Agent，跨仓库的业务逻辑漏洞。

补五：Rajesh Bhatia 谈 Cloudflare 的 AI 工程栈（2026 年 5 月 6 日）

对应第 8 周客座。一年内让 93% 的研发人员用上 AI，AI 网关、身份、Backstage 与 AGENTS.md 提供上下文，机器可读的工程规范和自建的多 Agent 代码审查器，怎样衡量投入产出，从辅助走向委派的后台 Agent。

补六：Eno Reyes 现场演示 Factory 的 Missions（2026 年 3 月 13 日）

第九讲的实操版。口语需求经提问补成 spec，dry run 先确认能验证，生成验证合同、features.json 和工人 Skill，编排者带工人按里程碑推进、工人踩坑后自己改 Skill，什么时候不该用 Mission。

补七：Micah Villmow 的多 Agent 工作流（2026 年 3 月 20 日）

用三个并行 Claude Code 会话一小时做出排球赛程网页：advise、plan、execute、review、commit、retrospective 的固定流程，CLAUDE.md 里的设计原则，技术债自动开 issue，用 linter 和类型检查约束 Agent，拦截破坏性命令。

补八：Dex Horthy 让 Agent 在复杂老代码库里交付（2026 年 4 月 28 日）

第三讲 RePPIT 的拆细版。现场用 HumanLayer 的八步流程（问题、研究、设计讨论、结构大纲、计划、worktree、实现、PR）做一个真实功能，研究只写客观事实，用学习测试验证 SDK 行为，计划按垂直切片排。

补九：Tomas Reimers 现场做 Electron 小工具，以及代码审查会怎样变（2026 年 5 月 26 日）

对应第十讲。用 Cursor 从空目录做出生成 git 测试状态的桌面应用，先本地跑通骨架再推到云端 Agent 自测、并行派出多个 Agent、看截图和录屏决定合并；代码审查的三个目的和审查平台为什么要重做。

补十：Mario Zechner 用 Pi 开发 Pi（2026 年 6 月 12 日）

Pi 是本课的开源合作方之一。极简编程 Agent 的 issue 处理流程，为什么不内置 MCP，AGENTS.md 里哪些规则模型会听，大代码库怎样给 Agent 找上下文，用会话树代替 plan 文件和子 Agent。

补十一：Mahmoud Hashemi 谈共享 Agent 记忆（2026 年 10 月 9 日）

AI 时代开源的变化，演示让 Agent 发布和互评所学的 Good Turn，现场加一个功能（意图文档、计划模式问答、找开源范例），以及 who-am-i skill、自记账的巡检 skill、并行提交锁、每个项目配一个 CLI 等工具。
