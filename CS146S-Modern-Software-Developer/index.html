CS146S: The Modern Software Developer

斯坦福讲 AI 原生软件开发的课：编程 Agent 的内部结构，上下文工程和规格驱动开发，MCP、Skill、AGENTS.md、Hook、子 Agent，以及给真实开源项目提交代码

主讲：Mihail Eric（斯坦福兼职讲师，Monaco 的 AI 负责人）
整理：Joyce（@JOYCE9896）

这门课讲什么

课程介绍里说，大模型把软件开发从以手工编码为主，变成了开发者和越来越能干的编程 Agent 协作。这需要新的方法来表达意图、组织工作、协调工具，好让 Agent 能在复杂项目里出力。课程讲 AI 原生开发背后正在形成的做法和技术，包括 MCP、Agent Skill、规格驱动开发、循环工程和"软件工厂"：怎样给 Agent 对的上下文和能力，怎样把产品需求变成可执行的规格，怎样设计人和 Agent 一起计划、构建、评估、改进软件的迭代流程。主讲人反复强调一句话：这门课讲原则，不讲工具。

课程 3 学分，先修要求相当于 CS111 和 CS161 的编程经验，推荐修过 CS221 或 CS229。每周二、四下午 5:30 到 6:20 上课，周二是主讲人的课，周四多是客座讲座。成绩构成：期末项目 50%，每周作业 15%，给开源项目的贡献 30%，课堂参与 5%。这一期有 14 个开源合作伙伴（Anyscale、Arize、Browserbase、cmux、CopilotKit、CrewAI、HeyGen、Marimo、OpenHands、Pi、Unsloth、Vercel、Warp、Zilliz），每位学生学期中会换一次合作方，目标是至少四次贡献，合不进主分支的"AI 垃圾"PR 得零分。

怎样读：会写代码、用过 Claude Code 或 Cursor 就能读。建议按顺序读，第一讲写的那个两百行的 Agent，是后面所有内容的参照。想了解编程 Agent 背后的模型原理，可以先读本站的 AI 基础；从系统和推理服务角度讲 Agent 的，可以对照 Harvard CS2680。

资料说明：这门课没有公开录像。笔记依据课程网站公开的课件、三讲的课堂转录（9 月 24 日、9 月 29 日、10 月 1 日）、课上的代码和 Skill 文件，以及 GitHub 作业仓库整理；没有转录的几讲只依据课件，讲者口头补充的内容这里没有。课程还在进行中，截至 2026 年 10 月 23 日公开了 7 次课的课件和第 1 到第 4 周的作业。10 月 15 日 Boris Cherny（Claude Code 的创造者）的客座讲座、10 月 20 日"让仓库适合 Agent"一讲、10 月 22 日 Eno Reyes（Factory CTO）的客座讲座已经上过，但还没有公开课件，公开后再补。期末项目说明发在课程内部平台上，没有公开。课程网站上还保留着 2025 年秋季第一期的课表，那一期的内容大部分已被替换，这里只整理 2026 年这一期。

笔记目录（7 讲加作业）

第 1 周：编程 Agent 的内部

01. 课程介绍，用两百行代码写一个 Claude Code（9 月 22 日）

2026 年的处境，讲原则不讲工具，课程安排与评分；从零写一个只有读文件、列目录、改文件三个工具的编程 Agent，逐块读课上写完的代码。

02. 现代编程 Agent 的解剖（9 月 24 日）

抓包拆开一次真实的 Claude Code 会话：约 40 个内置工具和 MCP 工具，系统提示词，CLAUDE.md / AGENTS.md，计划模式，Skill，子 Agent，Hook，上下文压缩，好外壳的原则是简单。

第 2 周：高级上下文工程

03. 复杂代码库的高级提示与上下文工程（9 月 29 日）

开源合作伙伴计划，规格驱动开发的 RePPIT 框架（研究、提议、计划、实现、测试）和给 Mint 克隆加功能的完整演示，课程公开的六个 RePPIT Skill，"聪明 token"与"笨区"，什么时候清空和压缩上下文，任务委派的分级，Superpowers 和 OpenSpec。

04. MCP、工具调用与更进一步（10 月 1 日）

从 M × N 到 M + N，主机、客户端、服务器、工具，一次调用的流程，好的 MCP 服务器怎样设计（面向结果、参数明确、说明即上下文），只暴露搜索和执行两个工具的 code mode，API、MCP、Skill 的区别。

第 3 周：Agent Skill 与命令行

05. Agent Skill（10 月 6 日）

为什么在 MCP 之外还要 Skill，四类常用 Skill，写好 Skill 的最佳实践：范围单一、从自己的对话记录里挖、带上触发措辞、渐进式披露、组合、配一个验证 Skill。

06. 常驻 Agent 怎样工作（10 月 8 日，客座：Lee Robinson）

一个一直在线、有自己的电脑和记忆的 Agent 怎样搭：触发与睡眠唤醒，每个用户一台虚拟机，持久化工作流，只用一个工具和用户说话，便宜的手段先试，安全措施，保持提示词前缀稳定以命中缓存，记忆分层，开放问题。

第 4 周：定制 Agent 和仓库

07. 定制你的 Agent 配置（10 月 13 日）

MCP 的额外好处，怎样写好 AGENTS.md，Hook 的事件和用途，子 Agent 适合的支线任务，常用 MCP 服务器，上下文是怎样一层层叠起来的。

作业：第 1 到第 4 周

拆解一次真实的 Claude Code 会话，为一个第三方 API 写带 OAuth 的 MCP 服务器，写一个能可靠触发的 Skill，给一个陌生开源仓库写 AGENTS.md。
