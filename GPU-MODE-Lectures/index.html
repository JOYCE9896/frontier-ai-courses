GPU MODE 精选讲座笔记

从在 PyTorch 里剖析第一个内核，到 FlashAttention 4 和生产环境的 megakernel：为写 LLM 内核挑出的 20 讲，2024 年 1 月到 2026 年 8 月，共 20 篇笔记、254 节，约 26 小时

整理：Joyce（@JOYCE9896）
资料来源：GPU MODE YouTube 频道 · github.com/gpu-mode/lectures（幻灯片和代码）

栏目说明

GPU MODE（2024 年初创立时叫 CUDA MODE）是 Mark Saroufim、Andreas Köpf、Thomas Viehmann 等人发起的开放社区，在 Discord 上组织，讲座全部公开在 YouTube 上。最早是一个读书会，按章节读 Programming Massively Parallel Processors（PMPP）；后来请来 NVIDIA CUTLASS 团队、FlashAttention 作者、Triton、vLLM、SGLang、ThunderKittens 等项目的人讲自己的工作。到 2026 年 11 月频道已有 120 多讲。

这里挑了其中 20 讲，标准是：读过本站 CS149（并行计算）和 CS2680（现代 AI 系统）笔记、想自己写和读懂 LLM 用的 GPU 内核的人最该看的那些。覆盖剖析工具、PMPP 的核心章节（内存与计算、合并访存、分块、归约、scan）、Triton、CUTLASS 和 CuTe、Tensor Core 与 Hopper、FlashAttention 1 到 4、量化内核和 Liger Kernel、ThunderKittens、NCCL 多卡通信、推理侧的投机解码和 FlashInfer，以及 2025–2026 年的 CuTe DSL 和 megakernel。每篇按讲座章节分节，每节附跳到视频对应时间点的链接，末尾摘了原话（英文原文加中文译文）。

笔记依据讲座录像的英文字幕（都是 YouTube 自动字幕，专有名词常被听错，正文里已改正，原话部分保留字幕原样）、GitHub 仓库里的幻灯片和代码整理，是中文转述，不是逐字翻译。仓库里有代码的讲座，正文照抄了关键内核；没有代码的讲座，少量示意代码按讲者现场的讲解写出，都标了 // sketch based on the talk。数字、基准结果和观点按讲者原话记录，以讲座当天为准。
