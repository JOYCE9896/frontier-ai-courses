07. 梯度下降与反向传播

有了损失之后，怎样一步步调整参数让它变小，以及怎样高效算出每个参数该往哪个方向调

需要的预备知识：06. Softmax 与交叉熵；知道导数表示函数的变化率（会在文中复习）
整理：Joyce（@JOYCE9896）

一、训练要解决什么问题

一个模型内部有很多可以调整的数，叫参数。同样的模型结构，参数取值不同，对同一个输入给出的分数就不同。上一篇讲了怎样用损失衡量一次预测有多差。把训练数据上所有预测的损失取平均，就得到一个数，它只取决于参数的取值。训练模型就是找一组参数，让这个平均损失尽量小。

难点在于参数很多。一个小型的图像分类网络就有几百万个参数，GPT-3 有 1750 亿个。不可能把所有取值组合都试一遍。我们需要一种方法，从当前参数出发，知道往哪个方向改一点能让损失变小，然后反复这样改。梯度下降就是这种方法，反向传播则负责算出"往哪个方向改"。

二、只有一个参数的情况

1. 导数告诉我们往哪走

先看最简单的情况：只有一个参数 $w$，损失是

$$L(w) = (w - 3)^2$$

这是一个开口向上的抛物线，在 $w = 3$ 时取最小值 0。我们假装不知道答案，从 $w = 0$ 出发，看能不能自己找到 3。

导数 $L'(w)$ 表示：$w$ 增加一点点时，$L$ 变化多少。导数为正，说明 $w$ 增大时损失也增大，应该减小 $w$；导数为负，说明 $w$ 增大时损失减小，应该增大 $w$。无论哪种情况，往导数的相反方向走都能让损失变小。导数的绝对值越大，说明这里损失变化越快。

这个例子的导数是 $L'(w) = 2(w - 3)$。在 $w = 0$ 处，导数是 $-6$，是负的，所以应该增大 $w$。

2. 更新规则

梯度下降每一步按下面的规则更新参数：

$$w \leftarrow w - \eta \cdot L'(w)$$

箭头表示"用右边算出的值替换 $w$"。$\eta$（希腊字母，读作 eta）是一个人为设定的小正数，叫学习率，控制每一步走多远。减号保证了往导数的相反方向走。

取 $\eta = 0.1$，从 $w = 0$ 开始走几步：

三、很多参数的情况

真实模型有很多参数，损失 $L$ 同时取决于所有参数。这时对每个参数分别求导：固定其他参数不动，只看这一个参数变一点时损失变多少。这叫偏导数，参数 $w_1$ 的偏导数写作 $\dfrac{\partial L}{\partial w_1}$，符号 $\partial$ 读作"偏"。

把所有参数的偏导数排成一列，就是梯度，写作 $\nabla L$（$\nabla$ 读作 nabla）。如果有一百万个参数，梯度就是一百万个数组成的向量，每个数告诉对应的参数该往哪个方向调、调多少。梯度下降对所有参数同时执行同样的更新：

$$w_k \leftarrow w_k - \eta \cdot \frac{\partial L}{\partial w_k}, \quad \text{对每一个参数 } w_k$$

课程里常用 $\theta$（读作 theta）表示"全部参数"，写成 $\theta \leftarrow \theta - \eta \nabla L(\theta)$，意思和上面一样。

四、随机梯度下降

严格来说，损失应该是全部训练数据上的平均。但大模型的训练数据有几万亿个 token，每走一步都把全部数据算一遍，代价太大。

实际做法是每一步只随机取一小批数据，比如 32 条或 1024 条，用这一小批的平均损失算梯度，然后更新参数。这一小批叫 mini-batch，批里的数据条数叫 batch size。一小批数据算出的梯度和全部数据的梯度不完全一样，带有随机的误差，但方向大体正确，而计算量小得多。这种方法叫随机梯度下降（stochastic gradient descent，SGD）。把全部训练数据完整过一遍叫一个 epoch。

今天训练大模型很少直接用最基础的 SGD，而是用它的改进版本，最常见的是 Adam 和 AdamW。它们的主要改进是给每个参数自动调整步长：一个参数的梯度长期很大，就让它走得小心一点；长期很小，就让它走得大胆一点。基本思路仍然是"往梯度的相反方向走一步"。

五、梯度从哪里来：手算一个例子

梯度下降需要每个参数的偏导数。第二节的例子损失函数很简单，导数一眼就能写出来。真实的神经网络是很多层计算套在一起，损失和参数之间隔着好几步。我们用一个小例子看怎样一步步算出来。

1. 前向计算

一个最小的分类模型：输入一个数 $x$，有两个参数 $w$ 和 $b$，判断输入是否属于某个类别。计算分三步：

  1. 算分数：$z = w \cdot x + b$
  2. 把分数变成概率：$p = \sigma(z) = \dfrac{1}{1 + e^{-z}}$。$\sigma$ 叫 sigmoid 函数，把任意实数压到 0 和 1 之间，相当于只有两个类别时的 softmax。
  3. 算损失：正确答案是"属于"，损失是 $L = -\ln p$。

取 $x = 2$，当前参数 $w = 0.5$，$b = -0.5$。从输入算到损失，这个方向叫前向计算：

步骤计算结果
分数$z = 0.5 \times 2 + (-0.5)$0.5
概率$p = \sigma(0.5)$0.6225
损失$L = -\ln 0.6225$0.4741

2. 链式法则

我们想知道 $\dfrac{\partial L}{\partial w}$：$w$ 变一点，$L$ 变多少。但 $w$ 不直接影响 $L$，它先影响 $z$，$z$ 再影响 $p$，$p$ 再影响 $L$。

链式法则说：沿着这条链，把每一步的变化率乘起来就行。如果 $w$ 变一点会让 $z$ 变 2 倍那么多，$z$ 变一点会让 $p$ 变 0.235 倍，$p$ 变一点会让 $L$ 变 $-1.6$ 倍，那么 $w$ 变一点，$L$ 就变 $2 \times 0.235 \times (-1.6)$ 倍。写成公式：

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial p} \cdot \frac{\partial p}{\partial z} \cdot \frac{\partial z}{\partial w}$$

右边每一项都只涉及相邻的两个量，叫局部导数，都很好算。

3. 反向计算

从损失出发，往回一步步算局部导数，再乘起来：

局部导数公式数值
$\dfrac{\partial L}{\partial p}$$-\dfrac{1}{p}$−1.6065
$\dfrac{\partial p}{\partial z}$$p(1 - p)$（sigmoid 的导数）0.2350
$\dfrac{\partial L}{\partial z}$前两项相乘−0.3775
$\dfrac{\partial z}{\partial w}$$x$2
$\dfrac{\partial z}{\partial b}$11

于是：

$$\frac{\partial L}{\partial w} = -0.3775 \times 2 = -0.7551, \qquad \frac{\partial L}{\partial b} = -0.3775 \times 1 = -0.3775$$

注意 $\dfrac{\partial L}{\partial z} = -0.3775$ 恰好等于 $p - 1 = 0.6225 - 1$。这就是上一篇讲的 $p_i - y_i$：正确答案的 $y = 1$，模型给的概率是 0.6225。sigmoid 加交叉熵和 softmax 加交叉熵一样，合在一起时导数是"预测概率减正确答案"。

4. 更新一步，验证损失下降

用学习率 $\eta = 0.1$ 更新两个参数：

$$w \leftarrow 0.5 - 0.1 \times (-0.7551) = 0.5755$$ $$b \leftarrow -0.5 - 0.1 \times (-0.3775) = -0.4622$$

用新参数重新做一遍前向计算：$z = 0.5755 \times 2 - 0.4622 = 0.6888$，$p = \sigma(0.6888) = 0.6657$，损失 $= -\ln 0.6657 = 0.4069$。损失从 0.4741 降到了 0.4069，正确答案的概率从 0.6225 升到 0.6657。训练就是把这个过程在海量数据上重复几万到几百万次。

六、反向传播

1. 计算图

上面的例子可以画成一串节点：$w, b, x \to z \to p \to L$。每个节点是一个中间结果，箭头表示"由谁算出来"。真实的神经网络也是这样一张图，只是节点有几百万到几十亿个，分成很多层。这张图叫计算图。

反向传播（backpropagation）就是在计算图上系统地执行第五节的过程：

  1. 前向：从输入沿着图算到损失，把每个节点的中间值都存下来（比如例子里的 $z$ 和 $p$，算局部导数时要用）。
  2. 反向：从损失出发，沿着箭头的反方向，每经过一个节点，就把已经得到的"损失对这个节点的导数"乘上这个节点的局部导数，传给它的上一个节点。

走完一遍，图里每个参数都拿到了自己的偏导数。

2. 为什么要从后往前

例子里 $w$ 和 $b$ 共用了 $\dfrac{\partial L}{\partial z} = -0.3775$ 这一段，算一次就够了，再分别乘上各自的 $x$ 和 1。在深层网络里，前面层的所有参数都要经过后面所有层才能影响损失，后面这些层的导数乘积是大家共用的。从损失往回走，每一段只算一次，向前传递给需要的参数。

如果换一种方式，对每个参数单独从头算一遍，有多少参数就要重复多少遍，十亿个参数就是十亿遍。反向传播只需要一次反向计算就得到全部梯度，计算量大约是前向计算的两倍。这是深度学习能训练大模型的前提。

3. 在 PyTorch 里

写模型时不需要手算任何导数。PyTorch 等框架会在前向计算时自动记录计算图，调用 backward() 就执行反向传播。上面的例子用代码写出来： 

import torch

x = torch.tensor(2.0)
w = torch.tensor(0.5, requires_grad=True)   # parameters we want gradients for
b = torch.tensor(-0.5, requires_grad=True)

z = w * x + b
p = torch.sigmoid(z)
loss = -torch.log(p)       # forward pass: loss = 0.4741

loss.backward()            # backpropagation
print(w.grad, b.grad)      # -0.7551  -0.3775, same as by hand

with torch.no_grad():      # one gradient-descent step
    w -= 0.1 * w.grad
    b -= 0.1 * b.grad

真实训练代码的结构也是这样：取一批数据，前向算损失，backward() 算梯度，优化器更新参数，然后清空梯度进入下一批。

七、训练中常见的问题

梯度消失和梯度爆炸。反向传播要把很多局部导数连乘。如果每一层的局部导数都小于 1，比如 0.5，乘上 50 层后是 $0.5^{50} \approx 10^{-15}$，前面层的参数几乎得不到更新，这叫梯度消失；如果都大于 1，连乘后变得极大，参数一步被改得面目全非，这叫梯度爆炸。早期的循环神经网络深受这个问题困扰，后来的残差连接、层归一化、LSTM 的门控等设计，很大程度上就是为了让梯度能顺利传回去。课程讲 RNN 和 Transformer 时会反复提到这一点。

局部最小值。神经网络的损失函数不像第二节的抛物线那样只有一个最低点，梯度下降可能停在一个"附近都比它高、但不是全局最低"的位置。实践中发现，对参数很多的大网络，这通常不是严重问题，找到的解一般都足够好。

训练损失下降，不代表模型在新数据上也表现好。模型可能只是记住了训练数据。这个问题叫过拟合，第 8 篇会专门讲。

八、小结

训练就是调整参数让损失变小。梯度下降每一步把每个参数往它偏导数的相反方向移动一小步，步长由学习率控制，太大会发散，太小走得慢。实际训练每步只用一小批数据估计梯度，叫随机梯度下降，大模型通常用它的改进版 AdamW。偏导数由链式法则得到：沿着计算图把局部导数相乘。反向传播从损失往回走，共用的部分只算一次，一遍反向就得到全部参数的梯度，PyTorch 的 backward() 自动完成这件事。
