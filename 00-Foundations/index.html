AI 基础：从零开始

读懂 Stanford 和 CMU 课程笔记之前需要的背景知识，按顺序从最基础的概念讲起

整理：Joyce（@JOYCE9896）

这部分写给谁

这个网站收录的课程大多是研究生课。课上默认学生已经会微积分、线性代数、概率，也写过神经网络，所以老师讲到"交叉熵""反向传播""softmax"时不会停下来解释。如果你没有这些背景，读课程笔记时很可能在第一页就卡住。

这部分把课程默认你已经会的东西单独写出来。每篇只讲一个概念，从"它是什么、为什么需要它"开始，用具体数字算一遍，再给出一般的公式。读的时候不需要先修课，会中学数学就够了；用到的每个符号在第一次出现时都会解释。

文章之间有先后顺序，后面的会用到前面的结论。如果你已经熟悉某一篇的内容，可以跳过。每篇末尾列出了课程笔记里用到这个概念的讲次，读完可以直接去看。

学习路线

读完这部分，建议按下面的顺序看技术类课程。前一门是后一门的基础，跳着读也可以，只是会多遇到一些没解释的概念。

  1. Stanford CS224N：从词向量讲到 Transformer 和后训练，覆盖面最广，适合作为第一门课。
  2. CMU 11-711：内容和 CS224N 有重叠，但每个主题讲得更深，后半部分有量化、并行、MoE 等工程话题。
  3. Stanford CS336：亲手从零实现一个语言模型，适合想弄清楚每个部件在代码里怎样实现的读者。
  4. CMU 11-664/763：只讲模型训练好之后怎样生成文本，包括采样、搜索和推理时扩展。
  5. Stanford CS329A 与 CMU 11-768：Agent 方向，需要前面几门的基础。
  6. Stanford CS25 与 CME296：前者是前沿研讨，后者讲图像生成，可以按兴趣穿插阅读。

非技术类的两门课（MS&E 435、CS153）讲产业和系统，几乎不用数学，不读这部分也能直接看。

第一部分：数学预备

01. 向量、矩阵与求和符号

向量是一列数，矩阵是一张数表。课程里几乎所有公式都写成向量和矩阵的形式，这篇讲清楚下标、求和符号 $\sum$、矩阵乘法怎样读。

02. 概率与对数

概率分布、条件概率、期望，以及为什么机器学习里到处都是对数。

03. 导数与链式法则

导数表示"输入变一点，输出变多少"。偏导数、梯度和链式法则是后面理解训练过程的全部数学基础。

第二部分：机器学习怎样工作

04. 机器学习在做什么

数据、模型、参数、损失函数、训练集与测试集。把"让机器学会一件事"拆成可以计算的步骤。

05. 神经网络：一层层叠起来的函数

线性层、激活函数，以及为什么叠很多层就能表示复杂的规律。

06. Softmax 与交叉熵

模型输出的是一组分数，softmax 把它变成概率，交叉熵用正确答案的概率给预测打分。从一个三分类的例子算起，一直讲到语言模型怎样用同一套方法预测下一个 token。

07. 梯度下降与反向传播

有了损失，怎样调整参数让它变小。从只有一个参数的例子开始，讲导数、学习率、随机梯度下降，再用一个小网络手算一遍反向传播，最后看 PyTorch 怎样自动完成这些计算。

08. 过拟合、验证集与正则化

模型在训练数据上表现好，不代表在新数据上也好。怎样发现和缓解这个问题。

第三部分：语言模型

09. 分词：把文字变成 token

模型只能处理数字。文本怎样被切成 token、再变成编号，以及 BPE 算法怎样决定切法。

10. 词向量与嵌入

每个 token 对应一个向量，意思相近的词向量也相近。嵌入层是怎样学出来的。

11. 语言模型：预测下一个 token

ChatGPT 这类模型在训练时只做一件事：给定前文，预测下一个 token 的概率。这件事怎样变成一个可以训练的问题。

12. 注意力机制与 Transformer

今天几乎所有大模型都用 Transformer。自注意力怎样让每个位置读取整段文本的信息，一层 Transformer 由哪些部件组成。

第四部分：大模型

13. 预训练、微调与对齐

一个大模型从随机参数到能对话的助手，中间经过哪几个训练阶段，每个阶段用什么数据。

14. 解码：模型怎样生成文字

有了下一个 token 的概率，怎样选出实际输出的那个。贪心、采样、温度和 top-p 的区别。

15. Agent 是什么

让模型调用工具、观察结果、再决定下一步。Agent 的基本循环，以及它和普通对话有什么不同。
