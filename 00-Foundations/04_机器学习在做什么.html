04. 机器学习在做什么

数据、模型、参数、损失函数、训练集与测试集：用一个只有五条数据的例子，把"让机器学会一件事"拆成可以计算的步骤

需要的预备知识：01、03
整理：Joyce（@JOYCE9896）

一、写规则，还是从数据里学

让计算机完成一个任务，传统做法是程序员把规则写出来。判断一封邮件是不是垃圾邮件，可以写"出现'中奖'就是垃圾邮件"。问题是规则很难写全：骗子换个说法就绕过去了，正常邮件里也可能有"中奖"两个字。语言、图像这类任务的规则多到根本写不出来。

机器学习换了一个思路：不写规则，而是准备大量带答案的例子，让程序自己从例子里找出规律。程序员要做的是选一个"可以调整的计算公式"，再给出一个"判断调得好不好"的标准，剩下的交给计算机去调。

二、一个最小的例子

1. 数据

假设我们想根据复习时长预测考试分数，手上有五个同学的记录：

复习时长 $x$（小时）12345
考试分数 $y$5261687985

每条记录有一个输入 $x$ 和一个正确答案 $y$，正确答案也叫标签。这样的数据集写作 $\{(x^{(i)}, y^{(i)})\}_{i=1}^{5}$，上标 $(i)$ 表示第几条。

2. 模型和参数

先选一个计算公式，叫模型。从表上看，分数大致随时长线性增长，所以选一条直线：

$$\hat{y} = w x + b$$

$\hat{y}$（读作 y-hat）是模型的预测。$w$ 和 $b$ 是两个可以调整的数，叫参数：$w$ 决定每多复习一小时多几分，$b$ 是不复习时的基础分。不同的 $w$、$b$ 就是不同的直线，学习就是要找出合适的那一组。

3. 损失函数

怎样判断一组参数好不好？看预测和真实分数差多少。常用的标准是均方误差：每条数据的误差平方后取平均。

$$L(w, b) = \frac{1}{n} \sum_{i=1}^{n} \left( w x^{(i)} + b - y^{(i)} \right)^2$$

这个数叫损失。损失越小，预测越准。平方的作用是让正负误差都变成正数，并且让大的误差受到更重的惩罚。试几组参数：

参数五个预测误差损失
$w = 5,\ b = 50$55, 60, 65, 70, 753, −1, −3, −9, −1040
$w = 10,\ b = 40$50, 60, 70, 80, 90−2, −1, 2, 1, 57
$w = 8.4,\ b = 43.8$52.2, 60.6, 69, 77.4, 85.80.2, −0.4, 1, −1.6, 0.80.88

第三组的损失最小。现在机器学习的问题变成了一个明确的数学问题：找到让 $L(w, b)$ 最小的 $w$ 和 $b$。

4. 训练

找最优参数的过程叫训练。这个例子很简单，有公式可以直接算出 $w = 8.4$、$b = 43.8$。神经网络没有这样的公式，只能从某个初始值出发，反复用导数判断每个参数该往哪个方向调（第 3 篇），一点点把损失降下来，这就是第 7 篇讲的梯度下降。

5. 预测

训练好之后，用模型去预测没见过的输入。一个复习了 6 小时的同学，模型预测 $8.4 \times 6 + 43.8 = 94.2$ 分。这一步叫推理（inference）。CMU 11-664 这门课讲的全是推理阶段的事。

三、三个组成部分

上面的例子包含了所有机器学习系统的基本组成。CMU 11-711 第一讲把它们概括为三个要素：

  • 参数化（模型）：用什么形式的公式，有哪些参数。上例是直线；语言模型是有几十亿参数的 Transformer。
  • 学习：用什么损失函数衡量好坏，用什么方法调整参数。上例是均方误差加直接求解；语言模型是交叉熵加梯度下降。
  • 推理：训练好之后怎样用模型得到输出。上例是代入公式；语言模型是一个 token 一个 token 地生成，涉及采样、搜索等算法。

从这个角度看，大语言模型和这个五条数据的例子做的是同一件事，只是数据从 5 条变成了几万亿个 token，参数从 2 个变成了几十亿到上万亿个，计算公式换成了更复杂的神经网络。

四、训练集、验证集、测试集

模型在训练数据上表现好，不代表它学到了真正的规律。它可能只是记住了这几条数据。要知道模型在新数据上表现如何，必须用训练时没见过的数据检验。所以数据通常分成三份：

  • 训练集：用来调整参数。
  • 验证集：训练过程中用来检查效果、挑选设置（比如模型大小、学习率）。这些设置叫超参数，由人选定，不通过训练学习。
  • 测试集：所有选择都做完之后，最后评估一次，报告最终成绩。测试集不能参与任何选择，否则成绩就会偏高。

模型在新数据上表现好的能力叫泛化。机器学习真正追求的是泛化，训练集上的损失只是手段。训练损失很低、测试表现很差的情况叫过拟合，第 8 篇专门讲。

大模型时代这个原则遇到了新问题：模型的训练数据来自整个互联网，公开的测试题很可能已经混进了训练数据，这叫数据污染。CMU 11-711 第十三讲（评估方法）讨论了这个问题。

五、几种学习方式

1. 回归与分类

预测一个连续的数（分数、房价）叫回归；从几个固定类别里选一个（垃圾邮件或正常邮件、正面或负面评价）叫分类。分类模型通常输出每个类别的概率，用交叉熵作损失（第 6 篇）。预测下一个 token 也是分类，类别数等于词表大小。

2. 监督、无监督、自监督

  • 监督学习：每条数据都有人工标注的答案，如上面的分数、邮件的类别。标注需要人力，数据量有限。
  • 无监督学习：数据没有答案，模型自己找结构，比如把相似的新闻聚成一类。
  • 自监督学习：答案从数据本身自动构造出来。语言模型就是这样：一段文字里，每个位置的"正确答案"就是原文中的下一个 token，不需要任何人工标注。所以互联网上的全部文本都可以拿来训练，这是大语言模型能做到如此规模的原因（第 11 篇）。

3. 强化学习

没有现成的正确答案，只有对结果的评分。模型自己尝试，得分高的行为以后更多做，得分低的少做。训练推理模型和 Agent 时大量使用（第 13 篇）。

六、小结

机器学习不写规则，而是选一个带参数的模型，用损失函数衡量预测和答案的差距，通过训练找到让损失最小的参数，再用模型预测新数据。系统由参数化、学习、推理三部分组成。为了检验模型是否真的学到了规律，数据要分成训练集、验证集和测试集，目标是在没见过的数据上表现好。按答案的来源，有监督、无监督、自监督和强化学习几种方式，语言模型的预训练属于自监督学习。
