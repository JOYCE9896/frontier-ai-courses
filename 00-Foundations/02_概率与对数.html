02. 概率与对数

概率分布、联合概率与条件概率、链式法则、期望、采样，以及为什么机器学习里到处都是对数

需要的预备知识：01. 向量、矩阵与求和符号中的求和、求积符号
整理：Joyce（@JOYCE9896）

一、为什么 AI 需要概率

语言模型不会直接说"下一个词是好"，它给出的是每个可能的词各有多大可能。"今天天气很"后面，"好"的概率是 0.6，"热"是 0.2，"冷"是 0.1，其他词分掉剩下的 0.1。整个模型的训练、生成和评估都建立在概率上。这篇讲读懂课程需要的那部分概率知识。

二、概率与概率分布

1. 概率

概率是一个 0 到 1 之间的数，表示某件事发生的可能性。0 表示不可能，1 表示一定发生。掷一枚均匀的骰子，掷出 3 的概率是 $1/6$。写作 $P(\text{掷出 } 3) = 1/6$。

课程里的随机变量常用大写字母（如 $X$）表示"一个结果尚未确定的量"，小写字母（如 $x$）表示它取的某个具体值。$P(X = x)$ 读作"$X$ 取值为 $x$ 的概率"，常简写为 $P(x)$ 或 $p(x)$。

2. 概率分布

把所有可能结果的概率都列出来，就是一个概率分布。骰子的分布是六个结果各 $1/6$。一个分布必须满足两个条件：每个概率都不小于 0；所有概率加起来等于 1：

$$\sum_{x} P(x) = 1$$

语言模型每一步输出的就是一个概率分布，覆盖词表里的所有 token，几万个概率加起来等于 1。第 6 篇讲的 softmax 就是用来产生这样一个分布的。

3. 离散与连续

结果只有有限个（或可以一个个数出来）的叫离散分布，比如骰子、下一个 token。结果可以取任意实数的叫连续分布，比如身高。连续分布用概率密度函数描述，最常见的是正态分布（高斯分布），钟形曲线。图像扩散模型里加的"噪声"就是从正态分布里抽出来的。读语言模型的课程，主要和离散分布打交道。

三、联合概率与条件概率

1. 用一张计数表来看

假设记录了 100 天的天气：其中 40 天早上多云，30 天下雨，既早上多云又下雨的有 24 天。

  • $P(\text{雨}) = 30/100 = 0.3$
  • $P(\text{多云}) = 40/100 = 0.4$
  • 联合概率 $P(\text{多云}, \text{雨}) = 24/100 = 0.24$，表示两件事同时发生的概率。

2. 条件概率

如果已经知道今天早上多云，下雨的概率是多少？只看那 40 个多云的日子，其中 24 天下雨，所以是 $24/40 = 0.6$。这叫条件概率，写作 $P(\text{雨} \mid \text{多云})$，竖线读作"在……的条件下"。一般公式是：

$$P(A \mid B) = \frac{P(A, B)}{P(B)}$$

代入：$0.24 / 0.4 = 0.6$，和数出来的一样。知道"多云"之后，下雨的概率从 0.3 升到了 0.6。

条件概率的方向不能颠倒。$P(\text{多云} \mid \text{雨}) = 24/30 = 0.8$，和 $P(\text{雨} \mid \text{多云}) = 0.6$ 不是一回事。

语言模型的输出就是条件概率：$P(\text{下一个 token} \mid \text{前面的文字})$。课程里写成 $p_\theta(y \mid x)$，$\theta$ 表示模型参数，意思是"参数为 $\theta$ 的模型认为，给定 $x$ 时 $y$ 的概率"。

3. 链式法则

把条件概率的公式变形，得到 $P(A, B) = P(B) \, P(A \mid B)$。推广到多个事件：

$$P(x_1, x_2, \ldots, x_n) = P(x_1)\, P(x_2 \mid x_1)\, P(x_3 \mid x_1, x_2) \cdots P(x_n \mid x_1, \ldots, x_{n-1})$$

用求积符号写成 $\prod_{t=1}^{n} P(x_t \mid x_1, \ldots, x_{t-1})$。这条公式是语言模型的基础：一整句话的概率，等于每个词在前文条件下的概率连乘。比如"今天 天气 很 好"的概率 = $P(\text{今天}) \times P(\text{天气} \mid \text{今天}) \times P(\text{很} \mid \text{今天 天气}) \times P(\text{好} \mid \text{今天 天气 很})$。所以只要模型能预测下一个词，就能给任何句子算概率。第 11 篇会详细讲。

4. 独立

如果知道 $B$ 发生与否，对 $A$ 的概率没有任何影响，即 $P(A \mid B) = P(A)$，就说 $A$ 和 $B$ 独立。这时 $P(A, B) = P(A)\,P(B)$。两次掷骰子的结果是独立的。上面的例子里，多云和下雨不独立。

训练模型时常假设各条训练数据互相独立，所以全部数据的概率等于各条概率的乘积（第 6 篇用到了这一点）。

四、期望与采样

1. 期望

期望是按概率加权的平均值：

$$\mathbb{E}[X] = \sum_{x} P(x) \cdot x$$

骰子点数的期望是 $\frac{1}{6}(1 + 2 + 3 + 4 + 5 + 6) = 3.5$。它表示大量重复时结果的平均水平，单次掷骰子不可能掷出 3.5。

课程里常见的写法 $\mathbb{E}_{x \sim p}[f(x)]$ 读作"$x$ 按分布 $p$ 抽取时，$f(x)$ 的期望"。强化学习的目标 $\mathbb{E}_{\tau \sim \pi_\theta}[R(\tau)]$ 就是"按模型的策略去尝试，平均能拿到多少奖励"。

2. 采样

按照一个分布随机抽出一个结果，叫采样，写作 $x \sim p$。从"好 0.6、热 0.2、冷 0.1、其他 0.1"里采样，大约 60% 的时候会抽到"好"。语言模型生成文字时，每一步就是从下一个 token 的分布里采样一个（第 14 篇讲各种采样方法）。

很多期望没法精确计算，因为可能的结果太多。这时可以采样很多次，用样本的平均值估计期望，这叫蒙特卡洛估计。强化学习里大量使用这种方法。

五、对数

1. 定义和基本性质

对数是指数的反运算。$e^y = x$ 时，$y = \ln x$。$e \approx 2.718$，以 $e$ 为底的对数叫自然对数，写作 $\ln$；机器学习论文里写 $\log$ 时，通常也指自然对数。几个要用到的性质：

  • $\ln 1 = 0$；$x$ 在 0 和 1 之间时，$\ln x$ 是负数，$x$ 越接近 0，$\ln x$ 越小，趋向负无穷。
  • 乘法变加法：$\ln(ab) = \ln a + \ln b$。
  • 除法变减法：$\ln(a/b) = \ln a - \ln b$。
  • $\ln$ 是单调递增的：$a > b$ 时 $\ln a > \ln b$。所以让一个数最大，和让它的对数最大是同一件事。

2. 为什么机器学习到处是对数

第一个原因是数值。一句话有 100 个 token，假设每个 token 的概率都是 0.1，整句话的概率是 $0.1^{100} = 10^{-100}$。电脑还能表示这个数，但到了 400 个 token，$10^{-400}$ 就小于常用浮点数能表示的最小值，直接变成 0。取对数后，$\ln(0.1^{100}) = 100 \times \ln 0.1 \approx -230.3$，是一个普通大小的数，不会出问题。所以模型内部和论文里几乎总是用对数概率（log-probability），而不是概率本身。

第二个原因是计算方便。链式法则给出的是一串条件概率的乘积，取对数后变成求和：

$$\ln P(x_1, \ldots, x_n) = \sum_{t=1}^{n} \ln P(x_t \mid x_1, \ldots, x_{t-1})$$

求和比连乘容易处理，求导也更简单（第 3 篇）。训练语言模型时用的损失就是这个式子取负号再平均（第 6 篇的交叉熵）。

六、小结

概率分布给每个可能结果一个非负的概率，总和为 1；语言模型每一步输出一个覆盖整个词表的分布。条件概率 $P(A \mid B) = P(A, B)/P(B)$ 表示已知 $B$ 时 $A$ 的概率，方向不能颠倒。链式法则把一整句话的概率拆成每个词在前文条件下的概率连乘，这是语言模型的数学基础。期望是按概率加权的平均，采样是按分布随机抽取。对数把乘法变成加法，避免很小的概率在计算机里变成 0，所以模型和论文里通常使用对数概率。
