01. 1.4.1 间接宾语识别（IOI）

原练习集：[1.4.1] Indirect Object Identification（可选，README 最推荐之一）

这一套围绕 Redwood Research 的论文 Interpretability in the Wild，目标是理解 GPT-2 small 里的间接宾语识别（indirect object identification, IOI）电路：模型怎样把 "John and Mary went to the shops, John gave a bag to"（John 和 Mary 去了商店，John 把一个袋子给了）补全为 " Mary"。第 1 到 3 部分改编自 Neel Nanda 的 Exploratory_Analysis_Demo notebook。原文按目标给了选做建议，比如只想学激活修补就做 1、2、3 部分。原文强调要记住一条“工具谱”：一端是看注意力模式这类简单、探索性、有时会误导的工具，另一端是修补这类更严格、更复杂的工具。

论文严格逆向出一个 26 个头组成、分 7 类的电路，大致分三步：找出句中有哪些名字；找出哪个名字重复了；预测没有重复的那个名字。练习后面用到的电路字典（来自参考代码）：

1️⃣ 模型与任务设置

学习目标：理解 IOI 任务以及作者为什么选它；写函数展示模型在任务上的表现。

模型是 GPT-2 small，12 层、1.24 亿参数（非嵌入参数 8500 万），加载时的若干选项在不改变输出的前提下简化内部结构。单个提示上模型给 Mary 约 70% 的概率。原文建议先在一个具体例子上弄懂细节，再推广：用 4 组提示、每组两个版本（第一个名字或第二个名字作间接宾语），并挑名字都是单 token、对应名字处在相同位置的提示。

性能指标是 logit 差（logit difference）：间接宾语名字的 logit 减主语名字的 logit。原文解释它为什么好用：模型训练优化的是 log 概率，给所有 logits 加同一个常数不改变 log 概率，所以单个 logit 不太有意义；但两个 token 的 logit 差等于它们 log 概率的差，而且取 logit 是对残差流的线性投影，logit 差同样是投影到一个方向上。练习（难度 3，重要性 4）实现 logits_to_ave_logit_diff。可选的“头脑风暴”小节建议实验前先推理行为可能怎样实现，并提醒两个极端陷阱：完全没有假设、拿到一堆数据不知所措，以及过度相信自己的假设。

2️⃣ Logit 归因

学习目标：用直接 logit 归因找出哪些头在显著地写入残差流；学会 TransformerLens 中以不同方式分解残差流的辅助函数。

从输出端开始倒推：logits = Unembed(LayerNorm(最终残差流))，反嵌入是线性的，LayerNorm 近似线性，所以 logits 可以分解成各部件贡献之和。用 cache.apply_ln_to_stack 把最终 LayerNorm 的缩放应用到一摞残差分量上，再投影到 logit 差方向。

  • logit lens：看每层之后的残差流算出的 logit 差（练习 residual_stack_to_logit_diff，难度 3，重要性 3）。
  • 按层归因：等价于相邻残差流之差；原文提醒术语重载，“第 k 层”指第 k 个 block，每个 block 有一个注意力层和一个 MLP 层。
  • 按头归因：每层 12 个头独立、相加，可以再拆开。然后用 circuitsvis 看直接 logit 归因最正、最负的各 3 个头的注意力模式。

3️⃣ 激活修补

学习目标：理解激活修补的思想和用法；用 hook 从零实现 TransformerLens 中一些激活修补辅助函数。

前面的方法只看直接影响 logits 的末端部件。激活修补（activation patching）由 ROME 论文推广（那里叫 causal tracing）：对干净输入和损坏输入各跑一次，干净输入给出正确答案、损坏输入不给，然后在损坏运行中把某个激活换成干净运行里的值，看正确答案的概率恢复多少，从而定位哪些激活重要。原文区分加噪（noising：在干净输入上换入损坏激活）和去噪（denoising：在损坏输入上换入干净激活）：去噪的结果更强，因为它表明一组部件足以完成任务。

这里的干净输入是 "When Mary and John went to the store, John gave a drink to"，损坏输入把第二次出现的主语（S2）换掉："When Mary and John went to the store, Mary gave a drink to"。原文注明这个损坏版本其实把信号反过来了，称“去噪”主要是框架上的说法。思考题：为什么不把三处名字都换掉？指标设计成损坏输入上为 0、干净输入上为 1：

关于 MLP0：在 GPT-2 small 上常观察到 MLP0 很重要，消融它会彻底破坏性能。目前公认的假设是第一层 MLP 起到“扩展嵌入”的作用，后面的层要读输入 token 时主要读的是 MLP0 之后的残差流；它在 S2 上重要，因为那是两个版本里唯一输入 token 不同的位置。原文认为这主要源于 GPT-2 small 的嵌入和反嵌入矩阵是绑定的（一个等于另一个的转置）。

阶段性总结（原文“Consolidating Understanding”）：

  • 9.9、9.6、10.0 是直接写入残差流最重要的头，它们在 END 处强烈注意 IO，说明它们把 IO 复制到 END 作为预测。
  • 第 7 层之前所有动作都发生在 S2 上，之后转到 END；注意力层重要，MLP 除 MLP0 外不太重要。这说明第 7、8 层有一簇头把信息从 S2 搬到 END，9.9、9.6、10.0 靠这些信息知道要注意 IO。
  • 第 7、8 层的关键头是 7.3、7.9、8.6、8.10，修补它们的 value 效果大，query 和 key 较小，说明重要的计算在“从 S2 搬到 END 的是什么”，END 为什么注意 S2 倒是次要的。
  • 第三簇是早期头（如 3.0、5.5、6.9），它们的 query 对性能重要。看 3.0 的注意力模式会发现 S2 注意 S1，即早期头检测目标 token 是否重复；“主语重复了”这一信息存在 S2 上，用来抑制后面的头去注意重复的名字，于是它们注意未重复的 IO。

其他细节：除了重复 token 头，第一簇里还有前一 token 头和归纳头，归纳头通过归纳机制完成同样的事，让 S2 注意 S1+1（原文注明论文的图暗示归纳头和重复 token 头相互组合，这是误导性的）。负向名字搬运头做的事和名字搬运头相反，抑制正确答案。备用名字搬运头在名字搬运头被消融后会接手任务，原文称之为模型内置的冗余。S-inhibition 头分为基于位置信息和基于 token 信息两种。修补 S-inhibition 头的 key 和 value 时 value 重要、key 不重要，所以这些头里没有真正的 K-composition。

4️⃣ 路径修补

学习目标：理解路径修补及其与激活修补的区别；用 hook 从零实现路径修补。

这部分更贴近论文作者的设置，用 IOIDataset（从名字列表、句式模板、物品列表随机生成），以及把三个名字都换成随机名字的 abc_dataset 作为另一种分布。激活修补问的是“把一个头写入残差流的值换成另一分布下的值、其他不变，会怎样”；路径修补（path patching）替换的是边而不是节点，问“头 A 直接输入到后面头 B 的那部分换成另一分布下的值，会怎样”。论文的做法把 MLP 算作直接路径的一部分，原文解释两种做法都说得通，在 IOI 电路里 MLP 不重要（MLP0 除外），两种做法结果相近。

  • 到最终残差流的路径修补（难度 5，重要性 4）：接收节点是最终残差流。步骤是先在两种分布上各缓存一次，再运行时冻结所有头的输出为原始值、只把待测头换成新分布的值（patch_or_freeze_head_vectors），最后看最终输出的变化。
  • 头到头的路径修补（难度 3，重要性 3）：接收节点是后面头的 query/key/value 输入，用来确认 S-inhibition 头的 value 输入来自哪些早期头。论文结果见其图 5(b)。
def patch_head_input(orig_activation, hook, patched_cache, head_list):
    heads_to_patch = [head for layer, head in head_list if layer == hook.layer()]
    orig_activation[:, :, heads_to_patch] = patched_cache[hook.name][:, :, heads_to_patch]

5️⃣ 完整复现：最小电路等

学习目标：复现 IOI 论文的大部分其他结果；练习更开放、引导更少的编码。

  • 写入方向（难度 4，重要性 2）与复制分数（难度 5，重要性 2）：用散点图展示名字搬运头的注意力与其输出在 IO 方向上投影的关系，按论文第 6 页计算正负复制分数（跳过第 0 层，因为那在被当作扩展嵌入的 MLP0 之前）。原文说这两个练习难度远大于概念重要性。
  • 早期头的验证（难度 3，重要性 3）：在随机重复序列上用注意力模式验证三类早期头（前一 token、重复 token、归纳）。
  • 最小电路（难度 5，预计至少一小时，原文称本 notebook 最难的练习）：除了已识别的头（各在指定位置）以外全部做均值消融，看性能是否恢复。论文的三条标准：忠实（faithful，电路能和整个模型表现一样好）、完整（complete，包含完成任务用到的所有节点）、最小（minimal，不含与任务无关的节点）。

02. 1.4.2 SAE 电路、transcoder 与归因图

原练习集：[1.4.2] SAE Circuits（可选）

这一套研究由 SAE latent 组成的电路：不同层的一组 latent 相互通信，端到端地解释某个模型行为。从 latent 到 latent、token 到 latent、latent 到 logit 的梯度开始，然后介绍 transcoder，再从零实现完整的归因图（attribution graph）流程，最后用 circuit-tracer 库研究真实电路并做特征干预。阅读材料有 Towards Monosemanticity、Scaling Monosemanticity、Dunefsky 等人的 Transcoders Find Interpretable LLM Feature Circuits，以及 Anthropic 2025 年的 Circuit Tracing。原文开头有一段 SAELens 速览（加载、run_with_saes、use_error_term、ActivationsStore、Neuronpedia 仪表盘），做过 1.3.3 可以跳过；梯度练习里通常先用 use_error_term=True 拿到干净前向下的真实 latent 激活，算 Jacobian 时再用 False，让函数真正经过 SAE。

1️⃣ Latent 梯度

学习目标：计算 Transformer 不同层 SAE latent 之间的 latent 到 latent 梯度；计算 token 到 latent 的梯度，看哪些输入 token 驱动某个 latent。

原文的出发点：能用 SAE latent 引导出有意思的效果，是否说明找到了模型真正的计算单元，还是只找到了一个有趣的聚类算法？目前并不确定。如果 SAE latent 之间能组成稀疏、可解释的电路，就是“latent 是模型基本计算单元”的有力证据。对给定输入和不同层的两个 latent，第二个 latent 激活对第一个的导数构成偏导矩阵 $J_{ij} = \frac{\partial f_i}{\partial x_j}$，可以作为早层 latent 对晚层 latent 贡献的线性代理，用 PyTorch 的 jacrev（反向模式 Jacobian）计算。

  • SparseTensor 类（难度 2，重要性 1）：在稠密和稀疏（非零值、非零索引、形状）两种格式之间转换。
  • latent_acts_to_later_latent_acts（难度 3，重要性 3）：把早层 SAE 的 latent 激活经“SAE 解码器、中间各层、后层 SAE 编码器”映射成后层 latent 激活。
  • latent_to_latent_gradients（难度 4，重要性 3）：对两个 SAE 所有同时激活的 latent 对求梯度。
  • token 到 latent 梯度、latent 到 logit 梯度（难度 4，重要性 2）：前者对嵌入乘一个缩放因子再对它求导。
  • （可选，难度 5）在注意力 SAE 中找归因电路：筛出在重复序列后半每个 token 都激活的第 5 层 latent。

2️⃣ Transcoder

学习目标：理解 transcoder 及其与标准 SAE 的区别；学会解释 transcoder latent 的技术：拉回（pullback）、去嵌入（de-embedding）和扩展嵌入（extended embedding）。

残差流 SAE 和注意力输出 SAE 只在模型的某一个点上把激活表示为 latent 的稀疏线性组合，并不学习 MLP 层的计算。Transcoder 读 MLP 之前的激活，去重建 MLP 之后的激活，仍然是稀疏线性组合。原文引用 transcoder 文章：它把 MLP 层的功能分解成稀疏、独立变化、有意义的单元（就像叠加被发现之前人们原本期望神经元的样子），大大简化电路分析。前面算 latent 梯度时只能算两个都激活的 latent 之间的梯度；transcoder 包住了整个 MLP（包括非线性），可以直接用早层 latent 的“写向量”和晚层 latent 的“读向量”做点积，判断一个 latent 会不会激活另一个（忽略中间层的影响）：

  • 拉回：某个晚层 latent 的拉回是 $p = W_{dec} f_{later}$，即晚层 latent 的读向量与所有早层 latent 的解码器（写）向量的点积。
  • 去嵌入是特例 $d = W_E f_{later}$：问哪些 token 最能激活某个晚层 latent（难度 1，重要性 3）。
  • 修正去嵌入（难度 2，重要性 3）：直接用 $W_E$ 不够，要用经过第 0 层 MLP 的扩展嵌入，并在 d_model 维上标准化。

3️⃣ 归因图

学习目标：理解局部替换模型，为什么冻结注意力模式、LayerNorm 缩放并把 MLP 换成线性跳连后残差流变成线性的；理解读/写向量抽象，即 token 嵌入、transcoder latent、MLP 误差和 logit 方向怎样与残差流交互。

这里换成 Gemma 3-1B IT 和 GemmaScope 2 transcoder。GemmaScope 2 是 Google DeepMind 第二套 SAE 与 transcoder，覆盖 Gemma 3 家族（不是 Gemma 2），在 27B 及以下所有规模的预训练和指令微调模型的所有层上都训练了 transcoder。它们用 Matryoshka 损失训练，latent 有天然层级：编号小的激活更频繁、对重建更重要，编号大的代表更窄更具体的概念。它们还有仿射跳连 W_skip，捕捉 MLP 计算中的线性部分，latent 捕捉非线性部分。构图时要把前 4 个 token（BOS、<start_of_turn>、user、换行）遮掉，提示例子用的是 Anthropic 归因图工作中的押韵对句。

局部替换模型（local replacement model）：Transformer 残差流几乎是线性的，主要非线性是注意力模式（query 和 key 上的 softmax）、LayerNorm 缩放（RMSNorm 归一化因子）和 MLP 激活。把三者冻结在前向时的取值，残差流就成了各节点特征激活的线性函数，归因就有了明确定义。MLP 换成线性跳连 mlp_out ≈ mlp_input @ W_skip.T。关键细节是注意力只冻结注意力模式（softmax 输出），value 计算（V @ W_O）保持可微，否则跨位置的梯度就全断了。练习 TranscoderReplacementHooks（难度 3，重要性 5）：前向时 MLP 输出保持精确不变，反向时梯度只走线性跳连，同时记录 transcoder 特征激活；之后检查每层平均 L0（每个 token 位置非零 latent 的平均数），过高（如超过 50）会让图很大。

节点与边。输出节点是显著 logit：取预测概率最高的若干 token（覆盖一定概率质量，或固定 3 到 5 个），用去均值的反嵌入向量作为读方向。去均值是因为给残差流加一个常向量会同等地影响所有 logits，不改变 softmax。各类节点的读写向量（原文表格）：

节点类型写向量读向量
Token 嵌入token 嵌入向量零向量（嵌入是输入）

误差项为什么要把跳连算进重建：在线性化模型里跳连 ln2(resid_mid) @ W_skip.T 是一条活的线性路径，它写的东西已经通过反向传播归到了上游节点，误差里再包含跳连输出就会重复计算。定义误差为 mlp_out - (decode(acts) + skip)，latent、跳连和误差加起来正好等于真实 MLP 输出。

  • compute_salient_logits（难度 2，重要性 3）；build_embedding_nodes、build_intermediate_nodes（难度 2 到 3，重要性 4）：后者为每层构建 latent 节点和 MLP 误差节点。
  • prepare_backward_batches（难度 3，重要性 4）：按层把目标节点分批。
  • compute_adjacency_matrix（难度 5，重要性 5，原文称本部分最难也最重要）：对每批目标节点，在冻结模型中前向，在目标位置把残差流与目标读向量点积后反向传播，再把梯度与源节点写向量缩并，得到边权。

剪枝分三步。先归一化：取绝对值并按行除以行和，得到每行和为 1 的非负矩阵，可看作“转移矩阵”，表示目标节点的输入中有多少比例来自各源节点。

$$A_{\text{norm}}[j, :] = \frac{|A[j, :]|}{\sum_i |A[j, i]|}$$

再用 Neumann 级数算影响力（节点对输出 logits 的直接加间接效应）。图是分层的（边只从早层指向晚层），邻接矩阵严格下三角，因而幂零；节点层为 $E, 0, 1, \ldots, L-1, \text{logit}$，最长路径有 $L+1$ 条边：

$$v_0 = w_{\text{logit}}, \quad v_{k+1} = v_k \cdot A_{\text{norm}}, \quad \text{influence} = \sum_{k=1}^{L+1} v_k$$

最后剪枝：节点剪枝按影响力排序，保留累计影响力超过阈值（如总量的 80%）的最小集合，logit 节点总保留；边剪枝的边分数为 $|A_{\text{norm}}[j,i]| \cdot \text{influence}[j]$，保留到累计分数达到阈值（默认 0.85），再去掉没有边的孤立节点。练习 compute_influence（难度 3，重要性 4）、prune_nodes、prune_edges（难度 3，重要性 3）。最后把这些串成 attribute 函数，用 create_attribution_dashboard 生成与 Anthropic 已发布归因图相同模板的交互式仪表盘，并导出 Neuronpedia 格式的 JSON。示例提示里的事实回忆题上，Gemma 3-1B 拿不准（' Fort' 约 41%，' Austin' 约 37%），图里两个答案在竞争。原文还说明怎样从 HuggingFace 的 gemma-scope-2-1b-it 仓库加载每个特征的激活直方图和最大激活样例，补全仪表盘。

03. 1.5.1 括号平衡分类器

原练习集：[1.5.1] Balanced Bracket Classifier（可选，README 最推荐之一）

在合成的算法任务上训练的模型，内部往往学到干净、可解释的计算。原文说研究算法问题让我们可以练习可解释性、积累直觉，并在已知真值的问题上检验工具和技术；研究玩具语言模型的两个理由是找到在大模型中反复出现的基本电路和模式（motif），以及更好地理解怎样逆向模型。这一套引导你部分地解释一个在括号分类任务上训练的双向模型。

1️⃣ 括号分类器

学习目标：理解怎样用 Transformer 做分类；理解怎样用 TransformerLens 的永久 hook 实现特定行为（如屏蔽填充 token）。原文说这一部分主要是打基础，内容很轻。

模型只判断一串括号是否平衡。与 GPT 的区别在注意力：GPT 用因果注意力，信息只能向前流；这个模型像 BERT 一样用双向注意力。分类模型的训练方式类似，只是不输出下一个 token 的分布，而是在第 0 个位置输出类别 logits (l0, l1)，分别对应（不平衡，平衡），其他位置的输出丢弃，但这些位置仍是重要中间计算发生的地方。每个序列是 [start]、最多 40 个括号、[end]，再用 [pad] 补齐；算注意力分数时，key 是填充 token 的位置全部屏蔽。数据集一半平衡一半不平衡。架构细节：

  • 正弦位置嵌入（不学习）；d_model 为 56；双向注意力。
  • 3 个注意力层和 3 个 MLP；每层 2 个头，d_head = 56 / 2 = 28；MLP 隐藏层 56 个神经元（线性层是方阵）。
  • 每个注意力层和 MLP 的输入先做 LayerNorm，所有层之后的残差流上还有一个 LayerNorm（和 GPT 一样）。
  • 词表只有 5 个 token：[start]、[pad]、[end]、(、)，嵌入矩阵 $W_E$ 有 5 行。

先手写两种算法解（难度 2，重要性 3）：循环版和向量化版。

def is_balanced_vectorized(tokens):
    # start/pad/end -> 0, "(" -> +1, ")" -> -1
    table = t.tensor([0, 0, 0, 1, -1])
    change = table[tokens]
    altitude = t.cumsum(change, -1)
    # balanced iff the total is zero and no prefix goes negative
    return (altitude[-1] == 0) and (altitude.min() >= 0)

模型的解法（原文直接告诉你）：在每个位置 $i$，模型看从当前位置到末尾的后缀 seq[i:]，计算其中右括号数减左括号数，称为位置 $i$ 的“高度”（elevation）。序列不平衡当且仅当 elevation[0] 非零，或者存在某个位置高度小于 0（any(elevation < 0)）。

2️⃣ 倒推回残差流

学习目标：理解怎样做 logit 归因；理解怎样从模型末端倒推，找出对最终分类概率最重要的部件。这是第一次在练习中处理 LayerNorm。

分类头有三步：最终 LayerNorm、反嵌入、softmax。逐步倒推：

  • 穿过 softmax：两个元素的 softmax 等于 logit 差的 sigmoid，$P(\text{unbalanced}) = \text{sigmoid}(\text{logit}_0 - \text{logit}_1)$。
  • 穿过线性层：W_U 形状 (d_model, 2)，所以最终 LayerNorm 输出应指向的方向是 W_U[:, 0] - W_U[:, 1]（练习 get_post_final_ln_dir，难度 1）。
  • 穿过 LayerNorm（难度 4，重要性 3）：LayerNorm 非线性，这里用线性回归拟合它的输入到输出（get_ln_fit），把它近似成矩阵 $L_{final}$，再把方向乘回去，得到最终 LayerNorm 之前的“不平衡方向” pre_final_ln_dir。
def get_pre_final_ln_dir(model, data):
    post_final_ln_dir = get_post_final_ln_dir(model)
    final_ln_fit = get_ln_fit(model, data, layernorm=model.ln_final, seq_pos=0)[0]
    final_ln_coefs = t.from_numpy(final_ln_fit.coef_).to(device)
    return final_ln_coefs.T @ post_final_ln_dir

然后把残差流写成 10 个部件之和：嵌入（位置加词表）、0.0、0.1、MLP0、1.0、1.1、MLP1、2.0、2.1、MLP2（练习 get_out_by_components，难度 3，重要性 2）。对每个部件，看它写到位置 0 的向量在不平衡方向上的点积（减去平衡样本上的均值），画直方图：如果某部件在不平衡输入上的点积明显高于平衡输入，它就对分类重要（难度 2，重要性 4）。再把失败类型分开：总高度不为零的失败、某处高度为负的失败（难度 3），并忽略以右括号开头的序列，因为它们可以立即判为不平衡。

3️⃣ 总高度电路

学习目标：练习把特有的注意力模式和人能理解的算法联系起来，推断模型行为；理解怎样把 MLP 看作一组神经元。这是第一次在练习中处理 MLP，原文说这一部分在编码和概念上都有挑战。

  • 2.0 的注意力（难度 2）：对以左括号开头的序列，query 为位置 0 的 [start] 时，2.0 几乎只注意位置 1，相当于把位置 1 的残差向量乘上 $W_{OV}$ 搬到位置 0。
  • 2.0 之前的不平衡方向（难度 2，重要性 3）：把不平衡方向经 2.0 的 OV 矩阵和第 2 层之前的 LayerNorm 倒推回去（get_pre_20_dir），再看前面各部件在位置 1 写入的向量在这个方向上的大小。

04. 1.5.2 Grokking 与模加法

原练习集：[1.5.2] Grokking & Modular Arithmetic（可选）

目标是逆向一个在模加法上训练的单层 Transformer，它的电路用到离散傅里叶变换和三角恒等式。练习改编自 Neel Nanda 和 Tom Lieberum 的原始 notebook（以及配套论文）。原文推荐 Welch Labs 的视频 The most complex model we actually understand 作为可选的直观入门。

问题设置：单层 Transformer，无 LayerNorm，学习的位置嵌入，$d_{model} = 128$、$n_{heads} = 4$、$d_{head}=32$、$d_{mlp}=512$。任务是模素数 $p = 113$ 的加法，输入是三个 token [x, y, =]，$d_{vocab}=114$（0 到 $p-1$ 的整数加上 =），预测 = 之后的 $(x+y) \bmod p$。全批量训练，30% 的数据作训练集，AdamW，$lr=10^{-3}$，权重衰减很大（$wd=1$）。

原文先给出算法概要：

  • 把 $x, y \in \{0, \ldots, p-1\}$ 映射为 $\sin(\omega x)$、$\cos(\omega x)$、$\sin(\omega y)$、$\cos(\omega y)$，其中 $\omega = \omega_k = \frac{2k\pi}{p}$。大部分频率被丢掉，只保留少数几个关键频率（key frequencies）。
  • 用注意力和 ReLU 以“取巧”的方式算出二次项 $\cos(\omega x)\cos(\omega y)$、$\sin(\omega x)\sin(\omega y)$、$\cos(\omega x)\sin(\omega y)$、$\sin(\omega x)\cos(\omega y)$，从而得到线性组合：
$$\cos(\omega (x+y)) = \cos(\omega x) \cos(\omega y) - \sin(\omega x) \sin(\omega y)$$ $$\sin(\omega (x+y)) = \sin(\omega x) \cos(\omega y) + \cos(\omega x) \sin(\omega y)$$
  • 输出 logit 向量的每个元素 $\text{logits}[z]$ 是以下形式项的线性组合：
$$\cos(\omega (x + y - z)) = \cos(\omega (x+y)) \cos(\omega z) + \sin(\omega (x+y)) \sin(\omega z)$$

（笔者整理：当 $z \equiv x+y \pmod p$ 时每个频率的余弦都取最大值 1，各频率的贡献在正确答案处叠加，其他 $z$ 处则相互抵消一部分。原文把“为什么这个算法有效”留作思考题。）

学习目标：理解问题陈述、模型架构以及任何可能解的函数形式；了解一维和二维傅里叶基，以及怎样用它表示任意函数。

$$\cos (\omega_k \vec{\textbf{x}}) = \big(1,\; \cos (\omega_k),\; \cos (2 \omega_k),\; \ldots,\; \cos ((p-1) \omega_k)\big)$$

周期函数在傅里叶基下是稀疏的。二维傅里叶基的每一项是两个一维基向量的外积，包含常数项、线性项（只依赖 x 或 y 的余弦正弦）和二次项（x 与 y 的乘积项）。练习实现 make_fourier_basis（难度 3）、一维变换、二维基和二维变换。对激活做二维傅里叶变换后结果极其稀疏，只有少数格子（大多在第 0 行或第 0 列，即常数和线性项）非零。原文有一段旁注：在 batch 维上换基很不寻常，注意力 softmax、ReLU、最终 softmax 以及与注意力模式的逐元素乘法这四个操作对 batch 维不是线性的，ReLU 变成“转回原基、逐元素 ReLU、再转回傅里叶基”。

3️⃣ 训练过程中的分析

学习目标：理解跟踪指标随时间变化，可以说明某些电路何时形成；研究模型权重矩阵奇异值随时间的演化。原文说这部分可选，观察比其他部分更具推测性，更多是展示论文结果。

检查点每 100 个 epoch 一个，从 0 到 50K（前面用的模型取自 40K）。概括：模型在相变之前很早就开始学习泛化算法，并且发展得相当平滑；排除损失（excluded loss）显示模型在用 $\cos(w(x+y))$ 方向“更高效地记忆”，原文称这清楚地否定了“grokking 是损失地形上的随机游走、最后碰巧走对”的假设。

  • 排除损失（难度 3，重要性 4）：在训练集上删去 logits 中对应 $\cos(w(x+y))$、$\sin(w(x+y))$ 的分量后的损失，每个关键频率一个。关键观察：排除损失（尤其频率 14）在 grokking 之前很久就开始上升，幅度远大于删掉一个随机方向。
  • 嵌入的演化：每个 epoch 嵌入的各一维傅里叶分量范数（fourier_embed），以及 $W_E$ 的 SVD；grokking 之前模型已在突出少数分量，但多数分量仍不小。
  • 三角分量的形成：logits 很早就具备“只保留三角方向、抵消其余”的能力，神经元直到接近 grokking 才出现显著的二次项和三角分量。原文推测电路可能倾向于“倒序”形成。
  • 可交换性：模型很快学会不注意最后一个位置，但直到 grokking 才学会对位置 0 和 1 给相等的注意力（约 43K epoch 处还有一次没研究过的奇怪相变）。
  • 三角损失：只保留关键频率三角方向的 logits 时，全数据上的三角损失与训练集上的训练损失完全相同，说明这些维度只用于对训练集和测试集一视同仁的通用算法，而不是记忆。
  • 权重平方和的几个阶段：0 到 1K 用神经元记忆（$W_{in}$、$W_{out}$ 总权重大增）；1K 到 8K 把计算平摊到各矩阵，总和都在下降；8K 到 13K grokking，权重迅速下降，推测模型已能用三角方向，清理掉用于记忆的其他方向。

附加讨论（Neel Nanda 的观点）：grokking 发生在“学习通用算法表现出相变”并且“给的数据量刚好够相变仍然发生”的时候；相变可能出现在模型学习任何一个需要不同部分以非线性方式协作的泛化电路时。局限：玩具模型只需少数电路；模型过度参数化（学到很多做大致相同事情的冗余神经元）；只研究了权重衰减这一种正则化。与对齐的关系：相变意味着训练或放大模型时能力可能快速跃升，出现预警信号的可能性更小。

05. 1.5.3 OthelloGPT

原练习集：[1.5.3] OthelloGPT（可选）

背景是 Kenneth Li 等人的 ICLR 2023 Oral 论文 Emergent World Representations：用随机生成的黑白棋（Othello）对局（每步从合法着法中均匀随机选择）训练模型预测下一步。主要结论是 Othello-GPT 学到了涌现的世界表示：从未被告知棋盘状态，只被要求预测下一步，却学会在每一步计算棋盘状态（目标是下合法着法而不是好着法）。论文的两项证据：用非线性探针（两层 ReLU MLP）从残差流中提取棋盘状态；用探针做因果干预（梯度下降让探针输出新棋盘状态），模型随后在新棋盘上走合法着法，即使在旧棋盘上不合法、即使新棋盘不可能通过合法对局到达。练习中的“我”指主要研究者 Neel Nanda，他的贡献是把这些技术大幅简化：模型学到的是线性的世界表示，可以线性地因果干预；它表示的是“这一格是我的/对方的棋子”，而不是“黑子/白子”，因为模型同时为黑白双方走棋，从它的角度看前者更自然。

1️⃣ 模型设置与线性探针

学习目标：理解 Othello-GPT 的基本结构；熟悉棋盘可视化等基本工具。

Neel 对论文的看法：探针给出的是提示性而非决定性的证据，训练探针提取特征时很容易骗自己，要区分探针只是读出特征还是自己在计算特征；因果干预更有说服力，但论文的技术“太强了”。他的判断是网络形成可分解的线性表示：模型算出一组有用的特征，表示为残差流中的方向；按这个框架，线性探针能找到的特征模型已经算好了，如果下游电路用到它，就应该能用线性干预（只改这个方向上的坐标）影响行为。

技术细节：对局有 60 步（8×8 棋盘，中间 4 格开局已占），模型上下文长度为 59，输入 moves[0:59] 预测 moves[1:60]。训练数据是随机合法着法；一步合法当且仅当它在横、竖或斜线上夹住对方棋子并把它们翻成己方颜色，所以预测合法着法并不简单。用交叉熵训练，模型的分布收敛到在所有合法下一步上均匀分布。模型 8 层、d_model=512、d_mlp=2048。取 50 局作为“焦点对局”（focus games），缓存全部激活。

探针（来自 MI Dynalist 笔记的定义）：给网络一批有某特征和没有该特征的输入，在某个激活上训练一个线性映射区分两者。原文说当初的探针训练有点乱，有三种模式：full_linear_probe[0]（黑方走棋即奇数步）、[1]（白方走棋即偶数步）、[2]（所有步），形状都是 (d_model, 8, 8, 3)，类别为 [empty, white, black]，在第 6 层（共 8 层）的 resid_post 读取。

  • 探针余弦相似度（难度 3，重要性 3）：比较奇数步和偶数步的“黑减白”方向。原文的关键结论是探针学到的是“我的/对方的”而不是“黑/白”，所以奇数步和偶数步的这两个方向应当近似相反（两种步里“我的”对应的颜色正好对调）；据此把它们合并换成“我的/对方的”基：新探针的“对方”方向是黑方走棋时的白方向与白方走棋时的黑方向的平均。在 50 局上算准确率，探针在角落附近较差。
  • 定义探针方向（难度 2，重要性 4）：每格探针有 3 个向量，但 softmax 平移不变，只有两个自由度。
  • apply_scale（难度 3，重要性 3）：在某位置沿 flip_dir 方向翻转并缩放残差流，从而改变模型对某一格的“认识”，观察合法着法预测随之改变。

blank_probe = linear_probe[..., 0] - linear_probe[..., 1] * 0.5 - linear_probe[..., 2] * 0.5
# mine(2) - theirs(1)
my_probe = linear_probe[..., 2] - linear_probe[..., 1]

学习目标：在多个层上使用线性探针；在给定序列位置做激活修补来检验假设。

跨层探测：探针输入是前七层在残差流中的累加，所以可以把每个注意力层和 MLP 层的输出投影到探针方向上，看棋盘信息在哪里、何时被写入（难度 3，重要性 4，原文称 logit 归因是最重要的工具之一）。读神经元权重：有了探针就有了一组可解释的残差流方向，可以读出任意神经元输入和输出权重的含义。以 L5N1393 为例，把它的输入权重投影到归一化的 blank 探针和 my 探针上（难度 3，重要性 4）。探针方向合起来秩为 124（128 个方向减去中间 4 格的 blank 方向），略少于 d_model=512 的 1/4；输入权重被探针很好地解释，输出权重只是部分被解释。看第 3 层激活标准差最大的神经元，验证这一层的神经元在直接计算“是否空格”，并把它直接送进反嵌入，提高空格的 logit（空格是合法着法的必要条件）。

06. 1.5.4 叠加玩具模型与稀疏自编码器

原练习集：[1.5.4] Toy Models of Superposition & Sparse Autoencoders（可选）

叠加（superposition）是理解 Transformer 的关键概念。Neel Nanda 词汇表中的定义：模型在 $n$ 维激活空间中表示多于 $n$ 个特征，特征仍对应方向，但可解释方向的集合比维数多。原因是世界上的特征比模型的维数多，无法一一对应。这一套专注于叠加理论，较少涉及在真实语言模型上的 SAE 应用（那是 1.3.3 和 1.4.2 的内容）；1.3.3 说速通本套第 1 部分和第 5 部分前半就够作为它的前置。阅读材料是 200 COP in MI: Exploring Polysemanticity and Superposition（约 15 分钟）和 Neel 的叠加笔记（约 10 分钟）。练习开头列了一组自测问题，比如什么是特权基（privileged basis），为什么神经元激活默认是特权的而残差流不应该是。练习主线跟随本合集 03 叠加的玩具模型 论文的 Demonstrating Superposition 一节往后的顺序。

1️⃣ 非特权基中的叠加

学习目标：理解叠加的概念及它怎样帮模型表示更多特征；理解叠加与多义性（polysemanticity）的区别。

论文中的瓶颈叠加（bottleneck superposition）玩具模型：取 5 维输入 $x$，映射到 2 维，再用第一个矩阵的转置映回 5 维，加偏置和 ReLU：

$$h = W x, \qquad x' = \operatorname{ReLU}(W^T h + b)$$

五个特征在 0 到 1 之间均匀采样。每个特征有重要性（importance，对降低损失有多大用）和稀疏度（sparsity，在输入中缺席的频率）。重要性是加权 MSE 损失中的系数，$L = \sum_x \sum_i I_i (x_i - x_i')^2$；稀疏度是对应元素为零的概率，影响数据生成。练习实现 forward、generate_batch、calculate_loss，一次训练多个实例（instances）以比较不同稀疏度。

解读图（难度 3，重要性 4）：从左到右稀疏度增加（最右特征概率为 2%）。没有稀疏时模型最多忠实表示 2 个特征，于是只表示两个最重要的，正交地放在二维里，其余 3 个置零。高稀疏时出现五边形结构：大多数时候最多一个特征活跃，干扰（interference）变小，把二维点投影到五个方向上恢复特征时，特征 $i$ 出现时投影基本只反映它自己。可选的“相关性”小节：负相关的特征更容易叠加，因为同时活跃的情况少；原文举例“这是排好序的 Python 列表”和“这是一段青少年吸血鬼言情小说”大概率负相关。

2️⃣ 特权基中的叠加

学习目标：理解神经元叠加与瓶颈叠加（计算叠加与表示叠加）的区别。

上面的模型没有特权基：任取正交矩阵 $O$，$W' = OW$ 给出完全相同的模型，因为 $(OW)^T(OW) = W^T W$。这类似词嵌入和残差流。要研究有神经元的表示（Transformer 的 MLP 层），最简单的办法是在隐藏层加 ReLU：

$$h = \operatorname{ReLU}(W x), \qquad x' = \operatorname{ReLU}(W^T h + b)$$

练习 NeuronModel 后解读图（难度 3，重要性 4）：稀疏度很低时没有叠加，每个特征由一个神经元忠实表示或干脆不表示，即纯单义性；稀疏度升高后出现多义神经元。原文指出这个模型的问题是它在重建恒等函数（线性），用不着 ReLU，会想尽办法绕开它。所以“叠加中的计算”小节训练模型计算绝对值，数据改为 $[-1, 1]$ 上采样；$\operatorname{abs}(x) = \operatorname{ReLU}(x) + \operatorname{ReLU}(-x)$ 是最简单的非线性函数之一，模型必须用到 ReLU（练习 NeuronComputationModel）。附加内容复现论文的非对称叠加模式（asymmetric superposition motif）：一个神经元以不同幅度存两个特征。

3️⃣ 特征几何

学习目标：了解维度（dimensionality），它衡量一个特征分到了多少比例的维度。

实验设所有特征同等重要、只改变稀疏度（200 个特征、20 维隐藏层、20 个实例）。表示的特征数可以用 $\|W\|_F^2 = \sum_j \|W_{[:, j]}\|^2$ 估计，因为每个嵌入向量表示了特征时平方范数约为 1，没表示时约为 0；再画“每个特征的维数” $m/\|W\|_F^2$。原文说特征会把自己组织成五边形、四面体这样的几何结构。单个特征的维度为

$$D_i = \frac{\|W_i\|^2}{\sum_j (\hat{W}_i \cdot W_j)^2}$$ 
def compute_dimensionality(W):              # W: [n_inst, d_hidden, n_features]
    W_norms = W.norm(dim=1, keepdim=True)
    numerator = W_norms.squeeze() ** 2
    W_normalized = W / (W_norms + 1e-8)
    denominator = einops.einsum(W_normalized, W, "i h f1, i h f2 -> i f1 f2").pow(2).sum(-1)
    return numerator / denominator

4️⃣ 叠加与深度双下降

学习目标：理解并刻画深度双下降（deep double descent）现象；把双下降的各阶段与叠加联系起来；练习以较少引导的方式复现论文。原文说这更像有引导的复现，可作为可选扩展。

复现 Anthropic 关于双下降与叠加的论文。理论大致是：模型先学到记忆解，把数据点放在叠加中，训练损失低、测试损失高；之后学到泛化解，把特征放在叠加中，训练和测试损失都低；损失尖峰出现在两者转换时。做法是用第一部分的玩具模型，生成一个随机 batch 并在整个训练中只用它，batch 大小称为数据量（data size），看数据量变化时会发生什么。参考代码为小数据量和大数据量各用一个模型，避免把小数据量全部补齐到 500。

5️⃣ 玩具模型中的稀疏自编码器

学习目标：了解 SAE 及其怎样帮助解开叠加中的特征；在前面的玩具模型上训练自己的 SAE 并可视化特征重建过程；理解重要的训练策略（如重采样）和架构变体（Gated、JumpReLU）。

SAE 由 Towards Monosemanticity（2023）推广，现已是机械可解释性最常用的工具之一。这里在 ToyModel 的隐藏激活上训练 SAE（注意与论文不同，论文在 MLP 层上训练，这里在非特权基上），提取特征并验证它们就是模型学到的特征。记号：SAE 隐藏激活称为 SAE latent，d_sae 是隐藏层大小，要求 d_sae >= n_features。练习依次实现 __init__、W_dec_normalized、generate_batch 和 forward（难度 3，重要性 5）： 

def forward(self, h):
    h_cent = h - self.b_dec
    acts_pre = einops.einsum(h_cent, self.W_enc, "batch inst d_in, inst d_in d_sae -> batch inst d_sae") + self.b_enc
    acts_post = F.relu(acts_pre)
    h_reconstructed = einops.einsum(acts_post, self.W_dec_normalized,
                                    "batch inst d_sae, inst d_sae d_in -> batch inst d_in") + self.b_dec
    L_reconstruction = (h_reconstructed - h).pow(2).mean(-1)
    L_sparsity = acts_post.abs().sum(-1)
    loss = L_reconstruction + self.cfg.sparsity_coeff * L_sparsity
    return {"L_reconstruction": L_reconstruction, "L_sparsity": L_sparsity}, loss, acts_post, h_reconstructed

训练时每步优化前做神经元重采样，并提到 Anthropic 2024 年 2 月更新发现把 Adam 的 $\beta_1$ 设为 0 能减少死特征。重采样：论文发现训练中有些 latent 不再激活，重采样这些死 latent 能让模型表示更多特征。resample_simple（难度 4，重要性 3）为每个死 latent 生成随机单位向量，设为新的解码器和编码器权重（编码器乘 resample_scale）；resample_advanced（难度 5，重要性 2）按重建损失加权采样输入来重新初始化，原文说在二维里看不出多少改进，高维时收益明显。

Gated SAE（DeepMind）出于两点观察：特征经验上“想要是二值的”（比如“这是不是关于篮球”）；SAE 有收缩（shrinkage）问题，L1 作为 L0 的代理，和重建项目标冲突，把激活压小。Gated SAE 把“是否激活”的阶跃门和“激活多大”的幅度项解耦：

$$\tilde{\mathbf{f}}(\mathbf{x}) := \mathbf{1}[\mathbf{W}_{\text{gate}}(\mathbf{x}-\mathbf{b}_{\text{dec}})+\mathbf{b}_{\text{gate}}>0] \odot \operatorname{ReLU}(\mathbf{W}_{\text{mag}}(\mathbf{x}-\mathbf{b}_{\text{dec}})+\mathbf{b}_{\text{mag}})$$

练习实现 Gated SAE（难度 5，重要性 4）并演示它的优势（难度 4）。JumpReLU SAE 有类似优点，但不需要 Gated SAE 那样为辅助损失做一次 detach 的前向：激活为 $\operatorname{JumpReLU}_\theta(z) = z H(z - \theta)$，$\theta$ 是每个 latent 的阈值向量；原文注明只用 JumpReLU 不能解决收缩，JumpReLU 加 L0 惩罚才能。阶跃函数不可微，用直通估计器（straight-through estimator）定义导数：用在跳变处很陡的累积分布函数近似阶跃，$\frac{\partial}{\partial \theta} H(z-\theta) := -\frac{1}{\varepsilon} K\left(\frac{z-\theta}{\varepsilon}\right)$，$K$ 是宽度为 1、以 0 为中心的矩形核；原文给了函数图像和概率两种直觉。用 L0 而非 L1 的好处是可以瞄准特定稀疏度，例如惩罚 L0 与目标值之差的平方。练习实现自定义梯度函数（难度 3）和 JumpReLU SAE（难度 5，重要性 4，THETA_INIT = 0.1）。
