上下文学习与归纳头

用 34 个模型、5 万多次注意力头消融拼出六条间接证据：训练早期有一次“相变”，归纳头在这次相变中形成，上下文学习能力也在同一窗口里突然出现；归纳头可能是大模型里大部分上下文学习的来源

资料来源：In-context Learning and Induction Heads（Transformer Circuits Thread；本文依据原文英文网页整理，是中文转述和讲解，不是逐字翻译；原文插图均为内嵌图片和交互图，本页用文字描述其内容，版权归原作者）

这篇讲什么

上一篇 01 Transformer 电路的数学框架 在两层、只有注意力层的小模型里找到了归纳头（induction head）：一对分处两层的注意力头，合起来实现“前面出现过 [A][B]，现在又看到 [A]，就预测 [B]”。这篇论文问的是下一步：在有 MLP、有几十层的大模型里，归纳头是不是也存在，它们是不是模型“上下文学习”（in-context learning，模型不改权重、只靠读前文就把后面的 token 预测得更好）的主要来源？

大模型的电路没法像两层小模型那样直接从权重里推出来，所以作者换了一种办法：像神经科学家研究大脑那样，观察训练过程、改动结构、敲掉部件，攒一组间接证据。核心观察是训练早期的一次“相变”（phase change）：只要模型多于一层，在训练到大约 25 亿到 50 亿 token 时，归纳头突然形成，上下文学习能力突然提升，训练损失曲线上出现一个小鼓包。作者围绕这个现象给出六条论证，并且对每条论证在小模型、大模型上的说服力分别打分。结论是：对只有注意力层的小模型，证据很强（有因果消融和机制分析）；对大模型，证据主要是相关性的，只能说“可能”。

归纳头的电路细节（QK 电路、OV 电路、K 组合）都来自 01 篇，这里只做摘要。下一篇 03 叠加的玩具模型 转向 MLP 层为什么难懂的问题。术语入门见 00 导读；用 TransformerLens 亲手找归纳头、做消融，可以看 13 ARENA 入门 里的 1.2 练习。

01. 引言：为什么要找间接证据

原文小节：开篇引言（无标题）

作者开篇先交代动机。Transformer 生成模型越来越大、用得越来越广，安全问题也越来越重要。机制可解释性（mechanistic interpretability）想把模型内部的具体计算逆向出来；如果能弄清楚是哪些内部结构导致了模型的输出，就有可能更系统地处理现有安全问题，也能提前预判更强模型的安全问题。原文特别说明，机制可解释性是可解释性这个大领域的一个子集，它的特点是专门去刻画网络内部的“电路”。

过去机制可解释性主要研究 CNN 视觉模型。作者之前的论文（01 篇）为 Transformer 建了一套数学框架，几乎完整地解释了 1 层和 2 层的纯注意力模型，其中最有意思的发现是归纳头：它在序列里往回找当前 token（记作 A）上一次出现的位置，看那次 A 后面跟的是什么（记作 B），然后预测这次也会接 B，也就是 [A][B] … [A] → [B]。机制上它由两个注意力头组成：第一个是“前一个 token 头”（previous token head），把前一个 token 的信息复制到下一个位置；第二个是真正的归纳头，利用这份信息去找“前面跟着当前 token”的位置。1 层模型里没有归纳头，因为它需要不同层的注意力头组合起来。

但目标是逆向前沿大模型，它们有几百层、几十亿到上万亿参数。层数多加上有 MLP，用数学精确锁定电路就难得多。作者的替代思路是：通过经验地观察、扰动、研究学习过程和各种结构的形成，为网络内部可能发生的事拼出一个间接论证。原文把它比作神经科学家了解大脑某部分功能的方式：看神经发育过程、研究这部分脑区受伤的病人、在动物身上扰动脑功能、或者看少数相关神经元。

要论证的假说

论文给出的是初步、间接的证据，支持一个假说：归纳头可能构成了大 Transformer 模型中实际上大部分上下文学习的机制。更具体地说，大模型里存在与两层模型归纳头机制相同或相似的电路，它们做的是一种“模糊”或“最近邻”版本的模式补全，即 [A*][B*] … [A] → [B]，其中 A* ≈ A、B* ≈ B 在某个空间里相似；而且这些电路实现了大模型里大部分的上下文学习。

证据主要来自一次相变：在每个尺寸（只要多于一层）的语言模型训练早期都会发生，表现为训练损失上的一个鼓包。在这次相变中，大部分上下文学习能力形成（用前文 token 和后文 token 的损失差来衡量），同时模型内部形成了能做相当抽象、模糊模式补全的归纳头。作者还试图证明两者有因果关系：如果改动结构让这个鼓包出现在训练的另一个位置，归纳头的形成和上下文学习的形成会一起跟着移动。

相变本身与安全的关系

作者认为这次相变本身也可能和安全有关。已知神经网络的某些能力（比如多位数加法）会随着训练或规模增长突然形成或改变，这让不想要的、危险的行为也可能突然出现。原文举的例子是奖励黑客（reward hacking），它也能在这样的相变中出现。近距离研究一次相变、理解它的内部机制，可能提供可推广的经验；这次相变也在可解释性的微观领域与缩放定律、学习动力学的宏观领域之间架了一座潜在的桥。

论文结构：先澄清几个关键概念，然后逐一给出六条论证，证据来自对 34 个 Transformer 在整个训练过程中的分析，包括超过 50,000 次注意力头消融（数据见“模型分析表”），最后讨论未解释的“怪现象”和相关工作。作者强调，就像任何经验研究或干预研究一样，这里可能存在大量微妙的混杂因素和替代假说；他们仍然选择发表，一是后续工作可以在此基础上把结论做实，二是随着可解释性发展，这类间接证据会越来越常见，他们希望建立一种即使证据不完全确定也照样报告的规范。

02. 关键概念：上下文学习与上下文学习分数

原文小节：Key Concepts · In-context Learning

在现代语言模型里，上下文中靠后的 token 比靠前的 token 更容易预测；上下文越长，损失越低。某种意义上这就是序列模型被设计来做的事（用序列前面的元素预测后面的），但随着这种能力变强，人们可以用它做很多有意思的事，比如指定任务、给出指令、让模型匹配一个模式，于是把它当成一个独立现象来看，称为上下文学习。原文脚注提到，有时也叫元学习（metalearning），但这个词暗含更强的主张：模型在“学会一项新能力”，而不是“定位”到一项已有能力（即学会它该做什么）。这个含义有争议，也不够精确。

上下文学习在 GPT-2 中被注意到，在 GPT-3 上受到广泛关注：只改提示词（prompt），不用重新训练，Transformer 就能做翻译、问答、算术等很多任务，“提示工程”也随之流行。

两种理解方式

文献里至少有两种很不一样的理解和测量方式：

  • 少样本学习（few-shot learning）视角，代表是 Brown 等人（GPT-3 论文）：把若干个某种“任务”的示例写成下一个 token 预测的格式放进提示里，比如几位数加法、英译法。这是微观视角，关注具体任务。
  • 按 token 位置看损失的视角，代表是 Kaplan 等人（缩放定律论文）：观察不同 token 位置上的损失，衡量模型拿到更多上下文后预测能好多少。这是宏观视角，关注总体损失，而总体损失平均来说和那些具体任务相关。

少样本视角在社区里更受关注：一个大模型不微调就能做很多任务，改变了模型训练的基本经济账，也让人重新思考模型“理解”“推理”是什么意思。但本文采用 Kaplan 的定义，即 token 位置越靠后、损失越低。理由是它更一般，不依赖研究者选定哪些“任务”；缺点是不能单独拎出某种具体行为。作者也会在论证 4 中从这个定义出发研究几个经典的少样本例子。

上下文学习分数

全文使用一个简单的启发式指标：

上下文学习分数（in-context learning score）：上下文中第 500 个 token 的损失减去第 50 个 token 的损失，在数据集样本上取平均。

这两个位置是“有点随意”地选的。第 500 个 token 接近长度 512 的上下文末尾；第 50 个 token 离开头已经足够远，语言、文档类型这类基本属性已经确定，但仍然靠近开头。作者后面会说明换成别的位置不改变结论。（原文这里写“第 500 减第 50”，论证 1 里又写成“第 50 减第 500”，两种写法只差一个符号；正文说“0.4 nats 的上下文学习”，指的是损失降低的幅度。）

上下文学习也可能与安全特别相关：它让人更难预料模型在读了很长的上下文之后会怎样表现。长远来看，mesa 优化（mesa-optimization）或内部对齐（inner alignment）这类概念设想，有意义的学习或优化可能在测试时发生，不改权重。上下文学习会是这种隐藏优化的一个现成机制，不管今天是否已经如此。

03. 关键概念：归纳头的精确定义

原文小节：Key Concepts · Induction Heads

上一篇论文在两层纯注意力模型里发现了归纳头。它由不同层的一对注意力头组成：第一个头把前一个 token 的信息复制到每个位置，于是第二个头可以根据“某个位置前面是什么”来决定注意哪里，而不只看这个位置本身的内容。第二个头（称为归纳头）找到序列中当前 token A 上次出现的地方，注意它后面那个 token B，把 B 复制过来，让模型更可能输出 B。两个头合起来，让 …[A][B]…[A] 更可能被补全为 [B]。

名字来自归纳推理（inductive reasoning）：如果前文里 A 后面跟着 B，那么后面再出现 A 时，大概率又跟着 B。归纳头把这个推断固化下来，它做的归纳是针对当前上下文的，不是针对训练数据的。

作者强调，归纳头实现的是一个简单算法，而不是记住一张固定的 n-gram 统计表。规则 [A][B] … [A] → [B] 对任何 A、B 都适用。脚注补充：归纳头在很大程度上把 A 和 B 解耦了，有些归纳头可能偏好某类 A 或 B，但这种解耦意味着它们能推广到新模式。所以只要上下文前面的局部统计能代表后面的统计，归纳头在某种意义上可以在分布之外工作。

用行为来定义

上一篇对归纳头的定义有点含糊，更像是找到了一簇常一起出现的行为和机制，把这簇里的头叫归纳头。这篇要论证更大的结论（归纳头在一般的上下文学习中起主要作用，而且在大模型里也是），所以需要更精确的定义。大模型有 MLP，权重层面的机制分析和特征值分析复杂得多，因此作者选择用狭窄的经验行为来定义：在一段重复的随机 token 序列上，一个头如果同时具备下面两个性质，就是归纳头。

  • 前缀匹配（prefix matching）：这个头会注意前面那些“后面跟着当前 token（和/或最近几个 token）”的 token。最简单的归纳头只匹配前一个 token，也常见对前面几个 token 做模糊匹配的头。换句话说，它注意的是“按归纳规则下一个该出现”的那个 token。
  • 复制（copying）：这个头的输出会提高它所注意的那个 token 的 logit。

也就是说，在完全随机的重复 token 序列上，凡是经验上提高了 [A][B]...[A] 之后出现 [B] 的概率的头，都算归纳头。实际中这两个性质不会完美出现，测量结果是一个连续谱，但有一个子集明显远高于随机水平。用随机序列来定义，是为了确认它真的在做归纳，而不是一个普通的复制头凭经验去注意那些“可能适合接在后面”的 token。（2022 年 9 月的更新记录说明，原文曾把前缀匹配错写成“注意前面被当前 token 领先的 token”，已更正为“后面跟着当前 token”。）

原文这里配了一张示意图，展示归纳头在重复序列上的注意力和输出。一个直接推论是归纳头擅长整段重复序列。例如给定 The cat sat on the mat. The cat …，归纳头会推动后面接 sat on the mat。这给出了它和一般上下文学习、甚至少样本学习之间联系的第一个提示：学会重复任意序列，本身就是一种（简单的）少样本学习。

更抽象的版本

作者想证明的一点是：当归纳头出现在足够大的模型里、作用于足够抽象的表示时，做序列复制的同一批头还承担了更广的角色，即“类比式序列复制”或“上下文内最近邻”。它们推动 [A*][B*] … [A] → [B] 这种补全，A* 和 A 不是同一个 token，但在某个嵌入空间里相似，B 和 B* 也不同。例如 A 与 A*（以及 B 与 B*）可能是同一个词的不同语言版本，归纳头就能逐词翻译一句话：找“像 A 的东西”，找到后面跟着 B* 的 A*，然后补全“像 B* 的东西”，也就是 B。作者承认还不能从机制上证明归纳头普遍这样做，但论证 4 会给出经验例子（包括翻译），论证 5 会指出小模型里已知的复制机制很自然地能这样工作。

04. 关键概念：逐 token 损失分析

原文小节：Key Concepts · Per-Token Loss Analysis

为了看清模型在训练中怎样演化，作者分析“逐 token 损失向量”（per-token loss vectors）。这个思路可追溯到 Erhan 等人的方法，更一般地来自数学里的“函数空间”：可以把一个函数看成一个无穷维向量，每个分量是它在某个输入上的取值。对神经网络来说，这样能绕开“功能相同的模型参数可以完全不同”这一点。无穷维向量没法直接表示，就用采样来近似。

具体做法：先准备一组模型。本文的做法是训练几种不同架构的模型，每种在训练中保存几十个“快照”，这些快照就是模型集合。然后让每个快照对同一组 10,000 个随机 token（每个来自不同的样本序列）给出对数似然，拼成一个“逐 token 损失向量”，再做主成分分析（PCA）。原文配了一张流程示意图（多个快照的损失拼成矩阵，再投影到主成分）。

对多个模型的训练快照都做这件事，就能把不同模型的训练轨迹画在同一个“输出空间”里比较。因为用的是 PCA，每个方向都可以理解成模型在其上移动的一个对数似然向量。作者主要看前两个主成分，因为便于可视化；模型当然也在其他方向上移动，但前两个主成分能抓住训练故事的最高层轮廓。

05. 六条论证概览与证据强度

原文小节：Arguments that induction heads are the mechanism for the majority of in-context learning

正文要论证的是：归纳头可能为一般 Transformer 模型的大部分上下文学习提供了主要机制。作者承认这是很宽的假说，很多证据是间接的，但认为所有证据合在一起构成了相对强、但并非决定性的论证。

作者先区分哪里证据更确定、哪里不确定。对只有注意力层的小模型，有消融和机制逆向的支持，证据很强，认为注意力头是大部分上下文学习的机制。对所有模型，都能有力地论证归纳头在上下文学习中起了一些作用，因为能展示例子和有提示性的相关性。但模型越大，越难证明归纳头占了上下文学习的大部分；对有 MLP 的大模型，只能主要依靠相关性证据，而它可能被混杂因素干扰。下表是六条论证加总后的证据强度（每个子论断取最强的那条论证）：

六条论证如下，后面每节对应一条，每节开头也附一张同样格式的强度表：

  1. 宏观共现（Macroscopic co-occurrence）：Transformer 语言模型在训练早期经历一次“相变”，期间归纳头形成，上下文学习同时大幅提升。
  2. 宏观共同扰动（Macroscopic co-perturbation）：改变 Transformer 结构，让归纳头能否形成、何时形成发生变化，上下文学习的大幅提升会精确地跟着移动。
  3. 直接消融（Direct ablation）：在小模型里测试时直接“敲掉”归纳头，上下文学习量大幅下降。
  4. 归纳头通用性的具体例子：虽然归纳头的定义只涉及复制字面序列，但同一批头也实现了更复杂、甚至高度抽象的上下文学习，因此它们解释大部分上下文学习是可信的。
  5. 归纳头通用性的机制合理性：在小模型里能从机制上解释归纳头怎样工作，并能证明它们贡献了上下文学习；它的实际机制也提示它可以自然地被改用于更一般的上下文学习。
  6. 从小模型到大模型的连续性：前五条在小模型上比在大模型上更有力，但许多与归纳头和上下文学习有关的行为和数据从小模型到大模型是平滑连续的，最简单的解释是机制相同。

06. 论证 1：训练中的相变

原文小节：Argument 1: Transformer language models undergo a “phase change” during training, during which induction heads form and simultaneously in-context learning improves dramatically.

贡献一部分中，相关性中，相关性中，相关性
贡献大部分中，相关性中，相关性中，相关性

第一条证据来自把“上下文学习”的指标和“归纳头存在程度”的指标放在整个训练过程里对比。作者在几十个不同尺寸、在不同数据集上训练的模型中观察到两者紧密共变。这条证据对大、小模型都适用，也是“归纳头负责大部分上下文学习”这个假说预期会看到的结果，但它只是相关性，可能被混杂。

上下文学习突然出现，然后保持不变

在训练过程中测上下文学习分数（第 50 个 token 与第 500 个 token 的损失差），会发现它在训练早期一个很窄的窗口里突然形成，大约在 25 亿到 50 亿 token 之间，之后在整个剩余训练中保持不变。窗口之前上下文学习不到 0.15 nats，之后大约 0.4 nats；这个量在后续训练中不变，在很多不同模型尺寸之间也不变。唯一的例外是 1 层模型，它从来没形成多少上下文学习。作者说这有点意外：天真地想，上下文学习应该随训练逐步提升、随模型变大而变好，机器学习里大部分东西都是这样。（脚注提示，后文会讨论为什么同样的 0.4 nats 对更强的模型可以看作“更大”的进步：从更好的基线上再降同样多更难。）

原文图中只展示了三个模型，但这个模式普遍成立，模型分析表里有不同结构和尺寸的大量例子。

有人会问这是不是只是“500 减 50”这个定义造成的假象。一个直接的检查是看损失对 token 位置取对数后的导数，可以理解为“上下文长度每增加 ε% 带来的上下文学习”。作者把它画成二维图：一个轴是已经训练了多少，另一个轴是被预测 token 的位置。相变之前，损失在 token 50 左右基本就不再下降；相变之后，过了这个位置损失仍在下降。

归纳头在同一窗口形成

上下文学习的突然提升并不是这个窗口里唯一的变化。用“前缀匹配分数”（衡量一个头完成定义归纳头那项任务的能力）给模型的每个注意力头打分，会发现归纳头恰好在上下文学习形成的同一窗口里突然出现。例外仍是 1 层模型：归纳头从未形成，上下文学习也从未明显发展。

损失曲线上的鼓包

这个窗口对整个训练过程也是一个枢纽：训练损失曲线上能看到一个鼓包。而且这是训练中唯一一处损失曲线不是凸的地方（即斜率不再单调变小）。这听起来不起眼，但损失曲线是对成千上万个 token 的平均，人们关心的很多语言模型行为（比如算术能力的出现）在损失曲线上根本看不出来。能在这个尺度上被看见，说明是一次大范围、重大的行为变化。对小模型来说，这也是损失曲线第一次和 1 层模型分道扬镳的地方，1 层模型没有这个鼓包，也没有其他突变。

PCA 轨迹的转弯

对逐 token 损失做 PCA，画出几个模型预测在训练过程中的前两个主成分，并用金色框标出上下文学习突然提升的同一区间，会看到训练轨迹恰好在这个窗口里转向。某种意义上，上下文学习提升时发生的事情，是 Transformer 训练基本轨迹上最主要的偏离。唯一例外还是 1 层模型。

小结：四件事同时发生

  • 上下文学习能力急剧提升（用上下文学习分数衡量）。
  • 归纳头形成。
  • 损失出现一个小“鼓包”（这一段损失曲线下降得明显比前后都陡）。
  • 模型的轨迹突然改变（在逐 token 损失空间里，用 PCA 可视化）。

这些结果说明训练早期 25 亿到 50 亿 token 的窗口里发生了某种重要转变，对大模型来说这大约是训练进程的 1% 到 2%。作者称之为“相变”：一次改变模型行为的突然变化，既有宏观表现（损失和上下文学习曲线），也有微观表现（归纳头），类似冰融化成水。作者还提到，相变期间还会发生许多其他奇怪的现象。

07. 论证 1（续）：细看相变与评估证据

原文小节：Looking at the Phase Change More Closely；Assessing the Evidence

排除外部原因

一个自然的解释是：在所有这些模型里，归纳头实现了上下文学习，它们的形成驱动了其他所有变化。作者做了几项检查来加强这个假说。第一，相变窗口并不对应学习率、预热（warmup）或权重衰减的计划变化，没有已知的外部因素触发。第二，把一些小模型换到另一个数据集上训练，相变以同样方式出现。不过除了换数据集的实验，所有模型都以相同顺序看到相同的 token。

哈利·波特第一段：哪些 token 变好、哪些变差

第三，作者定性地看相变期间模型行为的变化：挑一段文本，比较相变开始和结束时每个 token 的对数似然差。作者“为了好玩”用了《哈利·波特》第一章的第一段（脚注强调这只是一则轶事，用来给定性直觉，系统性证据见模型分析表里的“消融对前后向量的归因”分析）。大部分变化出现在文本中被重复多次的 token 上：一段 token 序列如果出现多次，模型在它第二次出现时预测得更好；反过来，如果某个 token 这次后面跟的 token 和上次不同，相变后的模型反而预测得更差。

也可以把损失曲线拆成单个 token 的损失曲线。原文挑了第一段里的两个 token：红色那条是 The Dursleys 四个 token 中的最后一个，这个序列在文中出现多次，它的预测在相变中大幅变好；蓝色那条是 Mrs Potter 第一次出现，前面两次 Mrs 后面都跟着 Dursley，它的预测在相变中明显变差。作者说，相变期间看到的这些行为，和“归纳头贡献大部分上下文学习”时预期看到的行为一致。

支持因果关系的理由

  • 归纳头的形成与模型上下文学习能力的大幅提升相关，在大大小小的多种模型里都如此。
  • 两次急剧转变在这么多模型里纯属巧合同时出现，可能性极低。
  • 两者几乎肯定有关联，最简单的可能是归纳头是驱动上下文学习提升的主要机制（但它也可能是混杂变量）。
  • 最终的上下文学习有超过 75% 是在这个窗口里形成的，天真地看，这可以当作归纳头负责的份额。

需要谨慎的理由

  • 大模型在训练过程上的时间分辨率很低，只有 15 个时间点，在这么少的点上共现，说服力就弱一些。
  • 也许这时还形成了别的机制，它们既促成了归纳头，也促成了其他上下文学习来源。例如，相变可能是模型学会通过残差流组合多层的时刻，这既让归纳头成为可能，也让许多同样需要多个头组合的其他机制成为可能。也就是说，共现可能主要来自一个共同的潜在变量，而不是归纳头直接导致了全部上下文学习变化。
  • 相变后上下文学习分数大致恒定在 0.4 nats，不代表底层机制恒定。这个指标是第 500 与第 50 个 token 的相对损失，而模型在第 50 个 token 上的表现会随训练变好。从更低的基线再降低固定的量可能更难，可能由更多机制驱动。训练早期，模型靠记住 bigram 统计这类简单办法就能大幅降低损失；后期容易摘的果子都摘完了，模型必须学归纳头这类更复杂、更难学、带来信息更少的算法。今天的 GPT-3 这样的模型已经有加法之类的复杂能力，可以想象未来接近完美损失的模型需要人类水平以上的语言理解才能拿到最后零点几个比特。所以 token 50 和 token 500 之间的相对损失，在训练中代表的很可能是越来越难的比特。（脚注说，为什么“上下文学习能力变强”和“边际比特变难”恰好抵消，仍是一个谜；也可能这两类信息重叠不多，所以并没有变难。）

作者因此指出：说归纳头在相变那一刻占了大部分上下文学习，比说它们在训练结束时仍占大部分，要站得住得多，因为即使上下文学习分数不变，训练期间也可能有很多东西在变。

08. 论证 2：改结构，相变跟着移动

原文小节：Argument 2: When we change the transformer architecture in a way that shifts when induction heads form or whether they can form, the dramatic improvement in in-context learning shifts in a precisely matching way.

论证 2 的证据强度
子论断小型纯注意力模型带 MLP 的小模型大模型
贡献一部分中，干预性中，干预性弱，干预性
贡献大部分中，干预性中，干预性弱，干预性

论证 1 的不足在于只是观察共变，像所有观察性研究一样，不如主动改一个变量、看另一个怎么变来得有说服力。这一节做的是一个“干预”实验：改动模型结构，让归纳头更容易形成，观察上下文学习的变化。这个改动对小模型影响更大，所以在小模型上更有说服力，对大模型也有一定分量。

为什么归纳头需要两层

出发点是上一节的观察：相变和上下文学习的提升只出现在多于一层的 Transformer 里。如果归纳头是大部分上下文学习的机制，这就是预期的结果，因为归纳头需要注意力头之间的组合（composition），而组合至少要两层。脚注解释了原因：在归纳头里，注意哪里必须取决于“被注意 token 前面那个 token”；可单个注意力头只用源 token 和目标 token 计算注意力分数。没有前面某个注意力头写进来的信息，被注意 token 处的分数就不可能是它前一个 token 的函数。

1 层模型这一条本身证据很弱（1 层模型和多层模型可能在各方面都不同），但它提示了一条更一般的攻击路线：如果归纳头是上下文学习大幅提升背后的机制，那它就对达到这种提升所需的最低结构提出了预测。对标准 Transformer，关键是要有两层注意力，但这只是因为 key 向量需要同时是“被注意 token”和“它前一个 token”的函数。

“抹开的 key”（smeared key）结构

作者定义了一个很简单的改动，让任何深度的 Transformer 都容易表达归纳头。对每个注意力头 $h$，引入一个可训练的实数参数 $\alpha^h$，用 $\sigma(\alpha^h) \in [0, 1]$ 在当前 token 的 key 和前一个 token 的 key 之间插值（第一个 token 的 key 不变）：

$$k^h_j ~=~ \sigma(\alpha^h) k^h_j ~+~ (1-\sigma(\alpha^h)) k^h_{j-1}$$

这样，单层的注意力头不需要前一层帮忙，key 里就已经带有前一个 token 的信息。“归纳头是上下文学习主要机制”的假说给出预测：加了这个改动后，1 层模型也会出现相变，多层模型的相变可能更早。如果归纳头只是几个主要因素之一，那可能部分上下文学习提升会提前出现，剩下的仍在原相变处出现。

结果与预测一致：用了 smeared key 结构，1 层模型形成了上下文学习（原本没有），2 层及更大的模型上下文学习形成得更早。原文图是模型分析表的节选，模型分析表里有更多 smear 模型和原版模型的对比。

作者提醒不要据此对大模型做太强的推断。这个实验说明归纳头是 Transformer 中大幅提升上下文学习的最小机制，但完全可以想象在更大的模型里它不是全部故事；这个实验也没有否定“上下文学习的机制在训练中会变化”这种可能。

09. 论证 3：敲掉归纳头

原文小节：Argument 3: When we directly “knock out” induction heads in small models at test-time, the amount of in-context learning greatly decreases.

论证 3 的证据强度（大模型没有消融数据）
子论断小型纯注意力模型带 MLP 的小模型大模型
贡献一部分强，因果性强，因果性无
贡献大部分强，因果性中，因果性无

在它覆盖的情形里，消融（ablation，把某个部件去掉再看模型表现）是作者最强的证据。“敲掉”指在测试时把某个注意力头从模型里去掉，做一次没有它的前向传播（具体做法见 方法附录：用的是“保留注意力模式”的消融）。除了看注意力头对上下文学习的贡献，也可以用消融研究它们对相变期间整体行为变化的贡献（见模型分析表）。

原文图（模型分析表的一小部分节选）显示：在小型纯注意力模型里，几乎所有的上下文学习似乎都来自这些归纳头。这从相变开始时就成立，一直持续到训练结束。脚注里有一个反直觉的细节：消融大多数其他注意力头反而会让上下文学习增加。作者的解释是，有些 token 既可以靠“普通预测”猜中，也可以靠上下文学习猜中；如果消融让模型的普通预测变差，原本猜不中的 token 就更多地要靠上下文学习，按定义算出来的上下文学习分数就上升了。

遗憾的是全尺寸模型没有消融数据。脚注给了成本：一整套消融的成本随模型规模超线性增长，约为 $O(N^{1.33})$，因为有 $O(N^{0.33})$ 个头，每次消融是 $O(N)$，$N$ 是参数量；每次消融还要在 10,000 个样本、每个训练检查点上评估，基础成本也不低。

能不能说归纳头是“主要”机制

对有消融的模型，证据明确说明归纳头提高了上下文学习（至少按作者选的评估方式）。能否进一步推断它们是主要机制，作者给了两点考虑：

  • 在纯注意力模型里，上下文学习只能是各注意力头贡献之和。脚注解释：logit 可以写成各注意力头的项加上一条到 token 嵌入的“直接路径项”（差一个 LayerNorm 缩放），直接路径项只依赖当前 token，不可能贡献上下文学习。所以所有上下文学习最终都来自注意力头，而且关系几乎是线性的，冻结注意力模式的消融是衡量它们贡献的有原则的方法。但在有 MLP 的模型里，上下文学习也可能来自 MLP 和注意力层的相互作用。消融注意力头会影响这些机制，但消融效果和真实重要性之间的关系就复杂了。脚注举了例子：消融一个头可能改变某个 MLP 层的统计，相当于移动了神经元的有效偏置，把神经元“弄坏”，而这个头本身并没有实际作用；或者某个重要的 MLP 机制依赖两个注意力头，去掉一个，另一个也能凑合工作。
  • 消融衡量的是去掉单个头的边际效应。如果两个头做类似的事，又有 logit 前的 LayerNorm 重新缩放，单个头的重要性可能被掩盖。

综合起来，作者愿意得出结论：在小型纯注意力模型里，归纳头是上下文学习的主要机制；对有 MLP 的情况，这条证据只是提示性的。

10. 论证 4：归纳头也能做抽象的上下文学习

原文小节：Argument 4: Despite being defined narrowly as copying random sequences, induction heads can implement surprisingly abstract types of in-context learning.

行为 1：字面序列复制

先看最简单的情况：一个直接复制重复文本的头。输入是《哈利·波特》第一段，后面再重复前几句。原文用交互可视化展示两样东西：红色的“Attention”显示这个头为预测下一个 token 注意了哪里；蓝色的“Logit attr”显示前面哪些 token 对当前预测有贡献，用的是“直接路径”logit 归因（把每个位置的 value 向量按注意力矩阵加权，乘以 $W_O$ 和反嵌入矩阵，取对应 token 的 logit；先把 logit 向量减去均值，因为 softmax 的所有输入加同一常数不影响结果）。

这个头会预测重复出现的名字 “Dursley” 和 “Potters”、短语 “a small son”，以及末尾整段重复的句子。所有成功预测都是靠注意回前文这个短语出现过的位置做到的。

行为 2：翻译

语言模型能翻译是众所周知的。作者遇到过许多能做翻译的归纳头，这里展示的是 40 层模型第 7 层的一个头，在英语、法语、德语之间翻译。它同样满足归纳头的定义：看到重复的随机 token 时，用前缀匹配的注意力模式逐字复制。

它的整体注意力模式大致是一条“偏离对角线”的线，但会稍微弯来弯去。原因是不同语言的词序和 token 长度不同：这个头依次注意前文中“语义上接下来会出现”的 token，于是在前面句子里被注意的位置会跳动。它的 logit 归因不太清晰，即使注意到了前一种语言里对应的词，也不总是直接提高对应预测的 logit；作者猜测是因为这个头的输出还要被后面的层进一步处理。但总体上，直接 logit 归因清楚显示它对正确翻译有净贡献。

行为 3：模式匹配

最后一个例子是一个做更复杂模式匹配的头（正文说在 40 层模型的第 26 层），甚至可以看作在上下文中学会一个简单函数。它在重复随机序列上的“基本”归纳行为得分也很高。作者生成了合成文本：每行按四个模板之一生成，后面接一个标签说明是哪个模板，模板和填进去的词都是随机选的。

  • (month) (animal): 0（月份 动物）
  • (month) (fruit): 1（月份 水果）
  • (color) (animal): 2（颜色 动物）
  • (color) (fruit): 3（颜色 水果）

为了易读，图里只把冒号 “:” 当作注意力的目标位置，logit 归因只显示输出为整数 token 的情况。这个头多数时候会注意到前面属于正确类别的一行。它常常知道跳过“某个词相同但模式不对”的行，例如 “January bird” 主要注意 “April fish”（同属“月份 动物”模板），而不是 “grey bird”（“颜色 动物”，只有 bird 这个词相同）。它不完美，但在一系列类似问题上测试，大约 65% 的注意力从冒号分配到了正确位置。

这些更抽象的头为什么也是归纳头

作者再次强调：上面这些头同时实现了抽象行为，而且完全同一个头（同一层的同一个头）也满足归纳头的形式定义（用前缀匹配复制随机序列的字面内容）。这不是比喻，也不是把定义放宽。

为什么同一批头既做随机文本的归纳复制，又有其他行为？一个线索是这些行为和复制“精神上相似”：定义里的规则是 [A][B] … [A] → [B]，观察到的头还做 [A*][B*] … [A] → [B]，A*、B* 在某种更高层表示里与 A、B 相似。几种可能的联系：一是字面复制是翻译的特例（把英语“翻译”成英语就是字面复制），也许归纳头实现的是更一般的算法，给它重复序列时就退化成复制；二是归纳头沿着只经过它自己的残差流路径时做字面复制，而当它处理前面层产生的更抽象表示（比如同一个词的英文和法文被嵌到同一位置）时，就做更抽象的行为。论证 5 会给出机制层面的说明。

关心归纳头是否驱动上下文学习，一个主要原因是我们能理解归纳头，从而有一条理解上下文学习的路。反过来，也可以从对归纳头的理解出发，做一个纯逻辑的论证：它们应当贡献上下文学习。

半经验的论证

先假定归纳头确实像描述和观察到的那样工作：在上下文中搜索之前的例子，复制接下来发生的事。这样的过程应当提升模型预测后文 token 的能力。这相当于把前文当作最近邻算法的数据点，而数据点越多，最近邻效果越好。所以如果归纳头如描述那样存在，就会按本文定义贡献上下文学习。如果只论证“存在一些情况下归纳头贡献了上下文学习”，这个论证很强：前面已经看到归纳头通过复制前例改进预测的具体例子，至少在这些情况里它们一定有帮助；按随机重复序列给出的定义，它们的这种行为也相当普遍。这个论证不说明归纳头占多大比例，但有力地说明在大、小模型里都占了一部分。

去掉对经验观察的依赖

这条思路更让人满意的地方在于，可以去掉对归纳头行为的经验观察，代价是论证更复杂。上一篇在参数层面逆向了归纳头，说明它们怎样（以及为什么应当）实现归纳行为；如果信任那份分析，不用运行就知道它们的行为，上面的论证就成立。局限是：上一篇只逆向了一个小型纯注意力模型里的一个归纳头（作者说其他的也能逆向，也做过）；更大的问题是目前还不能逆向有 MLP 层的模型中的归纳头。但至少在一些观察到的情形里，可以看着 Transformer 的参数认出归纳头，就像程序员读源代码认出一个算法。

对上一篇逆向过的两层纯注意力 Transformer，还能再进一步：不仅理解归纳头、知道它们应当贡献上下文学习，而且似乎没有别的机制能驱动它。脚注说，唯一可能的竞争者是普通的复制头，但 1 层模型里也有复制头，而 1 层模型没有两层模型那样大幅增加的上下文学习；归纳头在概念上也更强大。这说明至少在很小的模型里，归纳头是上下文学习的主要驱动。

归纳头逆向工程摘要

原文提醒这一节是带指针的浓缩摘要，不读上一篇的对应部分很难跟上（可对照本合集 01 篇）。

复制由 OV（输出-值，Output-Value）电路完成。复制是归纳头的定义性质之一，但不只归纳头会复制：Transformer 里有相当多的复制头，归纳头是其中的子集。复制靠的是一个“复制矩阵”形式的 OV 电路，最容易用它的正特征值来刻画。

前缀匹配由 QK（查询-键，Query-Key）电路里的 K 组合（K-composition）实现，Q 组合的作用较小。要做前缀匹配，被注意 token 处的 key 向量需要包含前面 token 的信息；事实上，被注意 token 本身的信息对计算归纳注意力模式无关紧要。（脚注：被注意 token 只是在通过 QK 电路计算注意力模式时被忽略，它对通过 OV 电路计算输出极其重要；计算注意力模式和计算输出的部分是可分离的。）在作者研究的模型里，这种“key 平移”主要通过 K 组合发生：归纳头的 $W_K$ 读取的子空间，是更早一个注意力头写入的。最基本的归纳头与一个更早的“前一个 token 头”做纯 K 组合，形成 QK 电路中如下形式的一项：

$$\text{Id}\otimes h_{prev} \otimes W$$

其中 $W$ 有正特征值。这一项让归纳头把当前 token 和每个更早位置的“前一个 token”比较，找相似的地方。更复杂的 QK 项可以造出不止匹配前一个 token 的归纳头。原文配图说明：归纳头用前面的头平移 key 信息，与当前 token 匹配；变得更复杂时，也会平移 query 信息。

两者合起来就是一个可检测的归纳头机制。在上一篇研究的小模型里，所有归纳头都有这个 QK 项驱动注意力模式，并有一个正特征值电路做复制。

GPT-2 里的另一种机制

有些模型用不同机制实现归纳头。在 GPT-2 中，作者看到过第二种“指针算术”（pointer-arithmetic）机制的证据，它用到位置嵌入和 Q 组合：前面一个注意力头注意当前 token 之前出现过的副本，它的 OV 电路把这些副本的位置嵌入复制到当前 token 的一个子空间里；归纳头再用 Q 组合把这个位置嵌入“向前旋转一个 token”，从而注意到下一个 token。本文研究的模型不往残差流里加位置信息（用的是类似 Press 等人的位置机制），所以用不了这种机制。

更复杂的归纳头

论证 4 里那些行为更复杂的归纳头能不能逆向？是不是同一机制？目前完全逆向它们做不到，因为它们在有 MLP 的大模型里，而作者还没有理解 MLP 的强有力框架。作者的假设是它们在两方面不同：（1）用更复杂的 QK 项，而不只匹配前一个 token；（2）匹配和复制的是更抽象、更复杂的语言特征，而不是精确的 token。归纳头最早被介绍时就被看作一种“上下文内最近邻”算法，从这个角度看，把同一机制用到更抽象的特征上产生更复杂的行为，是很自然的。

这条论证是对前面所有论证的延伸推断。论证 1 到 5 相当有力地说明在小 Transformer（尤其是小型纯注意力模型）里归纳头负责大部分上下文学习，对大 Transformer 证据没那么强。能在多大程度上从小模型推到大模型？这是判断问题。

模型分析表里的测量在小型纯注意力模型、带 MLP 的小模型、全尺寸模型三种情形下看起来完全类似：只要多于一层，都经历相变；都有同样急剧的上下文学习提升，前后量级也大致相同；在 PCA 空间里画出相似的路径；都形成归纳头。作者反问：如果从小模型到大模型情况变了，是在哪里变的？为什么所有测量里都看不到变化的迹象？

另一方面，大模型和小模型行为差别很大的例子也很多（见相关工作中关于随规模出现相变的讨论），把小模型的结论外推到大几个数量级的模型要谨慎。

作者认为最有力的替代可能是：相变期间也形成了其他的组合机制。大模型头更多，有余力表达小模型负担不起的其他有趣的 Q 组合和 K 组合机制。如果所有“组合头”都在相变中同时形成，那么超过某个规模后，非归纳的组合头合起来可能比归纳头贡献更多的相变和上下文学习提升。

13. 模型分析表与模型细节

原文小节：Model Analysis Table；Model Details

上述论证基于对 34 个仅解码器（decoder-only）Transformer 语言模型的分析，每个模型训练一次，训练过程中保存多个快照。模型来自四个系列：

  • “小型纯注意力模型”：1 层到 6 层，没有 MLP，专为本研究训练。
  • “带 MLP 的小模型”：1 层到 6 层，有注意力层和 MLP 层，专为本研究训练。
  • “全尺寸模型”：一系列逐步变大的带 MLP 模型，从 4 层 1300 万参数到 40 层 130 亿参数，是 Anthropic 多个项目的基础。
  • “smeared key 模型”：有针对性的结构实验，让任意深度的 Transformer 都能表达归纳头。

小模型和 smeared key 模型的训练数据是 Askell 等人描述的数据集的早期版本：过滤后的 Common Crawl 数据、网络图书，以及若干较小的分布，其中约 10% 是 Python 代码。全尺寸模型用的是大致相同分布的改进版。另外有一组小模型改在只含网络图书的数据集上训练，用来考察换数据集的影响。同一数据集上训练的所有模型以相同顺序看到相同样本，没有模型看过同一份训练数据两次。

原文的模型分析表是一张大型交互图表：每行是一种测量（PCA 轨迹、损失曲线、二维上下文学习图、二维损失导数图、上下文学习分数、前缀匹配分数、QK 特征值迹、消融对前后向量的归因、消融对上下文学习分数的归因），每列是一个模型，并附一句说明。各行的计算方法见 附录。

小模型

小模型是 1 到 6 层的 Transformer，包括有 MLP 和无 MLP（纯注意力）两类。上下文窗口 $8192$ 个 token，词表 $2^{16}$，残差流维度 $d_{model}=768$，无论模型多大每层都是 $12$ 个注意力头。训练 10,000 步（约 100 亿 token），每 $50$ 步存一个快照，共 $200$ 个。位置嵌入用的是标准位置嵌入的一个变体（类似 Press 等人）。

在小模型中，“相变”大约出现在 10 亿到 30 亿 token 处（原文 $1$–$3$ billion）。有人会问这些现象是否由超参数的计划变化引起。权重衰减在第 $4750$ 步（约 50 亿 token）时降低，其效果在所有模型损失曲线的大约中间位置表现为一个轻微偏折，位置完全相同；这一步远在相变范围之后，与相变无关。相变范围内唯一的其他超参数变化是学习率预热，它在前 $1.5e9$ 个 token 中逐渐升高。

全尺寸模型

全尺寸模型与 Askell 等人描述的是同一组模型。上下文窗口和词表与小模型相同（$8192$ 和 $2^{16}$）。与小模型不同，它们的维度随规模放大：激活维度 $d_{model} = 128 * n_{layer}$，注意力头数各不相同。它们同时有稠密注意力头和局部注意力头：局部头里每个 token 只能注意固定相对窗口内的更早 token；稠密头就是标准头，可以注意任何更早的 token（包括自己）。

快照按指数步数保存，间隔 $2\times$。分析使用第 $2^5$ 到第 $2^{17}$ 步的快照，再加之后的一两次最终保存，共 $15$ 个（$40$ 层模型是 $14$ 个）。这与小模型按线性间隔存 200 个快照不同，只有 14 或 15 个点，判断曲线形状就没那么有把握。到第 $2^{11}$ 步（$= 2.15e09$ 个 token）为止，各模型看过的 token 数一致，之后训练计划调整，$24$ 层和 $40$ 层模型每步的 token 数增加。

14. 尚未解释的现象

原文小节：Unexplained Curiosities

看似恒定的上下文学习分数

论文里最奇怪的观察之一是：相变之后，所有模型的上下文学习分数（第 500 个 token 的损失减第 50 个 token 的损失）差不多一样。不管是很小的 2 层模型还是 130 亿参数的大模型，不管是刚经历相变还是训练了很久，似乎唯一要紧的是有没有经历过相变。

这会不会是定义随意造成的？作者把大模型的“上下文学习分数”改成上下文最后一个 token（第 8192 个）与其他各位置的损失差，画了一张图。模型之间有小差别（按某些定义，小模型的“上下文学习”甚至略多一点；脚注说在 token 100 附近，小模型每个 token 降低的损失比大模型略多，作者解释为小模型在摘大模型在很早期上下文里已经摘过的低垂果实），但所有定义都显示，模型之间上下文学习量差别很小。

怎么解释？首先，大模型在所有位置上仍然比小模型预测得好，而且在后面的 token 上最好。实际情况是：大模型相对小模型的优势在上下文很早的地方就全部拿到了，事实上大部分差距形成在前十个 token 里。大模型似乎能从很早的上下文里榨出大量信息（部分原因可能是它们有更多世界知识，不需要从上下文中获取那么多信息），然后在剩余上下文里再降低一个大致固定的量（小模型在上下文中段收益略多，稍微追上一点，但效应很小）。这个固定的量对大模型可能是“更难的上下文学习”，因为起点损失更低。作者说，为什么不同模型的上下文学习分数相同仍然是个谜，但这个视角让它从“震惊”降为“奇怪”。

相变对损失导数的影响

另一个醒目的观察：看不同尺寸模型损失曲线的导数，它们的大小顺序在相变处调换。最容易看的方式是画损失对已训练 token 数取对数的导数（损失曲线通常在对数横轴上最好分析）。相变之前，小模型的损失下降得比大模型慢；相变之后正好相反。小模型在早期训练学得更快不算意外，但这个反转恰好和相变同时发生，是又一条说明相变是 Transformer 训练重要转折点的证据。

其他怪现象

模型分析表里：

  • 6 层纯注意力模型在训练后半段长出一个不寻常的头。它不是归纳头，但消融它的效果类似于把相变倒回去（在“前后向量”归因图上）。它是什么？
  • 4 层 MLP 模型的消融结果远不如其他模型那样“尖”。它的发展有什么不同？
  • 6 层 MLP 模型出现了一次“损失尖峰”（loss spike），作者还不知道损失尖峰的原因。
  • 6 层 MLP 模型有一个孤零零的归纳头，消融它对上下文学习分数的效果和其他归纳头相反。它是什么？

15. 讨论：安全含义与学习动力学

原文小节：Discussion · Safety Implications；Linking Learning Dynamics, Scaling Laws, and Mechanistic Interpretability

安全含义

研究的最终动机是：逆向神经网络可能帮助我们对它们的安全性有信心。本文只是很初步的一步，但已经触及几个与安全有关的问题：

  • 相变：如果神经网络的行为在不同规模之间不连续地变化，研究者和社会就更难为未来的问题做准备。
  • 上下文学习：它一直是安全社区担忧和猜测的话题。对能力较弱的网络，人们可能倾向于把训练后的行为看成相对固定（不过对抗性重编程的演示已经让这个假设打了折扣）。上下文学习说明模型行为在推理时可以某种意义上“改变”，无需再训练。即使把上下文学习理解为“定位”已学到的行为，而非学新东西，这种行为也可能是出人意料的、不想要的分布外泛化。
  • mesa 优化：有人担心上下文学习的底层机制可能是 mesa 优化，即模型内部发展出一个优化算法。本文的工作说明，至少在小模型里，上下文学习的主要机制是归纳头。作者没有观察到 mesa 优化器的任何证据。

连接学习动力学、缩放定律和机制可解释性

上下文学习相变可能是一块有用的“罗塞塔石碑”，把机制可解释性、学习动力学，以及神经网络那些类似统计物理的经验性质（缩放定律、相变）连起来。想研究这些方向的交汇，相变是理想起点：这些研究线索在这里交织在一起，可以在小模型里研究，限定在训练过程的一小段，还连着社区感兴趣的一项能力（上下文学习）。

16. 相关工作

原文小节：Related Work

本文逆向 Transformer 的整体方法大量依赖上一篇《A Mathematical Framework for Transformer Circuits》，与其他可解释性工作的关系请看那篇的相关工作。这里只谈本文新引出的、与机器学习文献的联系。

上下文学习

GPT-3 有力地展示了涌现的上下文学习。很多论文研究怎样利用它（尤其是提示工程），也有几篇研究上下文学习如何、何时发生。与归纳头假说一致或支持本文方法的：Kaplan 等人是用不同位置的损失来研究上下文学习这一做法的来源；O’Connor 和 Andreas 发现保留上下文中的词序很重要，正如归纳头假说所预期。

与归纳头假说有张力的：

  • O’Connor 和 Andreas 的一些实验显示，去掉名词以外的所有词可以改善损失，这似乎与归纳头假说不一致。但他们只在用修改后的数据重新训练模型的实验中发现这一点。这与本文关系较远（本文研究在自然数据上训练的模型），也不好解读（重新训练会引入不同运行之间的损失波动，而测到的损失差很小）。他们不重新训练的实验与归纳头假说一致。
  • Xie 等人发现，在由隐马尔可夫模型（HMM）生成、用于隔离某个上下文学习理论模型的合成数据上，LSTM 比 Transformer 表现更好。作者一般预期在自然文本上 Transformer 的上下文学习胜过 LSTM（如 Kaplan 等人所见），归纳头是主要解释；但 Xie 等人的实验不用自然文本，作者怀疑合成数据的结构不利于 Transformer 发挥，而 LSTM 可能更擅长模拟 HMM。

本文用的是比“少样本学习”更宽的上下文学习概念。Brown 等人描述语言模型“发展出一组广泛的技能和模式识别能力，然后在推理时用这些能力快速适应或识别所需任务”，举的例子是几位数加法、纠正拼写。本文的上下文学习指模型快速适应或识别上下文中正在发生什么的所有方式，即使“上下文中发生的事”并不适合被理解为某个特定任务的多个“样本”。

缩放定律

近几年，“模型按缩放定律平滑、可预测地变化”这一观察成了在训练前预测模型属性的有用工具。作者把缩放定律与机制可解释性的关系类比为热力学与单个粒子物理的关系：两者都在复杂系统里找到变量间的简单关系（热力学是熵、温度、体积、压强；神经网络是损失、计算量、参数量、数据量），而机制可解释性研究单个电路，有点像细致研究单个粒子。物理学里这两层抽象由统计物理连接起来。

机器学习里能不能连接这两层？作者说，归纳头相变是他们所知的第一座桥：一个宏观损失层面的现象，可以在电路和机制可解释性层面解释。归纳头还可能解释缩放定律以前观察到的例外：本文中 1 层 Transformer 与更深的模型很不一样，Kaplan 等人此前也发现 1 层 Transformer 不遵循更大 Transformer 的缩放定律。一个相当可信的原因是 1 层模型没有归纳头。原文此处配了一张缩放定律图，显示 1 层模型偏离其他模型的趋势。

相变与不连续行为

缩放定律描述的是平滑关系，但近来一批结果让情况更微妙：

  • Brown 等人发现，总体损失随模型规模可预测地变化，但做算术等具体任务的能力会突然改变。
  • Power 等人观察到“顿悟”（grokking）：模型在训练中从随机水平不连续地跳到完美泛化。
  • 双下降（double descent）：模型变大时性能先因过拟合变差（“经典”区间），过了某个点又变好（“现代”区间）。双下降的推广可以针对参数量、数据量或训练量。它们在损失上不是不连续的，但是令人意外的趋势反转，也许在导数上是不连续的。

更一般的讨论见 Steinhardt 的博客。本文观察到的不连续相变最接近 grokking，因为都发生在训练过程中。作者认为自己对这批文献的主要贡献，是把观察到的变化与归纳头的形成联系起来，并给出相关电路的参数层面理解。就作者所知，归纳头是第一个给机器学习中的相变提供机制解释的例子。

学习动力学

如果神经网络真的能用电路从机制上理解，那几乎必然存在某种用电路变化的动力学来理解学习过程的方式，归纳头是这两者之间一座初步的桥。Saxe 等人得到了无激活函数的线性神经网络学习动力学的闭式解，提供了在简化情形下思考网络学习的方式；后续工作还探讨了与模型学习表示语义信息的联系。粗略地说，他们发现线性网络可以理解为一组独立路径的演化，每条路径对应数据的一个主成分，这些路径可以被看作电路。另一条线是研究神经网络损失曲面的几何。作者对这里的联系想得比较浅，但认为损失曲面的某些方面一定和电路的形成有关；具体地，本文描述的相变必定对应 Transformer 损失景观里某个很大的特征。

普适性

在可解释性和电路研究的语境里，“普适性”（universality）或“收敛学习”指多个模型发展出相同的特征和电路。Circuits 系列认为普适性决定了什么样的可解释性研究有意义，原文引了这段话：

[I]magine the study of anatomy in a world where every species of animal had a completely unrelated anatomy: would we seriously study anything other than humans and a couple domestic animals? In the same way, the universality hypothesis determines what form of circuits research makes sense. If it was true in the strongest sense, one could imagine a kind of “periodic table of visual features” which we observe and catalogue across models. On the other hand, if it was mostly false, we would need to focus on a handful of models of particular societal importance and hope they stop changing every year.
（大意：设想一个世界里每种动物的解剖结构都毫不相关，我们还会认真研究人和几种家畜以外的动物吗？普适性假说同样决定了哪种电路研究有意义。如果它在最强意义上成立，可以设想一张跨模型观察、编目的“视觉特征元素周期表”；如果它大体不成立，我们就只能盯着少数对社会特别重要的模型，并希望它们别每年都变。）

普适性研究始于 Li 等人，他们发现许多神经元与同一模型重新训练版本中的神经元高度相关。后来许多论文表明，神经网络整体上发展出共享大量信息的表示。Circuits 系列试图把普适性从特征扩展到电路，发现至少某些被充分刻画的神经元家族在不同结构的网络里反复出现，而且实现它们的电路也相同。语言模型注意力头的可解释性文献常隐含某种普适性，例如普遍认为“前一个 token”注意力头在许多 Transformer 语言模型中都会形成。这种“普适注意力头”（不同模型里有相同注意力模式的头）和视觉里的特征普适性不完全一样，但类似。本文像之前的注意力头论文一样，把归纳头描述为普适的注意力模式；对 OV 和 QK 电路的分析把普适性主张扩展到电路层面；对 OV 电路分析的一个推论是关于这个头计算什么特征的主张（大致是：当前 token 之前某个副本后面那个 token 的嵌入），这更接近传统的普适性研究。此外，越来越多研究表明生物和人工神经网络学到相似的表示，Goh 等人发现人脑中的多模态“概念”神经元（如著名的“Jennifer Aniston 神经元”）也出现在神经网络里。

类似翻译任务中的注意力模式

论证 4 里有一个帮助实现翻译的归纳头。作者不知道先前文献里有这么一般的东西，但有些报告的注意力模式回头看有些相似：在类似翻译的任务中，注意力常常落在即将被翻译的 token 上，字面翻译中如此，语音识别中也如此（模型注意即将被转写的那段音频）。在编码器-解码器的可视化里，解码器按每个时间步预测的输出 token 来画，而不是按它的输入 token，这稍微掩盖了注意力模式的归纳性质。

原文小节：Comments & Replications；Change Log

仿照原 Circuits Thread 和 Distill 的讨论文章形式，作者邀请了几位同样在研究归纳头的外部研究者发表评论。

Adam Scherlis（Redwood Research）的复现

Redwood Research 发现归纳头在两层纯注意力 Transformer 里稳定出现，结构大致符合上一篇“分析两层模型”一节的描述：第 0 层有前一个 token 头，第 1 层有归纳头（常常各一个），注意力行为都符合预期。他们把注意力分数矩阵换成理想化版本，比较损失变化与消融该头的损失变化：把前一个 token 头的分数换成精确的“注意前一个 token”，恢复了 99% 的损失差；把归纳头的分数换成一个简单近似（注意第一个 token，以及精确的 [A][B]...[A] 匹配），恢复了约 65%。他们的归纳头还匹配 [A][B][C]...[A][B]→[C] 形式的模式，把这一点加入替换分数后又多恢复了 10%。归纳头的 OV 电路复制 token，包括对语义相近 token 的一些模糊匹配；QK 电路以与前一个 token 头的 K 组合为主：前一个 token 头的 OV 矩阵把信息复制到一个新子空间，归纳头的 QK 矩阵再把它复制回通常的 token 嵌入。他们还编目了几种其他注意力头，包括 skip-trigram 头。

Tom Lieberum（阿姆斯特丹大学硕士生）的复现

他用本文的经验判据在公开模型里找归纳头：在 [A][B] .... [A] → [B] 序列上，如果一个头在读到后一个 [A] 时注意前面的 [B]，并且前面的 [B] 提高了后一个 [B] 的 logit，就是归纳头。按这个定义，他在 GPT-2 和 GPT-Neo 中找到了可能的归纳头，大多从中间深度开始，并做了一个交互版本，在重复第一段的《哈利·波特》长提示上浏览所有层和头的注意力与 logit 归因。例如 GPT2-XL 第 21 层第 20 号头，GPT-Neo-2.7B 第 12 层第 0 号头。对这些头，重复段落里几乎每个 token 都注意原段落中它后面那个 token。算力由 EleutherAI 提供。

论文某处推测了形成归纳头所需的最小上下文长度。他在一个合成数据集上发现，上下文长度为 4 时归纳就很容易学会。但他认为这一般是数据集或数据分布的属性，而不是模型本身的属性，即“归纳对这个数据集上的这个任务有多有用”。他觉得这样思考语言统计很有意思，但不确定这条研究线对整体可解释性项目有多大用处。

19. 附录：数据采集与分析方法

原文小节：Data Collection；Analyses

作者测量了模型整体行为和每个注意力头的若干属性。除了计算最重的注意力头消融（只在小模型上做），其他属性都在所有模型的所有快照上测量：12 个小模型各 200 个快照，6 个全尺寸模型各 14 或 15 个快照。这样能看到每个属性在训练中怎样演化，而不只是最终模型。采集的数据有四类：

  1. 未改动模型的逐 token 损失；
  2. 逐个消融注意力头后的逐 token 损失；
  3. 用“头激活评估器”做的经验测量：基于观察到的激活，启发式地给头的“复制”“前缀匹配”“前一个 token 注意”打分；
  4. 数学测量：前一个 token QK 电路项的特征值之迹，衡量 $W_QW_K$ 权重矩阵在多大程度上读取被“注意前一个 token 的头”影响的子空间。

（1）逐 token 损失

每个快照在 10,000 个从数据集随机抽取的样本上运行，每个样本长 512 个 token，保存每个 token 的损失。这组样本在所有快照、三个模型家族的所有模型间保持不变。分析时有两种汇总：

  • 每个样本取一个随机 token：每个样本只保留 512 个 token 中随机一个的损失，得到每个快照一个长度 10,000 的向量（随机位置在各模型间一致）。
  • 按上下文位置平均：按位置对损失取平均，得到每个快照一个长度 512 的向量，第 $i$ 个分量是 10,000 个样本在位置 $i$ 上的平均。

（2）注意力头消融

研究单个头的一种办法，是比较完整模型与“只少了这个头、其他完全相同”的模型的整体行为。做法是依次把每个注意力头对残差流的贡献清零。原文把它比作生物学的基因“敲除”实验。有两种消融方式（模型分析表只展示后一种）：

两种消融方式
完全消融（full ablation）保留模式的消融（pattern-preserving ablation）
方法运行模型，把被消融头的结果向量换成零向量第一遍运行模型，保存所有注意力模式，丢弃输出 logit；第二遍运行时把被消融头的结果向量换成零向量，并强制所有注意力模式等于第一遍记录的值
结果所有下游计算都受影响，包括所有 Q、K、V 计算和注意力模式只影响下游的 V 计算，不影响 Q、K 计算；该头对后面层注意力模式的贡献被保留

能这样做本身就是上一篇洞见的一个应用：每个注意力头的注意力模式和输出向量由不同的参数电路计算，可以分开运行和研究。脚注补充：冻结注意力模式后每个头的作用是纯线性的，所以在纯注意力模型里，保留模式的消融等价于从输出 logit 中减去所有含该头的项；有 MLP 的模型由于非线性不成立。这是最耗算力的测量，好在由许多单 GPU 小任务组成，常常能用“空闲”算力跑。与上一篇的消融相比，相同点是冻结模式；不同点是这里一次只改一个头，而上一篇做的是 $n$ 阶项消融，一次操纵所有注意力头并迭代 $n$ 次。

（3）头激活评估器

三种启发式测量，基于在示例数据上观察到的激活：

  • 复制：这个头对残差流的直接作用，是否提高了与被注意 token 相同的 token 的 logit？
  • 前缀匹配：在重复的随机 token 序列上，这个头是否注意那些“后面跟着与当前 token 相同的 token”的更早 token？
  • 前一个 token 注意：这个头是否注意紧挨在当前 token 前面的那个 token？

“复制”取决于 OV 电路，“前缀匹配”和“前一个 token 注意”取决于 QK 电路。同时具有复制型 OV 电路和前缀匹配型 QK 电路的头，按定义就是归纳头；“前一个 token”头可以作为后面某层归纳头的算法部件。每个分数在 10 个样本上平均，具体实现：

  • 复制：生成 25 个随机 token 的序列（排除最常见和最不常见的 token）。计算这个头对残差流的贡献，沿“直接路径”经反嵌入转成对每个 logit 的影响；logit 先减去均值再过 ReLU，只关注被提高的部分。计算它对被注意 token 的 logit 提高量占对样本中所有 token 提高量的比例。这个值从 0（只提高其他 token）到 0.5（只提高当前 token），再缩放到 -1 到 1。
  • 前缀匹配：生成 25 个随机 token 的序列（同样排除最常见和最不常见的），重复 4 次，前面加一个“序列开始”token。计算注意力模式，前缀匹配分数是：从某个 token 指向“更早重复中同一 token 前面的那些 token”的所有注意力权重的平均。脚注承认复制评估器本该也加序列开始 token，但当时漏了；不加的话，一些在真实数据上做前缀匹配的头在测试序列上会得到异常低的分数。
  • 前一个 token：从训练分布取一个样本，计算注意力模式，取所有从 token $i$ 指向 token $i-1$ 的注意力权重的平均。

（4）前一个 token QK 电路项的特征值之迹

这是基于 01 篇概念的另一种前缀匹配测量：衡量 QK 电路中对应“与注意前一个 token 的头做纯 K 组合”那一项的 $W$ 矩阵，其特征值整体有多大、多正。$W$ 的正特征值表示“同类匹配”，即倾向于让 query 和 key 的这一部分相同；与“前一个 token”项相关联的同类匹配 $W$，是实现基本前缀匹配的简单方式。

“QK 电路”指作用在 one-hot token 向量 $t$ 上、算出某个头注意力模式 $A^h$ 的整个变换 $C_{QK}^h$：$A^h~=~ \text{softmax}^*\!\left( t^T \cdot C_{QK}^h t \right)$。$C_{QK}^h$ 可以展开成很多项，每项对应把 token 映射到该头注意力分数所需的一条路径；01 篇给出了两层模型的完整展开，层数更多项更多。这里只取最简单、可能贡献归纳头前缀匹配的项：纯 K 组合项（query 一侧只是来自嵌入的直接路径），而且只取其中与“稳定注意前一个 token 的更早头”做 K 组合的子集。计算步骤：

  1. 对更早各层的每个注意力头，在一段示例文本上取注意力模式沿“前一个 token”副对角线的平均，衡量它有多像前一个 token 头。
  2. 对更早层的每个头，计算 $Id \otimes A^{h_k} \otimes {W^T_E W^h_{QK} W^{h_k}_{OV} W_E}$ 这一项中的 $W$ 矩阵。
  3. 用第 1 步的“像前一个 token 头的程度”给第 2 步的矩阵加权，合成一个 $W$。
  4. 计算合成 $W$ 的迹（即特征值之和）。

这个指标依赖与更早层的 K 组合，因此只对多于一层的模型、第二层及以后的头有定义。

分析：逐 token 损失的几种视图

  • 损失曲线：“每个样本一个随机 token”的数据是一个（N 个快照 × 10,000 个样本）的矩阵，小模型 N = 200、全尺寸模型 N = 15，在样本维度上平均得到每个快照的平均损失。
  • 二维上下文学习图：“按位置平均”的数据（N 个快照 × 512 个位置）直接画成二维图，显示模型在上下文前后位置、以及训练时间上的表现，这个技术借自 Kaplan 等人。横切一条是某个位置的损失随训练步数的曲线，纵切一条是某个快照的预测能力随位置的变化。

分析：消融对相变的归因

只对小模型，模型分析表最后两行展示保留模式消融的结果（完全消融的结果在附录里），全尺寸模型没有做消融。

  • 对“前后向量”的归因：对一个模型，用“相变结束”快照的“每样本一个随机 token”损失减去“相变开始”快照的，得到一个长度 10,000 的向量，表示模型行为在相变中怎样变化，归一化为单位向量，称为前后向量（before-and-after vector），可以看作受相变影响的“token 损失空间中的方向”。消融某个头也会让快照的行为变化，得到一个长度 10,000 的变化向量（消融后的逐 token 损失减去未消融的）。两者的点积衡量相似度。对归纳头，这个点积为负，说明去掉归纳头就像撤销了相变期间模型行为的变化。
  • 对上下文学习分数的归因：上下文学习分数定义为 $\text{Loss}(n_{train}, i_{context}=500) - \text{Loss}(n_{train}, i_{context}=50)$，看消融每个头后它怎样变化。

这篇的要点

  • 研究对象是 34 个仅解码器 Transformer（小型纯注意力 1 到 6 层、带 MLP 的小模型 1 到 6 层、4 层 13M 到 40 层 13B 的全尺寸模型、smeared key 模型），做了超过 50,000 次注意力头消融。
  • 上下文学习用 Kaplan 式定义衡量：第 500 个 token 与第 50 个 token 的损失差。归纳头用行为定义：在重复随机序列上同时具有前缀匹配和复制两个性质。
  • 论证 1：多于一层的模型在训练约 25 亿到 50 亿 token 时经历相变，上下文学习从不到 0.15 nats 跳到约 0.4 nats，归纳头同时形成，损失曲线出现唯一一处非凸的鼓包，PCA 轨迹转弯；1 层模型都没有。最终上下文学习超过 75% 在这个窗口形成。
  • 论证 2：smeared key 结构 $k^h_j = \sigma(\alpha^h) k^h_j + (1-\sigma(\alpha^h)) k^h_{j-1}$ 让 1 层模型也出现上下文学习，让多层模型更早出现。
  • 论证 3：在小型纯注意力模型里，几乎所有上下文学习都来自归纳头，从相变开始一直到训练结束；消融大多数其他头反而让上下文学习分数上升。大模型没有消融数据。
  • 论证 4：40 层 13B 模型里，满足严格定义的归纳头还能做字面复制（复制 0.89、前缀匹配 0.75）、英法德翻译（0.20、0.85）和抽象模式匹配（0.69、0.94，约 65% 的注意力落在正确位置）。
  • 论证 5：机制上，复制靠有正特征值的 OV 电路，前缀匹配靠与前一个 token 头的 K 组合，QK 项形如 $\text{Id}\otimes h_{prev} \otimes W$；GPT-2 里还有一种用位置嵌入和 Q 组合的“指针算术”机制。
  • 论证 6：各类模型的测量从小到大平滑连续，最简单的解释是机制相同；最强的替代解释是更大的模型在相变中形成了更多非归纳的组合头。
  • 证据强度：小型纯注意力模型上“归纳头贡献大部分上下文学习”是强因果证据；带 MLP 的小模型是中等因果证据；大模型是中等相关性证据。
  • 未解释的现象：相变后所有模型的上下文学习分数几乎相同（大模型的优势主要在前十个 token 内拿到）；不同尺寸模型损失导数的大小顺序在相变处反转；若干异常头和损失尖峰。
  • 归纳头在小型纯注意力模型里形成在最后一层，在 24 层和 40 层模型里大多形成在深度一半之前。
  • 作者没有观察到 mesa 优化器的证据；认为归纳头相变是第一个在机制层面解释机器学习相变的例子，是连接缩放定律与机制可解释性的一座桥。
  • 外部复现：Redwood 在两层模型中用理想化注意力替换，前一个 token 头恢复 99% 损失差，归纳头简单近似恢复约 65%，加上 [A][B][C]...[A][B]→[C] 再多 10%；Tom Lieberum 在 GPT-2 和 GPT-Neo 中找到归纳头。
