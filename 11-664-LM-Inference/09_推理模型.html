第九讲：推理模型

什么是推理模型，STaR 与合理化，策略梯度，DeepSeek-R1 与 GRPO 的裁剪目标，"顿悟时刻"与蒸馏，推理模型对推理成本的影响，认知行为与中期训练，长思维链的余弦长度奖励，数学推理能否迁移、为什么 RL 比 SFT 迁移得好，以及 s1、长度控制、Stream of Search 与自适应并行搜索

主讲：Graham Neubig · 2025 年 9 月 23 日
资料来源：课程主页（本讲的 HTML 幻灯片未能获取） · 课堂录像（本文依据录像字幕整理课堂口述内容；课后学生报告未包含） · 主要阅读：STaR（Zelikman 等，2022）；DeepSeek-R1（2025）；Demystifying Long Chain-of-Thought Reasoning（Yeo 等，2025）

一、什么是推理模型

开头先答了几个第一次作业的问题：可以用一两天的宽限期；需要提交代码的题就要交代码，这次大概只会浏览、不会真去跑，真正跑代码是最后一次作业，所以要为它逐步积累，但请别把 Qwen 32B 之类的模型一起上传；输出格式不对时，可以用课上讲的约束解码，或者让它输出 JSON 再解析，Graham 说这正是需要推理算法的原因。

定义可以争论，现在多数人用的是：通常用强化学习训练、利用长思维链在特定任务上表现更好的模型。长思维链除了长，还有一些特点，后面会讲：推理序列很长，有自我修正，会回头重新审视之前的假设；序列越长通常表现越好，短思维链也有这个相关性，推理模型更明显。通常（不总是）用可验证奖励训练。

二、STaR

从大模型角度最早做这件事的论文是 STaR（Self-Taught Reasoner，Zelikman 等 2022）。问题输入语言模型，生成推理依据（rationale，即思维链）和答案；用可验证奖励检查对错，最典型的是数学和代码。数学就是把答案抽出来（常写在 LaTeX 的 \boxed 里）看是否匹配，一般很简单，但也有棘手的地方，比如 500 厘米和 5 米是等价的，得知道这一点才能判断，不过总比判断自由文本对不对简单得多。

STaR 还有一个如今推理模型不一定有的做法：答错时给提示，把正确答案告诉模型，让它生成与答案相符的推理依据，这叫合理化（rationalization）。流程：生成答案和推理依据；按奖励筛选，答对了保留整条链，答错了就给定答案生成推理依据；在筛选后的数据上微调。这很接近强化学习，甚至算是强化学习的一种：展开、得到结果、学习。

从策略梯度的角度看：得到奖励 $R$，用它乘输出对数似然的梯度：

$$\nabla_\theta J = \mathbb{E}\big[R(y)\,\nabla_\theta\log\pi_\theta(y\mid x)\big]$$

最有名的是 REINFORCE，变体很多，甚至可以说 GRPO 也是一种。最简单的版本是答对奖励 1、答错奖励 0，答错的样本梯度就被丢掉了。

他们用较小的 GPT-J 6B 在算术、CommonsenseQA 和 GSM8K 上测试。算术的格式很有意思：先用少量这种格式的示例，目标里有一个草稿区（scratchpad），写出逐位进位的过程，比如 9+4 得 3 进 1，2+5 加进位 1 得 8……最后 883。这是很结构化的推理表示，他们用规则生成，给模型打底，让它足够好。结果：一位数加法不用合理化也能训练得很好；三四位、五位数加法不用合理化就不行，奖励太稀疏，答对的五位数加法太少，没法加进训练数据；加上合理化，模型掌握长加法快得多。（两张图的横轴不同，一个到第 4 次迭代。）学生问早期有合理化是否总是更好：五位数那条线有点趋平，Graham 希望他们画得更远一些；他认为它确实更早趋平，这会是推理模型反复出现的主题：监督得过多，模型起步快得多，但最后停在比自由训练更差的地方。合理化指的就是图下半部分那条答错后给答案的路径。

三、DeepSeek-R1

STaR 引出了大量后续工作，Graham 不确定 OpenAI 的推理模型和它谁先谁后，但它肯定影响了大家熟悉的 DeepSeek-R1：直接在基座模型上做大规模强化学习训练出的推理模型。很有意思、甚至令人震惊的一点是，R1-Zero 完全没有先做监督微调，纯用强化学习目标（GRPO），没有合理化之类的东西。他们也有多阶段流程：从零开始做 RL，收集大量成功轨迹训练一个 SFT 模型，最后再做一次 RL。也就是说既试了冷启动 RL，也试了先做些 SFT。

1. GRPO

GRPO 因为这篇论文变得很流行，也因为它本身是个好主意。学生说看到时不觉得有什么新东西，确实不算全新，但它组合了 RL 里很多好的想法，值得了解。先对同一个查询生成一组输出，每个得到奖励 $r_i$；用组内统计量算优势函数，即这个输出比参照好多少（优势函数也可以是相对于预测回报的价值函数，这里不是）：

$$A_i = \frac{r_i - \text{mean}(\{r_1, \dots, r_G\})}{\text{std}(\{r_1, \dots, r_G\})}$$

即它比组里其他输出好多少。损失看着吓人，其实没那么可怕：

$$\mathcal{J} = \mathbb{E}\left[\frac{1}{G}\sum_{i=1}^G\min\left(\frac{\pi_\theta(o_i\mid q)}{\pi_{\theta_{\text{old}}}(o_i\mid q)}A_i,\ \text{clip}\left(\frac{\pi_\theta(o_i\mid q)}{\pi_{\theta_{\text{old}}}(o_i\mid q)}, 1-\epsilon, 1+\epsilon\right)A_i\right)\right]$$

当前策略下这个输出的概率除以旧策略下的概率，乘以优势：优势为正就想提高这个概率，为负就想降低。裁剪把比率限制在 $[1-\epsilon, 1+\epsilon]$ 内（比如 $\epsilon = 0.1$），再和未裁剪的取最小值，防止比率的两个极端值搞乱梯度、造成不稳定（Graham 说该事先练习画图讲解，会补一张图发到 Piazza）。

课上讨论了很久。以优势为正为例：比率再小，取最小值都会取未裁剪那项，这一侧梯度不会被截断，因为这是好输出，不希望它的概率被降到 0；而比率太大时被裁剪，因为不希望一个好输出的概率被一下推到 1，那是太剧烈的改变，可能伤害不在当前候选集里的其他输出的概率。优势为负时反过来，不希望概率涨得很高。学生追问优势是 −1000、比率 0.1 时会不会毫无约束地大幅下降：裁剪后是 0.9，乘以优势得 −900，未裁剪是 −100，取最小值 −900……Graham 说梯度可能变大，但优势已经用组内标准差归一化，不会真的很大。学生问这和 PPO 有什么不同：裁剪和 PPO 很像，主要区别是用组内统计量归一化优势，它就是受 PPO 启发、按组归一化优势。$\theta_{\text{old}}$ 是旧策略的参数，可以是本次更新前的参数（这篇论文大概如此），也可以更旧，取决于生成有多离策略，比如先在整个语料上生成、再逐步更新做离策略强化学习，那就是生成输出时的策略。

学生问生成时用什么温度：训练推理模型通常用温度 1。为什么不用多个温度、在一族分布上一起优化？可以，但那样就离策略了，因为采样的不是正在优化的策略；第一讲讲过，只有温度 1 才直接从策略采样。

2. 提示模板与训练结果

因为完全不做微调，提示模板是唯一的引导："这是用户和助手的对话，用户提问，助手解答。助手先在脑中思考推理过程，再给出答案，推理和答案分别放在 think 和 answer 标签里。"令人意外的是这就够了。为什么？学生说模型在训练数据里见过类似的东西，后面还会讲。一个在整个互联网上训练、几千亿参数的强模型，能在一部分时候遵循这个模板，足以从结果中学习。

训练曲线：R1-Zero 的 pass@1 和 cons@16（16 个样本自洽性）在 AIME（很难的数学题）上，一开始 pass@1 只有约 15%，用很大的批量训练很多步后超过 70%。另一个很有意思的结果是，分配给推理的思考长度随训练自然地从几百增加到几千个 token。还有那个著名的例子：R1-Zero 在推导中说"等等，这是个顿悟时刻，我可以在这里标记一下"，模型没被专门训练自我修正，却自发发现推导有问题并回去改正。论文里还可爱地写道，这对研究者来说也是一个顿悟时刻，让他们意识到强化学习的力量；Graham 说看到这种凭空出现的东西，确实会这样觉得。

3. 蒸馏

他们还证明可以把超大模型的推理轨迹蒸馏到更好管理的尺寸：用 R1 生成大量推理轨迹，筛出正确的，训练 Qwen 等小模型，比如 DeepSeek-R1-Distill-Qwen-32B，结果相当有竞争力。他们也试过在小模型上从头做 R1 式训练，发现从大模型蒸馏有效得多，Graham 认为原因就是大模型一开始更能得到不为零的准确率。学生问推理链长度是否会趋平，看起来一直单调增长，后面会讲。

4. 对推理的影响

这是推理课，所以不深挖训练。谁想用几千亿参数的模型跑一万个 token？大概没人。因为这些模型以及 OpenAI 的 o1、o3、o4、GPT-5，都用更多 token 来思考，推理变得更贵，模型也越来越大；但这也意味着小模型配上更多推理 token 可以打败大得多的模型：R1-Distill-Qwen-32B 打败了训练 R1 所用的基座模型 DeepSeek-V3。用小模型、在推理时多花 token，能得到更好的结果，正是这一范式让推理变得如此重要。

四、什么让推理能力涌现

1. 认知行为

Cognitive Behaviors that Enable Self-Improving Reasoners（与 STaR 同一个组）：用类 STaR 的强化学习分别训练 Qwen 和 LLaMA。Qwen 准确率上升很快，趋平时也更高；Qwen 的回答长度上升，LLaMA 的反而下降。区别在哪？他们分析了四种他们认为是零起点强化学习能否成功的关键行为：

  • 验证："让我检查一下答案。"
  • 设置子目标："先凑到 10 的倍数。"
  • 回溯："换个方法试试。"
  • 反向推理："24 是 8 乘 3……"

统计这些行为的平均次数，Qwen 基座模型的验证、回溯等都比 LLaMA 多得多，比 LLaMA 3B 和 70B 都多，而 Qwen 也只有 3B，所以差别在模型本身的倾向，规模解释不了。它们名义上都是没做过指令微调的基座模型，为什么差这么多？学生答：中期训练。Graham 认为有两种可能：

  • 中期训练：先在大量嘈杂的网页文本上预训练，快结束时在"更高质量"的文本上训练，比如专门挖出来的数学教材或高度"有教育意义"的内容。Qwen 虽然开源了很多模型，但很少谈数据；OLMo 和 Hugging Face 有公开的例子，Hugging Face 的 FineWeb 过滤了大量网页数据，证明在过滤后的版本上训练能快得多地得到好得多的结果。Graham 认为它会比在整个互联网上训练更早趋平，所以在全网训练仍然有价值；现在的典型做法是在全网训练，然后在退火阶段的最后加一点很高质量的数据，得到最终的基座模型。
  • 用了某种合成数据。

所以同样叫"基座模型"，训练方式可能很不同，这就是这些认知行为在某个模型里出现、在另一些里不出现的原因。论文还表明可以用鼓励这些行为的提示和几个示例来"预热"模型，提升它采取这些行为的能力，R1 刻意没这样做。学生问为什么各种预热策略最后的长度差不多：Graham 认为模型"觉得"解完了就会停，鼓励特定策略也在更高层面鼓励了推理本身，所以长度相近。

一个容易忽略的细节：R1 那张图横轴是 8000 步，批量很大，前 200 步长度根本没增加；而这张图只画到 250 步，批量大概还更小，训练量比 R1 那个"看起来趋平"的阶段还少。Graham 自己训练推理模型时也观察到，回答长度会停滞一段时间，等模型学会更广泛的推理策略（不一定是回溯）之后再上升。如果以为模型收敛到某个长度、之后不会再变长，这张图可能完全误导人。

2. 揭开长思维链的面纱

Demystifying Long Chain-of-Thought Reasoning（Graham 组的工作）想弄清：长思维链在什么条件下涌现，什么条件使推理成为可能，训练怎样影响思维链长度。设置：比较监督微调和带各种奖励函数、训练设置的强化学习，分析长度随迭代的变化，用多种模型规模和数据集。

  • 思维链类型：把模型分别用短思维链（传统思维链）和长思维链（从推理模型蒸馏）数据做监督微调（虚线），再做强化学习。原本用短思维链打底的模型从 RL 中获益很少，用长思维链打底的则大幅提升。长思维链配合 RL 有很大优势。
  • 训练崩溃：模型准确率上升一阵后突然崩溃。原因是超出了最大输出长度（他们测了超长率），一旦超长，最终答案被截掉，几乎全错。这篇论文没尝试扩展输出长度，训练就这样死了。
  • 余弦长度奖励：经典奖励答对给 1、答错给 0；他们把奖励乘上一个余弦函数，在最大输出长度处收敛到 0。答错时，越短给的负奖励越大，意思是"答错了就写长一点"，直到接近输出上限；答对时，越短越好，意思是"答对了就写短一点"，直到不再答对。这样平衡输出长度，能稳定训练。Graham 说之后他们又试了好几次，效果很好，做这类训练想走捷径的话推荐试试。
  • 其他发现：7B 模型很难发展出复杂能力；过多接触短数据会妨碍长思维链的发展，从长思维链出发的 RL 提升更多；基于规则的验证器比基于模型的验证器效果好。要让这些能力涌现，很多事都得做对，他们试着把它们都列出来。

3. SimpleRL-Zoo

既然认知行为那篇说要很特定的模型才能涌现，这篇就在大量不同规模的模型上直接从基座做推理 RL，不做 SFT，看较小的、各不相同的模型能否表现出涌现推理。在一定程度上可以：Qwen 提升最大，但只要训练得足够久、把一些设置调到能让模型在部分情况下拿到正奖励，很多模型都能做到。他们还分析了行为：Qwen 做很多子目标设置、枚举、验证，回溯少一些；Mistral 枚举更多。主要是经验性的论文，但代码库很适合做这类实验。

五、数学推理能迁移吗

Graham 组最近的论文 Does Learning Math Help Language Models Reason Better? 很多论文检验数学或代码推理数据能否提升数学或代码任务的分数，基本是领域内训练。他们问：解数学题的收益能否迁移到其他推理领域（科学问答、编程、Agent 规划），以及非推理任务（对话、指令遵循）？

受控实验：在 Qwen3-14B 上只用数学数据训练，比较监督微调（用 Qwen3-32B 当老师做拒绝采样）和强化学习（奖励是答案正确性）。课上问哪种迁移得更好，有人答 RL，理由是"直觉"，Graham 说他也凭直觉觉得 RL 更好，但做完这篇论文后有了解释。另有非受控实验：拿现有的推理模型和对应的基座模型，定义可迁移性指数，看在没训练过的任务类别上是否提升。结果：其他推理任务上，模型普遍提升，用 RL 训练的提升更多；非推理任务上，RL 训练的仍有些提升，SFT 训练的反而有所下降。

原因事后看有点显然：他们看了微调前后各 token 概率的变化，SFT 让模型变化很大，RL（GRPO）变化相对很小，而且主要改变与推理相关的词。为什么？学生猜 RL 编码启发式、SFT 编码偏差。Graham 引导大家想 GRPO 做什么：生成一批假设、比较、提高好的、降低差的；而 SFT 在一个序列上更新参数时，哪个序列的概率上升，一般来说哪些下降？学生答：其他所有的。区别就在这里：GRPO 只压低那些被采样到、奖励差（优势小于 0）的序列，相对于它们的旧概率；SFT 提高那一个好序列，同时压低其他一切。SFT 改变了每个序列，RL 只调整特定的序列。他们也不是第一个注意到这点的，但从推理角度看，这意味着 RL 的改动最小，论文里还检查了参数差异，RL 也小得多。所以 RL 泛化更好是说得通的：它没有删掉或损坏其他领域的大量知识。

学生问 R1 为什么要从零开始做 RL。Graham 认为这可以追溯到 AlphaGo，它完全从零训练，却发现了大多数人想不到的策略，对做 RL 的人影响很大；想法是让模型随意探索，只要能得到一些奖励，最终会收敛到好的东西。当然我们用的是大模型，有大量先验知识，并不是真正从零开始。学生问先 SFT 再 RL 是否性能更好：数学推理上他们确实做了 SFT 加 RL，结果更好，但按 Graham 组的论文，在其他任务上可能更差。

六、其他几项工作

  • s1: Simple Test-Time Scaling：只用约一千个精心挑选的推理示例，加上叫预算强制（budget forcing）的简单技巧在测试时控制思考时长，就在 Qwen2.5-32B 上用监督微调高效地得到很好的推理模型。两个做法：模型生成完思维链后，在后面加一个"Wait"让它继续生成，相当于强迫它重新审视之前的假设，这居然有效；接近 token 上限时截断，写上"时间到，现在作答"，它就作答。完全是启发式，但结果相当好。
  • 长度控制策略优化（L1，LTI 博士生 Pranjal Aggarwal 的论文）：提示里写"思考 N 个 token"，希望能控制思考时长；结果在 token 与准确率的权衡上比包括 s1 在内的其他模型都好。做法是在奖励里加一项，比较实际长度和目标长度。课程主页上把它列为"L1"。
  • Stream of Search（SoS）：发表于 R1 之前，R1 出来前很多人以为 OpenAI 模型在做类似的事，之后多数人改为认为更像 R1。做法：运行一个搜索算法（比如最佳优先搜索）得到解，再把搜索过程启发式地转成一条思维链，就像 STaR 把算术转成草稿区那样。他们试了广度优先、深度优先等策略的变体，在一个叫 Countdown 的游戏（要通过运算凑出目标数，需要推理）上收集了 50 万条搜索轨迹，效果不错。
  • 自适应并行搜索（Learning Adaptive Parallel Search）：把推理和工具使用结合一点。在类似 SoS 的基础上，让模型可以派生并行的搜索线程，就像一个工具，能分出不同的线程做推理，再把结果合并回父线程，像多线程编程；用端到端 RL 优化父子线程的协调。SoS 受总 token 长度限制，大家说推理时扩展就是生成大量 token，但 token 用完就不能再生成了；它允许分出并行线程再合并，限制了串行 token 的数量，大幅提高准确率。总 token 更多，整体延迟更慢，但仍然相当有益。

这是很热门的话题，还有大量工作没讲到，希望这些能给大家一些大方向。

八、小结

推理模型通常用可验证奖励的强化学习训练，学会使用很长、会自我验证和回溯的思维链，越长往往越好。STaR 生成推理依据、保留答对的、对答错的给出答案让模型合理化，再微调，监督多起步快但容易早早趋平。DeepSeek-R1-Zero 不做 SFT，只靠一个提示模板和 GRPO（组内归一化优势加 PPO 式裁剪），AIME 准确率从约 15% 升到 70% 以上，思考长度自然增长，出现"顿悟"；蒸馏到 32B 的小模型能打败训练它的大基座，这让推理时多花 token 成为主流，也让推理更贵。能否涌现取决于基座模型是否已有验证、回溯等认知行为，这和中期训练的数据有关；长度会先停滞后增长，超过输出上限会让训练崩溃，余弦长度奖励能稳住。只用数学数据训练时，RL 能迁移到其他推理甚至非推理任务，SFT 却会损害非推理任务，因为 SFT 压低了所有其他序列，RL 只调整被采样的序列。s1 的"Wait"、L1 的长度奖励、Stream of Search 和并行搜索是控制与扩展推理的其他思路。
