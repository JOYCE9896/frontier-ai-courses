第十七讲（补充）：扩散模型

从图像扩散到文本扩散，掩码扩散语言模型怎样训练、怎样一步步生成，解码顺序与重掩码策略，并行解码的代价，以及让扩散语言模型用上 KV 缓存的方法

原课：Diffusion Models，Graham Neubig · 2025 年 10 月 28 日
本讲没有公开资料，以下根据其他公开资料整理，不是原课内容：D3PM（Austin 等，2021）；SEDD（Lou、Meng、Ermon，2023）；MDLM（Sahoo 等，2024）；LLaDA（Nie 等，2025）；Block Diffusion（Arriola 等，2025）；Fast-dLLM（Wu 等，2025）；Mercury（Inception Labs，2025）

说明

课表上第 17 讲是 Graham Neubig 讲扩散模型，没有公开录像和幻灯片。这门课只讲推理，所以原课很可能侧重于"扩散模型作为一种不同的生成算法"，尤其是用于文本的扩散语言模型。这篇补充按这个方向，根据相关论文整理。图像扩散的数学细节在同站另外两处讲得更完整：CMU 11-711 第十五讲和 Stanford CME296。

一、为什么在推理课上讲扩散

到目前为止，这门课讨论的生成算法都建立在自回归模型上：模型从左到右，每次给下一个 token 一个概率分布，采样、束搜索、A* 都是在这个从左到右的过程上做文章。第 1 讲就指出，这种生成方式有一个根本的限制：生成 $n$ 个 token 需要 $n$ 次顺序的前向计算，后一个必须等前一个算完。

扩散模型提供了另一种生成方式：先给出一个完全"有噪声"的序列，然后经过若干步，一次修改序列里的很多位置，逐渐把它变成干净的文本。步数可以远少于 token 数，每一步内部所有位置是并行计算的。这带来了几个和自回归不同的推理问题：每一步该确定哪些位置，用多少步，能不能复用前面的计算。这些是这一讲的重点。

二、先回顾图像扩散

扩散模型最早在图像上取得成功。基本思路分两个过程。前向过程：从一张真实图片出发，一步步加入高斯噪声，加到最后图片变成纯噪声。这个过程是人为设定的，不需要学习。反向过程：训练一个神经网络，输入一张加了噪声的图片和当前的噪声程度，让它预测去掉噪声后的样子（或者预测加进去的噪声）。生成时从纯噪声开始，反复调用这个网络去噪，最后得到一张新图片。

图像的像素是连续的数值，加高斯噪声很自然。文本是离散的 token，没法给"猫"这个词加上 0.3 的噪声。所以把扩散用到文本上，第一个问题是：离散数据的"噪声"是什么。

三、离散扩散：文本的噪声是什么

1. D3PM：用转移矩阵加噪

Austin 等人 2021 年的 D3PM 把扩散推广到离散数据。加噪的方式是：每一步，每个 token 以一定概率被替换成别的 token，替换规则用一个转移矩阵描述。论文比较了几种矩阵：均匀替换成任意 token；模仿高斯核，替换成"附近"的值；按嵌入空间里的近邻替换；以及引入一个"吸收态"，也就是把 token 替换成一个特殊的 [MASK] 符号，一旦变成 [MASK] 就不再变回来。

论文指出，吸收态这种方式把扩散模型和两类已知的模型联系起来：自回归模型，以及 BERT 那样的掩码语言模型。后来的研究发现，在文本上效果最好的恰恰是这种最简单的掩码方式。

2. 掩码扩散

用 [MASK] 作为噪声，前向过程就很直观了。设时间 $t$ 从 0 到 1。在时间 $t$，每个 token 独立地以概率 $t$ 被换成 [MASK]。$t = 0$ 时是原文，$t = 0.5$ 时大约一半被遮住，$t = 1$ 时全部是 [MASK]。

反向过程就是从全是 [MASK] 的序列出发，逐步把 [MASK] 填成真实的 token。模型的任务是：给一个部分被遮住的序列，预测每个被遮住位置原来是什么 token。这和 BERT 的训练任务几乎一样，区别在于 BERT 只遮 15%，扩散模型要处理从 0% 到 100% 的各种遮盖比例。

和自回归模型的另一个区别是注意力。自回归模型用因果掩码，每个位置只能看到它左边的 token。掩码扩散模型用双向注意力，每个位置能看到整个序列里所有没被遮住的 token。

3. 训练目标

MDLM（Sahoo 等，2024）推导出，掩码扩散的训练目标可以化成一个很简单的形式：各种遮盖比例下掩码语言模型损失的加权混合。在上面的线性设定下（遮盖概率等于 $t$），LLaDA 使用的损失是：

$$\mathcal{L} = \mathbb{E}_{t,\, x_0,\, x_t}\left[\frac{1}{t} \sum_{i:\ x_t^i = \text{[MASK]}} -\log p_\theta\big(x_0^i \mid x_t\big)\right]$$

读法：随机抽一个时间 $t$，把原文 $x_0$ 按概率 $t$ 遮盖得到 $x_t$；模型对每个被遮住的位置 $i$ 预测原来的 token $x_0^i$，算交叉熵（AI 基础第 6 篇）；再乘以权重 $1/t$。遮得越少，被遮的位置越少，所以权重越大，起到平衡作用。这个损失是数据对数似然的一个下界，所以和自回归模型一样，训练的是一个真正的概率模型，可以算困惑度的上界。

4. 与自回归模型的差距在缩小

早期的文本扩散模型在困惑度上明显落后于自回归模型。SEDD（Lou 等，2023）提出"分数熵"损失，把连续扩散里的分数匹配推广到离散空间，在相近模型规模下比此前的文本扩散方法困惑度降低 25% 到 75%，并超过了 GPT-2。MDLM 进一步表明，配上现代的训练技巧，简单的掩码扩散就能接近自回归模型的困惑度。

LLaDA（Nie 等，2025）把规模推到 80 亿参数，按照和大语言模型相同的流程，从零预训练再做监督微调。它在通用、数学、代码等基准上与同等条件下训练的自回归基线相当，上下文学习能力可以和 LLaMA3 8B 竞争，微调后能进行多轮对话。论文还展示了一个有意思的现象：自回归模型有"逆转诅咒"，学会了"A 的下一句是 B"却不会从 B 推出 A；LLaDA 在倒背诗句的任务上超过了 GPT-4o，因为它没有从左到右的方向偏好。

四、怎样生成：扩散模型的推理算法

1. 基本流程

生成一段长度为 $L$ 的回答，最基本的流程是：

  1. 把提示词后面接上 $L$ 个 [MASK]。
  2. 设定总步数 $N$。每一步，模型对所有 [MASK] 位置同时给出预测分布。
  3. 从中选出一部分位置，把预测结果填进去（解除遮盖）；其余位置保持 [MASK]。
  4. 重复，直到所有位置都填完。

如果 $N = L$，每步只填一个位置，速度和自回归差不多；如果 $N = L/4$，每步填 4 个，前向计算次数降到四分之一。这就是扩散模型速度优势的来源。

2. 每一步填哪些位置

这是扩散模型推理中最重要的设计选择。LLaDA 的论文用"重掩码"的说法描述同一件事：每一步先预测所有被遮位置，再把其中一部分重新遮住，留到后面的步骤。比较的策略有：

  • 随机：随机选择要确定的位置。这和训练时的前向过程完全对应，理论上最"正确"。
  • 低置信度重掩码：确定模型最有把握的那些位置（预测概率最高的），没把握的重新遮住，等更多上下文填好后再决定。实践中这种策略通常效果更好。
  • 半自回归：把回答切成若干块，从左到右逐块生成，每块内部用扩散。LLaDA 在指令微调后的模型上使用这种方式，因为微调数据的回答末尾有大量填充用的结束符，纯扩散生成时模型容易过早地把很多位置填成结束符。

低置信度优先的策略和本课程前面讲的内容有呼应：它其实是在决定生成的顺序，相当于让模型先写最容易确定的部分。自回归模型的顺序固定为从左到右，扩散模型把顺序本身变成了推理算法可以选择的东西。

3. 并行解码的代价

一步同时填多个位置有一个隐患。模型对每个位置给出的是各自独立的分布，同时从多个分布里采样，相当于假设这些位置之间条件独立。但文本里相邻的词往往强相关。

举个例子：提示词是"说一个美国城市："，后面有两个待填的位置。合理的回答有"New York"和"San Francisco"。模型在第一个位置上可能把概率分给"New"和"San"，第二个位置上分给"York"和"Francisco"。每个位置单独看都没错，但两个位置同时独立采样，就有一半的可能得到"New Francisco"或"San York"。如果一次只填一个位置，填完"San"之后再预测第二个，模型就会给"Francisco"很高的概率，不会出错。在更长的文本里，这种不一致表现为重复的词、语法错误或前后矛盾。

所以步数和质量之间存在取舍：步数越少，每步并行填的位置越多，速度越快，但条件独立假设被违反得越严重。SEDD 的论文报告，它可以用少 32 倍的网络计算次数达到相近的质量；但在 LLaDA 这类模型上，把步数压得太低时质量下降明显。

Fast-dLLM（Wu 等，2025）的解决办法是置信度感知的并行解码：不固定每步填几个，而是把所有预测置信度超过某个阈值的位置一起填上。模型很有把握的位置之间，互相冲突的可能性小，可以放心并行；没把握的位置留到下一步。这样在容易的段落一次填很多，在难的地方放慢。

4. KV 缓存的问题

自回归模型推理快的一个关键是 KV 缓存（第 20 讲补充篇会详细讲）：前面 token 的键和值一旦算出就不再变，可以存下来复用。扩散模型用的是双向注意力，每填一个新位置，所有其他位置能看到的内容都变了，理论上所有位置的键和值都要重新计算。所以虽然扩散模型的步数少，每一步却要对整个序列（包括很长的提示词）做完整的计算，实际速度常常还不如自回归模型。

Fast-dLLM 用分块的近似 KV 缓存解决这个问题。它观察到，在相邻的几步之间，已经确定的位置（尤其是提示词）的键和值变化很小。所以按块生成：生成当前块时，缓存提示词和之前各块的 KV，只重算当前块；一块生成完再统一刷新缓存。这是一个近似，但精度损失可以忽略。结合置信度感知的并行解码，在 LLaDA 和 Dream 两个开源扩散模型上，吞吐量最多提升 27.6 倍，准确率几乎不变。

5. 块扩散：介于两者之间

Block Diffusion（Arriola 等，2025）从模型设计上解决同样的问题。它在块与块之间用自回归，块的内部用扩散：每个块的生成以前面所有块为条件，前面的块可以正常使用 KV 缓存；块内部的多个 token 并行生成。块大小为 1 时就是普通的自回归模型，块大小等于整个序列时就是普通的扩散模型。这种设计还解决了扩散模型只能生成固定长度的问题，因为可以一块接一块地一直生成下去。

五、实际的速度

商业化的扩散语言模型已经出现。Inception Labs 的 Mercury Coder 是面向代码的扩散模型，据第三方机构 Artificial Analysis 的测试，Mercury Coder Mini 和 Small 在 H100 上的吞吐量分别达到每秒 1109 和 737 个 token，比针对速度优化过的前沿模型平均快最多 10 倍，质量相当。在 Copilot Arena 上，它在质量上排第二，速度最快。Google 也展示过实验性的 Gemini Diffusion。

需要注意，"每秒多少 token"这种指标的意义取决于使用场景，下一讲（第 18 讲补充篇）会专门讨论怎样定义效率。扩散模型的优势在于单个请求的生成延迟低；在大批量服务的场景下，自回归模型通过批处理已经能把 GPU 用得很满，扩散模型的优势会缩小。

六、与本课程其他内容的联系

  • 第 3、4 讲的采样和束搜索都假设从左到右生成。扩散模型里，"先确定哪个位置"本身成了搜索的一部分，低置信度重掩码可以看成一种贪心的顺序选择。
  • 第 6 讲的受控生成在扩散模型里更自然：因为模型能看到整个序列，可以直接在中间固定某些 token 让它填其他部分（填空、改写），SEDD 论文称之为可控的填充。
  • 第 20、21 讲补充篇的 KV 缓存和推测解码，是自回归模型降低顺序计算代价的办法；扩散模型是从生成方式上绕开这个代价，但又引入了自己的 KV 缓存问题。

七、小结

扩散模型从噪声出发，经过若干步逐渐恢复出数据，每一步并行处理所有位置。文本是离散的，最有效的"噪声"是把 token 换成 [MASK]；掩码扩散的训练目标是不同遮盖比例下掩码语言模型损失的加权和，是似然的下界。LLaDA 把这种模型做到 80 亿参数，能力接近同等条件的自回归模型。推理时的关键设计是每一步确定哪些位置：低置信度重掩码、半自回归分块都比随机选择好。每步并行填多个位置会违反条件独立假设，步数和质量需要取舍，按置信度阈值动态决定并行数量是一种折中。双向注意力让 KV 缓存失效，分块的近似缓存和块扩散模型都是为此设计的。
