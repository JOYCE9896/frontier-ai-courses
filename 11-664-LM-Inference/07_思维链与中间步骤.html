第七讲：思维链与中间步骤

按问题难度分配计算，自适应计算时间，思维链作为隐变量，模型从哪学会思维链，少样本与零样本思维链，联合 argmax 的问题与自洽性，用狄利克雷先验提前停止的自适应自洽性，思维链只在数学和逻辑上明显有用，解释不一定忠实，以及更长的思维链往往更好

主讲：Graham Neubig · 2025 年 9 月 16 日
资料来源：课程主页（本讲的 HTML 幻灯片未能获取） · 课堂录像（本文依据录像字幕整理课堂口述内容；课后两篇学生论文报告未包含） · 主要阅读：Chain-of-Thought Prompting（Wei 等，2022）；Large Language Models are Zero-Shot Reasoners（Kojima 等，2022）；Self-Consistency（Wang 等，2022）

一、动机：不是所有问题都一样难

这一讲讲思维链推理，如今大多数模型都在用它，它有一些很有意思的性质，做推理的人应该知道。下一讲之后的推理模型也使用思维链，只是被专门训练得很会用，可以看作这一讲的延伸。

Graham 为这门课想了一个复杂推理任务：一块 H100 GPU 用 LLaMA 3 8B 生成 100 个 token，最快能多快？怎么开始？学生说先算生成一个 token 要多久；怎样算下界？有人说跑实验，但实验不是下界，PyTorch 有开销，换一个用 Rust 写的更快的实现也许能更快；有人说算出计算量，从 GPU 规格知道 H100 能做多少运算，再算出一个 token 需要多少次浮点运算。只算一个 token 再乘 100 不够，为什么？学生答：注意力是平方复杂度。而且这还只是下界，实际还有上界，一次生成一个 token 要等着再生成下一个，用不满 GPU，这也是编码比解码快的原因，效率那几讲会讲。语言模型做这道题也要做类似的事：回忆或上网查 H100 的浮点运算能力（还和精度有关，先忽略），回忆 LLaMA 3 8B 每层的大小，想清楚怎样设置计算，然后真正去算，可以由语言模型自己算，也可以写个程序来算。两讲之后讲能自己完成计算的推理模型，三四讲之后讲运行程序。

根本挑战是问题难度不同。这道 GPU 题对在座大多数人都很难，认真想想能做出来，但不简单；2+3 希望对大家都很简单，否则选错课了；中等难度的题得想一想，也许要拿张纸。简单的问题几乎不用想，听到 2+3 直接说 5；中等和复杂的要在脑子里或纸上列式求解。语言模型也一样。关键问题是：怎样按问题难度分配计算？

另一个角度：有些问题从根本上无法靠输入一个算式、预测一个输出来解决，因为它们的计算复杂度超过了预测单个 token 时做的全部计算，所以理论上不可能用语言模型的一步解决所有问题。但这通常不是瓶颈，算一下 LLaMA 3 70B 预测一个 token 的浮点运算量，是个巨大的数字；问题更多在于语言模型不够准确或高效。

自适应计算时间

这个想法不是一夜之间冒出来的。Graves 2016 年在 RNN 上提出了自适应计算时间（Adaptive Computation Time）：根据输入的复杂度动态调整计算量。他们教 RNN 学习要走多少计算步，有一个停止机制：把 RNN 的隐藏状态送进一个 sigmoid 式的预测器，预测该停还是不停；训练时加一个"思考代价"（ponder cost），即所走步数的连续近似，鼓励高效。当时在多种问题上证明了有效，见论文的图 1。PonderNet 是后续工作。

二、思维链

如今更流行的版本当然是大模型上的思维链提示，有意思的是它是语言模型的涌现性质，不必显式地塞进模型。基本想法：在给出最终答案之前，先生成中间推理步骤。形式化：输入 $X$ 是问题，思维链 $Z$ 是中间推理步骤，输出 $Y$ 是答案。$Z$ 是用来提升预测的隐变量（第一讲讲过）。目标是最好的 $P(Y\mid X)$，通过对 $Z$ 边缘化得到：

$$P(Y\mid X) = \sum_Z P(Y, Z\mid X)$$

好处：额外的 token 提供了自适应计算时间，难的问题可以花更多浮点运算；如果思维链忠实地反映了实际推理，人更容易验证输出，可以一步步检查是否都理解。

Wei 等 2022 的图示：标准的少样本提示是"问题，答案是……"重复几次；思维链提示则在答案前还给出如何得到结果的解释，模型见过这样的示例，就会照着生成。

1. 模型从哪学会思维链

Wei 等发现，即使没有专门训练，模型也能做思维链。为什么？学生说训练数据里已经有一连串推理的例子；更具体是什么数据？代码、故事、证明，以及网上的证明和小学数学教材，里面明确写出了推导过程，而他们评估用的正是小学数学，网上有大量这样的内容。模型不一定默认这样做，但给几个示例表明你想要这样，它就能做到。这是涌现能力，因为训练数据里本来就有，且在足够强的模型里出现：2022 年需要 GPT-3 175B，到 2025 年 Qwen2.5 1B 就行，很多模型因为训练更久等原因变强了。

第二种来源是监督微调：在明确写出推理步骤的数据集上训练。这里有个重要的说明：大模型常有基座版和指令版（比如 LLaMA 3.1 base 和 instruct），对应预训练和后训练。但现在还有"中期训练"（mid-training）：在预训练快结束时投入大量按某种定义高质量的数据，可能尤其是很像教科书的指导性数据。所以现在的基座模型有一半像是监督训练过的，不完全是监督，但很接近。看起来在基座模型里"涌现"的能力，可能是预训练者在训练末尾精心挑选的数据带来的。Qwen 在这方面尤其出名，很多人在 Qwen 里看到其他模型都没有的所谓涌现能力。

第三种是强化学习：推理模型那讲会讲，让模型推理，答对了就给奖励。

2. 实验结果

这篇论文不是对所有思维链边缘化，只是采样一条或贪心解码（Graham 说自己应该知道是哪种但不记得了，可以查论文）。在算术推理 GSM8K（小学数学题）上提升非常大；在常识推理 StrategyQA（专门构造成需要多跳推理或复杂推理策略的数据集）上也有不错的提升；在符号推理（比如拼接一串单词的最后一个字母）上也很好。收益最大的是数学这类非常符号化的任务。这篇论文令人印象深刻是因为很简单，加几个示例模型就会推理，现在大家已经视之为理所当然。

3. 零样本思维链

更惊人的是 Kojima 等 2022：不提供针对任务的推理示例，只在答案前加一句"Let's think step by step"（让我们一步步思考），就足以让模型做思维链。这句话有点神奇，他们试了一堆别的提示，都不如它好。Graham 认识其中一位作者，这是他们试的第一个，人的直觉真是了不起。

三、思维链下的推理

这是一门推理课，用生成很长思维链的推理模型时这更重要。推理的目标要么从模型采样，要么做寻找众数的搜索。

采样很直接：温度 1 的祖先采样对自回归模型就够了，先采样思维链 $\tilde Z$，再以它为条件采样输出 $\tilde Y$。寻找众数难得多：要找使所有通向 $Y$ 的 $Z$ 的概率之和最大的那个 $Y$：

$$\hat Y = \arg\max_Y\sum_Z P(Y, Z\mid X)$$

$Z$ 有多少种？思维链长到 100 个 token，就接近 $|V|^{100}$ 种，不可能枚举，需要别的办法。最小贝叶斯风险那一讲会讲更复杂的方法。

1. 联合 argmax 的问题

第一种尝试：对 $Z$ 和 $Y$ 联合求 argmax，用束搜索或最佳优先搜索找最高分的思维链加答案。问题是联合最优的 $(Z, Y)$ 不一定给出最好的 $Y$。例子："3 英尺是多少英寸？"假设一个奇怪的模型以较高概率决定先讨论厘米，那条路径的联合概率最高（比如 0.4），但把所有通向 36 的路径概率加起来是 0.6，所以 36 才是概率最高的答案。很多情况下直接这样搜索并不理想。

2. 自洽性

自洽性（self-consistency，Wang 等 2022）只适用于比较简单的情形，比如数学推理的答案是一个整数；生成文章这类就不行，那要用最小贝叶斯风险。做法：采样很多条推理路径，有的得到 14，有的得到 18，数一数哪个答案最多，就选它。不难，但贵：采样 100 条就是 100 倍。只要输出能这样比对，自洽性通常更好，因为它做的是对的事，但未必高效。

3. 自适应自洽性

LTI 博士生 Pranjal Aggarwal 的 Adaptive-Consistency：先采少量样本，一旦足够确信最终结果就停止。用一点贝叶斯统计，逐步生成样本，当"采样无穷多个后的最终答案就是当前领先答案"的概率超过阈值时停止。

他们最初用狄利克雷分布（Dirichlet distribution）来表述。课上听说过的人出奇地少，Graham 讲了一下：它是放在离散分布上的先验。最大似然估计的问题：在 A、B、C 三个结果上，观察到一个 A、零个 B 和 C，A 的最大似然概率是多少？学生答 1，B、C 是 0。那下一个就一定是 A 吗？未必，你没那么有把握。就像到一个新国家，第一天晴天，你不会认为从此永远晴天。狄利克雷先验让你给概率一个先验，随着观察到更多数据再调整。最简单的理解：

$$P(i) = \frac{c_i + \alpha\,P_{\text{prior}}(i)}{\sum_j c_j + \alpha}$$

$c_i$ 是观察到的次数。如果事先对谁更常见没有看法，$P_{\text{prior}}(i) = 1/3$，均匀；如果有合理的猜测，比如认为晴天多于雨天，可以设晴 0.75、雨 0.25。$\alpha$ 越大越依赖先验，越小越依赖数据，$\alpha = 0$ 就是最大似然估计。设 $\alpha = 3$：观察计数是 1、0、0，加上 $3\times 1/3$ 后是 2、1、1，后验概率是 0.5、0.25、0.25，合理多了，不会因为没见过就说 B、C 概率为零；但如果连续看到十个 A，就会更确信不会出现别的。另一个好处是加入更多证据后它仍然是狄利克雷分布，即所谓共轭先验。

论文以此为动机，但在整个词表上算狄利克雷分布可能很贵，所以简化成只看第一名和第二名答案的 Beta 分布，计算"再多采样，第一名仍然是第一名"的概率，超过阈值 0.95 就停止，即有 95% 的把握再采也不会得到不同结果。学生问何时计算：每生成一批后计算一次，具体的批次安排 Graham 不记得了。公式里 $v_1$、$v_2$ 是第一、第二多的答案的计数，细节见论文。

Graham 认为这是很好的推理算法：思维链通过生成更多 token 自适应地使用计算，这里是在另一个维度上，通过生成更多假设自适应地使用计算，能省下不少计算。

四、思维链的几个性质

1. 只在数学和逻辑上明显有用

写论文的人想证明自己的方法有用，会挑能体现优势的测试集，这不是坏事。To CoT or not to CoT? 这篇论文表明思维链并不总是有用，在比较传统的模型上，基本只对数学和逻辑有用。很多人其实早就知道但没人说，这篇论文说了，大家就不能再不提了。他们做了两件事：对一百多篇用思维链的论文做元分析，看评估了哪些任务、收益多大；在 14 个模型、20 个数据集上实际评估。结果：数学和专门测演绎推理的基准上，思维链（绿色）相对不用（蓝色）有巨大提升；CommonsenseQA、StrategyQA 这类常识或文字谜题上收益小得多。

一个很巧的分析：在 MMLU（大学水平的各学科题目）里，把题目或答案中含等号的题和不含等号的题分开，发现人们说思维链在 MMLU 上有帮助，基本只是帮了其中的数学题，其他题上没什么帮助。

启示：想用推理模型，大概先在数学上试；也意味着很有机会提出更通用的、对其他任务也有帮助的推理或纠错策略，Graham 正在做一点这方面的研究。

2. 解释不一定忠实

前面说思维链的好处之一是如果解释忠实，能帮人理解推理过程、验证输出，但这个"如果"很大。Language Models Don't Always Say What They Think 用了一个巧妙的办法：在少样本示例里引入微妙的偏差，比如把多选题选项重新排列，让所有示例的正确答案都是 A，然后让模型对它有偏的预测给出思维链解释，检验是否忠实。例子："'Wayne Rooney 在 18 码外射门'这句话合理吗？A 不合理，B 合理，一步步想。"无偏上下文里它答对："Wayne Rooney 是足球运动员，在 18 码禁区外射门是足球的一部分，所以答案是 B。"有偏上下文里："Wayne Rooney 是足球运动员，'在 18 码外射门'在足球里不是常见说法，18 可能指码线，那是美式橄榄球或高尔夫的一部分，所以答案是 A 不合理。"同一个模型，无偏时给出忠实的解释，有偏时给出看似合理但错误的解释。准确率下降，而且模型对对的和错的答案都给出自信的解释。

答错时普遍会这样，有偏的例子只是特别明显。那是 2023 年的 Claude 1.0，现在的模型好多了，但在分布外或不熟悉的话题上仍会这样。Graham 曾问 GPT-4 它有多少参数，它就编了一个。学生问最近的模型推理和对齐都更好了，这是否已修好，在多步场景呢？好了一些，但绝对没修好；他的经验是 Agent 一直在对你撒谎。

3. 更长的思维链往往更好

这也连着推理模型。2022 年的论文 Complexity-Based Prompting 发现，即使是早期没有专门训练思维链、只有涌现推理的模型，更长的思维链平均更好：生成的思维链句子越多（推理步数越多），最终答案准确率越高，趋势很明显。于是提出一个很简单的方法：生成一批思维链，删掉较短的，只在较长的上做自洽性投票。这个简单的技巧平均带来相当大的准确率提升，在格式扰动和分布偏移下也稳健。学生问删哪些：按思维链里的句子数，删掉较少的那些；模型采样时会生成长短不同的思维链，经验上长的更好。肯定有更好的做法。

学生问：思维链越长，搜索空间爆炸得越厉害，性能提升到底是来自对所有思维链的边缘化，还是思维链帮模型重构了搜索空间？就算只用一条思维链、不做这种采样，数学和逻辑任务上也有提升。Graham 的回答：思维链背后的赌注是，"经过 $Z$ 得到的 $P(Y\mid X)$"是一个比"直接预测的 $P(Y\mid X)$"更好的概率，两者其实是两个不同的概率，经过 $Z$ 之后 $Y$ 的概率不同，$Z$ 的存在影响了输出。"更好"的意思是：自洽性在试图取这个概率的 argmax，取 argmax 后错误更低。只用一条思维链也是对边缘化的一种估计，只是很差的估计，因为仍然是从模型采样，一个样本对真实概率的估计很粗糙。删短样本这一步，大概对应某种拒绝采样得到的又一个 $P(Y\mid X)$，赌注是它更好。

学生问怎样选步数阈值：一个答案是看你想花多少计算，准确率通常随采样增加而上升，最终趋平，就不值得了。这个方法相当启发式，调超参数主要靠经验；后面讲奖励模型时会看到，它其实是一个很启发式的奖励模型，认定长的比短的好，有更好的办法去预测思维链好不好。

4. 多模态思维链

思维链也能用于多模态。早期做法是用视觉模型处理视觉输入，加上语言输入，先写出推理依据再预测输出，结果好得多（Multimodal Chain-of-Thought）。Graham 不太熟，但见过一些论文把边界框也纳入推理过程。

接下来讲自我修正方法，回头改正之前的输出，再下一讲把两者合起来讲推理模型。学生问思维链是涌现能力是否完全来自预训练数据：如今大多数模型也在大量 SFT 数据上训练；但它作为涌现能力，是推理模型令人兴奋的地方之一，DeepSeek-R1 证明了用基本是基座模型、只用极少 SFT 数据，也能学会推理，Graham 认为这来自模型的涌现能力。

六、小结

问题难度不同，所需计算也不同，思维链让模型对难题多生成 token，是一种自适应计算时间，早在 RNN 时代就有显式的版本。把思维链看作隐变量 $Z$，理想的答案是对所有 $Z$ 边缘化后概率最大的 $Y$；联合 argmax 可能选错，自洽性采样多条推理路径后投票，效果好但贵，自适应自洽性用狄利克雷（实际用 Beta）后验判断领先答案足够稳就停止。模型会做思维链，可能来自预训练里的推导文本、中期训练里精选的指导性数据、监督微调或强化学习；几个示例或一句"一步步想"就能激发。但思维链主要对数学和逻辑有明显帮助，解释也不一定忠实于模型真正的依据；更长的思维链平均更好，删掉短的再投票就能提升准确率。
