11-664/763: Inference Algorithms for Language Modeling

语言模型的推理算法：采样与搜索，受控生成，思维链与推理模型，工具与 Agent，奖励模型、MBR 与推理时扩展

主讲：Graham Neubig、Amanda Bertsch（CMU 语言技术研究所）
整理：Joyce（@JOYCE9896）

课程简介

11-664/763 是卡内基梅隆大学语言技术研究所 2025 年秋季新开的课，由 Graham Neubig 和他的博士生 Amanda Bertsch 合讲，助教是 Clara Na、Vashisth Tiwari 和 Xinran Zhao，限 45 人。先修要求是 11-411/611/711、11-785、10-401/601/701、10-715 或 11-667 之一，也就是默认你已经学过 Transformer 和语言模型的训练。

这门课只讲推理，不讲训练：模型已经训练好了，怎样从里面得到好的输出，怎样花更多计算换更好的答案，又怎样把成本降下来。前半学期讲生成算法（采样、束搜索、A*、受控生成），然后是推理、工具与 Agent，再是把生成当作子程序的元生成（奖励模型、MBR、推理时扩展），最后是效率与系统。作业都是共享任务（数学推理、多项选择问答、开放式生成），期末项目要搭一个推理服务的 API 端点，同时比准确率、延迟和吞吐，12 月有海报展示。

课程主页：phontron.com/class/lminference-fall2025（链接为网页存档）；课堂代码在 neubig/lminference-fall2025-code；录像在 YouTube 公开。

读之前需要知道的几个概念

1. 采样与搜索

推理有两个目标：从模型分布里采样，或者找模型打分最高的输出。温度 1 的祖先采样是唯一对模型分布无偏的采样；找最高分则是一个搜索问题，贪心、束搜索、A* 是不同的近似。

2. 搜索错误与模型错误

第一讲提出、贯穿全课的区分：搜索错误是算法没找到模型最喜欢的输出，换更好的搜索能修；模型错误是模型最喜欢的输出本身不好，原则上该修模型，用推理去修相当于故意不找模型最优解。

3. 元生成

把整段生成当作子程序反复调用的算法：生成多个候选再重排序（Best-of-N）、投票（自洽性）、按一致性选择（MBR）、生成后再修改（自我修正）。课程后半部分大多在讨论它们的效果与成本。

课程目录（已整理 15 讲）

以下笔记根据课堂录像字幕和公开幻灯片整理，编号沿用课表。Graham 主讲那几讲的 HTML 幻灯片没能获取，只依据录像；第 14 到 16 讲没有录像，只依据幻灯片。

第 1 讲. 语言模型与推理导论

Graham Neubig。语言模型的定义与采样示例，Transformer 每层的计算量从哪来，推理用的硬件，训练与推理的根本差别，生成算法、元生成与隐变量，搜索错误与模型错误，多样性与质量，以及课程安排。

第 2 讲. 概率复习与生成基础

Graham Neubig。用一个二元模型复习条件概率、采样与温度，用采样估计算不出来的量，为什么只有温度 1 才无偏，边缘化与隐变量，GPT-2 上不同温度的输出，贪心解码为什么也不确定，用 LLM 作评委评估，以及最简单的元生成：用大模型重排序小模型的输出。

第 3 讲. 常用采样方法

Amanda Bertsch。局部归一化，校准与幻觉，熵、交叉熵与困惑度，祖先采样的长尾问题，温度、top-k、top-p 与 epsilon 截断，从有偏硬币讲典型性，局部典型采样与 η 采样，以及怎样选择采样策略。

第 4 讲. 束搜索及其变体

Amanda Bertsch。寻找众数的解码，贪心解码的三个毛病，束搜索与长度归一化，多样化束搜索，随机束搜索与 Gumbel-Max 技巧，束搜索的诅咒与似然陷阱，"如果束搜索是答案，问题是什么"，以及束搜索为什么不太用了。

第 5 讲. A* 与最佳优先搜索

Graham Neubig。为什么现在值得重新认真搜索，把搜索空间看成加权有限状态自动机，在图上演示贪心、束搜索、穷举最优搜索与 A*，可容许启发式，语言模型上用 A* 的两大困难，假设重组，未来代价预测，以及用一个比较器统一各种搜索的最佳优先束搜索。

第 6 讲. 受控生成

Amanda Bertsch。可验证与逐 token 可验证的约束，用状态机强制输出合法 JSON，不自然的 token 边界与 token 修复，正则语言、上下文无关语言与下推自动机，语义约束：logit 屏蔽、先生成再过滤、FUDGE 未来判别器，RLHF 的贝叶斯视角与奖励增强解码，对比解码及其在安全上的应用。

第 7 讲. 思维链与中间步骤

Graham Neubig。按问题难度分配计算，自适应计算时间，思维链作为隐变量，模型从哪学会思维链，少样本与零样本思维链，联合 argmax 的问题与自洽性，用狄利克雷先验提前停止的自适应自洽性，思维链只在数学和逻辑上明显有用，解释不一定忠实，以及更长的思维链往往更好。

第 8 讲. 自我修正与迭代改进

Graham Neubig。自我修正循环与四个设计维度，推敲网络的两遍解码，把编辑过程建模为标注加生成，学习编辑的表示，Self-Refine，Self-Debug 的代码执行反馈，Reflexion 与 CRITIC，以及"大模型还不能自我修正推理"。

第 9 讲. 推理模型

Graham Neubig。什么是推理模型，STaR 与合理化，策略梯度，DeepSeek-R1 与 GRPO 的裁剪目标，"顿悟时刻"与蒸馏，推理模型对推理成本的影响，认知行为与中期训练，长思维链的余弦长度奖励，数学推理能否迁移、为什么 RL 比 SFT 迁移得好，以及 s1、长度控制、Stream of Search 与自适应并行搜索。

第 10 讲. 工具使用

Graham Neubig。工具的定义与三类工具，基本调用范式，WebGPT，Toolformer 的自监督标注，函数调用标准与并行调用，MCP，程序辅助语言模型与沙盒执行，Gorilla 与 API 检索，用强化学习学用工具、用工具辅助推理，工具失效时的鲁棒性，以及让模型自己造工具。

第 11 讲. Agent 与多 Agent 通信

Graham Neubig。Agent 的定义与用途，OpenHands 演示，ReAct 与 CodeAct，任务跟踪工具与思考工具，网页的文本、可访问性树与标记集表示，提示缓存与上下文压缩，SWE-bench、WebArena 与 GAIA，用评判模型重排序多条轨迹，以及什么时候值得用多个 Agent。

第 12 讲. 奖励模型与 Best-of-N

Amanda Bertsch。拒绝采样，把 Best-of-N 看作拒绝采样的变体和推理时对齐，N 的选择与 KL 上界，Bradley-Terry 奖励模型与生成式奖励模型，偏好数据反映的是风格、安全和标注者的偏见，长度偏好与子序列上的奖励，RewardBench 2，谁在写偏好数据，以及怎样降低 Best-of-N 的成本。

第 14 讲. 最小贝叶斯风险与多样本策略

Amanda Bertsch（仅依据幻灯片）。概率最高的输出不一定最好，用其他样本作伪参考估计风险，MBR 的三个组成部分：分布、证据集与假设集、度量，由粗到细的 MBR 与基于置信度的剪枝，自洽性是 MBR 的特例，以及不能精确匹配时的通用自洽性。

第 15 讲. 推理扩展与模型规模

Amanda Bertsch（仅依据幻灯片）。花多少推理计算才值得，AlphaCode 与帕累托最优，计算最优推理的定义，多数投票的准确率上限，Snell 等：测试时计算的收益取决于题目难度，评估时必须计入成本，以及按每个 token 扩展计算的 ParScale、HARP 与 IMPACT。

第 16 讲. token 预算与训练时蒸馏

Amanda Bertsch（仅依据幻灯片）。怎样衡量 token 预算，不同的 token 成本不同，从大模型蒸馏的几种方式，把 MBR 等推理策略蒸馏进模型，用推理策略挑选偏好对，用长度惩罚、可变长度思维链和简短提示缩短推理链，以及缩短推理的代价。
