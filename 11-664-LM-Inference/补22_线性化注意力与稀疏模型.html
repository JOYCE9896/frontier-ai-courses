第二十二讲（补充）：线性化注意力与稀疏模型

注意力的代价随长度怎样增长，线性注意力怎样把 Transformer 变成 RNN，Mamba 的选择性状态空间，把训练好的模型"线性化"，以及混合专家与上下文稀疏这两种只算一部分参数的办法

原课：Linearized Attention and Sparse Models，Amanda Bertsch · 2025 年 11 月 18 日
本讲没有公开资料，以下根据其他公开资料整理，不是原课内容：Transformers are RNNs（Katharopoulos 等，2020）；Mamba（Gu、Dao，2023）；LoLCATs（Zhang 等，2024）；The Mamba in the Llama（Wang 等，2024）；Switch Transformers（Fedus 等，2021）；Deja Vu（Liu 等，2023）

说明

课表上第 22 讲由 Amanda Bertsch 讲线性化注意力与稀疏模型，没有公开录像和幻灯片。这篇补充根据题目涉及的几条主要研究路线整理。长序列模型的更多细节可以参考 CMU 11-711 第二十二讲，混合专家模型参考 第二十一讲。

一、注意力的代价

标准的自注意力里，第 $i$ 个位置的输出是所有之前位置的值向量 $v_j$ 的加权平均，权重由查询 $q_i$ 和每个键 $k_j$ 的相似度决定：

$$o_i = \frac{\sum_{j \le i} \exp(q_i^\top k_j)\, v_j}{\sum_{j \le i} \exp(q_i^\top k_j)}$$

推理时这带来两个随长度增长的代价。一是每生成一个 token，都要和前面所有 token 算一遍相似度，第 $N$ 个 token 的计算量正比于 $N$，生成整段长度为 $N$ 的文本总计算量正比于 $N^2$。二是要保存前面所有 token 的 K 和 V，KV 缓存随长度线性增长（第 20 讲补充篇）。上下文到了几十万 token，这两项都很昂贵。

这一讲讲两类办法。第一类改注意力本身，让每一步的代价不随长度增长。第二类让模型每次只用一部分参数，即稀疏化。

二、线性注意力：Transformer 也是 RNN

1. 换掉指数函数

Katharopoulos 等人 2020 年的论文提出：把相似度 $\exp(q^\top k)$ 换成两个特征映射的内积 $\phi(q)^\top \phi(k)$，$\phi$ 是某个把向量映射成非负向量的函数。代入上式：

$$o_i = \frac{\sum_{j \le i} \phi(q_i)^\top \phi(k_j)\, v_j}{\sum_{j \le i} \phi(q_i)^\top \phi(k_j)} = \frac{\phi(q_i)^\top \left(\sum_{j \le i} \phi(k_j)\, v_j^\top\right)}{\phi(q_i)^\top \left(\sum_{j \le i} \phi(k_j)\right)}$$

第二个等号利用了矩阵乘法的结合律：$\phi(q_i)$ 和求和无关，可以提到括号外面。括号里的两项和 $q_i$ 无关，可以累积计算。

2. 固定大小的状态

定义两个累积量：$S_i = \sum_{j \le i} \phi(k_j) v_j^\top$（一个矩阵）和 $z_i = \sum_{j \le i} \phi(k_j)$（一个向量）。它们可以逐步更新：

$$S_i = S_{i-1} + \phi(k_i)\, v_i^\top, \qquad z_i = z_{i-1} + \phi(k_i), \qquad o_i = \frac{\phi(q_i)^\top S_i}{\phi(q_i)^\top z_i}$$

这就是一个循环神经网络：每一步读入新 token，更新一个固定大小的状态，再从状态算出输出。生成时不需要保存所有历史 token 的 K 和 V，只需保存 $S$ 和 $z$，它们的大小只取决于向量维度，和序列多长无关。每一步的计算量也是常数。论文标题"Transformers are RNNs"说的就是这件事。在很长序列的自回归生成上，线性 Transformer 最多比普通 Transformer 快 4000 倍。

训练时则可以用另一种形式并行计算，所以线性注意力同时有 Transformer 训练可并行、RNN 推理代价恒定这两个好处。

3. 代价：状态装不下所有东西

固定大小的状态意味着信息被压缩了。softmax 注意力保留了每一个历史 token 的 K 和 V，需要时可以精确地"回头查"任何一个；线性注意力把所有历史加进同一个矩阵，早期的信息会和后来的信息混在一起。所以线性注意力模型在需要精确回忆的任务上（比如从长文档里找出一个特定的电话号码，或者"大海捞针"测试）通常不如 softmax 注意力。早期的线性注意力在语言建模上的质量也明显落后。

三、Mamba：让状态有选择地记忆

状态空间模型（SSM）是另一类具有固定大小状态的序列模型，可以看成线性 RNN 的一种，来自控制理论。Gu 和 Dao 在 2023 年的 Mamba 论文中指出，这类亚二次复杂度的模型（线性注意力、门控卷积、循环模型、结构化状态空间模型）在语言上不如注意力，一个关键弱点是无法根据内容进行推理：它们对每个 token 的处理方式都一样，不能决定"这个词重要，要记住；那个词无关，可以忘掉"。

Mamba 的改进是让状态空间模型的参数随输入变化（选择性），模型可以根据当前 token 决定沿序列传递还是遗忘信息。这个改动让原本可用的高效卷积算法失效，作者另外设计了一个硬件感知的并行扫描算法。Mamba 的吞吐量是 Transformer 的 5 倍，计算量随序列长度线性增长，在语言、音频、基因组等多种数据上达到了当时的最好水平。

后来的线性注意力变体（如带门控和 delta 更新规则的 Gated DeltaNet，以及 CMU 11-768 第三讲讲过的 Kimi Delta Attention）也加入了类似的"按内容决定写入和遗忘"的机制。实际的大模型常用混合结构：大部分层用线性注意力或状态空间层，少数层保留完整的 softmax 注意力，用来弥补精确回忆能力。例如 Qwen3-Next 中线性注意力层和标准注意力层的比例为 3:1。

四、线性化：改造已经训练好的模型

从头预训练一个线性注意力的大模型代价极高。能不能拿一个现成的 Transformer，把它的注意力换成线性注意力，只做少量训练？这叫线性化（linearizing）。早期的线性化方法会明显损害质量，仍需在几十亿 token 上训练，而且只做到 13 亿到 70 亿参数的模型。

1. LoLCATs

LoLCATs（Zhang 等，2024）分两步。第一步叫注意力迁移：把每一层的 softmax 注意力换成线性注意力，训练线性注意力使其输出尽量接近原来 softmax 注意力的输出（用均方误差损失），其他参数不动。第二步用 LoRA（只训练少量低秩附加参数的微调方法）整体微调，弥补剩下的近似误差。

结果是：在 Llama 3 8B 和 Mistral 7B 上，线性化后 5-shot MMLU 比以往方法高 20 多分，而训练的参数只有以往方法的 0.2%，训练 token 只有 0.4%。他们还首次把 70B 和 405B 的模型线性化，比之前的工作大了 50 倍。

2. The Mamba in the Llama

Wang 等人（2024）走了另一条路：把 Transformer 蒸馏成 Mamba 和注意力的混合模型，重用注意力层里的线性投影权重来初始化 Mamba 层，只用学术界的 GPU 资源就能完成。保留四分之一注意力层的混合模型，在对话基准上与原 Transformer 相当，并超过了用数万亿 token 从头训练的开源混合 Mamba 模型。从 Llama3-8B-Instruct 蒸馏出的最好模型在 AlpacaEval 2 上对 GPT-4 的长度控制胜率为 29.61，MT-Bench 为 7.35。论文还为 Mamba 和混合模型设计了硬件感知的推测解码算法（第 21 讲补充篇）。

五、稀疏模型：只用一部分参数

1. 混合专家（MoE）

普通模型对每个输入都使用全部参数。混合专家模型把前馈层换成多个"专家"（多个并列的前馈网络），每个 token 由一个路由器挑选其中少数几个来处理。总参数量可以很大，每个 token 的计算量却只相当于一个小模型。Switch Transformer（Fedus 等，2021）简化了路由算法，每个 token 只送给一个专家，在相同计算资源下预训练速度比 T5-Base 和 T5-Large 最多快 7 倍，并训练出了万亿参数的模型。

从推理的角度看，MoE 的效果要分情况。它节省计算，但不节省显存：所有专家的参数都要放在显存里。批大小为 1 时，每个 token 只读被选中专家的参数，带宽需求小；批大了，不同 token 选不同专家，几乎所有专家都会被读到，优势减小。第 18 讲补充篇说过，参数量、FLOPs 和实际速度会给出不同的结论。

2. 上下文稀疏

MoE 的稀疏性是训练时设计好的。Deja Vu（Liu 等，2023，Beidi Chen 是作者之一）发现，普通的稠密模型在推理时也有大量天然的稀疏性：对于一个具体的输入，只有一小部分注意力头和前馈层神经元真正起作用，只计算它们得到的输出和完整计算几乎一样。这部分取决于输入，所以叫上下文稀疏。

Deja Vu 在每一层前面加一个低成本的预测器，根据当前输入预测哪些头和神经元会起作用，只计算这些。预测器和主计算异步执行，实现上考虑了硬件特点，所以实际运行时间确实缩短了。它不需要重新训练模型，也不损失上下文学习能力。在 OPT-175B 上，延迟比 FasterTransformer 降低一半以上，比 Hugging Face 的实现快 6 倍以上，质量不变。

3. 稀疏注意力

第 20 讲补充篇讲的 StreamingLLM 和 H2O 也可以看成稀疏注意力：每个位置只关注一部分历史 token。另一种常见做法是滑动窗口注意力，每个位置只看最近固定数量的 token，一些模型在部分层使用它，再用其他层保留全局注意力。

六、怎样选择

方法省什么代价
线性注意力、状态空间模型KV 缓存变成固定大小的状态，每步计算恒定精确回忆能力下降，通常要配合少量全注意力层
线性化已有模型不用从头预训练与原模型仍有质量差距，需要少量训练
MoE每个 token 的计算量显存不省，大批量时带宽优势减小，路由带来训练和部署的复杂度
上下文稀疏跳过不起作用的头和神经元需要预测器，加速依赖实现
稀疏注意力、KV 淘汰KV 缓存和注意力计算有损，丢掉的信息无法找回

选择时要用第 18 讲补充篇的思路：先确定瓶颈是什么。上下文很长时，注意力和 KV 缓存是主要成本，线性注意力和稀疏注意力最有效；上下文不长但模型很大时，参数才是主要成本，MoE 和上下文稀疏更有帮助。

七、小结

softmax 注意力的计算量随长度平方增长，KV 缓存随长度线性增长。线性注意力把相似度换成特征映射的内积，利用结合律把历史累积进一个固定大小的状态，Transformer 由此变成 RNN，每一步的计算和显存都是常数，代价是精确回忆能力变弱。Mamba 让状态空间模型的参数随输入变化，能够有选择地记忆和遗忘；实际模型多用线性层和少量全注意力层的混合结构。LoLCATs 通过注意力迁移加 LoRA，Mamba in the Llama 通过蒸馏，用很少的训练把已有的 Transformer 改造成线性或混合模型。稀疏模型只用一部分参数：MoE 在训练时设计好路由，上下文稀疏在推理时预测每个输入真正需要的头和神经元。
