第十一讲：推理（上）：解码、DeepSeek-R1 与 GRPO

从贪心、束搜索到采样的解码方法，文本退化与推理模型的循环，top-k、top-p 与温度，DeepSeek-R1 从 R1-Zero 到蒸馏的主要发现，PPO 的复杂之处，GRPO 与 DAPO，以及推理什么时候有效、为什么有效、什么时候失效

主讲：Yejin Choi
资料来源：课件（Stanford 课程网站公开，2026 年冬季；课堂录像只对选课学生开放，本文依据课件整理）

一、解码

贪心与束搜索

自回归神经语言模型在推理时每一步经过 softmax 得到下一个 token 的分布，解码算法定义从这个分布中选 token 的函数。

  • 贪心解码：每一步取概率最大的 token。它的局限是短视，每步最大化局部概率，可能错过全局最优的序列。
  • 束搜索：每一步保留概率最高的 k 个部分序列（假设），k 是束宽。k = 1 时束搜索退化成贪心解码。和贪心相比，束搜索搜索更多路径，复杂度更高，能更好地近似全局最优，但多样性仍然有限（只在束内）。

束搜索曾是经典 NLP 模型事实上的标准解码算法，但在现代语言模型中已经不常用了。为什么？大约 2019 年，GPT-2 以出色的文本质量发布，它用的"采样"在当时令人意外。概率最高的序列可能（出乎意料地）重复（Holtzman 等 2019）：重复越多，重复的内容就越可能出现，比如 "I don't know." 后面接一串 "I don't know."。

到 2025 年前后，推理模型还会循环吗？推理大语言模型中的循环不是边缘情况。在 AIME 上，如果某个 30 元组重复超过 20 次，作者就把回答标为循环。在开源推理模型（Qwen、OpenThinker、Phi、Llama-R1）中，温度越低、模型越小、问题越难，循环越多。只是它们的循环比以前更隐蔽。

采样

问题一：束搜索可能退化。问题二：朴素采样（纯采样）可能不连贯。即使分布的大部分概率质量集中在少数选项上，尾部也可能很长，包含很多坏选项；虽然每个只有很小的概率，加起来在长序列中最终被选中的机会仍然很高。比如连续生成 30 个 token，每次都落在概率最高的 95% 区域的机会低到只有 21%。

  • top-k 采样（Fan 等 2018）：只从概率最高的 k 个 token 中采样。问题是对平坦的分布，top-k 可能截得太早；对尖峰分布，又可能截得太晚。
  • top-p（核）采样（Holtzman 等 2019）：从累计概率达到 p 的那些 token 中采样，也就是概率质量集中的地方。
  • 温度采样：用温度 $\tau$ 缩放 softmax 的输入。注意温度是解码算法的超参数，不是一种算法，束搜索和采样都可以用。

什么时候用贪心，什么时候用采样？用贪心：任务有确定的正确答案（数学、编程、事实问答），可以直接答出来；可复现性很重要；推理任务；输出空间受限。用采样：开放式生成（创意写作、对话）；长思维链推理（难的数学、代码）；信息查询；多样性比唯一最佳答案更重要。新兴趋势是 Best-of-N 采样：采样 N 个输出，用奖励模型选最好的，这是一种拒绝采样，能让小模型和大模型竞争，对推理任务尤其有效。

小结：解码在自然语言生成中仍是难题，还有很多工作要做；不同的解码算法可以注入偏置，鼓励连贯生成的不同性质；过去几年自然语言生成中一些影响最大的进展，来自对解码算法简单有效的修改。下一讲会讲推测解码。

二、DeepSeek-R1 详解

课件讲了从 R1-Zero 到 R1 再到 R1 蒸馏模型的流程。

R1-Zero 的奖励：保持简单

  • 准确率奖励：数学题把最终答案和标准答案比较，代码运行测试用例，奖励基本是二值的，对或不对。
  • 格式奖励：推理写在 <think>…</think> 标签里、最终答案写在后面，给一点小奖励。
  • 不用过程奖励模型（PRM）：DeepSeek 认为 PRM 贵、容易被钻空子，还可能限制模型发现新推理策略的能力；基于结果的奖励给了最大的自由。

注意：后期强化学习阶段加入了其他组合奖励（比如语言一致性、安全等），才得到最终的 R1。

涌现出的推理能力：自我验证，模型得出答案后检查自己的工作，这会涌现是因为自查过的输出更常是对的；反思和回溯，"等等，让我重新考虑"或"这个方法不行，因为……"，模型认出错误的路径，换一种策略重来；更长的思考，回答长度从几百个 token 增长到几千个，模型实际上是在学"想得更久，答案更好"，这是一种学出来的测试时计算扩展。

R1-Zero 涌现出的不良特征：可读性差，推理过程格式混乱，人很难跟上；语言混杂，不管输入是什么语言，模型经常在一个回答里切换语言；范围窄，纯 RL 只对有可验证答案的任务（数学、代码）有效，创意写作、一般对话这类开放任务处理不好，而且 R1-Zero 不会靠解数学和代码题自己发现安全护栏。

主要发现

  1. 只靠 RL 就能引出推理。之前的假设是思维链推理需要有监督的示例；R1-Zero 显示，没有过程监督、基于结果的 RL 就能引出复杂的推理能力。注意：最终的 R1 还是走了 SFT 到 RL 的流程；这对小（能力较弱的）模型不适用。
  2. 结果奖励能促成发现。之前的假设是做到 o1 那样的推理需要复杂的过程奖励；发现是过程奖励模型可能惩罚非常规但有效的推理路径，无意中限制探索。教训是有时更少的监督带来更多能力。注意：可验证奖励的强化学习（RLVR）不适用于所有推理问题。
  3. RL 和 SFT 相辅相成。纯 RL（R1-Zero）和纯 SFT 都不是最好的；多阶段流程显示两者作用互补：RL 发现能力，SFT 提供可靠性。冷启动数据防止早期 RL 不稳定；拒绝采样把 RL 的发现转成可重用的训练数据。
  4. 对小模型，蒸馏胜过直接 RL。计算预算有限时，从大推理模型蒸馏比直接对小模型做 RL 更好。通过蒸馏，推理能力可以迁移到小到 15 亿参数的模型。
  5. 开放权重的推理模型可行。R1 模型以 MIT 许可证发布，蒸馏出的 7B 和 14B 模型在推理基准上胜过很多大得多的闭源模型。
  6. 推理扩展需要结构化搜索算法吗？之前的假设是可能需要推理时搜索算法，比如蒙特卡洛树搜索；发现是推理可以完全自回归，不需要特殊的搜索算法。注意：后来针对难数学基准的模型确实加入了结构，只是不是传统 MCTS 意义上的。
  7. 测试时计算是可以学的资源。R1 的模型学会给更难的问题分配更多思考 token。这意味着测试时计算扩展不只是推理时的技巧（像束搜索或多数投票），模型本身可以通过训练把它内化，学会什么时候想、想多少。注意：这在一定程度上成立，后续研究揭示了要解决的问题。

三、PPO、GRPO 与 DAPO

PPO 的复杂之处

回顾 PPO：目标包括裁剪的替代损失、价值网络损失和熵损失；优化策略网络的裁剪项时，价值网络被冻结（停止梯度）。注意公式里的 $r$ 指重要性采样的比率，不是奖励。

  1. 内存中要放四个独立的模型。实践中是五个：由于 RL 基础设施和 GPU 优化带来的离策略漂移，不断更新的策略模型有两份副本。
  2. 广义优势估计（GAE）：要在每个生成回答的每个 token 位置调用价值函数。一个批次 512 个提示、每个 16 个回答、平均长度 2000 个 token，就是每个训练步大约 1600 万次价值函数前向计算，计算开销巨大。
  3. 价值网络的训练：价值函数必须和策略一起训练，损失通常是预测值和实际回报的平方误差，它有自己的学习率和单独的超参数调节。理论上价值网络应该帮助解决信用分配问题：不只是序列末尾一个标量奖励，而是估计每个位置还剩多少"价值"，通过时间差分残差把最终奖励往回分摊到每个 token。实践中，不清楚它学到的是不是有价值的信号。
  4. 完整的 PPO 训练步：生成一条轨迹；计算奖励（轨迹末尾只有一个分数 $R$）；构造带 KL 惩罚的逐 token 奖励，奖励模型只给整个回答一个分数，为了给 GAE 构造逐 token 奖励，用相对参考策略（原始模型）的 KL 散度作为逐 token 惩罚，中间 token 只有 KL 惩罚，最后一个 token 再加上奖励；逐 token 估计价值；逐 token 计算优势；更新策略网络；更新价值网络。

GRPO

GRPO（Shao 等 2024，DeepSeekMath）：对一个提示采样一组 $G$ 个回答，目标和 PPO 的很像，有逐 token 的重要性采样比率，优势函数非常简单，就是组内奖励的 z 分数：$\hat A_i = \frac{r_i - \mathrm{mean}(r_1, \dots, r_G)}{\mathrm{std}(r_1, \dots, r_G)}$。PPO 把 KL 项放进奖励计算，奖励又藏在优势项里；GRPO 把 KL 直接作为学习目标的一部分。

PPO 与 GRPO 对比：

  • 内存中的模型：PPO 有当前策略网络、稍旧的策略、原始参考策略、价值网络、奖励模型；GRPO 只有当前策略网络、稍旧的策略、原始参考策略（R1 用简单奖励，没用奖励模型）。
  • 优势估计：PPO 在每个 token 上算 GAE；GRPO 用组内奖励的 z 分数。
  • token 级信用：PPO 通过时间差分残差逐 token 分配；GRPO 对所有 token 一样。
  • 训练的模型：PPO 在策略网络和价值网络之间交替；GRPO 只训策略网络。
  • KL：PPO 并入 token 级奖励，藏在优势项里；GRPO 直接放在目标中。

DAPO

DAPO（《DAPO: An Open-Source LLM Reinforcement Learning System at Scale》，ByteDance Seed 等 2025）的三个技巧：

  1. 提高上限的非对称裁剪（Clip-higher）。动机：标准 PPO/GRPO 对重要性采样比率做对称裁剪，上限限制了探索，可能导致熵坍缩。做法：把上下裁剪范围解耦，比如裁剪到 [0.8, 1.28]，而不是标准的 [0.8, 1.2]。
  2. 动态采样。动机：一个提示的所有回答全对或全错时，组内标准差为零，形成梯度死区，有效批次变小。做法：只保留至少有一个对、一个错的回答组参与训练。
  3. token 级损失。动机：GRPO 用样本级损失，先在每个回答内对逐 token 损失取平均，再在 $G$ 个回答间取平均，这对长思维链不公平：100 个 token 的回答中一个 token 的梯度贡献是 1000 个 token 回答中一个 token 的 10 倍。做法：DAPO 改成 token 级平均，GRPO 是每个回答权重相同，DAPO 是每个 token 权重相同。

四、推理的本质

什么有效

  • 思维链提示大幅提升推理（Wei 等 2022）。思维链推理是模型规模的涌现性质，只有足够大的模型（1000 亿参数以上）才受益；小模型常常写出不合逻辑的思维链，并不提高准确率。
  • 自洽性（对 N 个样本多数投票）进一步提升推理（Wang 等 2022）：GSM8K 提高 17.9%，SVAMP 提高 11.0%，AQuA 提高 12.2%，StrategyQA 提高 6.4%。高概率区域中有多样的推理路径，贪心解码拿不到；N 越大，提升越大，已经有测试时扩展的意思。

为什么有效

《Chain-of-Thought Reasoning without Prompting》（Wang 和 Zhou 2024）提出"思维链解码"：第一个 token 在 top-k 个候选上分叉，后面的 token 用贪心解码。发现：即使没用思维链提示，这些备选路径中也常常包含思维链。含义：推理路径本来就存在于预训练大语言模型中，只是被标准的贪心解码遮住了。如果用 top-k 或温度采样取 K 个样本呢？结果是在没有任何思维链提示时，思维链路径更难浮现。

另外，解码序列中出现思维链路径时，模型对最终答案的置信度更高：样本碰到合适的思维链路径时，答案置信度大幅上升；如果直接多数投票，效果不会好（因为大多数分支没有思维链）；有合理思维链的解码可能比没有有用思维链的更短。怎样找到答案在哪？启发式一，取最后一个数字；启发式二，让模型接着写"So the answer is"，再把答案对齐回原解码路径中的文本片段。比较不同的思维链提取方法：整条解码路径的对数概率并不比贪心解码可靠；做长度归一化后有时有帮助。

《Large Language Models are Zero-Shot Reasoners》（Kojima 等）：即"Let's think step by step"。

《Why think step by step? Reasoning emerges from the locality of experience》（Prystawski 等 2023）：核心假设是，思维链推理有效，是因为训练数据由相关变量的局部簇组成，这些簇相互重叠；逐步推理把这些局部关系串起来，得出关于训练中从未一起出现的变量的结论。他们从数学上证明了存在"推理差距"：对在局部样本上训练的自回归模型，通过中间变量推理比直接估计偏差更小；中间推理步骤只在训练数据有局部结构时才有帮助，如果所有变量组合都能看到，推理没有好处；局部结构的数据加上推理，比在所有变量上同时训练的数据效率高得多。

《Cognitive Behaviors that Enable Self-Improving Reasoners, or, Four Habits of Highly Effective STaRs》（Gandhi 等 2025）：关键问题是为什么有的语言模型能通过 RL 自我提升，有的很快停滞，为什么在完全相同的 RL 训练下 Qwen-2.5-3B 大幅超过 Llama-3.2-3B。答案是四种行为：验证，进入下一步前检查中间结果；回溯，认出错误，退回去探索别的解法；设子目标，把复杂问题拆成可以独立解决的子问题；逆向链推理，从目标往回推，找出达到目标需要的步骤。Qwen-2.5-3B 天然表现出全部四种行为，RL 训练带来大幅提升，回答变长，准确率大增；Llama-3.2-3B 起初没有这些行为，在相同 RL 训练下停滞，用推理行为示例做预热或用筛选过的数据继续预训练后，它能追上 Qwen。行为比正确性更重要：用包含合适推理模式但答案错误的解做预热，RL 表现和用正确解训练的相当。

什么时候失效

《Reasoning Models Don't Always Say What They Think》（Chen 等，Anthropic，2025）。AI 安全上的含义：能否相信推理模型在思维链中说的话？思维链有可能提供一个观察模型推理的窗口，用来监控不良行为。作者在提示中给出 6 种推理提示，评估最先进推理模型思维链的忠实度：

  • 忠实度低：在六种提示类型和多个最先进模型上，提示确实影响了答案的情况中，思维链承认用了提示的不到 20%（大多数设置下至少有 1%）。模型系统性地使用信息而不承认。
  • RL 进入平台：基于结果的 RL 起初大幅提高忠实度（两个评测上相对提高 63% 和 41%），但停在 28%（MMLU）和 20%（GPQA），说明光靠它不足以达到高的思维链忠实度。
  • 奖励被钻空子时看不出来：RL 让模型更多利用提示（钻奖励的空子）时，思维链中说出这种利用的比例并没有相应增加，思维链监控不能可靠地发现模型的捷径或漏洞利用。

研究问题：能否教大语言模型让思维链更忠实？怎样教？课件最后还列了《Mind Your Step (by Step): Chain-of-Thought can Reduce Performance on Tasks where Thinking Makes Humans Worse》（Liu 等 2025）：在那些思考会让人表现变差的任务上，思维链也可能降低模型表现。
