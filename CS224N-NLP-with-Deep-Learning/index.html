CS224N: Natural Language Processing with Deep Learning

斯坦福最长寿的 NLP 课程之一，从词向量讲到 DeepSeek R1 式的推理训练

主讲：Christopher Manning（斯坦福大学计算机系教授，课程创立者）及多位客座与轮值讲者（Diyi Yang、Yejin Choi 等）
整理：Joyce（@JOYCE9896）

核心概念说明

CS224N 从 2017 年前后开始，就是斯坦福最受欢迎的深度学习课程之一，也是许多人接触"用神经网络处理语言"这件事的第一门课。这门课的特别之处在于它跨越的时间跨度：它没有停留在某一代技术上，而是随着整个领域的演化持续改版，早期版本重点讲 RNN 和词向量，后来加入 Transformer 和 BERT，到了这个 Winter 2026 版本，课程内容已经扩展到预训练、后训练、Agent、推理能力这些今天大语言模型讨论里最前沿的话题，同时保留了词向量、反向传播这些最基础的内容作为开篇。这种"从最基础一路讲到最前沿"的跨度，也是这份笔记试图完整保留的结构。

阅读这份笔记前，有几个贯穿全程的概念值得先有个印象：自然语言处理（NLP）研究的是让计算机处理人类日常语言这件事，人类语言天生充满歧义，这也是这门学科几十年来的核心难题；预训练指在海量无标注文本上，用自动构造出的任务（预测下一个词、填补被遮住的词）训练模型，后训练则是在预训练模型的基础上，用指令数据和人类偏好数据，把模型调整成一个听话、有用的助手；Transformer是今天几乎所有语言模型共享的底层架构，核心是让序列里任意两个位置都能直接计算相关性，而不需要像早期的循环神经网络那样按顺序一步步传递信息。

课程目录（12 讲笔记）

01. NLP发展简史与词向量表示

从人工写规则的 ELIZA，到统计语言模型，再到 word2vec 和 GloVe 如何用一个人造的预测任务，让词义自动浮现成向量空间里的几何结构。

02. 反向传播与神经网络基础

神经元、非线性激活函数、损失函数与梯度下降，以及反向传播如何用链式法则一次性算出所有参数的梯度。

03. 语言模型与循环神经网络

从只能看固定窗口的 n-gram 模型，到能携带任意长度历史信息的 RNN，再到 LSTM 如何用门控机制缓解梯度消失问题。

04. Transformer架构详解

自注意力机制的查询、键、值计算，位置编码、前馈网络、掩码这三样自注意力天生缺失的东西，以及多头注意力、残差连接与层归一化。

05. 预训练的规模系统与数据

编码器、编码器解码器、纯解码器三种预训练范式的区别，GPT-3 的情境学习现象，以及规模法则背后参数量与数据量的最优配比问题。

06. 后训练RLHF、SFT与DPO

监督微调如何教会模型"该怎么回答"，RLHF 如何用人类偏好训练出奖励模型，以及 DPO 如何把奖励建模和强化学习压缩成一步监督学习。

07. 高效适配提示工程与PEFT

零样本与小样本提示、思维链推理如何随模型规模涌现，以及 LoRA 如何用两个低秩矩阵近似完整的参数更新。

08. 智能体工具使用与检索增强生成

检索增强生成如何用外部文档弥补模型参数记忆的局限，以及 ReAct 框架如何让模型交替进行推理和真实世界的查证动作。

09. 基准测试与模型评估方法论

从 SQuAD 到 MMLU 的基准演变，标注痕迹如何让模型不理解也能拿高分，以及 Goodhart 定律、数据污染、提示敏感性这些评估陷阱。

10. 推理能力的技术剖析

解码算法与文本退化现象，DeepSeek R1 如何用极简的结果奖励诱导出自我反思能力，以及 GRPO 相比 PPO 省去了什么。

11. 分词多语言性与可解释性

SolidGoldMagikarp 故障 token 的真实案例，分词器如何让不同语言的使用者付出不同的真实成本，以及可解释性研究对"模型自我解释"的警惕。

12. 多模态、社会影响与开放问题（课程总结）

为什么校准良好的模型在数学上注定会产生幻觉，Chameleon 式的原生多模态架构，LoRA Without Regret 的发现，以及规模化之外的智能之路。
