CS224N: Natural Language Processing with Deep Learning

Stanford 2026 年冬季学期的 NLP 课程：从词向量、反向传播讲到预训练、后训练、Agent、评估和推理模型

主讲：Diyi Yang、Yejin Choi（Stanford 计算机系）
整理：Joyce（@JOYCE9896）

这门课讲什么

CS224N 是 Stanford 的深度学习 NLP 课程。2026 年冬季由 Diyi Yang 和 Yejin Choi 讲授，前半段讲词向量、神经网络与反向传播、循环神经网络、注意力与 Transformer，后半段讲预训练、后训练（RLHF、DPO）、提示与参数高效微调、RAG 与语言 Agent、评估、推理模型，以及分词与多语言、AI 对社会的影响。第一讲的 NLP 历史部分由 Christopher Manning 客座讲授。

需要了解基本的线性代数、概率和 Python。没有基础的话，可以先读本站的 AI 基础。

这一季的课堂录像只对选课学生开放，笔记依据 Stanford 课程网站公开的课件整理，每篇开头有课件链接。课件只有幻灯片上的文字和图，讲者口头补充的内容这里没有。下面几讲没有公开课件，所以没有笔记：期末项目指导，以及 Been Kim（可解释性）、Luke Zettlemoyer（多模态）、John Schulman（Tinker 与 LoRA Without Regret）三场客座讲座。

笔记目录（15 讲）

01. 课程介绍与 NLP 的历史

课程目标与安排，以及 Christopher Manning 讲的 NLP 四个时代：早期探索、手工构建的符号系统、统计 NLP、深度学习与大语言模型。

02. 词向量

WordNet 和独热向量的问题，分布语义，word2vec 的 skip-gram 目标，随机梯度下降与负采样，GloVe，词向量的评估。

03. 神经网络基础与反向传播

用窗口分类做命名实体识别，非线性函数，交叉熵损失，矩阵微积分与手算梯度，计算图上的反向传播与自动微分。

04. 语言模型与循环神经网络

n-gram 模型，固定窗口神经语言模型，RNN 语言模型的训练与生成，困惑度，梯度消失和爆炸，序列到序列的神经机器翻译。

05. 注意力与 Transformer

从 RNN 的瓶颈到注意力，自注意力的查询、键、值，位置表示与未来遮盖，多头注意力，残差连接和层归一化，Transformer 的成果与待改进之处。

06. 预训练

子词与字节对编码，编码器（BERT）、编码器-解码器（T5）、解码器（GPT）三种预训练方式，GPT-3 与上下文学习，缩放规律。

07. 后训练：指令微调、RLHF 与 DPO

指令微调及其局限，策略梯度与 PPO，奖励模型与 RLHF，InstructGPT，从 RLHF 中去掉 RL 的 DPO，偏好数据从哪里来。

08. 高效适配：提示与参数高效微调

零样本、少样本和思维链提示，剪枝与彩票假说，LoRA 与 QLoRA，前缀微调与提示微调，适配器。

09. 检索增强生成与语言 Agent

开放域问答与检索器-阅读器框架，DPR，长上下文中用不好文档，ReAct、Reflexion，Agent 的记忆与工具使用，SWE-smith，动手写一个编程 Agent。

10. 评估

好基准的条件与虚假偏差，无模型与基于模型的指标，MAUVE 等信息论指标，人工评估、Chatbot Arena 与大语言模型评委，数据污染。

11. 推理（上）：解码、DeepSeek-R1 与 GRPO

束搜索与采样，推理模型的循环，R1-Zero 的奖励与七条发现，PPO 的复杂之处，GRPO 与 DAPO，思维链为什么有效、什么时候不忠实。

12. 推理（下）：推测解码、在策略蒸馏、长上下文与测试时扩展

推测解码与 EAGLE-3、后缀解码，离策略漂移，在策略蒸馏与反向 KL，RoPE 与长上下文扩展，测试时计算扩展。

13. 分词与多语言

Julie Kallini 客座：词级、字节级与子词分词，BPE 演示，拼写与故障 token，跨语言迁移与多语言的诅咒，分词带来的语言间不公平。

14. AI 对人类的影响

幻觉引用，校准与谄媚，校准的语言模型为什么必然产生幻觉，AI 辅助创作的同质化，对就业的影响，宪法式 AI。

15. （小）语言模型的人工推理之道

Yejin Choi 的收尾讲座：ProRL 长时间强化学习，Prismatic Synthesis 数据多样化，RLP 与前置推理数据，OpenThoughts，以及关于智能的开放问题。
