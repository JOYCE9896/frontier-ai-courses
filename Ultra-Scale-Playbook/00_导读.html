01. 为什么写这本书

原书小节：开篇（无标题）

原书开头说，训练当今最强的 AI 模型要几千张 GPU 协同工作，这种规模的算力直到不久前还只属于少数顶尖实验室。开源改变了一部分局面：Llama、DeepSeek 的模型可以下载，它们的技术报告也能读到。但最难的部分，也就是训练代码以及协调 GPU 训练这些大系统所需的知识和技术，依然复杂，散落在一系列互不相连的论文和往往不公开的代码库里。

这本开源书想改变这一点：从基础讲起，带读者把 LLM 训练从 1 张 GPU 扩展到几十、几百乃至几千张，用代码示例和可复现的 benchmark 说明理论。原书标注的阅读时间是 2 到 4 天，并建议不要用手机看。

随着训练集群变大，人们发明了数据并行、张量并行、流水线并行、上下文并行，以及 ZeRO、kernel 融合等技术，目的都是让 GPU 始终保持高利用率，缩短训练时间，把昂贵的硬件用足。作者还说，这些分布式训练技术对微调大模型同样重要，而在专门数据上微调大模型往往效果最好。全书从最简单的方法讲到最精细的方法，并用一条主线串起来，让读者明白每种方法是从哪个问题里来的。

读者预设：对当前的 LLM 架构有基本了解，大致知道深度学习模型怎么训练，但可以完全没接触过分布式训练。模型训练的基础可以去 DeepLearning.ai 的课程或 PyTorch 教程补。作者把这本书看作三部曲的第二部，第一部是讲预训练数据处理的 FineWeb 博客；两部读完，就掌握了理解当今高性能 LLM 怎么造出来的大部分核心知识，只差数据配比和架构选择方面的部分，留给第三部。

原书基于 distill.pub 的模板制作。

02. 全书的三块基础

原书小节：开篇（three general foundations）

概念和理论的简要讲解

在写代码和做实验之前，先从高层理解每种方法怎么工作、优点和局限在哪。比如语言模型的哪些部分在吃显存、训练中什么时候吃；怎样通过把模型并行化绕开显存限制；怎样通过增加 GPU 提高吞吐。读完后应该能看懂原书页面上的一个交互小工具：它根据注意力头数、micro-batch 大小、隐藏维度、FFN 维度、层数、序列长度、词表大小、混合精度、序列并行、重计算方式（None / Selective / Full）、ZeRO 阶段（0 到 3）、FFN 激活函数（ReLU / GELU / SwiGLU）、张量并行度、数据并行度等参数，算出一个 Transformer 的显存构成，并带有 Llama 3 Tiny / 8B / 70B / 405B 预设。原书注明这个小工具还没有包含流水线并行。

03. 三个约束：显存、计算效率、通信

原书小节：High-Level Overview

全书讲的所有技术都在应对下面三个挑战中的一个或几个，后面会反复碰到它们：

  • 显存占用（Memory usage）：硬限制。一个训练步放不进显存，训练就进行不下去。
  • 计算效率（Compute efficiency）：希望硬件把大部分时间花在计算上，因此要减少花在数据搬运和等待其他 GPU 上的时间。
  • 通信开销（Communication overhead）：通信会让 GPU 空闲，所以要尽量减少。办法是充分利用节点内（快）和节点间（慢）的带宽，并尽可能让通信和计算重叠进行。

很多地方可以拿其中一项换另一项，例如激活重计算是用计算换显存，张量并行是用通信换显存。找到合适的平衡点，是扩展训练的核心。

04. 全书目录

本站按原书的顶层章节分篇，GPU 一章较长，拆成 09 和 10 两篇。

  1. 导读：动机、全书结构、三个约束。
  2. 单卡训练与显存：权重、梯度、优化器状态和激活各占多少显存；激活重计算；梯度累积。
  3. 数据并行与 ZeRO：梯度 all-reduce 与计算重叠、分桶、全局 batch size；ZeRO-1/2/3 依次切分优化器状态、梯度和参数。
  4. 张量并行与序列并行：按列、按行切矩阵乘法，在 Transformer 块里怎么用；序列并行切开 LayerNorm 和 dropout 的激活。
  5. 上下文并行：长序列沿序列维度切分，Ring Attention 和 Zig-Zag 排布。
  6. 流水线并行：按层切到不同节点，AFAB、1F1B、交错阶段、Zero Bubble 和 DualPipe。
  7. 专家并行：MoE 的各个专家放到不同 GPU 上。
  8. 5D 并行总览：五种并行怎样组合，各自切什么、通信什么。
  9. 寻找最佳训练配置：三步选配置的流程，以及几千次 benchmark 的结果和教训。
  10. GPU 结构与 kernel 优化：GPU 的 SM、warp 和存储层级，用 torch.compile、Triton、CUDA 写 kernel，内存合并访问、tiling、线程粗化、减少控制分歧。
  11. 融合 kernel、FlashAttention 与混合精度：kernel 融合，FlashAttention 1 到 3，FP16/BF16 和 FP8 训练。
  12. 结语与参考资料：作者的建议和参考资料清单。
  13. 附录：集合通信入门、分布式训练 profiling、LLM 训练的典型规模、通信与计算重叠的数学。

这一章的要点

  • 全书目标：从 1 张 GPU 讲到几千张，靠概念讲解、picotron/nanotron 代码和 4,100 多次实验（最多 512 张 GPU）支撑。
  • 所有技术都在处理三个约束：显存是硬限制，计算效率要求少等待，通信开销要靠用好节点内外带宽和计算通信重叠来压低。
  • 三者之间可以互相交换，例如重计算、张量并行；扩展训练就是找平衡。
