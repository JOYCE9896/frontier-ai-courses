01. 结语

原书小节：Conclusion

作者说，读到这里，你应该已经能比较轻松地看懂 Llama 3 的 4D 并行示意图。4D 指 Llama 3 训练时同时用了四种并行：张量并行、上下文并行、流水线并行和数据并行（具体每种怎么切，见本站 03、04、05、02 篇）。

让一大群 GPU 高效地训练 LLM 并不容易。全书教的是怎样安排计算和 GPU 之间的通信，让 GPU 一直保持高利用率。作者把它归成三件事：针对给定的模型和集群规模选对并行策略；能重叠的地方就让通信和计算重叠；按硬件结构写定制 kernel，让单个操作在 GPU 上尽可能快。

有人会觉得这些知识只跟少数做预训练的人有关。作者说过去也许如此，但 AI 开发者社区和模型尺寸都在快速增长，用分布式技术做推理、微调和训练的人也在成倍增加，分布式训练的配置越来越常见，所以现在深入学这些正合时宜。

作者也提到，这段学习对他们自己同样漫长。在 GPU 集群上跑几千个 benchmark 比预想的难得多（这部分经验写在 08 寻找最佳训练配置）。

02. 下一步学什么

原书小节：So, what’s next?

作者说全书只是给了主要分布式训练概念的总览，很多工具和技术只碰到了表面。他们推荐三步：

  • 仔细读一些里程碑论文或很新的论文。原书在 References 里列了他们知道的最有影响的论文、博客和书（见下文）。
  • 从零开始自己实现一个算法。很多方法只有亲手实现过才会真正想明白。
  • 挑一个常用框架参与贡献：修 bug、回答 issue、实现新功能。作者认为这是进入任何一个 ML 方向的最好办法。

04. 参考资料

原书小节：References

下面按原书的六个分类列出，每条后面是原书一句话说明的中文版。

里程碑式的 LLM 扩展论文（Landmark LLM scaling papers）

  • Megatron-LM：提出张量并行和高效的模型并行技术，用于训练大语言模型。
  • Megatron-Turing NLG 530B：用 DeepSpeed 和 Megatron-LM 组合训练一个 530B 参数的模型。
  • PaLM：Google 的 Pathways Language Model，在几百个语言任务和推理上表现强。
  • Gemini：Google 的多模态模型架构，能处理文本、图像、音频和视频输入。
  • Llama 3：介绍 Llama 3 系列模型。
  • DeepSeek-V3：DeepSeek 关于 DeepSeek-V3 架构和训练的报告。

训练框架（Training frameworks）

  • Nanotron：作者团队自己的 LLM 训练框架，支持多种并行策略。
  • Megatron-LM：NVIDIA 的 LLM 训练框架，支持多种并行策略。
  • DeepSpeed：Microsoft 的深度学习优化库，提供 ZeRO 各阶段和多种并行策略。
  • FairScale：PyTorch 的大规模训练扩展库，提供多种并行和优化技术。
  • Colossal-AI：集成多种优化技术的大规模模型训练系统。
  • torchtitan：PyTorch 原生的大模型训练库。
  • GPT-NeoX：EleutherAI 的 LLM 训练框架，GPT-NeoX-20B 就是用它训练的。
  • LitGPT：Lightning AI 对 20 多个开源 SOTA LLM 的实现，重视可复现性。
  • OpenDiLoCo：开源框架，用 DiLoCo 方法跨多个计算集群训练语言模型。
  • torchgpipe：GPipe 的 PyTorch 实现。
  • OSLO：Open Source for Large-scale Optimization，大规模建模框架。

调试（Debugging）

  • Speed profiling：PyTorch 官方教程，用 profiler 分析模型性能和瓶颈。
  • Memory profiling：理解和优化 PyTorch GPU 显存占用的完整指南。
  • Memory profiling walkthrough on a simple example：用一个简单例子把 PyTorch 显存可视化并解读。
  • TensorBoard profiler tutorial：用 TensorBoard 的 profiling 工具分析 PyTorch 模型。

分布式技术（Distribution techniques）

  • Data parallelism：对深度学习数据并行训练的完整讲解。
  • ZeRO：提出 Zero Redundancy Optimizer，通过节省显存训练大模型。
  • FSDP：PyTorch 中 Fully Sharded Data Parallel 训练的实现。
  • Tensor and sequence parallelism + selective recomputation：把张量并行、序列并行和选择性重计算结合起来的大规模训练技术。
  • Pipeline parallelism：NVIDIA 关于在大模型训练中实现流水线并行的指南。
  • Breadth-first pipeline parallelism：含有对各种流水线调度方式的广泛讨论。
  • Ring all-reduce：详细讲解分布式训练里用的 ring all-reduce 算法。
  • Ring Flash Attention：把 Ring Attention 和 FlashAttention 结合起来的实现。
  • Ring Attention tutorial：讲解 Ring Attention 概念和实现的教程。
  • ZeRO and 3D：DeepSpeed 关于 ZeRO 与 3D 并行之间性能权衡的指南。
  • Mixed precision training：提出深度学习的混合精度训练方法。
  • Visualizing 6D mesh parallelism：解释 6D 并行网格中涉及的集合通信。

硬件（Hardware）

  • Fire-Flyer, a 10,000 PCI chip cluster：DeepSeek 关于设计一个 1 万张 PCIe GPU 集群的报告。
  • Meta's 24k H100 clusters：Meta 对其基于 NVIDIA H100 的大型 AI 基础设施的详细介绍。
  • SemiAnalysis's 100k H100 cluster：对大规模 H100 集群及其对 AI 基础设施影响的分析。
  • Modal GPU glossary：原书的说明是 “CUDA docs for humans”，即写给人看的 CUDA 文档。

其他（Others）

  • Stas Bekman's handbook：覆盖 LLM 训练各方面的综合手册。
  • BLOOM training chronicles：BLOOM 模型训练过程和遇到问题的详细记录。
  • OPT logbook：Meta 记录 OPT-175B 训练过程的日志。
  • Harm's law for training smol models longer：研究模型尺寸和训练计算开销之间的关系。
  • Harm's blog on long contexts：从数据和训练成本角度研究长上下文训练。
  • GPU Mode：一个 GPU 读书会和社区。
  • EleutherAI YouTube channel：ML 可扩展性与性能读书会。
  • Google JAX scaling book：How to Scale Your Model。本站有全书中文笔记：How to Scale Your Model 目录。
  • @fvsmassa & @TimDarcet FSDP：一个独立的、约 500 行的 FSDP 实现。
  • thonking.ai：Horace He 的一些博客文章。
  • Aleksa's ELI5: FlashAttention：对 FlashAttention 的浅显讲解。
  • TunibAI's 3D parallelism tutorials：用 PyTorch 做大规模语言模型训练的教程。
