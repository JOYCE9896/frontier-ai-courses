11-768: AI Agents

基于大语言模型的 Agent：工具调用、上下文、记忆、规划、训练、安全与交互

主讲：Graham Neubig（OpenHands 作者之一）、Daniel Fried（CMU 语言技术研究所）
整理：Joyce（@JOYCE9896）

课程简介

11-768 是卡内基梅隆大学语言技术研究所（LTI）2026 年秋季开设的研究生课程，讲的是怎样构建、评估和训练基于大语言模型的 Agent。课程的五个目标是：在开源 LLM 上从零实现一个 Agent；为多步骤任务设计评估；训练 Agent 提升能力；权衡安全与可靠性；研究一个关于 Agent 的开放问题。前半学期以个人实现作业为主（Harness、评估、训练三次作业），后半学期是 2 到 3 人一组的研究项目。

这门课的先修要求很严格，需要有训练语言模型的实际经验。所以课程默认你已经知道 Transformer、预训练和微调是什么，直接从 Agent 讲起。这里的笔记在每一讲里补了必要的背景，尽量让没有这些基础的读者也能跟上。

课程网站：cmu-agents.com，幻灯片和课堂录像都公开。

读之前需要知道的几个概念

1. Agent 是"模型放进循环里"

语言模型本身只会根据前文预测下一个 token。Agent 在它外面包了一层程序，叫 Harness：模型输出一段写明"调用哪个工具、传什么参数"的文字，Harness 解析并真正执行，再把结果交回模型，如此循环，直到任务完成。第一讲和第二讲会详细讲这个机制。

2. 两条改进路线

让 Agent 更好用有两种办法。一是 Harness 工程，不动模型，改提示词、工具、记忆和控制流程。二是训练模型，包括监督微调（SFT，模仿示范轨迹）和强化学习（RL，按结果好坏调整）。课程前半部分主要讲第一条，第 8 讲开始讲第二条，实际系统两者都用。

3. Benchmark

课程里会反复出现各种基准测试。和 Agent 关系最密切的有：SWE-bench（修复真实 GitHub 项目里的 bug，用测试判断对错）；WebArena、OSWorld（在网页和桌面上完成任务，检查最终状态）；BrowseComp（需要多次搜索才能找到答案的问题）。每一讲会在第一次出现时解释。

课程目录（已更新 11 讲）

课程还在进行中，这里按官网进度整理到 9 月 29 日的第 11 讲。每一讲的笔记根据官方幻灯片整理，第 1 到第 9 讲附有课堂录像链接。

01. 什么是 Agent，它怎样工作

Agent 的定义，工具定义和工具调用怎样通过聊天模板变成 token，ReAct 循环，Agent 需要的六种能力，以及一个 Agent 系统由哪些软件组件构成。

02. 工具调用的机制与接口

为什么需要工具，用代码当工具（CodeAct），不同模型的工具调用格式，用 JSON Schema 和下推自动机做约束解码（XGrammar），REST API 与 MCP，并行调用，以及怎样评估工具使用。

03. 长上下文 Agent 的上下文管理

Agent 上下文为何按平方增长，推理中的预填充、解码和 KV 缓存，从线性注意力到 Kimi Delta Attention 的五步演进，位置编码与 YaRN，提示缓存的价格差，以及上下文压缩怎样做、怎样评估。

04. 技能与记忆

人写的技能包与渐进式披露，SkillsBench 的结果，MemGPT、Mem0、Reflexion 等记忆方法，让 Agent 自己归纳文字技能（AWM）和代码技能（ASI），以及技能库的维护与淘汰。

05. 规划、任务分解与多 Agent 协作

什么是计划，先分解再求解，经典规划与 LLM 规划的区别，加入规划结构的四个理由（模块化、反馈、长程、控制），Vending-Bench 里的长程失败，以及多 Agent 电脑操作系统 MACU。

06. 编程 Agent

代码模型的预训练、中期训练与填空训练，怎样评估生成的代码，定位、编辑、验证的循环，编辑格式对成功率的影响，SWE-bench 与 SWE-smith，前端开发，以及更广的软件工程任务。

07. 电脑操作 Agent

看截图、点鼠标的 Agent 怎样工作，从静态评估到长程评估的各类基准，视觉语言模型怎样根据交替的截图和动作预测下一步，以及用模拟环境（CUA-Gym、Gym-Anything）做强化学习。

08. Agent 的监督微调

轨迹怎样变成训练序列，损失只算在哪些 token 上，怎样选择轨迹和教师模型，多个数据集怎样统一格式（Agent Data Protocol），真实的训练配置，以及怎样判断训练是否有效。

09. Agent 强化学习基础

用猜数字的例子讲清 SFT 的三个问题，专家迭代（ReST），策略梯度（REINFORCE）的推导，基线与优势，以及 GRPO 和 DrGRPO。

10. 深度研究 Agent

从 BrowseComp 到 DeepResearchBench 的评估方法，用知识图谱造题，SFT 与 RLVR 训练，DR Tulu 的演化细则奖励，以及让检索器看到 Agent 推理的 AgentIR。

11. Agent 的进阶强化学习算法

critic、TD 误差与 GAE，异步 RL 与重要性采样，PPO、CISPO、GSPO、DAPO 的区别，假阴性、假阳性与奖励作弊，以及在线策略蒸馏。
