## 排版原则

- **字体统一**：英文用 Source Serif 4，中文用思源宋体（Noto Serif SC），正文、代码块、表格共用一套字体，不混排无衬线体。
- **字号精简**：全站只有两级字号，标题 1.35rem，其余一律 1.05rem。
- **公式支持**：数学公式用 KaTeX 排印。
