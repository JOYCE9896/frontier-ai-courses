第 11 章 · 结语与延伸阅读

全书的收尾：谁写了哪一部分，作者推荐接着读的 15 份资料各讲什么，以及怎样给作者反馈

作者：Jacob Austin、Sholto Douglas 等（Google DeepMind）· 整理：Joyce（@JOYCE9896）
资料来源：Conclusions and Further Reading（本文依据原书英文网页整理，是中文转述和讲解，不是逐字翻译；图片引自原书，版权归原作者）

这一章讲什么

这是 TPU 部分的最后一章，篇幅很短，没有公式和习题。作者先感谢读者读到最后，然后列出参与这本书的人和各自的贡献，接着给出一份延伸阅读清单：TPU 架构、GPU 与 CUDA、Pallas kernel、JAX 并行 API、Transformer 推理的数学、PyTorch 的并行实现、集合通信等方向都有。最后说明怎样反馈。读完前面十章之后，这份清单可以当作下一步的路线图。原书在这一章之后还新增了第 12 章，讲 NVIDIA GPU。

02. 延伸阅读

原书小节：Further Reading

相关的文章和资料有很多，作者列了下面这些，顺序照原书：

资料作者的介绍
TPU Deep Dive对 TPU 架构的深入介绍，写法和这本书一脉相承。
Domain specific architectures for AI inference同样风格的硬件和模型深度解读。
A Domain-Specific Supercomputer for Training Deep Neural Networks最早的 TPU 论文之一，有很多这本书没讲到的 Google TPU 项目细节。
Making Deep Learning Go Brrrr From First Principles更偏 GPU 和 PyTorch 的教程，讲 LLM 的 roofline 和性能工程。
Writing TPU Kernels with PallasTPU 编程越来越多地要用 Pallas 写自定义 kernel。这个系列讲怎样写 kernel，以及很多这里没提到的 TPU 底层细节。
How to Optimize a CUDA Matmul Kernel for cuBLAS-like Performance: a Worklog虽然针对 GPU 和 CUDA，但这篇博客把怎样在 CUDA 里优化矩阵乘法 kernel 讲得很好，也可以借它深入了解 TPU 和 GPU 的区别。（cuBLAS 是 NVIDIA 官方的线性代数库。）
Distributed arrays and automatic parallelizationJAX 并行 API 的一份很好的指南，适合学习怎样实际实现书里讨论的一些想法。
Rafi Witten's High Performance LLMs 2024 Class作者的前同事 Rafi 讲的一门 TPU 性能工程课，幻灯片都在 GitHub 上。有不少内容讲得比这本书更深。
[2211.05102] Efficiently Scaling Transformer Inference一篇详细讲 Transformer 推理数学的论文，这本书的很多内容受它启发。
Huggingface Ultra-Scale Playbook可以算是这本书的 GPU 版，更深入地讲 PyTorch 在训练时怎样实现各种并行技术和省内存技术。
Transformer Inference Arithmetic一篇博客，很多想法和这本书相同，插图很好。
Stanford CS336 Slides and Videos斯坦福的一门课，覆盖 LLM 训练和部署的很多细节，有一些有用的练习。作业 1 和作业 2 尤其相关。
Stas Bekman's ML Engineering Handbook一份很实用的 ML 基础设施指南，覆盖这本书没讲的话题，比如怎样和云服务商谈判、集群管理、GPU 吞吐的实测数据。
ezyang's blog一位 PyTorch 负责人的博客，内容围绕分片和 PyTorch，包括一份 PyTorch 内部机制指南和一篇分片矩阵乘法的文章，还有很多其他好内容。
The Anatomy of Collective Communication按这本书的风格把 GPU 和 TPU 的集合通信过了一遍。作者说它对 N 维集合通信和 GPU 集合通信写得比这本书好。

作者认为这个领域还有很大空间留给系统性的写作，希望这本书能带动更多这样的文章。他们也认为这是一个值得学习和研究的方向，而且很多情况下手头没有很多硬件加速器也能做。

这一章的要点

这一章没有 Takeaway 框，也没有公式。可以记住的几件事：

  • 书里很多想法最早来自 James Bradbury、Reiner Pope、Noam Shazeer、Blake Hechtman；第一版由 Sholto Douglas 撰写，Jacob Austin 主导成书和发布，Charlie Chen 写了推理部分。
  • 原书说 Efficiently Scaling Transformer Inference（arXiv 2211.05102）是书中很多内容的灵感来源；想看 GPU 版的对应读物，原书推荐 Huggingface Ultra-Scale Playbook 和 Making Deep Learning Go Brrrr。
  • 想动手写 TPU kernel，读 Pallas 的 TPU 文档；想在 JAX 里实际实现并行，读 Distributed arrays and automatic parallelization。
