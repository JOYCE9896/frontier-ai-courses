CS2680: Modern AI Systems: Agents and System Optimizations

Harvard 2026 年秋季新开的研究生系统课：从用好 Claude Code、自己写编程 Agent，一路往下讲到 LLM 推理服务、GPU 和整个 Agent 系统栈的优化

主讲：Juncheng Yang（Harvard SEAS，MaDSys 组）
整理：Joyce（@JOYCE9896）

这门课讲什么

CS2680 是 Harvard 工程与应用科学学院 2026 年秋季第一次开设的研究生课程，由 Juncheng Yang 讲授。课程跟着一个 Agent 系统，从 Agent 循环一路往下走到推理服务栈：先当用户，用 Claude Code 这样的编程 Agent；再自己设计、测量、优化一个 Agent；然后自己部署一个开源模型，接管下面的各层：批处理和调度、KV 缓存和前缀复用、路由、量化、投机解码。

课程分两部分。第一部分讲 LLM 和 Agent：怎样用编程 Agent，怎样设计 Agent，各种 Agent 架构、用法和优化。第二部分讲为 LLM 和 Agent 服务的系统。贯穿全课的一个观点是：对 Agent 来说，每秒 token 数是错误的优化目标，真正要优化的是在延迟、成本、可靠性等约束下的任务成功率，以及每个成功任务的花费。

先修要求是 Harvard 的 CS61，加至少一门研究生系统课，并会 Python 和 PyTorch。前八讲（Agent 部分）不需要深度学习背景；第九、十讲开始涉及 Transformer 和 GPU，没有基础的话可以先读本站的 AI 基础，训练方面可以参考 CS336，推理算法可以参考 11-664。

资料说明：这门课明确不录像（第一讲课件写着"No video recording"），所以没有视频转录。笔记依据 课程网站 公开的课件、课程参考笔记和作业说明整理，每篇开头有课件链接，讲者口头补充的内容这里没有。下面几讲没有公开课件，所以没有笔记：10 月 5 日 Snowflake 的 Harsh Nilesh Pathak 讲企业场景下的 Agent 开发与评估（客座），10 月 14 日学生主讲的 Agent 安全与自演进 Harness，以及几次学生分享课。课程还在进行中，截至 2026 年 10 月 23 日公开了前 10 讲的课件，后面的批处理与分页、投机解码、调度与前缀缓存、剪枝与量化、路由与负载均衡等讲次发布后再补。

笔记目录（10 讲加作业）

第一部分：LLM 与 Agent

01. 课程概览，AI 系统与 Agent 系统

五个作业和期末项目，AI 系统和传统系统在计算、非确定性、状态、负载、可靠性上的不同，Agent 的定义，为什么 Agent 是系统问题，Agent 系统栈，以及这门课要定量回答的九个问题。

02. 从用户角度看 Agent（一）：Claude Code 怎样工作

Agent 循环，开口之前上下文里已有一万多 token，模型提议、Harness 执行，权限层，上下文压缩，CLAUDE.md 和自动记忆，核心工具，Skill、MCP、Hook、Plugin 四种扩展，MCP 网关与新版规范。

03. 从用户角度看 Agent（二）：多 Agent 与最佳实践

Superpowers 和 Caveman 两个插件案例，git worktree 手动并行，子 Agent、Agent 团队、动态工作流、/goal 和 /loop，十六个 Agent 写 C 编译器，"编程 3.0"与不确定性，OpenAI 内部使用 Codex 的数据。

04. Agent 设计（一）：上下文管理与工具设计

ReAct 与 Agent 循环骨架，搜索、编辑、执行三类工具的几种做法和代价，工具设计原则，八种提示技术，上下文是有限资源，准入、卸载、变换、压缩四级手段，上下文失败的五种方式，Agent = 模型 × Harness。

05. Agent 设计（二）：多 Agent 架构、协调与通信

八种多 Agent 架构及其弱点，任务分解的维度、粒度和常见失败，通信的介质、通道、消息格式，多 Agent 继承的分布式系统难题，A2A 协议和 MCP 的区别，四条设计原则。

06. Agent 设计（三）：记忆与可靠性

持久记忆的写入、组织、存储、使用、检索、归纳、遗忘，Mem0、Graphiti、supermemory，记忆的失败模式和评估基准；错误怎样累积，故障来自任务说明、Harness、模型、工具、环境哪一层，怎样为失败而设计。

07. Agent 设计（四）：Agent 评估

组件级和端到端评估，基准演变史，pass@k 与 pass^k，GAIA、BFCL、WebArena、OSWorld、SWE-bench、τ-bench、Terminal-Bench、TheAgentCompany，数据泄漏、单轮指令、非确定性和基准饱和，帕累托前沿。

08. 进阶 Agent 设计（一）：成本与性能

把花费拆成轮次、步数、token、单价的乘积并逐项压缩（附全班 Claude Code 日志的统计），每种省钱办法的反作用，预算和停止条件，让 Agent 更快的五种办法与投机执行，单体、模块化、微内核三种 Harness 架构，八个 Harness 的独特设计。

第二部分：为 LLM 和 Agent 服务的系统

09. 高效 LLM 服务基础（一）：LLM 入门

请求的六个阶段，以 Llama 3 70B 为例拆解注意力、多头、GQA、参数分布和 KV 缓存，估算预填充时间和显存，混合专家模型，以及滑动窗口、MLA、线性注意力、Mamba、稀疏注意力、循环 Transformer、扩散语言模型。

10. 高效 LLM 服务基础（二）：GPU 入门

GPU 为什么是吞吐机器，线程束、SIMT 与分支发散，算力、容量、带宽三个上限，算术强度与屋顶线，批处理和上下文长度对解码的影响，H200 结构、张量核心、内存层级与 Little 定律，多卡互联，以及 AMD、TPU、Trainium 等加速器。

作业

作业与期末项目

五个作业逐一梳理：给 Claude Code 做网页界面，自己写 Agent 循环并自建测试任务，在三档模型上做成本和速度竞赛，在一张 GPU 上自己部署模型并优化推理，以及优化整个栈；排行榜的天际线排名规则；期末项目的两条路线、提案要求和评估标准。
