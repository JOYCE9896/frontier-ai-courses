第9讲：用大语言模型打造的 AI Agent

什么叫 AI Agent，现有的几个例子（AutoGPT、Stanford 小镇、Voyager、Figure 01、Inner Monologue、Talk2Drive），目标、记忆、状态、计划、行动这套框架，有记忆的 ChatGPT，以及用《芙莉莲》里的逃脱用哥列姆在 GPT-4 上一步步演示计划、行动、反思和经验

主讲：李宏毅（Hung-yi Lee，台湾大学电机系）· 上课日期：2024 年 4 月 12 日 · 时长：25 分钟 · 整理：Joyce（@JOYCE9896）
资料来源：课堂录像（台大公开，2024 年春季，本文依据录像字幕整理）· 幻灯片

这一讲的内容

前面几讲讲的都是让语言模型一问一答：给一句话，回一个结果。这一讲往前看一步，问的是：一个要分好几步、中途还会出状况的任务，能不能整个交给 AI？他把能做到这件事的 AI 叫作 AI Agent，然后拆出它需要的几样东西（终极目标、记忆、对外界状态的感知、计划、行动），再逐一说明今天的大语言模型在哪些环节已经能做、哪个环节最难。

这一讲很短，只有 25 分钟，是同一天第8讲（RLHF）之后的下半堂。开头 3 分 30 秒是他课后重录的。主要例子有两个：一个是他自己办朋友聚餐的生活例子，用来说明什么叫多步骤任务；一个是动画《葬送的芙莉莲》（Frieren）一级魔法使考试里的“逃脱用哥列姆”（golem，泥人），他把它当成一个由大语言模型驱动的 Agent，在 GPT-4 上把整套流程跑了一遍。录像结尾他说要留五分钟回答问题，但问答部分没有收进视频。

01. 一问一答之外：多步骤任务和 AI Agent 的定义

录像位置 0:00:00–0:03:22（视频说明写明这一段是课后重录）

今天多数人怎么用 AI

他说今天多数人让 AI 帮忙做事，往往只要求它做一个步骤。想翻译，就给 GPT 一句话，它给你翻译结果；想画图，就跟 ChatGPT 说“请帮我画图”，ChatGPT 去调用 DALL-E 生成一张图。幻灯片上画的是：人给一个任务，AI 一步交回结果。

朋友聚餐：一个多步骤任务

人类能做更复杂、需要好几个步骤才能完成的任务。他举自己的例子：接到任务要办一次朋友间的聚餐。

  • 先做计划：调查大家有空的时间，统计出最多人有空的时段，再去订常吃的餐厅 A。
  • 执行第一步：发一份 Google 表单给朋友，朋友填完，过两天统计，发现周四晚上最多人有空。
  • 跟餐厅 A 订位，对方说周四晚上没有位子了。
  • 只好换一家：用 Google Map 查还有哪些餐厅，从推荐里选了餐厅 B。

他从这个例子里抽出三点：这种任务需要先做规划；步骤的先后顺序有讲究，不能先订餐厅再调查时间，“不然没有人来就糟糕了”；执行过程中计划赶不上变化，原来要订 A，A 没位子，就得改计划。

这门课里 AI Agent 的定义

如果 AI 能完成这种多步骤的复杂任务，这堂课就把它叫作 AI Agent。他特别说明 Agent 这个词在不同领域用法不同，就算在谈 AI 时，每个人对 AI Agent 的想象也不一样。他在这堂课里的用法是：让 AI 能执行多步骤的复杂任务，能做计划，而且能修改计划。

他认为现在也许还看不到太多 AI 能做到这类事，但有了大语言模型之后，也许不久 AI Agent 就会出现在日常生活里。他请大家回想聚餐例子里的步骤：做计划、调整计划、使用工具，这些都是今天的语言模型有机会、或已经能够做到的。视频说明在这里补了一句：可以结合前面讲提示技巧的三讲（第3、4、5讲），想想语言模型能不能做到幻灯片上原本由人做的那些行动。

02. 现成的 Agent 和几个代表性例子

录像位置 0:03:22–0:09:14

可以直接体验的 Agent

幻灯片列了四个现成的 AI Agent：AutoGPT、AgentGPT、BabyAGI、Godmode。他说最知名的也许是 AutoGPT：给它一个任务，比如“帮我做个网页”，然后就不用管它，让它自己想办法；它会偶尔上网搜索、偶尔用工具、偶尔自己做 reflection（反思），设法完成任务。

能不能真的完成，他说“那个就不好说了”。AutoGPT 一度很红，但很多人觉得它有点被过誉。他讲了一个网红的故事：给 AutoGPT 下了一个指令，跑了一整晚，最后什么都没跑出来，还把 OpenAI 的额度花光了，网红很生气。他的解释是语言模型有能力上的极限，叫它自己想办法解决任务时，很多时候还是解决不了。但他仍认为 AI Agent 是未来的趋势：语言模型帮人做事不会再局限于一问一答，你也许不会再期待它马上给答案，而是它能自己跟环境互动，最终想办法解决问题。

虚拟世界里的 Agent

  • Stanford 小镇：由 AI 村民组成的虚拟村庄（幻灯片附 arXiv 2304.03442）。他说之前的上课录像已经讲过这一段，这里不重复。
  • Voyager：让 AI 活在 Minecraft（我的世界）里，自己做各种探索、打造各种工具、学新任务（去年五月的论文）。他展示论文里的一张图：不同的图标代表 AI 学会的不同技能，不同的线代表不同方法，论文提出的方法是表现最好的橙色线。AI 很快学会用木制工具，接着是石制工具、铁器工具，最后能打造钻石剑，其他方法都打造不出钻石剑。他开玩笑说照这样玩下去，很快就能打到终界龙（Ender Dragon）。

有实体的 Agent：机器人和自动驾驶

前面的例子都在虚拟世界里，他说未来这些 Agent 也很可能有实体、能跟物理世界互动。

  • Figure 01：最近最受关注的例子，他说大家应该都看过视频，所以课上不播。机器人背后有一个大语言模型，可以叫它清理桌子、拿点吃的过来。他强调用语言模型操控机器人不是新观念，Figure 01 厉害的地方在于机械手臂和手指很灵活。
  • Inner Monologue：2022 年 7 月的论文，他称之为 ChatGPT 之前“上古时代”的论文。机器人背后有一个语言模型。人说“给我一个汽水”，语言模型想出要做什么：先去找汽水；机器人看到一杯可乐，想把它拿起来。过程中遇到困难：人把可乐抢走了。机器人反思后发现做不到，就问人：看到一个 orange soda，喝这个好不好？人说不好，要喝别的，机器人只好再去找其他饮料。
  • Talk2Drive：去年年底的论文，用大语言模型开自动驾驶汽车。人类司机下指令，大语言模型根据天气、交通状况等信息来开车。它不直接输出“左转方向盘、踩刹车”这类指令，而是写一段代码，用代码去操控车的各个部件。人可以给反馈，比如不要超速、路边停车时小心一点；系统把反馈存起来，以后做决策时参考人过去给的反馈。

03. AI Agent 可能的运作框架

录像位置 0:09:14–0:11:35

接着他讲 AI Agent 背后可能的运作原理。幻灯片右边是 Agent，左边是外界环境。Agent 里有这几样东西：

  • 终极目标：它最终要达成的任务。
  • 记忆：过去跟环境互动时获得的经验。
  • 状态：它从环境了解到的当前情况。来源可以是文字输入，可以是视觉（看到外面的世界），可以是听觉（听到别人的声音、外面发生的事），如果有实体还可以有触觉（碰到很烫或很冰的东西）。他把这些统称为通过感知器（sensor）了解外界状态。
  • 计划：根据终极目标、记忆和状态产生的计划，也就是 Agent 的短期目标，即达到终极目标之前需要采取的行动。
  • 行动：根据短期目标执行的行为。可以是输出文字、生成图片、说话；如果有机械手臂，可以去操作机械手臂，操作方式也可能是生成一段代码来控制手臂；也可以是跟其他 Agent、其他 AI 互动。

行动会对世界造成影响，改变外面世界的状态。于是 Agent 可以根据新的状态修改记忆，从中学到新经验；也可以修改计划。他说一个 Agent 不会定了计划就永远照着执行，那样太不灵活、太死板。幻灯片上记忆和计划旁边都标着“可修改”。

他说这就是今天大家想象中一个 AI Agent 应有的能力。至于语言模型有没有这些能力，能不能根据记忆回复、修改记忆、制定并修改计划，他的判断是今天的大语言模型对这些已经有一定程度的能力，所以 AI Agent 就在不远的地方：现在也许还没看到太多应用，但他相信一两年之内 AI Agent 会“满地跑”。

04. 记忆：有记忆的 ChatGPT

录像位置 0:11:35–0:14:30

讲到记忆，他先说明 ChatGPT 没有长期记忆：它能记得的事情都发生在同一个对话里，一旦按了“开始新对话”，之前跟它讲过的事它一概不知，一切从头来过。

OpenAI 曾经在 blog 上说要释出有记忆能力的 ChatGPT，Twitter 上也有人说拿到了能记忆的版本，但不知为什么后来这个功能不见了。他说自己的账号还没看到这个功能，请有的同学告诉他。（视频说明补充：到 2024 年 4 月 26 日，他的 ChatGPT 已经有 Memory 了。）

他推测有记忆的 ChatGPT 可能这样运作：

  1. 一次对话结束后，把对话里的关键信息做摘要，比如记下“你正在准备期中考试”。
  2. 原本开新对话时过去的内容会全部清空，现在因为有摘要，它知道过去对话里有哪些重点。
  3. 下次对话时，它先对过去的记忆做一次 RAG（检索增强生成，先搜出相关资料再回答，前面讲过），找出跟你相关的信息，甚至可能主动问你：期中考考得怎么样？

有了记忆，ChatGPT 就能更加个人化。他说虽然 OpenAI 还没真正释出这个功能，但已经有很多人试着以 ChatGPT 为基础打造有记忆的 GPT，比如 MemGPT 这篇论文，展示大语言模型怎样加上 RAG 获得记忆能力。

05. 芙莉莲的逃脱用哥列姆：目标、记忆、状态到计划

录像位置 0:14:30–0:18:13

故事

他说如果讲到这里觉得模糊、不具体，那就举一个具体例子，又要讲一个“莫名其妙”的芙莉莲故事（幻灯片标题：“又要讲芙莉莲的故事了……”）。

《芙莉莲》里有一级魔法使考试，其中一关要攻略一个迷宫（字幕写作“灵洛的王座”）。迷宫很危险，进去之前主考官发给每人一个“逃脱用哥列姆”：一个装在瓶子里的泥人，遇到危险就打破瓶子，哥列姆会出来救你、带你离开迷宫。迷宫里，考生爱黛儿遇到了复制体（字幕写作“染折的复制体”）的攻击，受了重伤，决定放弃考试，打破了瓶子。哥列姆出来时先是坐着，他说“感觉正在做一些运算”。这时复制体对爱黛儿发动攻击，哥列姆替她挡住，爱黛儿还赞叹它能确保使用者的安全，真方便。然后哥列姆抱起她逃出了迷宫。

他接着说：你可能以为哥列姆是用魔法做的，但动画里讲过，这种哥列姆是这几年才开发出来的。魔法已经发展了上千年，为什么这几年才有能自动运行的哥列姆？他的答案是，因为背后用的是大语言模型，它是一个由大语言模型运作的 AI Agent，开发者是发现了大语言模型之后才把它加进哥列姆里，才让哥列姆能自主运行（这是他的玩笑式设定）。

把哥列姆套进框架

  • 终极目标：他设想为“你会自律行动，安全地把考生带出迷宫”。
  • 记忆：哥列姆刚被创造出来，没有任何记忆，所以是空的。
  • 状态：眼前是遭遇复制体攻击而重伤的爱黛儿。他提到实际看到的是画面，要变成文字输入语言模型，可以用 Image Captioning（图片描述生成，把图片转成一段描述文字）的模型，把现场情况“翻译”成文字。

在 GPT-4 上生成计划

接下来语言模型根据目标、记忆和状态来制定计划。他问：现在的 GPT-4 能做到吗？他实际试了（视频说明注明此处用的是 GPT-4）。输入是三栏：目标写“你叫哥雷姆，你会自律行动，安全的把考生带出迷宫”，记忆留空，状态写“眼前是遭遇复制体攻击而重伤的爱黛儿”，最后一句“请产生行动计划”。

GPT-4 产生的计划，第一点是立即评估爱黛儿的伤势，第二点是提供急救。他评价这两点看起来都合理。

06. 执行计划：文字行动怎么变成真实动作

录像位置 0:18:13–0:20:39

让模型按计划走一步

有了计划，再让大语言模型按计划执行。他把目标、记忆、状态和刚才生成的计划一起给模型，然后说“请采取下一步行动”。他特别说明自己在指令里强调了只执行一个动作，否则模型会把所有动作一次执行完。

模型给出的下一步是评估爱黛儿的伤势：仔细检查身上每一处伤口，看有没有大出血或骨折的迹象，看她是否还有意识，是否有脑震荡或其他休克迹象等等。

最难的一环

他指出这里的难题：模型生成的是文字形式的行动，一个机器人、一个哥列姆、一个泥人，要怎么按照这串文字真的行动？他说这是整个 AI Agent 他认为目前最困难的地方，有很多论文在尝试把文字指令转成在物理世界或虚拟世界可执行的行动。

他引用了一篇今年二月的论文（幻灯片附 arXiv 2402.19299 和 2402.03681 两个链接）。其做法是用两个 Agent：

  • Slow Agent：负责高层次的行动，产生的指令是人类能理解的自然语言。
  • Fast Agent：按 Slow Agent 的指令想办法真的执行。比如可以训练一个专门执行特定行动的神经网络，或者干脆生成一段代码，运行后把自然语言描述的行为转成物理世界或虚拟世界里真正可执行的动作。

效果如何，他把论文链接留在幻灯片上，说至少看起来能在 Minecraft 的虚拟世界里运作。

07. 环境变了：反思和修改计划

录像位置 0:20:39–0:22:15

先假设行动可以执行，哥列姆真的在评估爱黛儿的伤势。评估过程中外界环境会变：复制体还在旁边，可能袭击哥列姆。外部状态变了，计划也该跟着变。

他说语言模型可以通过反思来改计划，想看具体做法可以参考 DEPS 这篇论文（arXiv 2302.01560），它也在 Minecraft 里运作，让语言模型根据环境变化修改原计划。

他现场测试：除了原来的信息，再告诉模型“执行过的动作”是正在评估爱黛儿的伤势，以及新的状态“在评估爱黛儿的伤势时，你遭遇复制体袭击”，然后请它产生新的行动计划。模型的新计划第一点变成了“保护爱黛儿”：先把她移到相对安全的位置，找掩护物阻挡复制体。他的解读是评估伤势已经没那么重要，优先要做的是保护她。

08. 从反思得到经验，经验改变行动

录像位置 0:22:15–0:24:46

让模型总结经验

除了改计划，模型能不能反思刚才的状况，得到以后用得上的经验？他说可以，想了解可参考 ReAct（Reason + Act，arXiv 2210.03629）和 Reflexion（arXiv 2303.11366）两篇论文。

做法是下一句指令：“简短总结值得记下来的经验”。模型列了几点，幻灯片截图里能看到前两条：环境警觉性（专注救助伤者时也不能忽视周围环境的安全）和快速应变能力（面对突如其来的攻击要能迅速反应）。幻灯片写着“经验会影响所采取的行动”：再遇到同样的状态，模型会根据过去的经验采取不同的行动。

有记忆和没记忆的对比

他回到最初的场景，这次把刚才总结的经验填进“记忆”栏，状态还是“眼前是遭遇复制体攻击而重伤的爱黛儿”，再请它产生行动计划。

  • 计划：第一点仍是评估爱黛儿的伤势；第二点从没有记忆时的“立即施予急救”变成了“保持高度的环境警觉性”。
  • 下一步行动：没有记忆时，模型的行动是立即评估伤势；有记忆时，它多加了一句：评估伤势的过程中，也会保持高度警觉，注意四周是否有复制体或其他潜在威胁。

幻灯片把两种情况并排，标为“根据没有任何记忆的计划”和“根据有记忆的计划”。他的结论是记忆和经验会影响模型的行为，让它采取更好的行为。

结尾

他说这是想象中未来 AI Agent 可以做到的事情，依今天大语言模型的能力，他相信一两年后就会看到“满坑满谷”的 AI Agent 生活在我们周围。延伸阅读给了一篇综述论文：The Rise and Potential of Large Language Model Based Agents: A Survey（arXiv 2309.07864），最后一张图取自这篇综述，是作者想象的一个充满 AI Agent 的虚拟世界。之后他说还剩约五分钟回答同学问题，录像到此结束。

他是怎么讲的

讲的顺序

  1. 先从“今天大家怎么用 AI”起步：翻译、画图都是一步完成。这是听众已有的体验，用来做对照。
  2. 马上换成一个人人做过的生活任务（办聚餐），把“计划、顺序、计划赶不上变化”三点从故事里抽出来，然后才给出 AI Agent 的定义。定义里的三个要素（多步骤、做计划、改计划）都在故事里先出现过。
  3. 定义之后放例子：先是能直接上手的 AutoGPT（连同它翻车的故事），再是虚拟世界（小镇、Minecraft），再到物理世界（Figure 01、机器人拿饮料、自动驾驶）。从虚拟到实体，一步步扩大。
  4. 例子看够了才给抽象框架（目标、记忆、状态、计划、行动、外界环境）。他自己也承认这一段听起来模糊：「如果你觉得讲到这边很模糊 没有很具体的话 那我们来举一个具体的例子」（0:14:07）。
  5. 然后用同一个哥列姆故事把框架里每一格依次填满：目标、空的记忆、状态、计划、行动、环境改变、反思、经验，最后回到起点重跑一次，看有经验后有什么不同。全程只用一个例子，框架图在每张幻灯片上反复出现，每次多亮一格。

每个概念用了什么例子

  • 多步骤任务、计划和改计划 → 办朋友聚餐：Google 表单、餐厅 A 没位子、Google Map 改订餐厅 B（0:00:52）。
  • AI Agent 的定义 → 他明说只是“这堂课里”的用法：「我所谓的AI Agent指的就是 让AI能够执行多步骤的复杂的任务 能够做计划 而且能够修改计划」（0:02:33）。
  • Agent 的能力边界 → AutoGPT 跑一晚上什么都没跑出来，「把所有OpenAI的钱都喷光了」（0:04:09）。
  • Agent 自己探索、学技能 → Voyager 在 Minecraft 里从木器到钻石剑，玩笑“很快就会打到终界龙”（0:05:52）。
  • 遇到困难后反思、换方案 → Inner Monologue 机器人：「这个人很坏啊 把他的这个可乐抢走了」，于是改问要不要 orange soda（0:07:37）。
  • 行动不一定是直接控制，可以是写代码；记住人的反馈 → Talk2Drive 写代码控制车辆部件，存下“不要超速”等反馈（0:08:27）。
  • 记忆 → ChatGPT 开新对话就全忘；有记忆的版本记下“你正在准备期中考试”，下次问你考得怎么样（0:13:18）。
  • 状态从画面变成文字 → 给哥列姆接一个 Image Captioning 模型（0:16:35）。
  • 计划、执行、改计划、经验 → 全部用哥列姆救爱黛儿的同一个场景在 GPT-4 上演示（0:17:25 起）。

简化了什么、跳过了什么

  • Stanford 小镇只提一句，说之前录像讲过，请大家去看。
  • Figure 01 的视频不播，理由是大家应该都看过。
  • Slow Agent / Fast Agent、DEPS、ReAct、Reflexion 都只用一两句话说明做法，然后说“论文链接留在这边”，不展开。
  • “文字行动怎么变成真实动作”这个难题，他点明是目前最难的部分，但在演示里直接假设“行动是可以执行的”跳过去：「这就是整个AI agent 我觉得目前最困难的地方」（0:19:02）。
  • 记忆的实现只讲了一种可能的做法（摘要加 RAG），并用“可能”“也许”标明是推测。

怎样处理误解和提问

  • Agent 这个词：先声明不同领域、不同人用法不同，再给出本课的窄定义，避免听众带着别的想象来听。
  • “语言模型操控机器人是新东西”：他指出不是，早在 ChatGPT 之前就有人做，Figure 01 新在手臂和手指的灵活度。他用「是ChatGPT之前上古时代的论文」（0:06:44）来形容 2022 年的 Inner Monologue。
  • 对 AutoGPT 不夸大：先讲它红过，再讲它被认为过誉，再讲失败的故事，最后才说 Agent 仍是趋势。
  • ChatGPT 记忆功能：他直说自己账号还没有，「如果有人手上有的话,记得跟我讲一下」（0:12:26），后来在视频说明里补上“2024/04/26 我的 ChatGPT 现在有 Memory 了”。
  • 课堂问答没有收进录像。

现场演示

工具是 GPT-4（ChatGPT 界面截图），提示词固定为“目标 / 记忆 / 状态 / 指令”四段格式，每轮只改其中一栏：

  1. 目标“你叫哥雷姆，你会自律行动，安全的把考生带出迷宫”，记忆空，状态“眼前是遭遇复制体攻击而重伤的爱黛儿”，指令“请产生行动计划” → 计划：1. 立即评估伤势，2. 提供急救。
  2. 加上计划，指令“请采取下一步行动”，并要求只执行一个动作 → 详细描述检查伤口、意识、休克迹象。他解释为什么要限定一个动作：「我这边有强调说执行一个动作就好 不然他会把所有动作都执行完」（0:18:13）。
  3. 加上“执行过的动作”和新状态“在评估爱黛儿的伤势时，你遭遇复制体袭击”，再请产生行动计划 → 第一点变成保护爱黛儿。
  4. 指令“简短总结值得记下来的经验” → 环境警觉性、快速应变能力等几条。
  5. 把经验放进记忆栏，回到最初的状态重跑 → 计划第二点变成保持高度的环境警觉性，行动里多了“注意四周是否有复制体”。

幻灯片上用红线和蓝线标出提示词各栏和输出里变化的那一句，前后两版并排放，变化一眼可见。

其他手法

  • 《芙莉莲》梗：幻灯片标题“又要讲芙莉莲的故事了……”，视频标题也写“教你怎么打造芙莉莲一级魔法使考试中出现的泥人哥列姆”。他把动画设定接到技术上：魔法发展上千年，为什么哥列姆这几年才出现？「那是因为哥列姆背后是用大型语言模型在运作的」（0:15:46）。哥列姆出瓶时坐着，他说像“正在做一些运算”。
  • 回扣前面的课：Stanford 小镇、RAG、提示技巧三讲（视频说明里给了链接）。
  • 一个框架图贯穿后半段，每张幻灯片在同一张图上填一格，听众不用重新认图。
  • 对未来给出明确判断但带时间范围：「在一两年之内 AI Agent应该会满地跑」（0:11:35），结尾又说“满坑满谷”。
