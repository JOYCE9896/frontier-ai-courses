Andrej Karpathy 的 LLM 视频笔记

从模型原理到日常工作流：公开视频的中文研读笔记

演讲：Andrej Karpathy · 整理：Joyce（@JOYCE9896）

栏目说明

这里整理 Andrej Karpathy 在 YouTube 公开发布的长视频。它们不是大学课程，却很适合放在课程笔记旁边阅读：Karpathy 会亲自演示模型、工具和代码，先解释底层机制，再说明一个普通人在真实工作里怎样使用它们。

每篇以视频章节和英文自动字幕为依据，保留原视频链接、重要时间点和他自己的例子；对会随产品版本变化的功能、价格和模型名称，均以视频发布时为准，不把演示当成今天仍然成立的产品说明。当前目录覆盖频道现有的 17 条公开视频；makemore 五集与 Stable Diffusion 五条实验短片分别合并为系列页，但每条原视频均在页面中单独列出。

视频目录（持续更新）

01. 怎样使用 LLM

对 ChatGPT、Claude、Gemini、Grok、Perplexity 等产品的一次实践导览。解释聊天界面下的 token 与上下文，什么时候该用搜索、深度研究、文件上传、Python 和代码 Agent，怎样使用语音、图像、视频、记忆、系统指令与自定义 GPT，并反复说明如何核验模型输出。

02. 大语言模型深度导览

从 token、预训练和 Transformer 推理出发，讲到后训练、推理模型、工具、多模态与安全；建立“LLM 是概率程序而非可信资料库”的整体心智模型。

03. 复现 GPT-2（124M）

与公开 checkpoint 对齐后，从数据批次、交叉熵和单 batch 过拟合，走到混合精度、FlashAttention、DDP、FineWeb、HellaSwag 和可复现评估。

04. 从零实现 GPT 分词器

从 Unicode 与 UTF-8 开始手写 byte-level BPE，解释正则预切分、merge 表、特殊 token、多语言压缩率和多模态 tokenization。

05. 从 GPT 架构到可训练的语言模型

合并《Intro to Large Language Models》和《Let's build GPT》：从 bigram 基线逐层搭出因果自注意力、Multi-Head Attention、MLP 与完整 Transformer block，再放回预训练和 RLHF 的产品路径。

06. 从 micrograd 到 makemore

汇总 micrograd 与 makemore 五集：手写反向传播、bigram、MLP、embedding、初始化、激活与梯度诊断、BatchNorm、逐运算 backward 和 WaveNet。

07. Stable Diffusion 梦境实验

归档频道全部五条早期 Stable Diffusion 短片，并把它们接回扩散去噪、文本条件、随机种子与生成内容的事实、隐私和版权边界。

阅读顺序

若尚不熟悉语言模型，可先读 AI 基础 中的 Transformer、训练和解码；想了解 Karpathy 在本篇中提到的预训练、后训练与推理模型，也可配合 CS336 阅读。随后直接从第一篇开始即可。
