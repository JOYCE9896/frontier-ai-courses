从 GPT 架构到可训练的语言模型

两条视频：一小时全景介绍，与从字符级语言模型逐层搭出 GPT

演讲：Andrej Karpathy · 资料来源：[1hr Talk] Intro to Large Language Models（2023，59 分） · Let's build GPT: from scratch, in code, spelled out.（2023，1 小时 56 分）

一、一小时讲清 LLM 的生命周期

短讲将 LLM 分成训练与推理两端：预训练以大规模文本做 next-token prediction；推理将提示词编码、反复采样并解码为文字；微调和偏好优化使基础模型变成助手。随后它把缩放定律、工具调用、多模态、推理、定制、LLM OS 和安全问题放进同一张路线图。

这不是“模型会思考”的哲学证明，而是一套工程视角：模型能力来自数据、计算、架构与后训练的组合；访问浏览器、解释器或 DALL·E 是外部工具链；jailbreak、prompt injection 与数据投毒则提醒我们，模型输出和模型周围的系统都必须被保护。

二、从 bigram 基线走向 Transformer

完整代码课从 Shakespeare 字符开始。数据被映射为整数，切为训练/验证集，再用随机的长度为 block_size 的片段预测下一个字符。最初的 bigram 模型只根据当前字符预测下一个字符，它提供了所有后续改进都能比较的损失与生成基线。

随后模型逐步获得记忆：先对历史向量做均值；再用矩阵乘法实现可并行的加权汇聚；再加因果 mask 和 softmax，使每个位置只能关注自己与左侧 token。这里的“加权读历史”就是 self-attention 的核心，而不是一个只能用于文本的特殊技巧。

三、Transformer block 的组成

  • token 与位置嵌入：内容向量告诉模型“是什么”，位置向量告诉模型“在哪里”。
  • 多头因果自注意力：不同 head 学习不同关系；mask 阻止看到未来 token；$1/\sqrt{d_k}$ 防止点积尺度让 softmax 饱和。
  • 前馈网络：注意力之后在每个位置独立地混合特征、施加非线性。
  • 残差、LayerNorm 与 dropout：使更深的网络可训练，并在小数据实验中减轻过拟合。

课程也区分 decoder-only GPT、encoder-only BERT 与 encoder-decoder Transformer：差别主要是可见性和训练目标，不能只凭“是否有 attention”混为一谈。

四、从小模型到 ChatGPT

视频最后从字符级演示跳到 nanoGPT、GPT-3 和 ChatGPT。预训练模型先学习通用文本规律；指令微调把任务写成对话；人类反馈强化学习进一步选择更受偏好的回答。小模型训练代码并不等于工业训练系统，但梯度、token loss、数据批次和采样循环完全同构。

适合的练习顺序是：先能解释 bigram loss；再手写一个带因果 mask 的单头注意力；然后组合出多头 block 并训练一个小模型；最后用本项目的 动手练习 对照真实训练输出。
