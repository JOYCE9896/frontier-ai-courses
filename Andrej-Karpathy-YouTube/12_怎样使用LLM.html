我怎样使用 LLM

用他自己生活和工作里的真实例子，走一遍 ChatGPT 及同类产品的各种功能：模型选择、思考模型、搜索、深度研究、文件、代码、语音、图像、视频、记忆和自定义 GPT

演讲：Andrej Karpathy · 发布：2025 年 2 月 27 日 · 时长：2 小时 11 分
资料来源：How I use LLMs（本文依据公开视频英文字幕和章节整理；产品、价格、模型名称均以 2025 年 2 月为准，很多已经变化）

这条视频的定位

这是《深度导览》的实用续集。上一条讲的是模型怎么训练、怎样理解它的“心理”；这一条讲具体应用：大量例子、各种设置，以及他自己在生活和工作中怎么用。和上一条一样，他在 Excalidraw 白板上画图，白板文件公开在视频描述里。

一、生态和底层（0:00–13:12）

越来越大的生态

ChatGPT 由 OpenAI 在 2022 年部署，是第一次让人们能通过文本界面直接和大语言模型对话，迅速走红。到 2025 年生态大了很多：ChatGPT 是“元老级的现任者”，最流行、功能最全；大厂有 Google 的 Gemini、Meta 的 Meta AI、微软的 Copilot；创业公司有 Anthropic 的 Claude、xAI 的 Grok；还有中国的 DeepSeek、法国 Mistral 的 Le Chat。他推荐用 Chatbot Arena 和 Scale 的 SEAL 排行榜跟踪各家水平。视频以 ChatGPT 为主，因为功能最多，也会穿插展示其他产品独有的体验。

聊天气泡底下是一条 token 序列

他让 ChatGPT 写一首关于“做一个大语言模型是什么感觉”的俳句，说写作是这些模型很擅长的（诗、求职信、简历、回复邮件）。然后在 Tiktokenizer 里看：他的问题是 15 个 token，回答是 19 个；加上对话格式里的特殊 token，整段对话是 42 个 token。

他的心智图：点“新对话”就开始一条空的 token 序列；你往里写 token，按回车把控制权交给模型；模型写自己的 token，最后输出一个表示“我说完了”的特殊 token，控制权回到你。这条序列就是上下文窗口，是这段对话的工作记忆，里面的东西模型可以直接访问。

你在和谁说话：一个 1TB 的 zip 文件

复习上一集：预训练把整个互联网压成一个有损、概率性的“zip 文件”，比如 1TB 大约对应 1 万亿参数；预训练要几千万美元、三个月左右，所以不常做，模型有“知识截止日期”。后训练给这个 zip 文件“贴上一张笑脸”，让它扮演回答问题的助手。默认情况下它是一个完全自包含的实体：没有计算器、没有 Python、没有浏览器，只有 token 进、token 出。

他用 ChatGPT 的口吻写了一段自我介绍，大意是：“嗨，我是 ChatGPT，一个 1TB 的 zip 文件。我的知识来自大约半年前完整读过一遍的互联网，我只记得个大概。我讨人喜欢的性格是 OpenAI 的人类标注员通过示例编程出来的。”网上经常讨论的东西它记得更清楚，罕见的东西记不太清，这点和人很像。

二、基本用法的例子（13:12–18:03）

  • 一杯美式有多少咖啡因：他在比较美式和抹茶。ChatGPT 说约 63 毫克。他认为这类问题适合直接问：不是新知识，而且在网上出现得很多，模型应该记得好。但他还是去查了原始资料确认。
  • 感冒流鼻涕：他问哪些药有帮助，又拿出家里的 DayQuil 和 NyQuil 问是否有用。他会拿出药盒核对成分表，因为这只是统计性的回忆。这是常见药品、风险不高，最后吃了 NyQuil，确实有效。

两条使用建议：

  • 换话题就开新对话。上下文里的 token 很“贵”：太多无关内容会分散模型注意力、降低准确率，还会让生成每个 token 稍微变慢变贵。把上下文窗口当成珍贵的工作记忆，相关的留着，无关的清掉。
  • 知道自己在用哪个模型。未登录时 OpenAI 不告诉你用的是哪个模型，可能是更小、更“笨”的版本。当时 ChatGPT 的价格：免费版主要是 GPT-4o mini（更小，写作和知识都弱一些，更容易幻觉）；Plus 每月 20 美元，每 3 小时 80 条 GPT-4o；Pro 每月 200 美元，GPT-4o 无限量加其他功能。他自己付 Pro，因为工作中大量写代码，这个价格对他很划算。

其他家也有分档：Claude 付费才能用 3.5 Sonnet；Gemini、Grok 也一样，比如有 Grok 3 就别问 Grok 2。他说自己经常付好几家的钱，同一个问题问所有模型，他称之为“LLM 议会”。他举例问 Claude 哪个城市适合去玩，Claude 推荐了瑞士的采尔马特，他真的去那里过了新年，Gemini 也推荐了同一个地方。

三、思考模型（22:54–31:00）

复习：强化学习让模型在大量数学和代码练习题上发现思考策略，很像人解题时的内心独白：尝试、回溯、检查假设。这是最近一两年的突破，DeepSeek 是第一个公开详细讨论的。他在白板上的笑脸旁边加了一个可选的“思考气泡”。代价是要等，可能要几分钟。

他的真实例子：自己写的 MLP 优化代码梯度检查不通过。GPT-4o（不思考）列了一堆可能的问题，都没说到点子上。换成 o1 pro（Pro 档，“最擅长推理”），想了一分钟，找到了真正的原因：参数打包和解包的顺序不一致。

他把同样的问题给了其他模型：Claude 3.5 Sonnet（据他所知不是思考模型）也找到了；Gemini 找到了；Grok 3 绕了一阵也找到了；Perplexity 上托管的 DeepSeek R1 能展开看到原始思考过程，里面写着“但是等等，他们累积梯度时做错了……这是一个关键错误”。他吐槽 Perplexity 把它渲染得很糟。OpenAI 只显示思考摘要，命名也很乱，o1、o3-mini、o3-mini-high、o1 pro 都是思考模型。

他的习惯：先用不思考的模型，因为快；觉得答案不够好，想给模型多一点时间时，再换思考模型。问旅行建议之类的不需要。Grok 里要点 “Think” 按钮才会切换到思考模型，各家都有类似开关。

四、工具：联网搜索（31:00–42:04）

他刚看完《白莲花度假村》第三季第一集（他说很喜欢这部剧），想知道第二集什么时候播。以前要去 Google 搜、点开好几个链接、躲着广告。现在模型可以输出一个特殊的“搜索”token，应用暂停生成，去搜索、访问网页，把网页文本塞进上下文，模型再根据这些文本回答。没有搜索，模型不可能知道答案，因为播出时间是最近几周才确定的。

各家当时的情况：Perplexity 是第一个把这件事做得令人信服的；ChatGPT 有“搜索网页”按钮，有时模型会自己判断需要搜索；Grok 会自己搜；Claude 当时没有集成搜索，只会说“截至我 2024 年 4 月的更新……”；Gemini 2.0 Pro 实验版没接搜索，2.0 Flash 接了。他的结论是各家集成程度不同，要留意；他知道需要搜索时就直接勾选，不让模型猜。

他自己用搜索的例子（习惯去 Perplexity）：今天股市开门吗（那天是总统日，休市）；《白莲花度假村》第三季在哪拍的；Vercel 提供 Postgres 数据库吗（会变的信息）；明天苹果发布会发什么、有什么传闻；某恋爱综艺第四季的演员现在怎样；Palantir 股价为什么涨；《文明 7》什么时候发售；Bryan Johnson 用什么牙膏（他喜欢 Bryan 的做法，而且这既冷门又可能变化）；去越南旅行安全吗；推特上很多人在讨论 USAID，想知道是怎么回事。

他的判断标准：凡是“Google 搜一下、点开前几个链接就能找到答案”的问题，都适合用搜索工具。尤其是新近的、会变化的、冷门的信息。

五、工具：深度研究（42:04–50:57）

深度研究大致是“搜索加思考，跑很长时间”，当时 ChatGPT 放在每月 200 美元的 Pro 里。他认为这个功能很酷，但被很多人忽略了。

例子：他在网上买补充剂（“我知道这有点疯狂”），Bryan Johnson 的“长寿配方”里有一种叫 Ca-AKG 的成分，每份 2.5 克，说明写着“促进能量产生、维持活力”。他让深度研究调查 Ca-AKG：为什么出现在配方里、在人类或动物模型中的效果、可能的作用机制、潜在风险。模型先问了几个澄清问题，然后花了约 5 分钟，看了 27 个来源，写出一份报告：蠕虫、果蝇、小鼠的研究，正在进行的人体试验，机制，安全性，参考文献。

同时他也在 Perplexity 的 Deep Research 和 Grok 的 DeepSearch 上跑了同样的问题。他喜欢 Grok 的界面，但认为 ChatGPT 的报告最全面、最长、最好读，另外两家更短、细节更少。

他强调：即使做了研究，也不能保证没有幻觉，任何地方都可能是编的或误解了。所以引用很重要，把报告当初稿、当阅读清单，自己去读原文核对。

他的其他例子：Chrome 删了他所有标签页，他想换 Brave 或 Arc，问哪个更注重隐私，读了报告和来源后换成了 Brave；小鼠寿命延长的研究；美国 LLM 实验室的规模和融资表格。最后这个他专门拿出来当失败案例：有些数字看着不太对；漏掉了 xAI，这是重大遗漏；又放进了 Hugging Face 和 EleutherAI，他认为不该算作主要 LLM 实验室。

六、上传文件：把具体资料放进上下文（50:57–59:00）

搜索和深度研究的本质是给模型具体文档，而不只依赖参数里的模糊知识。你也可以自己上传。

和 LLM 一起读论文

他对 Arc Institute 一篇在 DNA 上训练语言模型（Evo 2）的论文感兴趣，但自己不是学生物的。他把 PDF 拖进 Claude 3.7（录视频时刚发布，带“extended”思考模式），结果超出长度限制，“天哪，真的吗”，于是换 ChatGPT。他猜测 PDF 上传后很可能被转成文本，图片可能被丢掉或理解得不如人好。他一般先要一份摘要，然后边读摘要和引言边提问。

和 LLM 一起读书

他说现在几乎从不独自读书。例子是亚当·斯密 1776 年的《国富论》，他觉得这本书里很多见解今天仍然适用。做法：从古腾堡计划找到原文，复制当前在读的章节（比如第一卷第三章：分工受市场范围限制，市场小就无法专业化），贴进 Claude，说“我们在读《国富论》，先总结这一章”。Claude 虽然知道这本书，但不太可能记得某一章的细节，所以要把原文放进上下文。

他说这样做大大提高了他的理解和记忆，尤其是读其他领域的文献或很老的文本时，他会更有勇气去读莎士比亚这类东西。他也吐槽：目前没有好用的工具，他只能来回复制粘贴，“很笨拙”。理想的是读书时选中一段直接提问。他的建议是：“别一个人读书。”

七、Python 解释器，以及生态的混乱（59:00–1:04:35）

30×9 这种简单乘法，模型直接“心算”得出 270，更像是记忆。两个很大的数相乘，人会去找计算器，ChatGPT 也被训练成认出自己心算不了的题，转而写 Python 程序运行，再把结果告诉你。

问题是各家工具不一样：Grok 3 当时没有 Python 解释器，它心算，结果“非常接近”但错了；Claude 写了 JavaScript，算对了；Gemini 2.0 Pro 没用工具也算对了，他很意外，于是出了更难的题，它就给出一个接近但错误的答案。结论：要清楚你用的模型有哪些工具，没有工具时它会尽力猜，可能产生幻觉。

八、高级数据分析：一个初级数据分析师（1:04:35–1:09:00）

他让 ChatGPT 搜索 OpenAI 历年估值（特意要求用搜索，防止编数据），做成表格，再画图，纵轴用对数。ChatGPT 写代码画出了图。

两个问题被他抓到了：

  • 2015 年的估值是“不适用”，代码里却悄悄写成了 0.1（也就是 1 亿美元），没告诉他。
  • 让它拟合趋势线外推到 2030 年，它说约 1.7 万亿；但图上的标注和这个数不一致。让它直接打印变量，实际是约 20 万亿。他“质问”它撒谎了，它说抱歉搞错了。

他的结论：它像一个很初级、有点心不在焉的数据分析师。能画图很了不起，但你要懂代码在做什么，仔细检查。他说自己会读代码，但如果别人不能读懂和核对代码，他会犹豫是否推荐用这些工具。

九、Claude Artifacts：为你一个人写的应用和图（1:09:00–1:14:02）

他把亚当·斯密维基百科的引言贴给 Claude，生成 20 张问答卡片，然后说“用 artifacts 功能写一个卡片测验应用”。Claude 写了 React 代码，直接在浏览器里运行：点击显示答案，标记对错，打乱顺序。他说这是一种不同的范式：以前是软件工程师写应用，给你一些自定义选项；现在 Claude 专门为你写一个应用。当然没有后端和数据库，是浏览器里的本地应用。

他承认自己不是 artifacts 的日常用户，但有一个用途他觉得很有用：画概念图。把《国富论》那一章贴给 Claude，让它画“这一章的概念图”，它会用 Mermaid 库画出论证结构：核心是分工与市场范围的关系，然后是陆运和水运的比较、地理因素、早期文明因水运繁荣。他说自己是偏视觉的思考者，喜欢把信息排成树状，帮助记住论证的布局。书、章节、源代码都可以这样画。

十、Cursor：专业写代码的方式（1:14:02–1:22:28）

他工作中大部分时间在写代码，但不会去 ChatGPT 网页要代码片段，因为太慢，而且网页没有他项目的上下文。他用 Cursor（也可以是 VS Code、Windsurf 等）：一个本地应用，能读写你电脑上的文件，背后调用 Claude 3.7 Sonnet 的 API。

他回顾了工具的演变：先是 Ctrl+K 改一行代码，然后 Ctrl+L 解释一段代码，现在是 Ctrl+I 的 Composer，加上 agent 功能后，它像代码库上的自主智能体，会执行命令、跨多个文件修改。他说：“这个叫 vibe coding，这个名字我想大概是我造的。”意思是把控制权交给 Composer，告诉它做什么，希望它能成。最坏的情况，所有文件都在，可以退回到传统编程。

现场演示：从一个空项目开始，用几句话让它搭了一个 React 井字棋。然后说“谁赢了就放彩带”，它要安装 react-confetti（一个他不知道的库），修改代码，给获胜格子加样式，还自作主张要加胜利音效。他说不知道它从哪弄来的音效文件，也没完全跟踪它改了什么，但试玩时“哇，没想到真能行”。

十一、语音（1:22:28–1:37:09）

“假”语音：转写和朗读

他说大约一半的问题是用说的，因为懒得打字；在手机上更多，约 80%。手机 ChatGPT 应用有麦克风按钮，把语音转成文字。桌面应用没有，他用系统级的转写软件 SuperWhisper（类似的还有 WisprFlow、MacWhisper），绑定 F5 键：按一下开始听，再按一下转成文字。产品名、库名这类容易转错的，他还是打字。输出端可以用“朗读”功能，把文字转成语音。他的建议：“别打字，用语音，效果很好。”

“真”语音：高级语音模式

上面是“假”语音，因为中间还是文字。真正的音频处理是把音频切成频谱图的小窗口，量化成 token（比如 10 万种音频片段），在模型内部直接理解和生成。ChatGPT 的“高级语音模式”就是这种。

他现场演示：问天为什么是蓝的，让它用尤达大师的口吻、海盗的口吻说话，讲一个故事，飞快地从 1 数到 20。让它学牛叫，它说了“哞”；让它学狐狸叫，它说做不到。他指出“你刚才明明学了牛叫”。他觉得高级语音模式“非常谨慎（cagey）”，经常拒绝，有时有点尴尬和烦人。当时听说这个功能正在向免费用户开放，他提醒这些东西变化很快。

Grok 手机应用也有高级语音，而且有很多模式。他说 OpenAI 很拘谨、经常拒绝，“Grok 会去那里”，想要娱乐的话 Grok 更合适。他依次试了默认、浪漫、“无拘无束”、阴谋论模式（随口说了一个阴谋论，它就顺着展开到光明会和蜥蜴人），还有一个成人向模式，刚开头他就打断了：“我想你懂了。”

NotebookLM：按需生成播客

在 Google 的 NotebookLM 左边上传资料（文本、网页、PDF），可以和资料对话，也可以在右边生成“深度探讨”播客，几分钟后得到一个约 30 分钟、两个主持人对话的节目，还能加特别指令、在播放中插话提问。他在散步、长途开车时用它听自己有点兴趣但不是专家的冷门话题，人做的播客不会覆盖这些。他还生成了一季叫 “Histories of Mysteries” 的播客放在 Spotify 上，供大家感受效果。

十二、图像（1:40:20–1:49:14）

图像也能变成 token：切成小方块，每块从约 10 万种“标准块”里找最接近的。Transformer 本身不知道哪些 token 是文字、哪些是音频或图像，只是建模 token 流，区别只在编码器和解码器。

图像输入

  • 营养成分表：Bryan Johnson 长寿配方的标签。他总是分两步：先让模型把图转成文字（表格），确认它读对了，再基于文字提问。他让它把成分分组，并按安全程度排序：哪些是普通复合维生素里的，哪些研究得少、比较可疑。
  • 验血报告：拿到一份 20 页的 PDF，“毫无用处”。他截图一块块贴给 ChatGPT（Mac 上 Ctrl+Shift+Cmd+4 截取区域到剪贴板，再 Cmd+V 粘贴），先确认读数正确，再要解读。他说血检结果网上资料很多，所以他比较信任模型的解读，但还是应该找真正的医生，这可以当作和医生讨论的初稿。顺便说，他的结果很好。
  • 数学表达式：论文里一个刁钻的式子，先转成文字，再问 x 取 π 时的值。
  • 高露洁牙膏成分：转写、解释每种成分、哪些最安全哪些最不安全、只保留功能性成分的话哪些可以去掉。他说剧透一下，大部分都不该在里面，公司在食品和化妆品里加这么多不必要的东西让他很不满。
  • 解释梗图：朋友看不懂他发的一张乌鸦梗图。一群乌鸦英文叫 a murder，所以一只乌鸦靠近另一只就是“attempted murder（谋杀未遂）”。

图像输出

OpenAI 的是 DALL·E 3。他自己不常用这个功能，演示时先让它搜索今天的头条，再“生成一张总结今天的图”。他实际的用途是内容创作：他 YouTube 视频的封面图（比如《复现 GPT-2》）用过 Ideogram 等工具生成，也用来做图标。他说明当时 ChatGPT 里的生成图片并不在语言模型内部完成：模型先写一段图片描述，再交给单独的图像生成模型，是“拼接”起来的。

十三、视频（1:49:14–1:53:29）

手机 ChatGPT 的高级语音模式里可以打开摄像头。他拿着手机演示：模型认出墙上的黑色吸音棉（他说其实效果不太好，模型建议覆盖墙角或换布局）；认出 Jack Weatherford 写的成吉思汗传记和费曼的《别逗了，费曼先生》；认出 Aranet4 二氧化碳检测仪，并说 713 ppm 在室内正常，低于 800 较理想，超过 1000 需要通风；认出《指环王》的中土世界地图。

他自己不常用这个，因为他是“重度用户”，问题通常是关于代码的、很有针对性；但如果要给父母或祖父母展示，他会选这个，因为他们可以直接拿着镜头指着东西问。他推测底层可能并不是真的处理视频，而是每秒取一张图之类。

视频生成他不多讲，因为自己不在创意行业。他展示了一条推特，比较各家模型生成“丛林里的老虎”，他认为 Google 的 Veo 2 接近最先进，还有 OpenAI 的 Sora 等，风格和质量各有不同。

十四、提升体验的功能（1:53:29–2:06:30）

记忆

他问 ChatGPT“好莱坞的巅峰大约是什么时候”，它居然给出了观点：90 年代到 2000 年代初，系列电影统治之前。他说很意外，因为这些模型通常回避发表观点；他也完全同意。新对话会清空上下文，但 ChatGPT 能跨对话保存信息：有时自动触发，有时要你说“请记住这个”。它会把对你的了解写成一小段文字存进“记忆库”，这个库会被放在每次对话的开头。

他说这个功能刚推出时他不确定有没有用，现在他“改变了看法”：自然地用下去，ChatGPT 会慢慢更了解他、回答更相关。比如它很擅长推荐电影，有了记忆会推荐得更好。他本来想展示自己的记忆列表，“但看了一下，说实话有点太私人了”。记忆就是一列文本，可以编辑、添加、删除。他认为当时只有 ChatGPT 有这个功能。

自定义指令

在设置里可以全局修改 ChatGPT 的说话方式。他写的是：别像人力资源业务伙伴那样说话，正常跟我说话；尽量多给解释、讲解、见解，要有教育性。他在学韩语，还规定了给他韩语时用哪种敬语程度，否则它有时太随便、有时太正式。

自定义 GPT

他主要用来学语言：

  • 韩语词汇提取器：给一句韩语，按“韩语;英语”格式列出原形词汇，可以直接导入 Anki 做卡片。打开编辑页可以看到，这只是一段提示：背景（我在学韩语，初学者）、指令、四个具体示例。他说给 LLM 指令时，他总是既描述任务、又给具体例子，这叫少样本（few-shot）提示，“我发现这总能提高准确率”。自定义 GPT 本质上就是帮你省下每次重写提示的时间。
  • 韩语详细翻译器：韩语在 Google 翻译上出了名的不好，很多人用 Naver Papago。但这些翻译他看不懂句子是怎么对应过来的，助词等也被省略了。他做的翻译器先给整句英文，再逐词拆解（比如“下午三点了，我想去我最喜欢的咖啡馆”），还能继续追问。他说如果你在学一门语言，“我不会用 ChatGPT 以外的翻译器，我都不知道为什么翻译软件还存在”。指令里用了类似 XML 的标签框住每个示例的输入和输出，让模型分清例子的边界。他说这和教人很像：用语言解释是一回事，给示例好得多。
  • 韩语字幕翻译：看韩国恋爱综艺《单身即地狱》时，字幕是烧录在画面里的，他截图贴进去，这个 GPT 先 OCR，再翻译，再拆解。指令里先给了背景：“你会收到一张来自电视节目的截图，里面是一小段对白”。

十五、总结（2:06:30–2:11:00）

LLM 应用生态在快速增长和变化。ChatGPT 是最早、功能最全的现任者，是很好的默认选择；其他的在追赶，有些方面已经超过。他的个人搭配：搜索还是去 Perplexity（做得久，模型好）；做简单网页原型和画图喜欢 Claude Artifacts；想聊天觉得 ChatGPT 高级语音不错，嫌它拘谨就换 Grok。

他列出选择和使用时要考虑的维度：

  1. 你在和一个 zip 文件说话：留意价格档位和对应的模型。大模型知识多、写作好、更有创意；小模型知识少、更容易幻觉。
  2. 思考模型：数学、代码、推理问题上准确率更高。先试不思考的，不行再换。
  3. 工具：新近信息用搜索；画图、算数、分析数据用 Python（高级数据分析）；网页原型和图表用 Artifacts；专业编程用 Cursor 这类应用。
  4. 多模态：文字、音频、图像、视频的输入输出。有些是模型原生处理的（所谓 omni 模型），更强大；有些是外接的另一个模型。
  5. 体验功能：文件上传、记忆、自定义指令、自定义 GPT。
  6. 网页端和手机端功能不一样，比如手机有视频，网页没有。

他是怎么讲的

  • 全部用自己的真实例子。咖啡因、感冒药、梯度检查 bug、白莲花度假村、补充剂、验血报告、牙膏、《国富论》、韩语学习、换浏览器。观众不只是学到功能，还看到一个具体的人怎样把这些工具嵌进生活。这是他讲实用内容时最突出的选择。
  • 先复习底层，再讲用法。开头用十几分钟回顾“1TB zip 文件”和上下文窗口。后面每条建议（开新对话、贴原文、用搜索、用代码）都能追溯到这个底层模型，建议变得有道理，而不是一堆技巧。
  • 每个功能都配一个“什么时候用”的判断标准。常见、稳定、低风险的直接问；新近、会变、冷门的用搜索；难的数学和代码用思考模型；能 Google 前几个链接解决的就用搜索。观众带走的是判断方法。
  • 把失败和成功一起展示。深度研究漏了 xAI、数据分析悄悄把 N/A 换成 0.1、外推结果打印错、Claude 超长度、Grok 心算出错、语音模式拒绝学狐狸叫。他不替产品打广告，观众因此更相信他推荐的部分。
  • 横向比较多家产品。同一个问题给 ChatGPT、Claude、Gemini、Grok、Perplexity、DeepSeek 都试一遍，并给出个人偏好。这既是信息，也示范了“LLM 议会”的使用习惯。
  • 毫不掩饰个人态度。吐槽 OpenAI 命名乱、未登录不告诉你模型、Perplexity 渲染差、语音模式拘谨、读书工具笨拙、牙膏成分多余。观点鲜明，但都基于具体体验。
  • 现场演示中保留意外。Claude 突然报超长、Cursor 自作主张加音效、语音模式自相矛盾，他都没剪掉，反而顺势讲解。视频像是跟着他真实地用了一遍。
  • 反复强调核实。几乎每一段都回到同一句话：当初稿、看引用、读代码、找医生、自己负责。实用性和谨慎并存。
