这一讲讲什么

01. 开场投票：Bradley-Terry 和奖励的平移、缩放

录像位置 0:00:05–0:05:02

开头几句是期中考试安排：周三课堂考试，可以带一面纸的笔记，范围到这一讲为止。然后是复习投票，选出所有正确的说法：

  1. Bradley-Terry 模型表达的是某人在两个选项 $b_i$、$b_j$ 中选 $b_i$ 的概率。
  2. 用偏好元组和 Bradley-Terry 模型，可以学到一个奖励函数的模型。
  3. 学到的奖励函数加上任意常数，不改变由它导出的偏好。
  4. 学到的奖励函数乘以任意常数，不改变由它导出的偏好。
  5. 在 RLHF 中，每次 PPO rollout 之后都要更新奖励模型。

全班对 (a) 为真、(e) 为假基本一致。RLHF 里奖励模型学好之后就固定了，PPO rollout 之后不更新它。分歧在 (c) 和 (d)，Emma 让大家和邻座讨论，提示是“想想正负号会不会改变结果”。

答案：(a)(b)(c) 为真，(d) 为假。一位学生答对了 (d)：乘以一个负数，所有奖励的大小顺序就反过来了，偏好自然不再保持。平移为什么没关系，代入 Bradley-Terry 的式子就能看到，指数里的常数上下相消：

$$P(b_i\succ b_j) = \frac{\exp(r(b_i)+c)}{\exp(r(b_i)+c)+\exp(r(b_j)+c)} = \frac{\exp(r(b_i))}{\exp(r(b_i))+\exp(r(b_j))}$$

这件事后面会用到：奖励只在平移意义下可辨识。推导 DPO 时会看到，这个“缺点”在那里反而派上了用场。

02. Emma 的回顾：从奖励模型到 ChatGPT

录像位置 0:05:02–0:12:50

为什么用成对偏好

Emma 先回顾上一讲。模仿学习拿到的是完整的示范轨迹；成对偏好（pairwise preference）能提供更多信息，又处在两种极端之间：一端是像 DAgger 那样让人在每一步标注该做什么，或者让人写出稠密的奖励；另一端是只给示范。Bradley-Terry 模型的参数可以用交叉熵最大化似然来学，参数不唯一（刚才的投票：平移不改变偏好）。上一讲讲了对整条轨迹和对只有有限个行动的老虎机问题分别怎么做。作业 3 会在 MuJoCo 类问题的 rollout 上同时实现 DPO 和 RLHF。

语言模型上的偏好数据

接着她借用 Tatsu Hashimoto 在 NLP 课上的讲义，回到第一讲出现过的 ChatGPT 流程图：先收集示范数据，再收集比较数据，最后优化策略。现在后两步都讲过了。人可以给成对偏好，也可以给完整排序，用来学奖励模型。讲义里的语言例子是对同一个提示的几个回答排序，比如“旧金山发生地震，有轻微财产损失，无人受伤”“旧金山发生 4.2 级地震，造成大规模破坏”“湾区天气好，但有时有山火和地震”。此时上下文就是提示（prompt），行动就是所有可能的回答，人给它们排序。

先检查奖励模型

真正跑 PPO 之前，最好先检查奖励模型的质量，作业 3 也要考虑这一点。能不能抓住人背后潜在的奖励，取决于数据量和奖励模型的复杂度。Emma 展示的图是不同大小的奖励模型在验证集上的准确率。这里的奖励模型很大，和语言模型同一个量级，70 亿参数的奖励模型并不少见。数据足够多、模型足够大时，才能刻画复杂的人类偏好。她提醒做项目和作业时也要想：要多复杂的模型才能捕捉人的偏好？需要的偏好数据也不少，比训练 LLM 的数据少得多，但远不是一两条。如何减少额外需要的在线偏好数据（相对已有历史数据新收集的那部分）是一个活跃的研究方向。

RLHF 和 best-of-n

有了奖励模型，就可以用 PPO 优化。和之前讲 PPO 时一样，需要一个参考策略（reference policy），一般来自行为克隆或监督微调（SFT），优化时要正则化，别离它太远，这个散度约束和之前一样重要。效果上，用奖励做 RLHF 比之前的方法有明显提升，固定模型大小也是如此，说明换优化目标、用奖励函数，能带来实质收益。

Emma 指出这里和课上大部分内容的区别：以前训练智能体做一件事，比如后空翻、走网格世界；这里是训练一个语言模型去做用户可能想要的任何任务，写感谢信、做网站……以前被看作不同任务的东西都混在一起，更像元强化学习（meta RL）或多任务强化学习。

她还展示了 Stanford 2023 年的一项对比。其中一个基线叫 best-of-n：从原模型生成 $n$ 个样本，用奖励模型挑出得分最高的那个。它不用任何强化学习，也不用 PPO，只把奖励模型当作外部评委。结果它和 PPO 相比也不差，总体略逊一点。Emma 认为这类替代基线值得考虑，要看你能不能重新训练模型、能不能训练奖励模型、手上是否只有现成的 LLM，几种情况可以组合。怎样最好地训练和改进这类模型仍是很活跃的方向。

03. RLHF 三阶段与奖励建模

录像位置 0:12:50–0:21:07

Emma 介绍：DPO 拿到了 NeurIPS（机器学习顶会）的杰出论文奖亚军，作为 RLHF 的替代方法已经在 LLM 社区产生了广泛影响；三位作者几天前还在 arXiv 发了一篇扩展工作。作业 3 据她所知是第一份同时包含 RLHF 和 DPO 的作业。

为什么现在在语言模型上做 RL

Eric Mitchell 先铺背景。他说人们在语言模型上做 RL 已经很久了，不是 ChatGPT 出来才开始的。ChatGPT 让大家注意到，这些方法第一次真正好用了。一大原因是可以从一个很强的预训练模型出发，它已经有很多技能和预先学到的行为，RL 只需要在上面微调，不用从零开始，这让这些算法容易产生收益。

三阶段流程

  1. 第 0 步是无监督预训练：在海量文本上拟合一个大的生成模型。Eric 说某种意义上这一步是“元学习”出一堆技能，后面从中挑选。
  2. 第一阶段，监督微调（SFT）：准备一批提示，比如“给六岁小孩解释登月”，由人写出合理的好回答，做监督学习。得到的模型就是 Emma 说的参考策略。后面会约束模型别离它太远，这让学习容易一些，也防止过度优化那个近似的代理奖励函数（proxy reward）。
  3. 第二阶段，学奖励模型：通常从 SFT 模型采样若干回答，请人（或一组人）给这些回答做排序标注，再学一个从（提示或对话历史，候选回答）到标量奖励的映射。
  4. 第三阶段，策略学习：微调 SFT 模型，让它生成在奖励模型下得分高的回答。

反馈的形式

数据集里每条是一个提示 $x$（可以是单个提示，也可以是多轮对话历史加最近一条用户消息），通常只有两个回答，标注一个二元偏好。也可以对更多回答排序，但收益很快就到平台期，一般来说多一些提示、每个提示少一些回答更好。

为什么不直接让人打分，比如 1 到 10 分？Eric 给了两个理由。第一，人和人之间的绝对分数不校准：两个人读同一份“做一个好蛋糕的食谱”的两个回答，可能给出同样的排序，但具体分数差很多。第二，给出绝对分数在认知上更难；以一个回答为锚、判断另一个更好还是更差要容易。所以和让人写高质量示范、或直接给奖励相比，收集偏好是在单位认知成本下拿到更多标注信息的方式。

Bradley-Terry 与奖励模型损失

Bradley-Terry 模型是一个简单的离散选择模型，把一个打分函数（这里是奖励 $r(x,y)$）和在两个离散选项之间做选择的概率联系起来。记数据中被标为更好的回答为 $y_w$（preferred），更差的为 $y_l$（dispreferred）：

$$p(y_w\succ y_l\mid x) = \frac{\exp r(x,y_w)}{\exp r(x,y_w)+\exp r(x,y_l)} = \sigma\big(r(x,y_w)-r(x,y_l)\big)$$

其中 $\sigma$ 是 sigmoid 函数。对观测数据做最大似然，就是最小化负对数似然：

$$\mathcal{L}_R(r_\phi) = -\mathbb{E}_{(x,y_w,y_l)\sim\mathcal{D}}\Big[\log\sigma\big(r_\phi(x,y_w)-r_\phi(x,y_l)\big)\Big]$$

Eric 说这就是一个二分类问题：logit 是奖励模型给“被选中回答”的奖励减去给“被拒绝回答”的奖励，然后做最大似然。到这里第二阶段完成。

04. 策略学习阶段：KL 约束和几个提问

录像位置 0:21:07–0:26:21

第三阶段才是“RL 的部分”：学要微调的策略 $\pi_\theta$，在数据集中的提示上、对策略采样的回答，拿高奖励。Eric 问大家：只最大化奖励会出什么问题？

问题在于这个奖励不是真奖励，是从有限数据学来的。在某个分布里它给出准确或有意义的奖励，出了这个分布，没有任何保证它能合理地泛化。奖励模型是在参考模型的样本上训练的，策略离参考模型太远，就到了奖励模型没见过的区域，开始拿到“虚假”的高分。所以目标里加一个对参考模型（SFT 模型）的 KL 惩罚：

$$\max_{\pi_\theta}\ \mathbb{E}_{x\sim\mathcal{D},\,y\sim\pi_\theta(y\mid x)}\big[r_\phi(x,y)\big] - \beta\,\mathbb{D}_{\mathrm{KL}}\big[\pi_\theta(y\mid x)\,\|\,\pi_{\mathrm{ref}}(y\mid x)\big]$$

KL 散度（Kullback-Leibler divergence）衡量两个概率分布差多少；$\beta$ 控制奖励和“别走远”之间的权衡。

学生提问

  • 参考模型会变吗？Eric：看算法。最初的经典 RLHF 里参考模型是固定的；之后有很多工作提出随时间更新参考模型。
  • $y_w$ 和 $y_l$ 都来自同一个参考模型吗？在经典 RLHF 里是的，从参考模型采两个回答，拿偏好，学奖励模型。之后人们提出了各种采样方案，决定给人看哪一对回答。
  • 学生听说实践中两个回答会用不同温度、甚至不同模型生成，理论上是否有问题？Eric 说不一定有问题。把对话历史看作状态空间、回答看作行动空间，我们希望奖励模型在整个空间都表现好，这样更新策略时拿到的奖励才有意义。所以偏好数据越多样越有帮助。这里有取舍：既想把偏好数据集中在高质量回答上，也要覆盖足够广，免得高估差回答的奖励。
  • 深度学习里大网络在小训练集上训到接近零误差，仍能在测试集上泛化，奖励模型为什么不行？Eric：同样适用，双下降（double descent）这类现象在这里也有，更大的奖励模型通常更好。但有限的偏好数据所含信息有限。如果偏好数据全是“喜欢哪种宠物”，模型再大也不会告诉你量子场论该怎么答。

Eric 最后说，用 PPO 做策略学习这一步很繁琐，有很多部件（他打趣说大家会在作业里“有幸”亲手实现）。DPO 的起因之一就是 Rafael 当时在一个问题上很难把 PPO 调好。

05. DPO 的推导

录像位置 0:26:21–0:33:07

Archit Sharma 接手。他的问题是：按人类偏好微调模型，真的要做上面这一整套吗？答案是不需要。

高层思路

现在奖励函数是一个单独的网络，告诉我们人喜欢什么、不喜欢什么。语言模型本身就给出了对补全（completion）的概率，目前表示的是互联网文本的分布。能否“重载”这个分布，让它只把概率放在人喜欢的回答上？DPO 利用的是语言模型和奖励模型之间存在一一对应关系，于是可以直接用偏好训练策略。

第一步：KL 约束目标的闭式解

对上一节的 RLHF 目标（对任意奖励函数 $r$ 都成立，一般是学到的那个），最优策略有闭式解（closed form）：

$$\pi^*(y\mid x) = \frac{1}{Z(x)}\,\pi_{\mathrm{ref}}(y\mid x)\exp\Big(\frac{1}{\beta}r(x,y)\Big),\qquad Z(x)=\sum_y \pi_{\mathrm{ref}}(y\mid x)\exp\Big(\frac{1}{\beta}r(x,y)\Big)$$

Archit 没推导，留作练习，说不难。他说这就是 Boltzmann 分布的形式，是早已知道的结果，不是他们的贡献。直觉是：从参考分布出发，按指数化的奖励给每个回答加权，奖励高的回答概率变高。只乘上指数项得到的不是概率分布，所以要除以配分函数（partition function）$Z(x)$，它是对给定问题 $x$ 的所有可能回答求和。$\beta$ 是在奖励和 KL 约束之间权衡的温度项。

问题是 $Z(x)$ 无法计算：要枚举所有句子，算每个句子的概率再乘指数奖励，这不可行。所以这个式子本身用处不大。

第二步：把奖励写成策略的函数

把上式取对数、移项，就能用最优策略反过来表示奖励：

$$r(x,y) = \beta\log\frac{\pi^*(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)} + \beta\log Z(x)$$

Archit 强调这一步的直觉：如果最优策略在某个回答上放的概率比参考分布多，这个回答的奖励就高；放得少，奖励就低。这和我们对奖励的期待一致，被偏好的回答应该概率更高、奖励更高。奖励函数和概率分布之间的联系就这样建立起来了。剩下的麻烦还是那个 $\log Z(x)$。

第三步：代入奖励模型损失，配分函数相消

回到奖励模型的 Bradley-Terry 损失：logit 是两个回答的奖励之差。把上面的表达式代进去，$\beta\log Z(x)$ 只依赖输入 $x$，不依赖回答 $y$，相减时正好消掉。于是“奖励函数上的损失”加上“奖励与策略之间的变换”，得到一个直接定义在策略上的损失，也就是 DPO 损失：

$$\mathcal{L}_{\mathrm{DPO}}(\pi_\theta;\pi_{\mathrm{ref}}) = -\mathbb{E}_{(x,y_w,y_l)\sim\mathcal{D}}\Big[\log\sigma\Big(\beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\mathrm{ref}}(y_w\mid x)} - \beta\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\mathrm{ref}}(y_l\mid x)}\Big)\Big]$$

它形式上就是奖励建模损失，只是“奖励”换成了 $\beta\log\frac{\pi_\theta}{\pi_{\mathrm{ref}}}$，常被称为隐式奖励（implicit reward）。最小化这个损失就是拉大括号里的差：策略在偏好回答 $y_w$ 上的对数概率要比参考分布高，在不被偏好的回答 $y_l$ 上要比参考分布低。（录像里 Archit 第二处口误说成了“偏好回答”，按式子应为不被偏好的回答。）

随后有人补充：可以把这看作利用了“奖励可以平移任意常数”这一点。平时这被当作缺点（奖励不唯一），这里正好用它消掉了配分函数。

整个过程不需要单独训练奖励模型，不需要在训练中从策略采样，也不需要 PPO 的那一套部件，只要对偏好数据做一个类似分类的监督损失。

06. IMDb 情感实验：奖励-KL 前沿

录像位置 0:33:07–0:39:20

实验设计

Rafael Rafailov 讲结果。这是他们在项目里做的第一个对照实验：用 IMDb 影评数据集，目标是让模型生成正面的影评。用一个预训练的情感分类器充当“黄金奖励函数”（gold reward），所以这里知道真实奖励是多少。他们从基础模型（2026 课件写明是 GPT2-XL）生成大量样本，用情感分类器排序，造出合成偏好，然后在这份数据上比较多种基线。他们关心的是：作为核心目标的优化器，DPO 到底好不好。整个问题背后是奖励和 KL 的权衡，他们想看各方法能画出多好的帕累托曲线。

有学生请他定义帕累托曲线（Pareto curve）。Rafael：这是经济学和决策分析里的概念，用于多个目标之间的权衡，这里是奖励对 KL。我们关心能拿到的最优权衡；如果一个方法在不放弃另一个目标的情况下能在某个目标上拿到更多，就说它帕累托占优（Pareto dominate）另一个。这里的意思是在同样的 KL 下，DPO 拿到的奖励更多。

Rafael 说他花了大概两个月调 PPO 的数字。PPO 能用，能出结果，但追不上 DPO 的曲线。

他对评估方式的批评

Rafael 放这张图，还有一个用意：他认为直到现在，几乎所有 RLHF 论文的评估方式都可能有问题。论文通常只报胜率（win rate）或比较结果，却不画这种曲线，你不知道它落在权衡曲线的哪个位置。单个数字说明不了什么，因为这是一个优化问题，只取曲线上一点，看不出优化做得好不好。比如图上某个 PPO 点的奖励比某个 DPO 点高，看起来更好，但作为优化算法并非如此。他认为每次出现新方法，都应该先问这个问题。

关于方差的提问

有学生问：PPO 不如 DPO，是奖励模型设定错了，还是 PPO 的优化不好？Rafael 指出图中紫色那条是开箱即用的 PPO（TRL 库），他们自己的实现好很多。主要差别出乎他意料地简单：每个提示多采几个回答。他说后来很多论文专门写这件事，而在他看来它只是个脚注。问题出在方差上；RLHF 里奖励可以任意平移，方差问题更严重。他们写论文时做过分析：大约 60% 的奖励分数是噪声，常规 PPO 的信噪比大约 40%，整个流程混在一起后方差会爆炸，信号很稀疏。为什么信噪比差，论文里有半页分析；简单说，每个提示多采几个回答，问题基本就消失了。

  • 怎么读这张图？横轴是 KL，纵轴是奖励。奖励当然越高越好，但 RLHF 是在 KL 代价下最大化奖励，图展示每种方法在给定 KL 下能拿多少奖励，希望在同样 KL 下奖励最多。
  • 情感任务的奖励是什么？就是句子的情感，1 表示很正面，0 表示很负面。
  • 模型是否可解释，喂了噪声数据能不能调试？Rafael 说这个问题比表面复杂，有整条研究线在做含噪反馈的平均、多模态反馈、对齐的多元性（plurality of alignment），一句话答不了。
  • 实际模型里会选多大的 KL，比如 10 左右？Rafael 说完全取决于模型和数据，这张图放到摘要任务上毫无意义。另一位讲者补充：很难选具体数字。通常做法是看其他关心的基准（比如 MMLU）表现，KL 越小，其他基准的能力越能保住，所以一般偏向小 KL，在其他基准表现仍然好的地方停下。

07. 业界采用和理论延伸

录像位置 0:39:20–0:42:55

论文里还有其他实验，时间关系 Rafael 跳过了。他认为对算法最好的证明是它被社区大规模采用：

  • 几个月前 Hugging Face 的 Open LLM Leaderboard（开源语言模型排行榜）前十名里，有 9 个是用 DPO 训练的（他说这个数据可能已经有点旧）。
  • 机构也开始用。他引用了 Mistral 的论文，那里 RLHF 阶段只用了 DPO；一些较强的 Mistral 模型在某种程度上能和 GPT-4 竞争。所以有证据说明它在很大规模上可行。
  • 上周公布的 LLaMA 3 的优化流程里也用了 DPO，有意思的是和其他方法混在一起用。

论文到这里结束。此后他们和其他人做了大量后续工作。Rafael 提了两个：

  • 课上讲过最大熵逆强化学习。在最大熵 RL 设定下，DPO 可以推导成一种逆 Q-learning（inverse Q-learning）算法，论文叫 Your Language Model is Secretly a Q-Function。他说这听起来简单，但确实可以做到。
  • 听说作业要在控制问题上用 RLHF。在经典表述下，DPO 并不适用于控制问题，需要把偏好建模在遗憾（regret）上，而不是建模在奖励函数上。这是另一项独立工作，他希望助教考虑过这一点。

08. DPO 与 PPO 之争，以及 DPO 的过度优化

录像位置 0:42:55–0:52:19

争论的两个问题

Rafael 选择重点讲社区里、业界、Twitter 上正激烈争论的“DPO 还是 PPO”。他说不想显得自我中心，但他认为整个争论几乎都问错了。DPO 拟合的是一个隐式奖励函数，围绕它有两个问题：

  1. 隐式奖励函数和显式参数化的奖励函数一样好吗？
  2. 对 DPO 拟合的隐式奖励，可以解析地得到最优策略。也可以把这个隐式奖励交给 PPO 去优化：如果 PPO 优化得完美，会得回同一个 DPO 策略。但机器学习里的优化很少完美，PPO 会得到一个次优解。这种次优会不会带来某种正则化效果，反而让模型更强？

第一个问题：RewardBench

最近出了 RewardBench，一个大规模评估奖励模型的基准。DPO 模型既是生成模型，也能当判别式的奖励模型来评估。在对话（chat）类偏好打分上，排名前四的都是 DPO 模型，超过了一些更大的闭源专有模型。在推理（reasoning）上，第一名是 Cohere 的专有模型，接下来五个都是 DPO 模型。Rafael 说研究总还有要做的，但在他看来这项工作基本确认了 DPO 的隐式奖励和经典 RLHF 的奖励差不多好，用隐式模型代替显式参数化的模型，没有损失通用性或能力。

第二个问题：越训越啰嗦

那么，用 PPO 这种较弱的优化器，会不会通过某种正则化得到更好的解？他们最早收到的反馈之一来自有人训练了很大规模的 DPO 模型：开始效果不错，然后越来越啰嗦，回答越来越长，最后停不下来，完全跑偏。

他们在摘要和对话两个数据集上看了回答长度的分布。蓝色是偏好回答的长度，红色是不被偏好回答的长度，偏好回答略长一点，人有偏向长回答、长摘要的倾向。用 DPO 训练后（每一列是一个正则化强度），在任何一种正则化强度下，这个偏差都被极度放大。绿色直方图是 DPO 输出的长度。DPO 没有停留在数据分布内部重新分配概率，它把输出推到了数据集覆盖范围之外很远的地方。

奖励过度优化

这就是奖励钻空子（reward hacking），也叫奖励过度优化：策略找到奖励函数的漏洞，让代理奖励很高，真实质量却不升反降。Rafael 介绍了 OpenAI 的论文 Scaling Laws for Reward Model Optimization：相当于更大规模的情感实验。他们用真实人类偏好训练了一个很强的奖励模型当“黄金”奖励，用它给合成数据打标、造合成偏好，再在合成偏好上重做整套 RLHF。图的横轴是 KL，纵轴是奖励。虚线是 PPO 训练时学到的代理奖励，实线是黄金奖励。从 RL 的角度看，代理奖励一直在涨，模型似乎做得很好；但真实质量停滞甚至下降。

之后这个概念越来越受重视，一方面是实际用途，另一方面 AI 安全社区很担心它，Rafael 提到“回形针”的说法：模型找到利用奖励函数的办法，以为自己在做好事，其实在做很坏的事。这篇论文有约 200 次引用，已有大量缓解工作。在经典 RLHF 中出现这个现象不意外：学了一个代理奖励，又不断用新数据去查询它，新数据可能在分布之外。

Rafael 说社区大体还没意识到，直接对齐（direct alignment）方法也会这样。直觉上似乎不该如此：一是没有代理奖励函数，直接在数据上优化模型；二是没有新数据，不采样，全在数据集内。但他们正在整理的新结果显示，奖励钻空子在 DPO 中相当普遍，DPO 的各种变体（IPO、SLiC 等）都有。甚至可能比 PPO 更严重：PPO 是较弱的优化器，要用力推才能碰到奖励函数的尾部；DPO 给出精确的解析最优解，在某种意义上是“绝对地”钻空子。

他展示的图横轴仍是 KL，纵轴换成 GPT-4 判定的胜率，每个点是一个 DPO 训练检查点，几组对应不同模型大小。图中呈梳子形的规律：训练越多、KL 越大，表现不升反降。理论上这条曲线应该单调，放弃一些 KL 换来一些奖励，实际并非如此。DPO 的隐式奖励本身和其他奖励一样好，但优化过头就会落入奖励钻空子，这时较弱的 PPO 优化可能更稳定、更有利。

接下来的方向

  • 大量工作曾用于让 RLHF 更稳健；现在看来直接对齐算法同样容易钻空子，也需要做稳健化。
  • 在线微调算法越来越受关注：怎么获取偏好、怎么高效微调。
  • RLHF 扩展到各种模态：视觉语言模型、扩散模型（他说 Stable Diffusion 3 也用 DPO 训练）、文生图、文生视频，语音和音乐可能是下一个。他们几周后会发一篇用反馈做蛋白质合成的论文，也在做大规模机器人基础模型的安全。
  • 多轮交互（经典 RLHF 做不了）和智能体工具使用。

09. 问答（一）：数据覆盖、标注置信、多步奖励、非传递偏好

录像位置 0:52:19–1:02:07

奖励钻空子是不是 Bradley-Terry 模型本身带来的？

回答：这本身就是一个研究课题，根本上是有限数据的问题。如果数据对所有东西都有均匀覆盖，钻空子就会消失。学生追问：奖励里有比值或指数化的比值，模型会想办法把比值拉偏，换一个奖励形式会不会好？回答：换成 hinge 损失或平方损失，照样发生。讲者用 cheetah 举例：目标速度是 10，跑 8 比跑 7 好，跑 9 比 8 好，于是模型推断跑 11 比 10 更好，但数据里从没见过跑 11 的，这种外推是错的。长度那张图也一样：数据说长一点更好，模型就认为越长越好。

如果一个提示下所有回答都不好？

标注者必须排出顺序，却没法表示“最好的那个也不怎么样”，有没有办法给排序加置信度权重？讲者说没有简单答案，这几乎是 RL 里的探索问题：如果从来没见过好的轨迹，能学到什么？有用的做法是换反馈形式，比如点赞点踩，全部都差时可以把大部分回答降权。另一位讲者接着说，常有人问 PPO 能在训练中从策略采样、能探索，应该更有优势，而 DPO 只用固定偏好数据。但我们优化的只是代理奖励，真正重要的探索发生在收集偏好数据的时候：训练策略时采到了一条很好的轨迹，如果奖励模型没把它判为好，也没用。所以这是探索问题，多轮或迭代式的流程可能很有帮助。

多步推理、只在最后给奖励，能用吗？

可以。前面说过可以把它看作 Q-learning 问题，这一点不容易证明但成立。如果只在最后有稀疏奖励，把问题看作按 token 的 MDP，模型最终会对中间 token 做某种信用分配（credit assignment），虽然不做显式自举（bootstrapping）。已有若干结果表明，只有序列级奖励也能学到有意义的中间行为。

真实数据和合成数据有什么区别？

有学生请讲者回到 OpenAI 那页。回答：他们用真实人类比较训练出一个黄金奖励模型，再从基础模型生成数据，用黄金奖励打分造合成偏好。这样可以随时查询黄金奖励，知道合成样本的真实分数，才能画出那些图。学生问：钻空子是不是因为没用真实奖励？回答：用有限数据训练任何奖励函数都会这样，无限数据下大概不会出现。有限数据下，分布外会有误差，有的高估有的低估；你对着它优化，就会专挑误差偏正的回答，于是学到的奖励上升、真实奖励下降。讲者让大家回想 DAgger 里监督学习误差的累积，是同一回事。

Rafael 还补充了一个他认为很意外的结果：那些高 KL、胜率很低的检查点，作为奖励函数的损失都很低、准确率都很高。也就是说奖励函数的质量和下游策略的表现不一定相关。

偏好不满足传递性，比如石头剪刀布？

讲者说有一批新工作想离开“最大化奖励”的框架，把问题看作博弈：在策略层面搜索，使得从我的策略采一个行动、从某个对手（或比较）策略采一个行动时，我方的期望胜率最高。这需要选一个对手策略类，对石头剪刀布来说合理，因为那里没有单一最优行动，好坏取决于对手的策略。这样即使只有偏序、不能比较所有回答对，也能用这类数据，不必先拟合奖励函数。学生提到“Nash 策略”，讲者说对，比如 Direct Nash Optimization、Nash Learning from Human Feedback。Rafael 补充：石头剪刀布没有确定性的 Nash 不动点，只有随机的那个，也就是对所有行动等概率。这和更深的结果有关：这种偏好多元的例子在理论上是无法满足的，理论上和实践中都训练不出能满足这组偏好的模型。另一位补充：这也是一个动机，不同人群各自的偏好可能都满足传递性，合在一起却不满足。

10. 问答（二）：步长、集成与权重平均、胜率与奖励归一化

录像位置 1:02:07–1:18:44

DPO 里什么限制了每步更新太大？

回答是 KL 正则，也就是 $\beta$。sigmoid 过了某个点会饱和；$\beta$ 越大，括号里的对数概率差只需拉开较少就能让损失变小。粗略说 $\beta$ 控制损失变化有多快，学习率等其他超参数也有影响。

集成和权重平均

有学生问：缓解奖励钻空子常用奖励模型集成（ensemble），DPO 这类直接方法能不能也集成？回答：可以，麻烦是要保留所有模型。但有更聪明的集成方式，不必保存整个模型的完整副本，可以只集成模型的一部分，或者把奖励模型表示成分布而不是单个标量。这又和偏好不一致的数据联系起来：建模这种数据的一种方式是用非确定性或多峰的奖励函数，只要能用生成模型的结构表示它，就仍然可以放进类似 DPO 的损失里。

问到 DPO 里缓解钻空子有什么有希望的方向，Rafael 说经典 RLHF 上的很多方法可以直接迁移。他特别感兴趣的一个来自开源社区：Twitter 上有人发现，把一堆随机的 RLHF 模型的权重直接平均，模型就变好了。他说他们并不理解自己在做什么，但其实 2018 年前后就有大量关于优化地形（optimization landscape）的工作解释这一点。有一篇论文叫 WARM（Weight Averaged Reward Models）：训练一组奖励模型，不保留整个集成，而是把权重平均，奖励函数的稳健性显著提高。DPO 似乎也一样，把训练好的一组 DPO 模型权重平均，稳健性也显著提高。他们手上有约 400 个检查点，下一步打算试试进化式合并（evolutionary merge）这类策略能挤出多少稳健性。

KL 约束可能太粗

另一位讲者补充：起点是带 KL 惩罚的奖励最大化目标，直觉是 KL 小就不会过度优化奖励函数。但这是一种粗糙的表达。更接近我们想要的是：在奖励模型高度不确定的地方保守；某个区域虽然在分布外，但奖励模型很有把握（不确定性低，比如奖励的低分位数仍然很高），那就可以在那里大幅改变模型。离开 KL 正则的目标是一个方向。KL 正则的好处是给出策略和奖励模型之间的一一对应，但它可能过度约束了策略，损失了一些性能。

Rafael 又补充：既然这些算法都可以看作 Q 函数，DQN 当初也很难调通，过了几年才靠一系列技巧变得稳定：防止自举出问题、防止过拟合等。这些技巧也许能迁移到 LLM 上。权重平均就受到 DQN 的启发：DQN 的目标 Q 网络是对权重做 Polyak 平均（滑动平均）得来的，这对稳定性帮助很大。他认为对“LLM 的 Q 函数”可能也有类似结果，但还在实验计划里。

过拟合与小数据领域（比如医疗）

回答：这就是过拟合问题，数据覆盖有限，往错误方向外推。但更复杂一些：人们发现在 DPO 等设定里，过拟合有时反而有益，小数据集上可以跑多个 epoch，他们有的实验用很小的偏好数据集也能用。人们明显在过拟合，性能却还在涨。不过很大程度取决于怎么评估，你多半在别处有所损失，要看具体用途。

另一位讲者补充了另一层错位：前面讲的奖励过度优化，是代理奖励和看不到的真实奖励之间的差距；还有一层是评估时我们通常不看平均奖励，而是看胜率，也就是和某个基线策略比。这更像“够好就行”（satisficing）而不是最大化，训练目标和真正对人有用的东西之间又多了一层脱节，又多了一种对目标过拟合的可能。

能不能把 SFT 和偏好学习合成一步？

有学生问：先 SFT 再 DPO，用 KL 防止离 SFT 模型太远；能不能从头训练时就一起做偏好学习？回答：有一些工作尝试过，仍是活跃研究方向。先理解为什么 RLHF 之前要做指令微调：从预训练模型出发，它的回答常常是乱的，甚至不按指令回答，指令微调让模型能生成合适的偏好数据。所以在一个典型流程里，手上一开始还没有偏好数据，才需要先做指令微调。如果已经有偏好数据，也有方法把指令微调和偏好学习放进同一个优化里，损失函数的组成部分和已经见过的差不多。

学生追问能不能像 DAgger 那样训练后再微调、迭代。讲者说有这样的方法，有论文称效果很好，他自己的经验是效果不好；有人插话说 DAgger 本身也不好调，但不代表不可能。Rafael 个人对一步到位合并比较怀疑，因为优化地形太复杂、陷阱太多，一次性同时走对方向很难，也不清楚好处在哪。另一位讲者说这又回到探索：第一天 OpenAI 只有 SFT 模型，还没有任何偏好数据，要得到偏好，必须先有一个探索来源生成轨迹，所以只能先做一个再做另一个。如果想在单个离线阶段完成，就被已有数据的探索程度卡住；能采样、再对新样本收集偏好，是有用的。

能不能直接优化胜率？

讲者说 Nash 类算法基本就是这么做的：如果只能评估偏好函数（输入两个回答，判断哪个更好），而不是奖励函数，可以把目标定为在我的策略下、偏好函数在“我方一个回答”和“基线策略（或最坏情况的对手策略）一个回答”上的期望值，也就是显式优化平均或最坏情况的胜率。和 PPO 比怎么样？看问谁。提出这些方法的论文报告了胜率提升，这不意外，因为用胜率评估、也用胜率训练。一个好处是不经过奖励函数，不要求对所有回答有完全的全序，框架没那么受限。但任何相对参考模型得到的策略都可以解释成一个奖励函数，所以优劣怎么看他也不确定。

Rafael 补充：如果 Bradley-Terry 模型确实是数据生成模型，最大化奖励和最大化胜率的概率其实是同一件事。奖励最大化因为奖励可以任意平移，方差很高。OpenAI 在其他论文里（他说总是在百页论文的脚注里）会对奖励做归一化：减去人类基线，让人类写的回答奖励为 0。这样 PPO 优化的奖励，就是在 Bradley-Terry 下“生成的回答比人类回答更受偏好”的对数概率，两者紧密相连。他说从他们的角度看，归一化不改变最优策略，但实验里显著降低了方差。有学生说这就像一个基线（baseline），Rafael 说完全就是基线，而且有效，方差明显下降。

多目标

最后一个问题：DPO 能否用于多目标？有一篇论文叫 MODPO（multi-objective DPO）：可以对多个目标的某种标量化（一组权重）做条件，学一个以权重为条件的策略，之后选想要的权重组合，不必为每一种标量化重新训练。还有方法在奖励模型的不确定性上做类似的事。Emma 感谢讲者，祝大家期中顺利。

这一讲的要点

  • Bradley-Terry 下奖励加常数不改变偏好，乘负数会反转偏好；RLHF 中奖励模型训好后固定，不在每次 PPO rollout 后更新。
  • LLM 的 RLHF：预训练，SFT（得到参考策略），收集成对偏好、训练奖励模型（可大到 70 亿参数），用 PPO 在 KL 约束下优化；best-of-n 不用 RL 也是有竞争力的基线。
  • 收集偏好而非绝对分数，因为人与人的绝对分数不校准，比较也更省力。奖励模型损失：$-\mathbb{E}[\log\sigma(r_\phi(x,y_w)-r_\phi(x,y_l))]$。
  • KL 约束的原因：奖励模型只在参考模型样本附近可靠，走远了会拿到虚假高分。目标：$\max\ \mathbb{E}[r_\phi(x,y)]-\beta\,\mathbb{D}_{\mathrm{KL}}[\pi_\theta\|\pi_{\mathrm{ref}}]$。
  • 闭式解 $\pi^*\propto\pi_{\mathrm{ref}}\exp(r/\beta)$，移项得 $r=\beta\log\frac{\pi^*}{\pi_{\mathrm{ref}}}+\beta\log Z(x)$；代入 Bradley-Terry 损失后 $\log Z(x)$ 相消，得到 DPO 损失 $-\mathbb{E}\big[\log\sigma\big(\beta\log\frac{\pi_\theta(y_w|x)}{\pi_{\mathrm{ref}}(y_w|x)}-\beta\log\frac{\pi_\theta(y_l|x)}{\pi_{\mathrm{ref}}(y_l|x)}\big)\big]$。
  • IMDb 情感实验中 DPO 的奖励-KL 前沿优于 PPO；Rafael 认为只报胜率、不报 KL 的评估看不出优化好坏。PPO 的高方差可靠每个提示多采样来缓解。
  • DPO 被广泛采用（Open LLM Leaderboard、Mistral、LLaMA 3、Stable Diffusion 3）；RewardBench 显示 DPO 隐式奖励和显式奖励模型一样好。
  • DPO 同样会奖励过度优化，比如回答长度被推到数据分布之外，胜率随 KL 增大反而下降；作为更强的优化器，它可能比 PPO 更容易钻空子。根源是有限数据下奖励在分布外的误差。
  • 问答要点：真正重要的探索在收集偏好数据时；非传递偏好可用 Nash 类博弈方法、直接优化胜率；权重平均（WARM）提升稳健性；$\beta$ 控制更新幅度；奖励减去人类基线等于一个降方差的基线。
