第三讲：Black Forest Labs 与视觉智能

从 Stable Diffusion 到 Flux，为什么要从图像、视频、声音这些"自然表示"学起，Flux Kontext 怎样从用户反馈里诞生，开源权重怎样变成生意，以及扩散模型和自回归模型的根本区别

主讲：Anjney Midha · 嘉宾：Andreas Blattmann（Black Forest Labs 联合创始人，Stable Diffusion 作者之一）
资料来源：课堂录像（Stanford Online 公开，本文依据录像字幕整理）

一、本讲的位置

Anjney 先回顾了第一讲的框架：技术栈正在从旧系统转向新系统；AI 的缩放配方有两个循环，用算力和数据造出模型，推理带来收入去买更多算力，同时带来上下文反馈；进步的瓶颈有四个，上下文、算力、资本、文化；做项目时，要先选定要攻克的前沿方向（孵化），然后发布一个最先进的版本，再逐步扩展到更多能力。第一讲"参观"了 Anthropic 这座"前沿 AI 工厂"，上一讲是 ElevenLabs 的音频，这一讲参观德国的 Black Forest Labs（BFL），主题是视觉智能。Anjney 认为视觉可能是最关键的前沿，要让模型在真实世界的关键场景里工作，必须先突破它。Andreas 从德国弗莱堡远程连线，Anjney 说那里正在成为欧洲前沿研究的中心。

二、从机械工程到 Stable Diffusion

Andreas 2019 年开始接触 AI。他原本学机械工程，他说这是典型的德国式选择：觉得自己偏技术又不知道具体做什么，就去学机械工程。后来因为一些机缘转到计算机科学，先做机器人，然后在海德堡读博士，认识了后来的两位联合创始人 Robin 和 Patrick。那是一个很小的实验室，大家都在做视觉表示学习。2019 年时，计算机视觉在 AI 里还算小众，人们看到了潜力，但没人想到后来会爆发。当时生成图像多用 GAN（比如 StyleGAN），生成一张 256×256 像素的图都是挑战。

他们和 Google、OpenAI 这些大得多的研究团队竞争，算力少得多，只能想更高效的算法。图像和视频的维度比文本高得多，他们花了两年研究：怎样找到一种和像素空间在感知上等价、但维度低得多的表示。做法是先训练一个压缩模型，类似一个"学出来的 JPEG 编码器"，再在压缩后的空间里训练生成模型。这就是潜在生成建模的一系列论文，用少几个数量级的算力，做出和对手相当甚至更好的模型。由此提出的潜在扩散（latent diffusion）算法催生了 Stable Diffusion：他们在开源社区找到算力，训练并在 2022 年发布了它。热度让他们自己也很意外，他说湾区比德国热得多，直到今天德国知道这个模型的人都不多。

Anjney 回忆，当时 DALL·E 2 还在预览阶段，Stable Diffusion 出来后，有人在 Reddit 上把孩子的蜡笔画用图生图功能变成了一幅漂亮的插画，他截图发了推文，上午开完会出来就有三四千个赞。他意识到，生成模型这项技术因为是视觉的，第一次让机器学习圈子以外的人也看懂了。他说当时机器学习圈有一种教条：语言是智能的全部，人通过语言思考和推理。他做过 3D 地图和计算机视觉公司（Ubiquity6），觉得语言很有价值，但不完整，因为语言只是人沟通和推理的一种方式。

三、自然表示与人造表示

Andreas 区分了两类表示。你现在通过视频和音频感知他：看他打手势、听他说话，这些是"自然表示"，源头是太阳光这类人类无法控制的电磁波，以及河流的声音这类自然信号。文字则是人造的，每个符号携带的信息量远高于图像中每个像素的信息量，因为在进化中人类需要高效沟通，逐渐去掉了冗余。这也是为什么训练生成模型前要压缩图像和视频，而文本不需要。

他认为对学习来说，自然表示更根本。婴儿先是观察、听和看，然后与物理世界互动，最初的三到五年都是这样，大概五岁才识字；而一个三岁孩子的智能和一个语言模型的智能很不一样。所以 BFL 相信音频和视频会是这些系统将来更高层智能的基础；从语言出发、再往上叠其他表示，他认为是错误的方向。应该从第一性原理出发，像人一样先在自然表示上观察学习，再去互动。他说这两点也是 BFL 对"视觉智能"的定义。

两三年前的共识是单模态的基础模型：文生图、文生视频。Stable Diffusion 就是一个为内容创作而做的文生图模型，可以做艺术风格迁移，可以训练 LoRA 让角色保持一致，用于营销，但都属于内容创作。现在 BFL 训练的是一个统一的、在自然数据上训练的多模态模型，它能做的不止内容创作：物理 AI、机器人、电脑操作、世界建模和仿真。关键是把不同的自然表示结合起来训练。比如两个刚体碰撞时总会有声音，模型能观察到这种相关性，就能更好地理解发生了什么；只看一种模态，很难分辨手伸进水里和碰到一个透明瓶子有什么不同。

四、Flux 的反馈循环

Anjney 说，BFL 现在有数亿美元收入，Flux 被全世界几百万人使用，但对学生来说，更有用的是回到起点：资源比大公司少、团队小、数据少，怎样确定从哪里开始？

Andreas 说创业最重要的是聚焦。他们在单模态图像生成上经验丰富：做过 Stable Diffusion，在 Stability AI 又发布过几个模型，基本掌握了训练前沿图像模型的配方。创业时他们看到，当时的图像模型连五根手指的手都画不好，市场需要新一代模型，于是目标是做一个比其他模型好十倍的图像模型。他们坐下来花了三个月，配方都有，只需扩大规模，做出了 Flux 1，并且一开始就有了产品市场匹配：API 公开之前，就有几个很大的客户帮他们建立了反馈循环。

Flux 1 的流程是：预训练只用文本和图像；中期训练加入更高的分辨率和一些新能力；后训练先做离线部分，包括蒸馏让模型更高效、按他们对客户需求的理解做对齐，然后发布到真实世界获取反馈。他们观察到，很多人用 Flux 1 训练 LoRA 来保持角色一致，说明大家想用文字以外的方式控制模型。文字简单、谁都会用，但很模糊："一只蓝色的鸟"对应无数张图，鸟可以停在树枝上，也可以在飞。用户真正想要的是图像编辑。于是他们部分基于这些数据、部分加入新数据做了后训练，推出了图像编辑模型 Flux 1 Kontext（德语式拼写），这是第一个能快速、可规模化地保持角色一致的编辑模型：比如把 Anjney 和 Andreas 两人的照片合成为在咖啡馆聊天的场景，这对营销等内容创作很有用。

Anjney 补充了这段经历。18 个月前，给图像模型一张自己的照片、让它"给这个人加一顶帽子"，出来的人往往不像你，很多聪明人（包括这门课的一些嘉宾）都很肯定地说这个问题解决不了。而 BFL 从开源权重的 Flux 1 被广泛使用的情况里，看到了用户在怎样写提示词、哪里不满意，找到了清楚的改进路径。团队在意大利开团建时，正好 ChatGPT 推出了图像功能，看起来比他们的好很多。他说新团队面对资源多得多的实验室发布强大产品时，第一反应往往是慌，但好的领导者不会慌，而是冷静看数据、评估局面、一步步制定计划，往往直觉会告诉你还有没解决的问题。团队成员 Dustin 提出专门做一个编辑模型，团队 24 小时内重新安排了分工，大约 60 天后 Kontext 发布，六周内来自 Kontext 的收入翻倍。不久后 Meta 宣布和 BFL 合作，用这个当时只有约 25 人的德国团队的模型，为 Facebook 等应用的约 20 亿用户提供图像编辑。BFL 从零做到几亿美元收入，估值超过 30 亿美元。他说很多图像生成团队后来都不存在了，因为它们放弃了；BFL 坚持了下来，是少数仍在推进视觉前沿的独立公司之一。往往技术上并不难，差别在于有没有坚定的信念，一次又一次地攻克认定的问题。

五、下一步：从观察到互动

Andreas 说，现在的方向是统一的多模态模型，能同时做物理 AI、电脑操作、世界建模和仿真以及内容创作，而且这些能力会相互促进。

  • 预训练：在图像、视频、音频这些自然表示上一起训练，用他们 3 月发表的 Self-Flow 算法，让模型从不同模态之间的相关性中获得叠加的收益，得到很通用的表示。
  • 中期训练：加入更多上下文和新任务，比如以一张图和一段音轨为条件，"用这个声音说某句话"。为了超出内容创作的范围，还要以动作为条件、让模型预测动作，比如电脑操作模型根据视频或图像预测下一步的按键，去完成"打开一个新浏览器标签页"之类的任务。
  • 后训练：预训练和中期训练都还只是"观察"，模型看例子、算损失、反向传播，没有任何互动。要让模型真正和物理世界互动，就把能根据视频预测动作的模型接到真实世界里，比如接到机器人上，让它互动、产生数据，再送回训练，闭合反馈循环。所以 BFL 的后训练意味着与物理世界互动。

Anjney 联系到第一讲的"可验证性"：能可靠验证的地方，进步就快。软件工程可以写单元测试；图像生成则不容易验证，除了手指数对不对、角色是否一致这些基本问题，大多是偏好。Andreas 说，接到真实世界后，物理会自然施加约束：机器人手臂的关节有些动作做不到，这是很好的环境。而对审美和视觉偏好，需要大量人工判断再反馈给模型，既繁琐又因人而异：给一个从没接触过图像生成的人看图，和给他这种看过无数图的人看，得到的信号很不同。

Anjney 认为这是一个关键洞察：当"怎样验证"的答案是"取决于受众"时，说明系统的价值很大程度上取决于能否针对特定受众定制，这就是开源的价值所在。把好的通用权重开放出来，Meta 可以按自己用户的偏好定制，另一个文化偏好不同的国家政府也可以掌控最后一步。他说开源和闭源是一个虚假的对立，两者都只是交付价值的手段：在偏好分布很宽、长尾很多的领域，开源很有道理；偏好很集中的领域，闭源模型更有价值。

Self-Flow

Anjney 说，Self-Flow 发表后，他在各大实验室的朋友纷纷打电话问他知不知道这个方法。Andreas 解释说，训练视觉生成模型时，一直很难让模型不只会生成像素，还能理解语义上发生了什么。过去两年有一系列工作，把生成模型内部的表示和表示学习模型（比如图像领域的 DINO）的表示对齐，让生成模型不只是"笨的像素生成器"。但这些方法都局限于单一模态。Self-Flow 用一种很自然的方式，把这种对齐损失和多模态表示结合起来。他推荐大家读这篇论文。

六、学生提问

怎样保护个人数据、防止滥用

Andreas 说，他们相信这些模型是帮人创作的强大工具，所以 API 上有很多内容过滤器防止产生有害内容。BFL 在欧盟，遵守欧盟 AI 法案和相关法律：如果有人上传自己的照片后要求不保存，他们必须删除，为此建立了相应的系统。

和 xAI、Meta 等大公司合作时怎样决定和谁合作？Andreas 说他们在为所有人建设视觉智能基础设施，会在模型周围设好护栏防止滥用，但基础设施对所有人开放，要选择性地决定和谁合作，最后很难说清理由。Anjney"翻译"说：公司的护栏对所有人一视同仁，无论你多大、多有钱、多有政治影响力，想让他们去掉护栏都不行。作为标准和基础设施，就不能区别对待。规模大的客户可以有技术上的定制需求，比如部署方式、延迟，但护栏一律适用。有合作方要求去掉护栏，他们就拒绝，有时因此损失了可观的收入。他说这呼应第一讲：基础设施要稳定，需要可信的标准和执行标准的机构，有时得自己来执行。

Anjney 还提到 BFL 的文化：内部对做什么、不做什么有很多争论，但一旦决定就一起执行。公司成立以来只有一个人离职，他说在 AI 圈这很少见，"有的公司联合创始人六个月就走了"。他认为湾区的文化忘了，要在长远目标上取得进展，有时需要团队一直在一起。

图像数据怎样标注

Andreas 说，训练从预训练到中期训练再到后训练，数据量逐渐减少、质量逐渐提高。预训练阶段用自动标注就够了，可以大规模进行，有公开的工具，也有 BFL 内部的工具；越到后期，越需要人工信号，因为后期要把模型学到的通用表示和大家真正在乎的东西对齐，人工标注仍是黄金标准。

扩散模型的迭代去噪还会需要吗

有学生问到"漂移模型"（drifting models）这类可能一步生成的新方法。Andreas 比较了两类模型：扩散模型和流匹配模型的迭代发生在一个人为设定的、和数据正交的"时间"维度上，从纯噪声到目标数据；语言模型这类自回归模型的迭代则沿着数据本身的方向，一个 token 接一个 token。这带来训练和推理上相反的性质：训练时，扩散模型对数据的利用效率低，因为每个样本在从噪声到干净图像的连续轨迹上可以取无数个点，每个点都能算一次损失；自回归模型可以并行地在所有 token 上训练，效率高。推理时则反过来：自回归模型必须逐个 token 生成，推测解码等技巧只能部分加速；扩散模型可以蒸馏，BFL 写过多篇对抗扩散蒸馏的论文，把步数从 50 步降到 4 步甚至 2 步，这时一步的漂移模型差别就不大了，而蒸馏到两步的流程更成熟稳定。他认为一个很有意思的研究问题是：怎样把自回归模型的训练数据效率和扩散模型的推理性质结合起来。

Anjney 说，潜在对抗蒸馏对 BFL 很重要，一是让模型很高效，二是成了商业模式的关键。BFL 的理念是开放权重，但要让它在商业上可持续，因为很多开源项目开源之后就消亡了，那也不是可依赖的基础设施。Flux 1 发布时分成三个版本：Flux Schnell（德语"快"），只需四步，速度快、质量较低，完全 Apache 2.0 开源；Flux Dev，开放权重但商业使用需要付费；Flux Pro，步数更多、质量最高，通过 API 提供。要点是这三个版本模型大小一样，区别只是步数。而 Claude 的 Haiku、Sonnet、Opus 这类自回归模型家族，是把大模型蒸馏成越来越小的模型。这种打包方式让开源社区有了能在本地跑的快模型，不想折腾定制的企业有了 API 上的高质量模型，介于两者之间的开发者有了质量较高又开放权重的版本。他说两年前的做法是训练一个模型、放出权重、看看会怎样；从长远考虑，就要把它当作一个系统，让每一轮迭代都帮助打通下一轮的瓶颈。

空间智能需要显式的 3D 表示吗

Andreas 认为人脑里没有任何东西的显式 3D 坐标表示，人只是从视频和音频中学习，眼睛做一点三角测量，其实仍是投影；可以转头、可以和物体互动，这就够了。显式 3D 表示还有数据问题：能给所有数据都标上 3D 信息吗？所以他不太相信显式 3D 表示，认为应该从自然表示学习再加上互动。

Anjney 表示部分不同意，但态度更细致。他做过一家失败的 3D 地图公司 Ubiquity6，用深度学习重建三维世界。技术本身可行也有价值，但显式的静态 3D 表示很窄、不灵活，去掉时间维度后用途很有限，只在一些场景有用，比如点云能帮机器人在没有 GPS 的室内定位。要做供人互动的系统，点云、三维网格这些都是中间表示，某种意义上是权宜之计，不如能自然融合时间、声音等模态的表示通用。他说自己规划讲课时，脑子里对这个教室有一种空间表示；Andreas 说那是隐式的，是从感知中学来的，不是靠显式坐标强加的先验。两人最后同意：在人机交互的接口层面，用显式 3D 来推理很不自然。Anjney 说："欢迎来到我们的深夜对话。"
