第十三讲：Satya Nadella 谈前沿生态

微软为什么在 2019 年押注 OpenAI，"每家公司都在前沿"意味着什么，Scout、本地算力和新的设备形态，自研芯片与量子计算，以及成长型思维和给学生的建议

主持：Mike Abbott · 嘉宾：Satya Nadella（微软董事长兼 CEO）
资料来源：课堂录像（Stanford Online 公开，本文依据录像字幕整理）

一、为什么押注 OpenAI

这是本学期最后一位嘉宾，正赶上期末周。Mike 说，2019 年微软向 OpenAI 投资 10 亿美元，可以说为这场 AI 的"寒武纪大爆发"搭好了舞台，当时是怎么想的？

Satya 说，回看六七年前，让他确信值得一试的是一种"有准备的头脑"：微软一直执着于自然语言。不过当时微软主要靠机器学习和 NLP 去做，如果在 2017、2018 年问他们，答案会是符号逻辑加机器学习，他们当时未必真相信深度学习能带来 NLP 的突破，但很希望这件事发生，所以愿意多处下注。大家只谈 OpenAI，其实微软还收购和投资了很多公司：凡是在自然语言上有雄心的团队，不论什么出身、在公司内还是公司外，他们都会押。后来缩放规律的论文出来了，OpenAI 想用更多算力和数据推进 Transformer，这对微软很有吸引力（他笑说那时"大家还是一家人"）。能力曲线一直沿着缩放规律走，他觉得很惊人。

Mike 二十年前在微软工作过，问当时内部有没有人反对，说"我们自己能做"。Satya 说核心押注必须是内部自己做，同时也有合作和并购。在微软成长起来的人都知道，既可以靠自建、也可以靠合作创造大量企业价值：PC 革命离不开所谓"Gates-Grove 模式"，也就是英特尔和微软一起建立 PC 生态；他做过 SQL Server，微软和 SAP 合作，微软做数据库、SAP 做 ERP 应用。所以没有反对浪潮。真正的大决定不在资本，而在算力集中：把稀缺的算力集中给某一项努力，而这正是想推动它的团队，微软也因此获益巨大。

二、前沿生态：每家公司都要有自己的"爬坡机器"

Satya 来湾区是因为微软的开发者大会 Build，前一天微软宣布了"前沿智能生态"，发布了七个新模型。Mike 提到 Mustafa Suleyman 说这些模型的数据很干净，很注意不侵犯版权，为什么要做七个？

Satya 说这门课叫"前沿"，问题是：任何个人创业者、开发者、公司，怎样参与前沿？有了前沿模型，怎样真正有自主权去增加价值、获取价值、保护价值？如果模型从数据中学习，公司本身的未来是什么？今天的公司建立在运营和人力资本中积累的隐性知识上，在 token 和人一起协作的世界里，公司会变成什么样？微软的愿景是一个前沿生态：每家公司都能在前沿上运作，自己的知识产权随时间复利增长，不只是人力资本，还有"token 资本"。

他推荐大家读这批模型的技术报告，认为这是最近同等规模模型里对整条流水线写得最透明、最详细的文档之一。以推理和编程模型为例，做这些模型的目的是连同权重一起授权，让每家公司搭建自己的"爬坡机器"。微软自己"爬坡"时用了来源非常干净的数据，没有往里面混大量合成数据，让推理能力真正从训练中涌现，于是得到一个又好又高效的模型，放进任何公司都能搭建的爬坡机器里，用这家公司的轨迹和任务继续学习。所以每家公司都应该从战略上想：搭什么样的强化学习环境、有哪些私有评估、怎样把任何模型请进这个"健身房"、同时保住知识产权、不让价值外泄。他说如果只是基础模型的消费者，他看不出怎样保住企业价值，更不用说创造价值；只有让大家能拿前沿模型或像微软这样授权的开放权重模型，在自己的环境里爬坡、建立自己的知识产权，这个生态才是非零和、正和的，很多参与者都能在前沿上。

他说最酷的一点是，Microsoft 365 的客户可以直接起步。Microsoft 365 就是你用来经营业务的工具，人们围绕业务流程互相沟通，所以微软可以帮你自举出强化学习环境，甚至根据对你工作的观察，为比如人力资源入职流程生成评估，而这是你公司独有的，数据本来也是你的。微软做过多租户的 SaaS 应用，现在可以把它变成多租户的"爬坡服务"，数据、环境、模型、轨迹和结果都归公司所有。

大多数公司有人才建这种机器吗？Satya 说这就是"简易按钮"：爬坡机器已经替你实例化好了，你需要的是一点战略纪律，把模型、工具框架、上下文、评估当作自己理解并管理的资产，就像过去重视隐私、保密和安全一样，AI 进入公司后，这些会成为同样重要的架构和战略考虑。

Scout 和 Agent 的隔离

Satya 说 Copilot 的形态在演变：先是聊天，有了推理模型后不只是像搜索那样用，而是当作思考助手；然后是 Cowork，用来委派任务，它是多步推理、调用工具的 Agent 循环，可以分配长任务或短任务，很像两年前 Agent 循环刚出现时 GitHub Copilot 做的事，现在用在知识工作上；Scout 是第三种形态，"自动驾驶"：持续运行的 Agent，一直在监控，有心跳，会"做梦"，具备 OpenClaw 那类 Agent 的一切。你可以把自己的 Entra ID 作为委托身份交给 Scout，它就是持续替你工作的数字孪生；还可以创建更多有自己身份和沙箱的自动驾驶 Agent。他把它看作企业版的 OpenClaw，界面和 Copilot 的其他部分融为一体。

Mike 说他自己装 OpenClaw 时不敢把所有凭证交给它。Satya 说 OpenClaw 的作者 Peter 也上了 Build 的台，微软在和 OpenClaw 基金会合作让它能安全运行：Windows 上开箱即可安装 OpenClaw，并放在一种叫 MXC 的新容器里沙箱化。他认为隔离是关键，因为现在有长时间运行、能生成并执行代码的 Agent，必须管住执行；在容器里可以设定策略和隔离边界，进程级、会话级，甚至虚拟机级。他自己要跑什么，都放在 Windows 365，也就是完全隔离的云端实例上。他认为我们都要学会和很多 Agent 一起工作，也要学会给它们隔离环境，就像当年思考进程那样，去思考 Agent 的进程边界、会话边界和容器边界。

本地算力和新设备

Satya 说他们对"不计量的智能"很兴奋。现有 PC 里有大量独立显卡，token 供应紧张，所以要利用边缘的芯片算力。NVIDIA 发布了新的 RTX 系统级芯片，微软秋天会推出基于它的 Surface 笔记本，各家 OEM 也会有设计。他们还发布了一台开发机：一千万亿次（1 petaflop）AI 算力、20 个 CPU 核、128 GB 统一内存，能在本地跑约一万亿参数的模型；还和 NVIDIA 合作让 Windows 能跑在 GB300 上，于是有了 DGX 工作站，他称之为"数据中心桌面"。他认为需求会很大：装了 Scout 或 OpenClaw 这类东西后，你希望它 24 小时运行又不被计费，最好的办法就是在自己的笔记本或台式机上跑。

另一方面，Agent 时代也需要新的设备形态，这就是 Project Solara。他们展示了两个参考设计：一个胸牌，一个桌面伴侣。胸牌有指纹识别器和摄像头，用联发科处理器，足以唤醒 Copilot 之类的东西：你可以口述一个编程任务，它拿到输入后在云端执行，再通知你。如果你是护士，在各个护理站之间走动，可以用它录入数据，而不是用手机。现在人们习惯了用 PC 输入或用手机，而在环境智能、无处不在的计算时代，可以有这些作为长时运行 Agent 端点的设备。微软会做一些，但更想建平台，并且要有新的平台规则：Windows 一直是唯一开放的平台，可以不经应用商店装任何东西，开发 Windows 应用不需要给微软打电话，他希望新的 Agent 平台也保持这种开放，不把上一个时代的平台规则带过来。

AI 的"夜里的光"是什么

Mike 提到之前有嘉宾说，电力普及时卖的不是电而是光，AI 对应的是什么？在湾区和西雅图之外，人们在问 AI 对自己有什么好处。Satya 说，我们可能太沉浸在自己的泡泡里，为技术本身的进步而兴奋，但最终世界会看我们为每个社区创造了什么价值。只有当 AI 真正改变医疗的成本和人们能得到的照护，而且不是抽象地，而是发生在我们社区和家人身上；当它带来经济机会，人们才会看到好处。任何颠覆性技术都会带来真实的岗位替代，但也会有新的经济活动，人有自主权，有工资；如果现在的智能被商品化，人类是最善于在新商品之上创造新价值的物种。这必须是真实的，而不是抽象的。前沿生态也是这个道理：如果每家公司都担心让前沿模型进门就会碾压它们积累的知识产权，它们凭什么欢迎？所以创业者、学生和老牌公司都要把生态塑造成正和的；如果只有少数公司拿走全部回报，其他人都处境糟糕，"我们一定会失去社会许可"。

三、学生提问

微软自研芯片的思路

有学生说，Google 和 Amazon 都有训练和推理分开的芯片，有自己的 XLA、Neuron 等软件栈，NVIDIA 和 AMD 则保持统一芯片，微软怎样考虑？Satya 说设计任何新系统都要从新的工作负载出发，现在有三大新负载：训练、推理，以及同时用到推理和普通计算的长时运行 Agent。从第一性原理看，它们不像过去的横向扩展负载，而是同步的数据并行负载，正如 Amin 讲的，要在纵向扩展上也创新，过去横向扩展的一些技巧不管用了。微软前一天发布的 Maia 200 是和微软自己的模型以及 OpenAI 的模型协同设计的（微软拥有相关知识产权），现在已在多个数据中心运行 GPT-5.5、支撑 Copilot，带来总拥有成本优势。他们还做了 ARM 处理器 Cobalt，用 GitHub Copilot 的轨迹来优化它在 Agent 循环中的延迟性能，因为 Agent 循环最需要好的 CPU 核，再和网络栈结合起来。同时他们也很喜欢 GPU 的通用性：用舰队里的旧 GPU 加速数据仓库，Fabric 因此性能提升了 7 倍以上。所以他们把机群当作异构的，用软件做聪明的负载调度，同时为推理、训练、Agent 循环这些大负载从头设计系统。设计点很多：AI 加速器只是其一，还有 CPU、智能网卡、存储加速、能跨多个数据中心的 AI 广域网。他说他入行时 Patterson 的书刚出来，正是 RISC 与 CISC 之争，现在又回到了可以重新思考一切的时候，从数据中心的物理设计，到把电子以尽量少的损耗送到芯片，让 token 更高效，计算机体系结构的设计空间非常大。

量子计算

Satya 说微软做量子已经 20 多年。量子计算机的意义在于能模拟自然，因为自然本身是量子的，可以比依赖 DFT 等方法得到高得多的化学和分子动力学模拟精度。即使在量子项目之外，他们这两年和合作伙伴用中性原子量子计算机加上微软的软件栈，已经能生成很好的轨迹，再拿去训练材料科学和化学模型。软件方面，他们的栈会跑在合作伙伴的离子阱、光子和中性原子机器上，他说年内会在丹麦和合作伙伴建成一台由 Atom Computing 硬件驱动、运行微软软件栈的量子计算机。另一方面，要做到公用事业规模就需要容错：一位理论物理学家在 1930 年代预言了一种叫马约拉纳的物态，微软押注要把它真正造出来；一年前发布了第一款量子处理器 Majorana 1，证明了基础物理上的突破，新一代芯片可以按工业规模制造，他们还完善了对量子计算机的数字控制。时间表呢？他说自己是第三位坚持量子之路的微软 CEO；他把量子看作新的加速器，它不会取代经典计算，不擅长存储和内存，而擅长计算，所以要经典加量子结合，会分阶段到来：如果有 100 个纠错良好的逻辑量子比特，就可以用来为科学模型生成合成数据，这可能更早实现。微软的说法是到本十年末能造出开始解决真正难题的量子计算机。

新人项目和公司文化

一位在微软工作过十年的学生问校招轮岗项目对文化的意义。Satya 说，任何公司要保持在前沿，都需要带着新想法和新能量的人进来重塑它。他对每个新人说：你当然要学习微软怎样运作，但我们也希望微软向你学习，更希望你有自主权去重塑微软的文化，文化不是静止的，而是由员工的行为和决定塑造的。很多人在微软待一段、出去、再回来，Mike 就是微软的老员工，现在仍和微软有联系。微软 50 年来的核心基因没变，是开发者工具、平台和知识工作者工具公司，但每到新平台都会重新诠释它。他 90 年代加入时，生死对手是 Novell；现在是一家五年前他都没听说过的基础模型实验室。他觉得这让公司保持活力。

Mike 问他怎样把成长型思维带到整个公司。Satya 说这不是灌输，而是唤起人人都有的东西，靠的是实践；他最需要表现的是直面自己的固定型思维的能力。谈成长型思维容易，自己做很难，有人说"人人都喜欢改变，只是希望改变的是别人"。所以它不能变成公司教条，在微软起作用正是因为从来没把它变成命令；它也不是微软的专利，直面固定型思维会让你成为更好的人、同事、朋友、邻居、父母、学生，你是为自己这样做。他说有两样东西对他影响很大，都是通过妻子的阅读接触到的：一是《非暴力沟通》，培养同理心，理解对方的立场，不让杏仁核一直被触发；二是 Carol Dweck 关于成长型思维的研究。它们本是讲儿童心理的，但也适用于企业文化，因为人有 Herbert Simon 说的"有限理性"，常常看不清自己的利益，被情绪劫持。他说这些练习是"你需要的训练轮次"。

怎样成为好的演讲者

Satya 笑说"很高兴你觉得我是好的演讲者，就到此为止吧"。他说他没有刻意练演讲，当上 CEO 后要谈一些以前没机会谈的事，好在这些事他以前就在想，因为天生感兴趣，比如技术的影响、AI 对全球南方意味着什么。他父亲是发展经济学家，让他相信趋同增长会发生，他对此很执着。有广泛的兴趣并能自由地表达，现在又有各种媒介（演讲、写作、播客）可以去表达、触达和辩论，这是很好的时代。

给本科时的自己的建议

他说本科时一切都在前面，随时可以冒险。他前一天在 Hacker News 上看到斯坦福一门计算机课的编程 Agent 使用规范，列了该做和不该做的，他觉得写得很好。现在学新东西容易多了，因为有一个深入、个性化、随手可用的导师。比起作业焦虑、成绩焦虑，他会追求同事说的"认知覆盖率"（类似测试覆盖率）：顺着好奇心走。如果回到本科，他会像现在在 GitHub 上管理编程 Agent 会话一样，让一万个 Agent 和自己一起在斯坦福学习，但关键是不把学习外包给它们：你在指导它们什么，它们做完后你能否理解它们做了什么，这样才算学到，就像同时上一百门课。开发者工具从一百个命令行工具，演变出管理命令行复杂度的新 IDE，比如 GitHub 应用成了管理会话的新收件箱；他认为总有人会发明配套的新教学法，帮学生在学习中最大限度地保持好奇、更快更深地学习。现在按个按钮就能做完作业，成绩可能重要也可能不重要，我们看重的很多东西都要重新讨论。

图形界面还是命令行

有学生说，Agent 擅长写代码，不擅长操作图形界面，比如设计海报，让它生成 HTML/CSS 或矢量图比让它操作设计软件容易。Satya 说代码生成很强，用 HTML 和网页 UI 来创建产物会大量普及；比尔·盖茨以前常问做应用、写文档、建网站有什么区别，现在没有区别，都可以用代码完成。难点在直接操作。中期会有中间格式：先生成 HTML，再转成 Excel、PowerPoint，Copilot 等就是这样创建产物的。最终要让模型理解画布的语义、学会直接操作，这需要通过 API 或协议把语义暴露出来。他还说，GitHub 前一天加了一个叫 Canvas 的功能，不是因为 Agent 需要界面，而是人需要：命令行或聊天会话太密集、是线性的，翻起来很痛苦，现在可以有一个看板，人和 Agent 一起在上面工作。他认为生成式界面成为人与 Agent 交互的新方式，可能是所有产品线上最酷的变化之一。

如果现在是大一新生，会去解决什么问题

他说人做选择时是在找两件事的交集：自己真正有热情的，以及世界看重的（人总有某个目标，想要某个职业、某份工作、创办某家公司）。他本来学电气工程，后来转到软件；如果回去，他可能会回到硬件，因为现在是硬件的大好时机，他很想深入了解光网络这类系统。也可以做政策，AI 安全有很多方面需要人深入思考。Mike 问微软有没有请哲学家，Satya 笑说 Mustafa 算是个"哲学系辍学生"，从创办 DeepMind 起就一直在思考这些；微软研究院也一直有经济学家、道德哲学家、社会学家等多学科的人。

太空数据中心

有学生说他的研究显示，按每公斤发射成本，可能只有 Elon Musk 能盈利地做太空数据中心。Satya 说他不是这方面的专家，就他读到和跟专家聊到的看，似乎有道理。问题是不仅要能上去，还要建好在那里运行的整套技术栈，解决硬件返修等实际问题。数据中心是复杂工程，建立在土木、电气、机械工程的深厚积累之上，为太空这种新载荷要重新建立同样水平的供应链，这是可能的。微软曾有项目把 Azure 设备送到太空，但更像边缘设备；如果有人说太空里有几吉瓦甚至几兆瓦可用，他乐意接上去。

微软会做前沿开源模型吗

有学生说 Meta 似乎在退出前沿开源模型，Google 的开放模型都比较小。Satya 说微软一定会一直有开放权重模型，主要用于微软自己发布的产品：前一天就发布了两个，一个指令模型、一个规划模型，用于本地 Agent 循环，是基于之前 Phi Silica 的衍生模型，会在 Windows 上运行并开放权重。MAI 系列模型则是授权模式，但会广泛授权，比如可以在 Baseten、Fireworks 上用它们的推理栈来微调。目标是让每家公司，无论是 SaaS 公司、AI 原生公司还是传统企业，都有自己可以后训练、做强化学习的模型，围绕 MAI 系列建立生态。之所以授权而不完全开放，是因为在这个能力水平上需要检查和安全保障，他也提到中国的模型正在很快转向闭源。他说黄仁勋在做开放权重模型，微软支持；最终目标是让每个人都能拿一个模型往上增加价值，并保护自己的成果不外流。在 Fireworks 等平台上使用时，会有相应的授权和经济模式。
