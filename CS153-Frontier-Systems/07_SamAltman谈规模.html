第七讲：Sam Altman 谈规模

为什么最有意思的事都和规模有关，ChatGPT 和 Codex 是怎样被发现的，智能会不会成为新的公用事业，以及对 LeCun、教育、算力短缺和未来十年分岔的看法

主讲：Anjney Midha · 嘉宾：Sam Altman（OpenAI CEO）
资料来源：课堂录像（Stanford Online 公开，本文依据录像字幕整理）

一、创业的规则变了

Anjney 说这门课的灵感之一，是 2014 年 Sam 在斯坦福开的 CS 183B"如何创业"，对他和很多同学影响很大。Sam 说走进教室时就在想，如果有时间他想把那门课更新一遍，因为创业的一切都变了，他还没见过有人讲好现在应该怎样创业。

他说 OpenAI 可能是硅谷几十年来最奇怪的创业公司：它一开始是研究实验室，根本不是公司。通常的路径是先做产品公司，增长放缓后再建研究实验室去找下一件事，OpenAI 正好反过来，先有实验室，后来才不得不加上一家公司，他不推荐这样做。OpenAI 起步时仍按 AI 之前的创业规则来，但现在最好的创业公司的做法，和几年前已经很不一样。最大的变化是：花一笔负担得起的 token 费用，就能做到一个一百人的优秀工程团队能做的事，这在以前根本不在选项里。所以能有多大的野心、能多快行动、能同时做多少事，都完全不同了。

如果再教一次，他会不会给学生布置要攻克的问题？他说布置问题从来没用：如果一个创业点子明显到他能想到，很多人也能想到。OpenAI 刚成立时，宽泛地说全世界也只有大约四个 AI 项目，你要找的就是这种机会。他相信现在一定有某件在自动编程时代之前根本不可能、也不明显、很快会成为数万亿美元市场、而只有四家公司在做的事，"你们比我更可能知道它是什么，我的脑子已经被 OpenAI 占满了"。

二、规模

Anjney 请他从系统设计的角度拆解"规模"。Sam 说，下面这个观察他无法解释，没有满意的理论，这让他有点不敢建议大家照做，但经验上它似乎成立：他职业生涯中见过的最有意思的事情，都和规模带来的涌现性质有关，或者和规模持续带来回报、远超共识预期有关。AI 模型的缩放规律是这样，让更多聪明人一起想一个问题也是这样，公司的规模经济也是。

他是在 YC 学到这一点的。当时很多聪明人说 YC 太大了，每批应该少投一些，每批十家公司的时候才是最好的。这很诱人，工作量会少很多，理由是最好的公司总是很明显，其余的投了也帮不上多少。但 YC 的魔力很大一部分来自批次内部的网络效应，而这是规模带来的、以前没人发现的涌现性质，因为以前没人以这种规模投资创业公司。同样，OpenAI 决定真的去扩大模型规模时，领域里大多数"天才"都说这没用，变好只是因为规模更大，算不上科学成果。他见过很多创始人担心扩大规模，说不出具体理由；回看大量扩大公司规模的案例，几乎总能发现有意思的东西。所以当一件事在小规模上已经以某种有趣的方式在起作用、而你能把它推到没人试过的规模时，多数情况下这是好主意，而且大多数人做得不够。

人们为什么不这样做？因为规模越大，东西坏得越快、越难预测，真要扩大规模，系统总是有点坏的，总有聪明人告诉你别太有野心、先做小一点。拿扩大 AI 模型来说，阻力来自几个方面：技术上能不能做到，以前没人想过在一万甚至十万块 GPU 上跑一次训练，需要大量工程人才；资本上需要多少钱，将来怎么会有商业模式，怎样看待这个风险；文化上，研究者会说既然有这么多算力，为什么全押在一个项目上，为什么不分给很多项目。把每个难点、每个"不该做"的理由拆开，一个一个解决，这一直很重要。

Anjney 追问，最难重构的往往是系统里人的部分，怎样组织大规模的人？Sam 说要有清晰的目标、清晰的计划，以及清楚地说明怎样到达、一路上怎样做决定。当初决定押注扩大深度学习规模，很多人说行不通、该分散投资组合，但一旦说清楚"我们就押这个，错了就失败；这是我们为什么这样做，这是我们相信做到之后世界会是什么样"，就很有力量。另外，人类没有进化出理解指数增长的能力：很难想象缩放规律会指数式地延续、收入会指数式地增长、一个组织能承担指数式增长的复杂性，他的经验是要花很多时间和人一起从第一性原理推理，才能让人相信这会发生。

三、ChatGPT 和 Codex 是怎样来的

Anjney 说，很长一段时间里大家的心结是这些模型到底有什么用；ChatGPT 证明聊天是通用模型面向消费者的杀手级应用，几年后编程又成了企业端的杀手级应用。两者是怎样发现的？

Sam 说，做出 GPT-3 后他们需要赚钱，因为想建十亿、几十亿美元级的计算机。GPT-3 是个很酷的演示，但他们想不出围绕它做什么产品，试了几样都不成。于是决定放进 API，希望别人能想出产品，大约 2020 年夏天发布了 GPT-3 API。一开始几乎没人用，大约一个月后，似乎是偶然地，几个开发者在同一天让它做了很酷的事发到推特上，突然火了，很多人开始试。但模型差得惊人，现在回头用 GPT-3 或 3.5，你会惊讶它们当时那么差却引起那么大的兴奋。真正做成规模的生意只有文案写作，而且也不怎么样，他们觉得只能等更好的模型。

但他们注意到，很多人没能把 API 用到业务里，却在用 API 密钥直接和模型聊天。既然大家显然想要，那就做一个好的聊天机器人。当时 GPT-4 其实已经做好了，但还有一个介于中间的新模型 GPT-3.5，而且他们摸索出一种新的后训练方法，让模型更好地遵循指令、更容易聊天。API 生意大概只有一两千万美元的年化规模，按 YC "看用户喜欢什么就做什么"的原则，他们做了 ChatGPT。他们仍不认为它会做得很好，它本来是个研究演示，用来说服别人去做聊天产品并付费用 API。结果它疯狂传播。他在 YC 学到的另一点是：一个东西还不太好却真的开始增长，那就是稳赢的。头五天，流量每天冲高再回落，大家说这只是炒作，但第二天的峰值又更高；到第四五天他说"我知道这是怎么回事"，把所有人召集起来说这是紧急情况，好的那种紧急情况，我们必须同时建一家公司和一个产品。接下来是两个月疯狂的扩容。商业模式他们说以后再想，先收费免得付不起算力账单，没想到这也成了长期的模式。

Codex 方面，ChatGPT 之前的计划其实是全力做代码。他们知道模型能写代码，也知道这很有价值。当时内部的看法是：代码是模型控制计算机上的东西的方式，机器人是模型控制物理世界的方式，一个足够聪明、又有写代码和驱动机器人这两种"执行器"的模型，就能替你在世界上做事。后来 ChatGPT 的事插了进来，花了一段时间才回到这条线上。他说 Codex 今年年初变得很好，到 GPT-5.5 时出现了真正的拐点，人们用它做出了不可思议的事。

Anjney 问，预训练、中期训练、后训练、强化学习和监督反馈这条流水线会保持稳定吗？Sam 说这确实是现在的流水线，他预计会有一次大的重写，不知道什么时候、怎样发生，他觉得它以流水线的形式存在有点奇怪，不像是最优解。最优解是什么？他说那是留给 AI 去解决的研究问题。OpenAI 定下的目标是：今年 9 月前用大量算力（他说相当于 50 万块 A100）做出一个 AI 研究实习生，2028 年 3 月前有一个完全端到端、能想出全新架构的优秀研究员。他认为用现在的流水线和架构，就能越过 AI 能做出极好工作的那条线。

四、智能会成为新的公用事业

Anjney 问，"AI 实习生"这类类比在硅谷内部好用，推广到缺少背景的人群时会怎样失真？Sam 说他认为我们正在创造一种新的公用事业，这种事很少发生，电、互联网、水，没几个，所以可借鉴的例子不多。他最近研究了电力成为公用事业的历史：电力公司（至少他能查到资料的那些）并不宣传"卖电"，因为没人知道电是什么、为什么需要它，听起来还很可怕，会进你家、可能电死你。后来他们卖的是"夜里的光"。你可以说同样的东西以后还能帮你洗衣服，人们会说那跳得太远了。即使 OpenAI 完全判断对了，智能会成为每家公司、每个人、每个政府都需要的公用事业，你会有一个 OpenAI 的 token 订阅，接入一切、一直替你运行，他也认为现在说"我们在卖智能"并不能打动人。他还不知道 OpenAI 的"夜里的光"是什么，但如果要成为新的公用事业，就要找到办法向世界解释拥有一根"智能管道"意味着什么。

Anjney 说，黄仁勋在这门课上把算力比作公用事业，Sam 则说的是智能，哪个对？Sam 说，作为企业或个人消费者，你会按 token 或比 token 更高一层的单位来考虑，不会太在乎硬件在哪里、是哪种芯片、用什么供电，这些会被抽象掉。你在乎的是能不能大量用、便不便宜、做得好不好。就像付手机账单时你买的是通话时长和流量，用来跑各种应用，不会去想基站的硬件。等大家都有一直在运行的 Agent，可能会再往上一层来考虑。

如果他也在做这门课的期末项目"一人前沿实验室"，会做什么？他说很多聪明人在做训练方面的好点子，不管大家做什么，很快都会有极好的模型；但大规模提供大量便宜智能这件事投入不够，所以他会去做推理这一层：怎样让智能便宜而充足。他认为所有前沿实验室在很大程度上都会变成推理公司。

五、学生提问

LeCun 说大语言模型是死路

Sam 说，就达到人类水平的智能而言，这些模型有些方面已经远超人类，有些方面又差得多，比如需要很长周期、高度判断力的任务。但就在昨天，OpenAI 的一个模型推翻了一个埃尔德什问题中的猜想，很多聪明人研究了很久；不久前还有很多科学家说这不会发生（他不知道 LeCun 是不是其中之一），现在数学家们在问"数学是不是结束了"。所以大语言模型显然能发现新知识，能做一些人类做不到的智力任务，而且还会继续扩展，具体在哪些任务上超过人类、超过多少，以后会知道，他猜会很多。他说这个领域曾被一代对"规模带不来什么"过于确定的科学家拖累，而有些人只是看着曲线说"看起来一直很漂亮，继续吧"。世界模型显然重要，机器人需要它，但现在押注大语言模型扩展会失败，在他看来是误判。

Anjney 问他当"早就告诉过你"的那个人会不会烦。Sam 说推特上有人多年来一直说"这行不通""这是骗局""这家公司会失败"，他以前更在意，现在连"早告诉过你"的感觉都没有了，数据很明显站在他们这边，对方还说他们错也不困扰他。他说如果把身份认同绑在某件事行或不行上，等科学和实证结果证明你错时，就会因为放不下身份而看不清事实，这个提醒对两个方向都适用。

教育应该怎样变

Sam 说教育显然必须大幅调整，他原以为现在已经变了。如果继续按 AGI 之前的世界来教和考，会导致思考能力的萎缩。ChatGPT 刚发布时他以为，会有一年学生作弊、学不到东西，然后教育体系会重新设计，教得好得多：项目要求必须用 AI 才能完成，但仍要拓展大脑、想更多、想出新东西。但 ChatGPT 发布三年半来，他说不出教育体系有任何重大的系统性变化，这是他的预测错误。他相信教育能像过去应对每一项技术那样重新设计，让人仍然要学会思考。有些事机器做得更好，但仍值得教，因为能训练思考和学习的元技能：他是靠写作来思考的人，写了很多从不给别人看的东西，很庆幸自己学会了写作，编程也一样。但还有很多东西应该彻底改变教法、学法和考法，否则人们的批判性思维会明显萎缩。

在斯坦福最喜欢的课

他大一每学期上三门新生研讨课，每门都很不一样，都很喜欢。回头看，能对很多领域有广泛而浅的接触很宝贵；否则他只会上计算机和物理课，那也不错。他现在更常想起的是那些和现在工作毫无关系、却给了他某种视角的课，编程无论如何他都会学会。他只读了两年，很多想上的课没上成。

你最"辣"的观点

他说多给点时间他能想出更辣的，但他的观点是：AI 会一直进步下去。他认为这还没被广泛相信，否则社会上的震动会比现在大得多。ChatGPT 出来三年半了，即使只是沿着同样的指数轨迹再走三年半，社会的可能性和能力也会完全不同。

Anjney 让他把自己当作一个被 OpenAI 和外部世界持续强化学习过的预测模型，说出未来十年最可能的三个分岔和概率。Sam 说了两个：

  • 这项技术会广泛普及，还是集中在少数几家公司手里。默认情况下有很多理由会走向集中，少数公司占据地球财富的很大一部分，这会很糟，他们在努力反对，但需要全世界的意志才能避免，因为那是一个吸引子状态。这也是要推动"公用事业"模式的原因：少数公司拥有一切既不稳定也不公平，而且在一个脆弱的世界里会是一种真正的对齐失败；最能让所有人都赢、所有人的价值观都被代表、人人有自主权的办法，是把技术推向世界。他预计会有很强的、以安全和稳定为理由的反对声音，也会有想集中权力的人。他鼓励学生在职业生涯中努力推动普及：要到达那个科幻般美好的未来需要承担一些风险，但让技术集中在少数公司手里（"哪怕我们是其中之一"）的风险不应该容忍。他给的概率是约 80% 走上民主化的道路。
  • 算力怎样分配。很多人讨论未来的经济模式：全民基本收入、人人持有每家公司的一部分、资本主义不变还是彻底的共产主义，但很少有人讨论具体怎样分配算力。他说自己现在连短期的就业悲观都少了很多，一直相信人们会找到新的事做，短期冲击可能比他原先想的小。但现在已经出现算力短缺，他能想象它变得严重得多，算力成为人们最需要的公用事业；如果算力的供需价格严重失衡，怎样公平分配算力会成为很重要的分岔。

Anjney 提到这门课的另一位嘉宾、挪威主权财富基金的 Nicolai Tangen：基金持有全球上市公司约 1.5% 的股份，挪威事实上也有类似全民基本收入的制度；美国最大的雇主是政府，某种程度上也在做再分配。这些方案需要新发明吗？Sam 说不需要全新的想法，但比起每月固定发现金，他更看好让人们持有某种所有权。他资助过一个大型全民基本收入研究，也看过人们投资创业公司时的反应，知道哪种模式更符合人的心理。他希望随着世界的杠杆从劳动转向资本（他认为这会持续），能有类似"公民财富基金"的东西，先在一国、最终在全世界，让每个人拥有资本主义的一份、这些公司的一份。

Anjney 说据他看到的数据，H100 和 Blackwell 长期预订价和现货价的差距一度有五倍，今年的 H100 基本都卖光了，像新冠时卫生纸被抢光一样，为什么大家不慌？Sam 说差距可能没那么大了，但确实很高，算力短缺是巨大的。人们以为能在现有硬件上大幅提高推理效率，而且一大波硬件正在到来，但需求的浪潮可能更大，他认为大家应该有点慌。短缺会持续多久？他说谈全球电力需求不能不谈价格，电价降十倍或涨十倍，需求完全不同，AI 也是这样：如果模型足够聪明、成本足够低，需求几乎没有上限。所以只要还能继续进步，短缺某种意义上会永远存在，价格会被抬到高于大家认为的合理水平。如果有了很好的个人 Agent，你会想让十个、一百个一直替你工作。
