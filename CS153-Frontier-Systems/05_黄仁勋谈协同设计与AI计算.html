第五讲：黄仁勋谈协同设计与 AI 计算

计算模型 60 多年来第一次改变，协同设计怎样让 NVIDIA 十年获得百万倍加速，为什么 MFU 是错误的指标，Hopper、Grace Blackwell、Vera Rubin 各为什么而设计，NVIDIA 为什么做开源模型，以及他犯过的最大错误

主讲：Anjney Midha · 嘉宾：黄仁勋（Jensen Huang，NVIDIA 创始人兼 CEO）
资料来源：课堂录像（Stanford Online 公开，本文依据录像字幕整理）

一、计算模型变了

这是黄仁勋第二次来这门课。Anjney 本想先问"协同设计"，黄仁勋先讲了一段开场：现在是学计算机科学最好的时候，因为计算 60 多年来第一次被如此彻底地重新发明。从 IBM System 360 开始的 64 年里，计算机的架构、编程和运行方式、怎样把计算机推向市场，基本没变，他学计算机体系结构的第一本书就是 System 360 的手册。PC、互联网、移动、云带来了很多变化，但计算模型的根本一直没变，直到现在。

他的简单说法是：过去的计算基本是"预先录制"的，图片、视频、软件都是事先做好的；现在一切都是生成的。实时生成的好处是能贴合上下文，还能回应你的意图，而不仅仅是你明确下达的指令。这意味着技术栈的每一层都要重新想：软件怎样开发、公司怎样组织、运行的是神经网络而不是编译好的二进制、计算机系统、网络、存储、云服务以及应用。他举了 NVIDIA 刚开源的自动驾驶模型 Alpamayo 的例子：他做自动驾驶已经约 13 年，认为将来"所有会动的东西都会是机器人"，而这类应用在深度学习出现之前根本不会去做。

他说看到 GPT 时，别人看到的是能生成图片，他看到的是能生成"想法"，也就能推理。剩下的是工程问题：怎样训练和微调 AI，让它一步一步推理，并且能以半监督的方式大规模地教会它。思考就是生成自己内部消费的 token，生成给外部消费的 token 就叫工具使用。所以 GPT 出现后，他认为走到今天这一步是相当好预测的。现在有了 Agent，下一个问题是：过去的计算是"按需"的，分时计算机变成了云计算，也是按需使用；而 Agent 系统中的计算机是持续运行的，那么云服务、个人电脑会变成什么样？这些都值得重新思考。

二、协同设计：十年百万倍

过去计算被分层抽象：设计微处理器的人只管微处理器，做编译器的人只管编译器，做语言的只管语言。他说斯坦福的 John Hennessy 做 RISC 的妙处，就在于把编译器和微处理器架构放在一起设计：一个高度优化但很难编译的处理器不会好用；更简单的指令集让编译器能生成更好的代码，结果是协同设计的简单机器比各自单独优化的两个系统性能更好。他说这是斯坦福的传统。

通用计算机之后呢？有些问题计算量极大，比如早年的计算机图形学、分子动力学、量子化学、流体力学、多尺度多物理场问题，还有深度学习，没理由用通用计算机去做。关键在于同时理解算法、计算机系统、编译器和框架、芯片架构，并同时优化所有这些。NVIDIA 可能是第一家做极致协同设计的计算机系统公司，覆盖 CPU、GPU、网络、交换机和存储。

结果是什么？摩尔定律的好时候大约每 18 个月翻倍，相当于每 5 年 10 倍、每 10 年 100 倍。摩尔定律依赖登纳德缩放（Dennard scaling），而登纳德缩放大约十年前就失效了，所以过去十年如果只靠半导体进步、不动软件，最好情况是 100 倍，实际上大概只有 10 倍。NVIDIA 靠协同设计在十年里得到了大约 10 万到 100 万倍的加速。计算快到这种程度，AI 研究者就会说：何必费心挑选和制作数据，把整个互联网都交给计算机吧。他打比方说，如果能以光速旅行，住在哪里就无所谓了；计算快了一百万倍，计算的一切也就变了。

讲完这段，他笑说："这就是在 NVIDIA 工作的感觉，你给我一个词，我给你讲半小时。"

三、教育和开源

教育应该怎样变

黄仁勋认为 AI 应该进入课程，不只是学 AI，还要用 AI 来学。他在斯坦福上课时，Hennessy 还在手写教材，似乎每周写一章，几年后这些讲义才变成第一版教材。预先写好的教材跟不上 AI 实时产生的知识，所以未来应是两者结合。他说自己已经离不开 AI 学习：让 AI 读论文，再让它读相关的一大批论文，它就成了专门为你服务的研究员，你先让它总结、问些基础问题，然后像和研究员讨论一样和论文互动。很多人以为 AI 只是在做总结，其实它在总结的过程中学到了很多。

但他也为教材辩护：第一性原理不会变。Mead 和 Conway 的芯片设计方法依然扎实；现代半导体设计中那些基于恒定功率密度的缩放优化虽然已经用尽了，了解来龙去脉仍然有益。他在斯坦福读书时已经在 AMD 设计微处理器，同时看到实践中怎样设计和第一性原理的方法，学到了更多。用 AI 学习贴近现实，同时学第一性原理，就能得到和他当年类似的体验。

NVIDIA 为什么做开源模型

他先说 NVIDIA 用的 OpenAI 和 Anthropic 的 token 几乎比任何公司都多，100% 的工程师都有 Agent 辅助。能用 OpenAI 和 Anthropic 就用，因为它们好用而且一直在进步。大语言模型只是里面的技术，Claude 是产品，Claude Code 是围绕它的一整套工具框架，从 GitHub 下载一个开源模型不太可能有同样的效果。

那为什么还要做开源模型？他说 AI 学的是信息的表示、意义和结构。世界充满结构，否则每天都会像白噪声一样，生物系统和物理系统也有结构，能学到表示，就能操纵和使用它。他想对化学、蛋白质、基因、物理、机器人做语言模型对语言做的事。这些领域的表示、结构、维度都不同，也没有像互联网语料那样的大量数据，需要新的训练策略。NVIDIA 有人才和规模，能在几个领域率先给出第一批成果：数据、模型、训练方法。这些领域包括语言（Nemotron）、生物（BioNeMo）、自动驾驶（Alpamayo）、人形机器人（GR00T）、气候科学（多尺度多物理场）。如果不这样做，这些领域的科学家没有规模和技术去造基础模型。他说这样做带动了医疗和生命科学，全世界每家自动驾驶公司都在用 NVIDIA，现在又在带动机器人。

做语言模型有两个原因。一是很多语言的使用人口不够多，不会成为别人的优先事项，比如瑞典语；中文和印度的某些语言照顾得很好，但还有两百多种其他语言，除非有人真正在乎，否则永远做不好。所以他们做了接近前沿的 Nemotron，并公开全部内容，谁都可以按需微调。二是要把语言模型和领域模型融合，给领域模型加入人类先验。Alpamayo 就是语言模型和世界模型的融合：如果自动驾驶模型能像人一样带着人类先验推理，达到安全驾驶所需的经验和训练数据就会大大减少。他说 Alpamayo 只跑了几百万英里而不是几十亿英里，却是世界上最有效的自动驾驶系统之一。

他还加了一条：要让 AI 安全，就必须开放。你没法防御一个黑箱，也没法让黑箱变得安全，更不能把一个能力极强又完全不透明的东西放进自己的系统。可以要求模型行动前先逐步讲清计划，但它总可以撒谎。开放的系统人人可以检验，研究者可以使用。将来防御超强 Agent 带来的网络安全威胁，不应该是你出 7.0 版、我出 8.0 版这样来回军备竞赛，而是用成百万上千亿个便宜的 AI 把威胁包围起来，像一个巨大的穹顶。他说网络安全公司就在用 Nemotron Nano，因为它快且便宜，可以训练来检测攻击，然后大规模部署。

四、MFU 是错误的指标

Anjney 提到他们在讨论"联盟式扩展"（coalition scaling）这样的开放扩展实验，并提到上周有报道说 xAI 孟菲斯集群的 MFU（模型浮点利用率）只有 11%，问开放生态在没有垂直一体化公司的情况下怎样提高利用率。

黄仁勋说 MFU 是错误的指标。它衡量的是你做事时用掉的浮点运算占比，但任何指标都可能量错东西。他自己宁愿 MFU 低：数据中心里有浮点运算能力、内存带宽、内存容量、网络容量，任何时刻总有一项是瓶颈，所以应该每样都超额配置，避免一直和阿姆达尔定律作斗争。到了关键时刻 MFU 会冲到 100%，但只持续很短时间；如果那时算力不够，短时间就会变成长时间。而且浮点运算本身很便宜。Anjney 说 H100 在涨价，他说那不是因为它的浮点能力，而是因为它的带宽、架构和其他一切。

他用汽车打比方：以前大家问车有多少马力，现在谁还这么问？要定一个真正严肃的评估指标，否则你提高了一个数字，并不会让你更聪明、更成功。Anjney 问，是不是该用"每瓦智能"？他说每瓦 token 数就比浮点运算更有意义：大语言模型解码时，决定每瓦 token 数的最重要因素是整个 NVLink 72 的总带宽，而这时 MFU 非常低，因为大部分时间在解码而不是预填充（两者可以拆开在不同机器上做）。也就是说，可以在极低的 MFU 下做到极高的每瓦 token 数。

Anjney 又问，token 并不等值，编程 token 比别的更值钱，各家客户（做编程的、研究超导的）评估标准完全不同，却都用 NVIDIA 的芯片，怎样设计架构？他说这正是难处：为某个问题过度拟合，可以在那个问题上极强，但那个市场可能撑不起足够的研发投入；什么都擅长，就会什么都不突出，变成通用处理器。在两者之间把握平衡，决定不做什么、加倍投入什么、十倍投入什么，就是他的工作，需要愿景、策略、试错，也需要一点个人兴趣。

五、每一代架构为什么而设计

  • Hopper：为当时还很新的预训练设计。他们判断预训练会成为很大很重要的问题，应该建比任何科学超级计算机都大得多的系统。当时世界上最大的超级计算机约 3.5 亿美元，而他们要做几十亿美元的系统，"市场规模恰好为零"，但还是基于第一性原理做了。
  • Grace Blackwell NVLink 72：训练会继续进步，但 AI 的目标是推理。神经网络处理分预填充（处理上下文、注意力）和解码（生成 token），解码需要极高的内存带宽，一颗芯片远远不够，于是把 72 颗连在一起，为此发明了新的交换和互连系统，做出了世界上第一台机架级计算机。相比上一代提速 50 倍，两年 50 倍，摩尔定律只会给 2 倍。它正好赶上大语言模型推理需求爆发。
  • Vera Rubin：目标不只是思考，而是做事，所以为 Agent 设计。Agent 要加载长期记忆和工作记忆，长期记忆放在存储里，存储需要直接和 GPU 通信，而不是从网络存储里拷贝。Agent 要大量调用工具，工具跑在 CPU 上；现在的 CPU 为云计算设计，动辄两百个核，但当一个价值数十亿美元的 GPU 超级计算机发出工具调用、等着一个 CPU 时，那个 CPU 需要极低的延迟。于是他们做了 Vera CPU，在单线程代码上性能最好。
  • Feynman：他预计将来所有软件都是 Agent，Agent 有子 Agent，子 Agent 还有子 Agent，形成一群 Agent，Feynman 大概就是为这种计算模式设计的。

他说思路都是一样的：想清楚计算模式是什么、和过去有什么不同，形成心智模型，再造一个能运行它的系统。

能源

Anjney 说 NVIDIA 擅长提前一代发现瓶颈，一年前是光子学，现在能源和铜线成了瓶颈。黄仁勋说，首先做自己能控制的事：能效。每瓦 token 数已经提高了 50 倍，还要继续以很大的倍数提升，而且会复利。其次是教育整个生态做好准备。他认为计算所需的能源可能是现在的一千倍，因为未来的计算一是生成的，二是持续运行的，而不是按次检索预先录好的内容；他说就算差一两个数量级也不奇怪。至于能源来源，过去因为担心成本，人们对可持续能源投资不足，而现在是人类历史上投资可持续能源最好的时机，因为以前建太阳能电站、核电站需要政府补贴，现在市场就会付钱让你去建，这是升级陈旧电网、增加各种可持续能源的最好机会。

六、学生提问

该做喜欢的事吗

有人建议职业要选自己热爱的事。黄仁勋说如果你知道自己热爱什么，那很好，但很多人不知道，因为谁也不可能知道自己不知道的东西，所以只选能带来激情和快乐的职业，这个标准太高了。无论做什么，都尽力做好。他以前的工作是刷厕所和收拾餐桌，他照样尽全力。他说 CEO 说自己从早到晚都热爱工作，那是撒谎：他真正喜欢的只占工作的 10%，另外 90% 很难，他照样尽力去做，"我真的是在受苦"。他认为经历过很多这样的困难，才会有韧性，等到家人、公司、同事需要你坚强的时候，你才有这块"肌肉"。所以不要只追求快乐，也要接受一些痛苦，而且这本来就是你的工作。

还有学生问他在 Denny's 最爱点什么（他年轻时在 Denny's 打工）。他说炸鸡出乎意料地好，Superbird 做得好也很棒，Grand Slam 和"毯子里的小猪"也喜欢；他第一次吃热巧克力圣代、第一次吃上面放奶酪的苹果派、第一次喝奶昔，都是在 Denny's。

该不该把芯片卖给对手国家

黄仁勋说 GPU 用于电子游戏、送外卖、医学影像（他前一天刚做了 CT），世界上每台医学影像设备里都有 NVIDIA。他反对三种说法。第一，把 NVIDIA GPU 比作原子弹毫无道理：有十亿人在用 NVIDIA GPU，他向家人孩子推荐 GPU，但不会向任何人推荐原子弹，从这个类比出发就没法把道理想完。第二，"反正会输，为什么还要去国外竞争"：按这个逻辑早上何必起床？竞争服务市场、让公司变强，他不怕竞争。第三，为了让一两家公司受益，就剥夺某些国家使用通用计算的机会，让整个行业受损，也没有道理。美国科技产业是国家的宝藏，如果通过政策把世界三分之二的市场让给别人，学生们毕业时进入的将是一个空壳产业；他说电信业就发生过这种事，如今美国已经没有基础电信技术了。

他也批评有人说 AI 会突然出现奇点、"游戏结束"、有一定概率终结社会。他认为把科幻幻想公开表演给依赖他们说法的大众是不负责任的：说没人知道这些系统怎样工作，不是真的；说技术会在一瞬间变得无限强大并接管世界，不是真的；说没有办法防御，也不是真的。这种说法也伤害正在学计算机的学生，他希望创造一个对技术乐观的未来："人人都应该有 AI，没人应该有核弹。"

Anjney 换了个角度反驳：在美国，独立团队、创业公司、大学都拿不到算力，稀缺资源不应该先满足美国吗？黄仁勋说当然应该，但"有人下了订单而我们不交货"不是事实，芯片有的是，斯坦福校长下单他保证交货。真正的问题是体制不再能支撑大规模计算：大学各院系各自申请经费，没人会把经费拿出来共享，而单个经费都不够建一个偶尔使用但用时要很强的大系统；世界已经从集中计算转向人人用笔记本电脑。Anjney 问这是谁的错，他说是斯坦福的错，并解释说，指出是谁的错，就是赋予对方解决它的能力。他建议斯坦福像当年建直线加速器一样，建全校共享的超级计算机，或者委托别人建，但需要约 10 亿美元，从捐赠基金里拿出 10 亿，作为云服务给每个学生和研究者用。他补充说，你不能去杂货店说要买 10 亿美元的番茄，店里没有就说人家扣着不卖，需要提前规划，比如明年需要 10 亿美元的算力，他们就会去建。

当 CEO 最好和最坏的部分

最好的部分是要处在愿景、战略和执行的交汇点上，身边有很多出色的计算机科学家（很多来自斯坦福），愿景很容易实现，也因此可以更有野心。他几乎一直在做这部分：不断更新对未来的看法、NVIDIA 在其中的角色、公司该怎样重塑自己。没有标准答案，是最高形式的创造。另一面是对加入这艘船的人的责任。早年公司差点倒闭四五次，那时尴尬、屈辱、在黑暗中摸索、害怕，所有人的情绪都被放大千百倍；作为上市公司 CEO，做得好大家高兴，做得不好大家马上告诉你，这是一份非常容易受伤的职业。

犯过的最大错误

他说有人会以为是第一代产品：技术完全错了，用曲面而不是三角形，没用 Z 缓冲，用正向纹理映射而不是逆向纹理映射，内部没有浮点，几乎每个技术选择都错了。但他认为这些技术错误最终带来了战略上的妙招：一家名声不好、浪费了两年半时间和大量资金、被竞争对手包围的公司，如今成了唯一留下的那家。他三十出头从这次几乎让公司消失的失败中学到了很多战略思维，受用至今。

真正的错误是进入移动设备市场。移动设备兴起时，移动领域的重要公司找 NVIDIA 合作，他把很多资源转去做手机芯片，当时应该拒绝。如果多想几步就会发现，在他们擅长的方面，能带来的价值很有限。这块业务一度做到十亿美元规模，正面反馈让他继续投入；后来 3G 到 4G 转换时，手机最重要的部分是调制解调器，不是 SoC、图形或应用处理器，Qualcomm 是那里的领导者，把他们完全挡在了门外，业务归零。补救是把在移动设备上积累的极低功耗和能效经验全部转向当时还不存在的应用，机器人。现在的 Thor 芯片就是当年移动芯片的"玄玄玄孙"。但他说这只是事后合理化，当初进入那个市场就是浪费时间，是一个战略错误。

前景不明时怎样判断方向

他说先问自己观察到了什么，再推回第一性原理，问接下来会发生什么。首先问"这重要吗"：比如 AlexNet，Alex、Ilya 和 Hinton 几个人用一个神经网络，一下子超过了几十年来所有计算机视觉研究者的成果，这是大事。然后问能走多远，还能解决什么问题，这对计算机和计算意味着什么，比如自动驾驶和机器人、模型会变多大、计算机会是什么样、处理神经网络和处理浮点数整数有什么不同（神经网络不一定要用 FP64、FP32）。这样不断追问，形成对未来计算的心智模型，找到自己在其中的位置，再倒推回来。你可能会错，但推理得当的话不会全错也不会全对。他习惯把事情分成"一定会发生""很可能发生""可能发生"，据此确定大方向，边走边摸索。追求一个战略要花精力、时间和金钱，真正的代价是机会成本，所以要想办法降低机会成本、增加可选项，"让这段旅程自己养活自己"。
