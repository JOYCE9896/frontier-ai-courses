CS143: Compilers

斯坦福的本科编译器课：词法分析、语法分析、语义分析与类型检查、运行时组织与代码生成、操作语义、优化、寄存器分配、垃圾回收，课程项目是自己写一个把 Cool 编译成 MIPS 汇编的完整编译器

主讲：Fredrik Kjolstad（2026 年春季）；课件设计和公开课录像：Alex Aiken
整理：Joyce（@JOYCE9896）

这门课讲什么

一个编译器分五个阶段：词法分析认出单词，语法分析认出句子结构，语义分析找出程序里的不一致（主要是类型检查），优化让程序少用资源，代码生成把程序翻译成另一种语言。这门课把这五个阶段一个个打开来看：每个阶段用什么形式化工具描述（正则表达式、上下文无关文法、推理规则、操作语义），用什么算法实现（有限自动机、LL 和 LR 分析、符号表和类型检查、栈机器代码生成、数据流分析、图着色），以及语言设计上的种种取舍怎样决定了什么容易编译、什么难编译。课程把正确性放在性能前面。

课程项目是 Cool（Classroom Object Oriented Language），一门专门为了让学生在一个学季里写完编译器而设计的面向对象语言，有类、继承、静态类型、动态分派和垃圾回收。四次编程作业依次用 C++ 写出它的词法分析器（flex）、语法分析器（bison）、语义分析器和 MIPS 代码生成器，最后得到一个能在 SPIM 模拟器上运行的完整编译器。另有四次书面作业，以及期中、期末考试。

怎样读：会写程序、学过数据结构就能读。前四讲之后会用到一点离散数学（集合、函数、归纳），类型规则和操作语义两讲用推理规则的记号，笔记里都从头解释。建议按顺序读，后面的讲常常引用前面的结论。想对照硬件和系统层面的背景（MIPS 和 x86 汇编、栈帧、缓存），可以配合本站的 CMU 15-213：它讲编译器生成的机器代码长什么样、程序怎样在机器上跑，这门课讲编译器怎样生成这些代码。

笔记目录（18 讲加作业）

第一部分：概览与 Cool

01. 课程概览

解释器和编译器，从 IBM 704 和 Speedcoding 到 FORTRAN I，编译器的五个阶段，中间表示，各阶段分量六十年来的变化。

02. 语言设计与 Cool

编程语言的经济学（为什么语言这么多、为什么还在出新语言、什么是好语言），抽象、类型、复用三条思想史，Cool 语言概览和三个现场编程演示。

第二部分：词法分析

03. 词法分析

token、词素和类别，FORTRAN、PL/I、C++ 里的词法难题和向前看，形式语言、正则表达式、语法与语义、意义函数为什么是多对一，用正则表达式描述各种 token。

04. 词法分析的实现

最长匹配、规则优先级和错误规则，有限自动机，DFA 与 NFA，正则表达式到 NFA，子集构造和 ε 闭包，表驱动实现和时空取舍。

第三部分：语法分析

05. 语法分析入门

正则语言为什么不够，上下文无关文法，推导和语法分析树，二义性，分层改写、悬空 else 和优先级声明。

06. 错误处理、语法制导翻译与递归下降

恐慌模式、错误产生式和自动纠正，抽象语法树，语义动作和属性，递归下降分析的写法和局限，消除左递归。

07. 自顶向下分析

预测分析和 LL(1)，提取左因子，用栈和分析表分析，First 集、Follow 集的计算，构造 LL(1) 分析表。

08. 自底向上分析

移进归约，句柄，活前缀，LR(0) 项和识别活前缀的自动机，LR(0)、SLR 和冲突，SLR 分析算法的完整演示，LR(1) 和 LALR(1)。

第四部分：语义分析

09. 语义分析与类型检查（上）

作用域、符号表和多遍分析，类型和类型之争，推理规则，类型环境，子类型和最小上界，分派规则，把规则写成代码。

10. 类型检查（下）

静态类型和动态类型，SELF_TYPE 的动机、含义和规则，它能出现在哪里，类型错误的恢复：Object 还是 No_type。

第五部分：运行时与代码生成

11. 运行时组织

活动和活动树，活动记录，全局变量、栈和堆的布局，对齐，栈机器和累加器。

12. 代码生成

用 MIPS 模拟栈机器，一门小语言的完整代码生成（表达式、if、函数调用和定义、变量），临时值放进活动记录，对象布局和动态分派。

13. 操作语义

为什么要单独定义求值规则，环境、存储和求值判断，各种表达式的规则，new 和动态分派的语义，运行时错误。

第六部分：优化

14. 中间代码与局部优化

三地址码，基本块和控制流图，代数化简、常量折叠、公共子表达式消除、复制传播、死代码消除，窥孔优化。

15. 全局优化

全局数据流分析，用 ⊥、常量、⊤ 做常量传播，循环和不动点，抽象值的序和终止性，活跃性分析，前向和后向分析。

16. 寄存器分配

存储层次，寄存器冲突图，图着色启发式，溢出和乐观着色，编译器能为缓存做什么（循环交换）。

第七部分：内存管理与一门真实语言

17. 自动内存管理

可达性和根，标记清除，停止复制，保守回收，引用计数，垃圾回收的利弊。

18. 用编译器的眼光看 Java

数组协变的不可靠，异常的语义和实现，接口为什么慢，强制转换，线程和同步，类加载与初始化，特性交互。

作业与考试

PA1 到 PA4 写出完整的 Cool 编译器，PA5 加分做优化，WA1 到 WA4 四次书面作业，期中期末和往年考卷。
