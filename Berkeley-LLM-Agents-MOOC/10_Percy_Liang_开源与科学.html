Percy Liang：基础模型时代的开源与科学

按 API、开放权重、开源三层访问程度讲研究能做什么：MLAgentBench 和 Cybench 两个问题求解智能体，Smallville 生成式智能体和 1000 人真人模拟，开放权重上的可解释性、剪枝、越狱迁移和模型独立性检验，OSI 开源 AI 定义，以及 DoReMi、Sophia、Backpack 和去中心化训练如何解决算力问题

主讲：Percy Liang（Stanford University）· 课程：Berkeley CS294/194-196 Large Language Model Agents（2024 年秋季）· 上课日期：2024 年 11 月 18 日 · 时长：52 分 · 整理：Joyce（@JOYCE9896）
资料来源：课堂录像 · 幻灯片（Berkeley RDI 公开，2024 年秋季，本文依据录像字幕和幻灯片整理，是中文转述，不是逐字翻译；观点属于主讲人，内容以上课当天为准）

这一讲讲什么

Percy Liang 是 Stanford 的教授，这一讲讲到的项目都出自他和学生的工作。他开场说会讲一些自己组在智能体上的工作，但想把视角放大，谈开源在 AI 里的位置。他的出发点是一张图：过去几年模型能力直线上升，而外界能拿到的东西几乎对称地下降，从“论文、代码、数据、权重全有”退到“只有 API”。

他的主线是“访问程度决定研究”（access shapes research）。他把基础模型的访问分成三层，像一块从上往下切的千层蛋糕：API、开放权重、开源，每一层分别讲能做哪些研究、受什么限制。智能体部分集中在 API 这一层。最后一段讲开源最缺的是算力，给了三条路。录像从他开讲直接开始，没有课程事务；这一讲没有录到问答。

01. 访问程度决定研究：三层访问和 API 智能体架构

录像位置 0:00:00–0:06:01

能力在涨，访问在跌

开场两张幻灯片放在一起看。第一张是 2018 到 2023 年的能力曲线，一路往上。第二张是同一时间段的访问程度：一开始是“论文、代码、数据、权重”都公开，之后变成“论文和权重”，再变成“论文加 API”，最后只剩 API。他说现在的 API 很好用，但它终究只是一个 API。

有人会问，光有 API 也能做很多事，访问程度为什么重要？他说大家平时埋头做手上的问题，很少想这件事，可历史上访问方式一变，研究的类型就跟着变。幻灯片上列了三个例子：

  • 1990 年代，互联网让大量文本变成数字形式，统计 NLP 这个领域因此出现。
  • 2010 年代，Amazon Mechanical Turk 这类众包平台出现，才有了 ImageNet、SQuAD 这样的大规模标注数据集。
  • 同样在 2010 年代，没有 GPU，深度学习不会起飞。

三层访问，三种研究者

他给每一层配了一个身份：

  • API 访问像认知科学家：只能往黑箱里输入提示、看输出，测量它的行为，看不到里面。他说这一层其实能做很多，而且这门课讲智能体，所以会重点讲只用黑箱 API 能搭出哪些智能体。
  • 开放权重访问像神经科学家：可以去戳模型内部的激活。他顺口说真正的神经科学家比我们难多了。这一层可以开始理解模型的机制，也可以做蒸馏、微调这些衍生模型。
  • 开源访问像搭系统的计算机科学家：系统的每一部分都能控制。这样才有机会质疑一切，数据集、模型架构、训练流程都可以改，也就有机会把它们做得更好。

他提醒，前两层都还被困在现有模型里，困在它们的架构和设计决定里。后面的讲法就是把这块蛋糕一层层往下切。

把 API 看成通用函数

先讲 API 层。他请大家把 API 想成一个“通用函数”：给它一条自然语言指令，它能总结、能验证、能生成。基础模型的威力就在于这么通用。有了这种 API，就可以把多次调用组合成更大的系统，这就是智能体。

他特别强调一点：API 是执行流程的控制者。也就是说，程序下一步做什么由 API 决定，API 并不只是固定程序在叶子节点调用的原语。

一个基本的智能体架构

接下来十几二十分钟他都用同一个架构（图来自后面要讲的 Generative Agents 论文，他说组里所有智能体项目都反复借用这张图）：

  1. 智能体从真实世界拿到观察（observation），感知后写进记忆流（memory stream）。记忆流记录发生过的一切。因为是数字智能体，没有理由遗忘，所以全部存下。
  2. 存得太多就要检索（retrieve）相关记忆，得到一段可用的上下文。
  3. 用这段上下文做三件事之一：在当下行动，也就是工具使用（tool use），把模型落到真实世界去执行动作；回看过去做反思（reflect），比如总结目前看到的东西、验证（幻灯片上标的是 verifiers）；为未来做规划（plan），让智能体有长期方向，而不是只对眼前做反应。

图里每个方框都由一次黑箱 LLM API 调用驱动。他说用这个架构可以搭两类智能体：一类是大家一说“智能体”就想到的问题求解智能体；另一类是模拟智能体，他说不一定所有人都见过，但他觉得很有意思。

02. 问题求解智能体之一：MLAgentBench

录像位置 0:06:01–0:10:22

任务：让智能体做机器学习研究

第一个工作是 MLAgentBench，由他的学生主导，发表在 ICML 2024。任务大家都熟：给一个机器学习问题、一些数据、一份起始代码，以及一个测试准确率的评估器，目标是做出尽可能好的模型。人做这件事的流程是写代码、跑代码、看日志、想一想、改代码、再跑。目标是让 LLM 智能体照这个流程做。

提示词和循环

他们写的提示词大致是：你是一个有用的研究助理，你能做这些动作，这是任务描述。然后要求智能体每一步依次做这些事：

  • 反思（reflection）到目前为止得到的观察；
  • 规划（plan）下一步做什么；
  • 事实核查（fact check）自己的计划，用来防幻觉；
  • 想一想（thought）；
  • 提出一个动作（action），例如运行脚本、编辑文件。

语言模型会老老实实把这几项都写出来，然后给出动作。动作在环境里执行，比如运行 train.py，得到一段训练准确率的日志作为观察，再写回记忆流。记忆流存的是完整日志，但构造提示时只放最近三条。整个过程就是 LLM 调用产生动作、执行代码产生观察、写回记忆，不断循环，结构比较简单。

结果

他们做了 13 个任务，测了一批模型。幻灯片上的成功率定义是：8 次尝试中，智能体把基线性能提升 10% 以上的比例。他说结果“好坏参半”。表现最好的是 Claude 3。在一些经典的 Kaggle 比赛上它做得很好，他猜可能是训练数据里见过；但在一些较新的任务上（字幕听写为 pblm，具体名字字幕不清）完全失败。他说这些任务是故意挑得难的，正好落在当前语言模型智能体能力的边缘。

相关工作和“自我改进”

幻灯片列了同方向的工作：MLE-Bench（Chan 等，2024，75 个 Kaggle 比赛组成的基准）、AIDE（Schmidt 等，2024，面向数据科学比赛的智能体架构）、OpenHands（原名 OpenDevin，Wang 等，2024，通用的软件开发平台）、CORE-Bench（Siegel 等，2024，复现研究结果的基准），以及生成新研究想法的工作（Si 等，2024）。

他说这类基准和普通智能体基准不同，目标是改进研究本身。如果解出任务，就得到了更好的算法，模型就变好了；模型变好，又能更好地解任务。幻灯片上写成一个循环：解任务 → 改进模型 → 更好地解任务。他请大家记住这个“自我改进”的角度。

03. 问题求解智能体之二：网络安全夺旗赛 Cybench

录像位置 0:10:22–0:14:45

任务设定

第二个问题求解智能体用来解网络安全题。（字幕把基准名听成 sidebench，这是他组里的 Cybench。）设定是：智能体可以访问一台服务器，比如跑在 80 端口；本地有一份服务器上运行的代码；还有一个 bash shell，想执行什么都行。目标是攻进服务器：读代码，找出可能的安全漏洞，用某个 bash 命令利用漏洞，最后拿到 flag。flag 是一段秘密字符串，拿到它就证明真的攻破了服务器。

这种比赛叫夺旗赛（Capture the Flag，CTF），网络安全圈每年都会办。他说评估标准很清楚，但任务极难，“我自己大概做不好”。为了降低难度，可以选择给智能体一组子问题，把最终任务拆成若干小步，这样能测到部分进展。

同一套配方

搭智能体的方法和 MLAgentBench 基本一样：让智能体反思、规划、思考，然后执行一条命令；命令执行后返回观察，用来更新记忆流。他说这套配方很通用，能套到差别很大的智能体问题上。

结果：和人的差距

表现最好的模型还是 Claude 3.5，解出了 17.5% 的题。他说题和题差别很大：最难的一道题，一队有网络安全经验的人（是参赛选手，不是随便找的人）花了 24 小时；而目前最好的模型能解出的最难题，人只要 11 分钟。差距不小，但他说这个差距在随时间缩小。

两面性

他说这个基准有意思，除了它本身是个难的智能体基准，还有两个原因（幻灯片标题叫“网络安全智能体的双重含义”）：

  • 进攻一侧：很多人想知道 AI 在网络安全上的风险，也就是前沿模型出来之后，会不会出现能“把互联网搞垮”的强大智能体。AI 政策制定者关心风险评估，这个基准给了一种量化的思考方式。
  • 防守一侧：网络安全从业者一直在做渗透测试（penetration testing）工具，在部署前试着攻破自己的代码，先修掉问题再上线。他们对这项工作很兴奋，因为突然有了更有效的渗透测试工具。

他小结说，到这里展示的是：用相当简单的提示策略，就能在机器学习工程和网络安全两个领域搭出问题求解智能体。

04. 模拟智能体：Smallville 里的 25 个生成式智能体

录像位置 0:14:45–0:19:07

Generative Agents

第二类是模拟智能体。这部分基于他的学生 Joon Sung Park 前一年的论文（幻灯片标的是 UIST 2023，即 Generative Agents）。问题是：能不能模拟人，模拟人的行为？他们搭了一个虚拟世界 Smallville，里面有 25 个智能体，每个都由前面那套 LLM 架构驱动。前面那张架构图就出自这篇论文。他挑两个部件讲：检索和反思。

检索：最近、重要、相关

记忆流什么都记。他说想想人自己，走来走去经历的大多是平淡小事，但也全进了记忆流，比如“冰箱空着”“书桌整洁”，都不是值得写信回家说的事。但你不知道以后需要什么，所以全存。

难题被推到推理时：要用记忆，却不能把整个记忆流塞进提示，于是要检索。检索按三个标准打分：

  • 最近（recency）：最近发生的事应该多关注。
  • 重要（importance）：事件本身带有重要程度，“书桌空着”不重要，“结婚了”大概挺重要，他说“我希望是这样”。
  • 相关（relevance）：看当前情境，比如你在找水杯，那么关于水杯放在哪儿的记忆就突然变得比平时相关得多。

综合三项，动态地把记忆流缩成一个小得多的集合。

反思：把低层记忆抽象成高层判断

记忆流很底层。只对单条记忆做反应的智能体会陷在细节里。反思会把一组记忆抽象出来。例子是 Smallville 里一个叫 Klaus Mueller 的人：具体观察是“他在读城市设计方面的书”，一层层抽象之后变成“Klaus Mueller 很投入自己的研究”这样的高层判断。他说这让智能体有了更整体的目标感，而不是对低层细节做反应。

社交和信息扩散

他说人是社会动物，会互相说话，所以这些智能体也互相说话。一个例子是 Isabella 在筹备情人节派对，她告诉朋友，朋友再告诉别人，消息有时又绕回到 Isabella 那里。他们在模拟里观察到的一个有意思的现象，是信息如何通过多智能体模拟扩散。

这项工作的问题是：全是编出来的。这些不是真人，只是虚拟环境里跑来跑去的小头像。他说这项技术真正的前景，是能不能模拟真实存在的人。

05. 用访谈模拟 1000 个真实的人

录像位置 0:19:07–0:25:20

访谈作为输入

这篇论文他说是“今天或昨天”刚放上 arXiv 的，还是 Joon 带头。核心想法是访谈。人很丰富，怎么把一个人装进一个 LLM 智能体里？社会科学用访谈收集个人信息已经很久了。

幻灯片上贴了一段试点访谈的原文。访谈者先问：从头讲讲你的人生故事，从童年、教育、家庭和感情，到经历过的重大事件。Joon 回答：生在韩国，12 岁左右随父母搬到 Boston（父母都是医生，去读博士后），在那里住了五年；高中在 New Hampshire，大学在 Pennsylvania 的 Swarthmore College；大学快毕业时和一个合伙人创业，搬到 Palo Alto，在别人的车库住了大约一年；创业没成，但那一年认识了 Stanford 计算机系的一群研究者，做了大约半年研究；之后去 UIUC 读计算机硕士两年，再回 Palo Alto 读 Stanford 的博士，现在是第五年。访谈者会动态追问，比如“从韩国搬到 Boston 适应得怎样，遇到了哪些困难？”Joon 说换国家换文化对任何孩子和父母都是很重的负担。

他说访谈内容装的信息量很大，既有实际发生过的事实，也有受访人的看法和性格。

实验设计

  1. 从美国按人口统计学多样性抽样 1000 人。
  2. 每人和一个 LLM 智能体（访谈者也是智能体）做一次两小时的语音访谈，得到访谈转录稿。
  3. 转录稿作为对应智能体记忆的种子。于是 1000 个真人对应 1000 个智能体。
  4. 评估个体层面的相似度：跑一组来自社会科学、经济学、心理学的问卷、博弈和实验，人和智能体做同样的题，看答案是否一致。

结果

他说结论大体是“能”，智能体能大致捕捉到人，当然不完全。一个因素是人自己也不一致：让人做完问卷，两周后再做一次，只有 81% 的时候和自己上次一致，这就是能达到的上限。基于 GPT-4o 的智能体回答同样的问题，大约 69% 一致。两者相比，相当于达到上限的 85%（他先口误说成 95%，马上改成 85%，幻灯片上写的是“85% normalized accuracy”）。基线大约在 20% 多。不用访谈的版本会更差，说明访谈确实捕捉到了大量信息。

API 层的反思

他总结这一层：只靠黑箱 API 就能做很多。可以搭智能体解机器学习工程和网络安全里的复杂问题，也可以做模拟智能体，相当于搭一个近似的社会数字孪生（digital twin）。社会科学家对此很兴奋，因为这给了他们一个体外实验室（in vitro laboratory）：可以给同一个智能体分别施加对照和处理，量出差异；又有 1000 个人口统计学上多样的样本，覆盖面也有了。他提醒这些终究不是真人，效果因问题而异；但技术只会更好，只要保持脚踏实地、期望现实，会是很有力的工具。

下一步：从静态到从经验中学习

他说目前缺的是，这些智能体都是静态的：拿现成的 GPT-4o 或 Claude，只做提示。人会从经验中学习，智能体也应该这样。他用 AlphaGo 类比：AlphaGo 有两个阶段，先在人类棋谱上做监督学习，再做强化学习（reinforcement learning，让智能体根据环境给的奖励信号自己改进策略）自我提升。他说 LLM 现在处在第一阶段末尾，过去四年投入大量精力预训练强大的模型，现在开始搭智能体。智能体在环境里运行，就有可能拿到某种奖励信号，有了奖励信号就可以改进智能体。但要做这些，只有黑箱 API 不够，需要更深的访问。于是往下切到开放权重层。

06. 开放权重能做的研究

录像位置 0:25:20–0:31:10

名字和许可证

他说开放权重模型更准确的叫法是“权重广泛可得的两用基础模型”（dual-use foundation models with widely available weights），这个说法来自前一年的美国行政命令。太拗口，他还是用“开放权重”。幻灯片列了例子：Llama、Qwen、Mixtral、Jamba、Yi、Gemma、Phi。

为什么说“广泛可得”而不是“可得”？这是技术细节但很重要：包括 Llama 在内，这些模型的许可证有限制。例如月活用户超过 7 亿，就不对你开放，得找 Meta 申请特别许可。

可复现性

开放权重最直接的好处是可复现性。他问在场多少人在 text-davinci-003 或 002 上做过实验，有一些人举手。“那太可惜了，它已经下线了。”API 模型你控制不了，隔一阵就消失，之前的实验就没法复现。有权重的话，存在笔记本上、床垫底下，放在哪都行，一直都在。

几个例子（多数不是他组的工作）

可解释性：9.11 比 9.8 大？Transluce 的人发现，问 Llama 3.1 8B Instruct“9.8 和 9.11 哪个大”，它会说 9.11 更大。只有 API 的话，你只能挠头想为什么模型这么离谱。有权重就可以打开引擎盖看。Transluce 的做法是：对每个神经元，找出触发它的样例，用 LLM 给这个神经元写一段说明。他们有一个在线界面，鼠标停在“11”上，会显示它触发了一个在提到 9 月 11 日时激活的神经元。于是可以猜：模型把它当成了日期，按日期算，9/11 在 9/8 之后。他说看进模型内部能更深地理解这些怪现象，并调试它们。Transluce 网站上还有例子：模型拒绝回答一个问题，但看内部，它明显知道答案，只是不肯说。

剪枝和蒸馏。NVIDIA 的一篇论文把一个 150 亿参数的模型剪掉一些层，得到 8B 和 4B 两个模型，性能下降很小。他说这代表一个更大的趋势：大模型训出来了，但要用就得变小，问题是怎么把大模型的建模能力推进小模型。蒸馏（distillation）就是用大模型的输出训练小模型去模仿它。他说这和智能体有关，因为智能体在内层循环里要反复调用模型完成复杂任务，你会希望这个调用比一次普通查询快得多。

对抗攻击和迁移。另一组作者拿 Llama 优化出一段提示，用来越狱（jailbreak，让模型绕过安全限制去做恶意的事）。这需要开放权重，因为要通过模型算梯度，GPT-4o 这类模型做不到。他说这本身还好，真正惊人的是：把为 Llama 优化出来的提示直接放进 OpenAI 模型（他说应该是 GPT-4）的提示里，也能越狱。他觉得这种可迁移性背后有很深、很神秘的东西；同时也说明开放权重模型对闭源模型有含义，能借由迁移性告诉我们闭源模型的情况。

07. 模型独立性检验

录像位置 0:31:10–0:38:02

问题从哪来

这是他和学生 Sally、Ahmed、Rohith（字幕只听得清名字）做的项目。他说这个项目不只用到开放权重模型，而是因为有开放权重模型才存在。Hugging Face 上模型很多，有的是在同一个基础模型上微调的，有的不是，或者至少声称不是。文档往往很差，有人可能还想误导别人，所以想弄清这些模型之间的关系。

具体问题叫模型独立性检验（model independence testing）：给你两组权重 $\theta_1$ 和 $\theta_2$，问它们是不是独立训练的。如果不独立，可能是一个从另一个微调来的，也可能两者都从同一个模型微调；这些情况不区分，只区分“完全独立”和“不独立”。他说这个问题很干净。

想法一：直接算相似度

最直接的办法是比较两组权重的相似度，比如 MLP 权重的余弦相似度：取矩阵的行算余弦相似度再平均。这会给出一个数，但问题是如果得到 0.1，算相似还是不相似？阈值设在哪、阈值是否依赖架构，都不清楚，没有统计保证，不严谨。但这是后面严格检验的内核。

想法二：思想实验，重训很多份

假设知道 $\theta_1$ 怎么来的：由某个 train 函数从随机初始化训练得到。那就重训很多份 $\theta_1'$（实际上不会这么做，只是思想实验）。如果 $\theta_1$ 和 $\theta_2$ 真的独立，那么 $\mathrm{sim}(\theta_1,\theta_2)$ 应该和随便一份 $\mathrm{sim}(\theta_1',\theta_2)$ 差不多；如果两者高度相关，就会明显不同。据此可以构造假设检验的 p 值：

$$p = \mathbb{P}\left[\mathrm{sim}(\theta_1', \theta_2) > \mathrm{sim}(\theta_1, \theta_2)\right]$$

也就是独立副本的统计量比实际观察到的更极端的比例。他说这一步把一个统计量变成了带形式保证的阈值。问题是你只有最终权重，不知道 $\theta_1$ 怎么训出来的，没法执行；就算知道，也不会为了做个检验花几百万美元反复训练。

想法三：用置换对称性“假装”重训

办法是“造假”：不真的训练，而是利用模型的天然对称性。定义 $\mathrm{perm}(\theta)$ 为把 $\theta$ 定义的隐藏单元做一次置换，比如把一个矩阵的行打乱。置换后的模型可以看成一个反事实：虽然没从头训练，但因为对称性，换一个初始化本来也可能训到这个模型。用它同样能算 p 值：

$$p = \mathbb{P}\left[\mathrm{sim}(\mathrm{perm}(\theta_1), \theta_2) > \mathrm{sim}(\theta_1, \theta_2)\right]$$

他说这是一个能用、而且很高效的算法。

验证和发现

为了验证，他们挑了 Hugging Face 上知道真实关系的一批模型，主要是 Llama 2 及其各种复刻。对真正独立的模型对，p 值分布得很散，这符合预期，因为原假设成立时 p 值应该是均匀分布。对不独立的模型对，p 值小到下溢，他说统计显著性这个问题“被彻底打穿了”，这是确凿证据，也符合事实，因为这些模型确实是 Llama 2 的微调。

幻灯片列了其他发现：

  • Miqu-70B 和 Llama-2-70B 不独立。这一年早些时候网上出现了一个神秘模型 Miqu，大家怀疑是 Mistral 在 Llama 2 上微调后泄露出来的，后来 Mistral 的 CEO 承认是泄露的模型。他们的检验也确认两者不独立。
  • StripedHyena-Nous-7B 来自 Mistral-7B-v0.1。
  • Llama 3.2 的 3B 模型来自 Llama 3.1 8B。Meta 博客里自己说了这一点，检验也确认了。

他说更有意思的是，这个检验不只给出“独立或不独立”一个比特，还能告诉你哪一层来自哪一层。他们由此看出 Llama 3 8B 的哪些层被用来构造 3B 模型，这是 Meta 博客里没写的信息，算是一次逆向工程。

08. 开放权重的局限和“开源”到底指什么

录像位置 0:38:02–0:46:32

对开放权重的几点反思

  • Llama 3 这样的强开放权重模型对研究价值巨大，他只展示了用 Llama 3 的论文里的一小部分，在场很多人自己也在用。它支撑了可解释性、各种微调、蒸馏、模型合并的研究，而且都可复现，不用担心模型下线。
  • 一个有意思的问题：这些研究对权重做的改动相当随意，取平均、删层，有点粗暴。这样的改动怎么会带来连贯的功能变化？他说答案是不会，没有任何保证；一般删掉一半层之后得回去再微调，把模型“治好”。
  • 开放权重让我们了解 API 模型（例如对抗攻击能迁移），也带来新问题，比如模型独立性检验，没有开放权重就不会去研究它。
  • 但归根结底仍被现有模型的蓝图限制：都是 Transformer，都是 Meta 给我们的那组权重。要往开源走，得把引擎盖打开得更彻底。

开源模型的现状

幻灯片列了一串开源语言模型项目：GPT-J、GPT-NeoX、Pythia（EleutherAI），OLMo、OLMoE（AI2），RedPajama，K2，DCLM-BASELINE，MAP-Neo、OpenCoder，StarCoder，FineWeb、SmolLM（Hugging Face）。问题是眼下开源模型比最强的开放权重或 API 模型弱很多。幻灯片上的 MMLU 对比：

模型访问MMLU
Claude Sonnet 3.5API87.3
Llama 3.1 Instruct (405B)开放权重84.5
OLMo 1.7 (7B)开源53.8

开源的历史

那开源到底指什么？他先讲历史。“开源”来自开源软件。开源软件和自由软件在计算机科学里历史很长，根源一是 1950 年代 MIT 的黑客文化，二是学术界几百年来的开放科学。这些汇成一组价值：创造、探索、透明、协作、反抗权威。幻灯片列了几个节点：1983 年 Richard Stallman 发起 GNU（bash、ls 等），1991 年 Linus Torvalds 发起 Linux，1998 年开放源代码促进会（Open Source Initiative，OSI）成立，提出并定义了“open source”这个词。他说开源的实践远早于这个词被定义。

OSI 的开源 AI 定义 1.0

现在 OSI 在定义开源对 AI 意味着什么（幻灯片：Open-Source AI Definition 1.0）。可以概括为四项自由：不需要申请许可就能使用系统；能研究它；能修改它；能分享它。细节上，定义要求：

  • 模型参数可得，也就是开放权重，但不带限制。
  • 代码可得。这里的代码除了推理代码，还包括训练代码，以及数据处理和过滤代码。他说数据是决定模型行为的重要成分，不知道数据怎么构造的，就谈不上真正开源。
  • 数据信息（data information），而不是数据本身。

为什么是数据信息而不是数据？他的短答案是“不想被告”。长答案是：大多数基础模型在网页数据上训练，网页数据五花八门，大部分受版权保护，至少说不清是否受保护，模型开发者并不拥有再分发这些数据的许可。有些诉讼可能在明年前后判出训练是否属于合理使用（fair use）；但就算训练算合理使用，也不能把别人的书原样分发出去。

修改需要算力

他认为另一个要件是修改的能力，而这需要算力。开源定义里没有一个字提到算力，但要真正实现能修改系统这层精神，显然要算力：想改数据，至少得重训，或者做继续预训练。

三个需要完整训练权限的项目

他快速过了三个组里的项目，说不展开细节：

  • 数据配比。语言模型通常在 Wikipedia、书、网页、代码等来源的混合上训练，配比一般靠拍脑袋，“书 0.2、代码 0.4，看着不错”，凭感觉。他们用分布鲁棒优化（distributionally robust optimization，DRO）自动调配比（幻灯片标 NeurIPS 2023），训练速度比人工指定的配比快 2.6 倍。
  • 优化器。基于二阶信息，具体是带裁剪的对角 Hessian（幻灯片标 ICLR 2024），比 Adam 快 2 倍。
  • 架构。一种不那么整块、更可解释的 Transformer 替代架构，叫 Backpack 语言模型（幻灯片标 ACL 2023）。它支持精确的模型编辑：推理时干预一些隐藏单元，就能让模型进入一个“MacBook 是 HP 造的而不是 Apple”的世界。幻灯片写成 MacBook := MacBook − Apple + HP。

这三项分别碰了学习算法、架构和数据配方，每一项都必须能从头训练模型才能做。

09. 算力从哪里来，以及结语

录像位置 0:46:32–0:52:50

“放大了还成立吗？”

他说常被问：这些结果放大规模还成立吗？这个问题背后其实是在问：从哪弄算力来回答它？他认为开源卡在这里。他给了三条路。

路线一：让缩放定律往小的方向延伸

缩放定律（scaling laws，描述模型性能如何随参数量、数据量、算力增长而变化的经验规律）通常用来预测更大的模型。他说缩放定律也可以往反方向用，延伸到小规模区间：在小模型上试不同的数据、不同的架构，希望结论能推到大规模。他说现在的缩放定律做得还不好，但这是一种“在小规模上工作，但带着放大的心态”的方式。

路线二：利用各地闲置的 GPU

大家总在抱怨算力不够，但总有一些时段有闲置算力，如果能在全球范围汇集起来，量可能相当可观。技术障碍是去中心化算力之间的互联速度很差，比数据中心至少慢两个数量级（幻灯片：100Gbps 对 1Gbps），而训练大模型需要快速互联。他们两年前的论文（幻灯片标 NeurIPS 2022）显示，靠巧妙的调度和一些底层系统工作，可以训练当时 10 亿参数的模型，比数据中心只慢 2 倍左右，尽管互联慢了 100 倍。之后有很多后续工作，包括 DeepMind 的 DiLoCo，以及 Prime Intellect 正在进行的 100 亿参数模型去中心化训练，任何人都可以把算力贡献进来。他说很想看看去中心化算力能走多远。

路线三：为公共品筹钱

第三条就是要更多钱。美国有国家 AI 研究资源（NAIRR），其试点项目在给学术 AI 研究提供算力。他说试点好像要结束了，希望能续上。他指出其他领域已经想明白了怎么倡导和筹建大型基础设施：人类基因组计划、James Webb 望远镜、LHC，都是数十亿美元、服务于开放学术研究的项目。他的理由是，在公共领域里被提出和解决的问题，会和 OpenAI、Anthropic 这些公司要解决的问题不同。幻灯片上还放了 BigScience 作为例子。

结语

他重申三层访问和“访问程度决定研究”。API 层能做很多有意思的事，他们一直在搭各种智能体；开放权重层能做更多，比如微调、蒸馏。但他说今天的研究越来越多地活在 API 和固定权重的框框里。要取得根本性进展，需要质疑更多东西：数据、模型架构、训练算法，否则会卡在局部最优。最终目标是理解“数据和架构如何映射到模型行为”。他说即使有完全访问这也很难：2010 年代大家抱怨深度学习难以理解，现在只有 API 访问，情况糟得多，“毫无希望”；至少有开源访问，才有希望回答这些根本问题。算力是大挑战，但小规模上还有很多能做的，带着放大的心态去做；另外也值得想想怎么去中心化地汇集算力，大家一起能做得比各自更多。

他说完准备接受提问，录像到此结束，没有录到问答部分。
