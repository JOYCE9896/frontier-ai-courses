这一讲讲什么

这一讲和下一讲侧重机器人：这一讲讲自主性，下一讲是关于仿真到真实迁移和人形机器人的客座课。内容包括：为什么机器人还没有自主，定义自主强化学习（Autonomous RL）问题，以及两类算法：在没有人工干预的情况下学策略，以及单次生命强化学习（Single-Life RL）。目标是让智能机器拥有自主性，能自己学习、交互、练习、变好，不需要人在回路中。2026 年课程没有这一讲（换成了 RL for VLAs，没有公开录像）。

01. 强化学习在真实机器人上为什么不自主

录像位置 0:00:00–0:08:30 · Introduction to autonomy / Limitations of current RL / Simulation vs real world / Need for human intervention

模仿学习训练 agent 模仿专家演示，强化学习让 agent 通过试错练习，从自己在世界中的经验学习，这本身已经更自主了。但在物理机器人上跑这些算法时，实际并不完全自主。

设想机器人从初始状态分布出发，要到达状态空间中奖励高的区域。学习过程中收集尝试：第一次尝试还没学到什么，轨迹不好；然后再试一次，又从初始状态分布里的某个状态出发运行策略。执行时从策略分布中采样动作，按 agent 自己的动作行动，所以每条轨迹都在机器人控制之下，这部分是完全自主的。问题是：一次尝试结束在某个状态之后，下一次尝试时，好像会神奇地回到起点再试。我们从没讨论过怎样从那里回到起点。传统强化学习算法一直假设有人或某种方式把系统复位到初始状态，实践中可能意味着人亲手把机器人或场景里的物体挪回初始条件，所以这个过程并不完全自主。

在仿真环境里，可以建环境、走一千步，然后调用 env.reset()，这是个很友好的小工具；但只有在仿真里能这样，物理世界不能随意复位。例子：

  • 小型移动机器人或自动驾驶车学习去篮球场送东西，探索时转错了弯，就真的到了那个地方，得自己想办法回到起点，或者从错路找到篮球场。
  • 机械臂学抓杯子，失误把杯子碰倒了，想再练习，杯子得在够得着的地方。
  • 移动机器人学把书放上书架，犯了错得设法回到书在够得着的位置。

这特别重要的原因是强化学习往往需要很多次尝试，不是试三次就解决了；每次重试都意味着有人或别的干预把你带回初始状态分布。真实例子：机器人学把冰球打进球门，她的朋友 Yevgen 干的活大概比机器人还多；Ali 在把门关上，好让机器人学开门；Archit（这学期早些时候做过客座课的那位）在给机器人复位，好让它练习叠毛巾。

02. 定义自主强化学习，以及两种评估

录像位置 0:08:30–0:12:33 · Defining autonomous RL / Evaluation metrics for RL

问题在于复位通常需要人工干预，希望消除它，让 agent 自己练习变好。一个想法：把 episode 长度 $H$ 加大，原则上需要的人工监督就少了，也许能用课上学过的同样算法，只是学习中需要的监督更少。定义：初始化场景一次（也许已经是初始化好的），然后让 agent 在没有任何环境复位的情况下自主地和世界交互；也可以放宽，只以很低的频率复位，比如 $H$ 很大。

两种评估方式

  • 一生中获得的奖励：agent 自主探索、没有复位、不回初始状态，收集了一些经验，它在这段经历中拿到高奖励了吗、真的完成任务了吗？比如部署火星车收集科学数据，你不太在乎它学完之后能否部署一个好策略，你在乎的是它被部署、边学边做的过程中表现好不好。
  • 学到的策略的质量：学习结束后，得到的策略能否被部署、反复完成任务？比如学做饭，训练过程中做得怎样不太重要，在乎的是之后能不能部署、为很多顾客反复把饭做好。

部署策略评估（Deployed Policy Evaluation），和课上一直用的目标很像：

$$\mathbb{E}_{s_0\sim\rho_0,\ a_t\sim\pi(\cdot\mid s_t)}\left[\sum_t\gamma^t r(s_t, a_t)\right]$$

持续策略评估（Continuing Policy Evaluation），学习过程中的平均奖励，取生命长度趋于无穷的极限：

$$\lim_{H\to\infty}\ \mathbb{E}\left[\frac{1}{H}\sum_{t=1}^{H} r(s_t, a_t)\right]$$

这个期望不是在单个策略下取的，而是对整个学习过程取的，这是和衡量学到的策略好坏的另一个区别。有学生问只跑一条轨迹，为什么要期望？如果只想评估一次生命、一次学习过程，直接跑一遍看结果就行；但环境有变化，学习过程（怎样采样批量等）也有变化，想在算法层面衡量算法在这个问题上有多好，就要对算法多次运行取期望。

为什么重要：希望机器人在部署时少需要人工监督，训练时也少需要。一般来说，在真实机器人上做强化学习是一条有希望的路，能比模仿学习得到高得多的成功率和可靠性；如果训练时需要的人工监督少，就能收集更多数据，更多数据可能带来更高的可靠性和更好的泛化，前提是这些系统能大规模部署到各种真实环境中。

03. 加长 episode 为什么不行：偏离和塌缩

录像位置 0:12:33–0:21:15 · Algorithm performance / Drift and state collapse

直接拿标准算法（这里是 SAC）、episode 越来越长，原则上需要的监督越来越少。纵轴是部署策略达到的奖励（上面那个部署评估），横轴是训练步数。episode 长度 1000 步（绿线）时，SAC 能学到完成任务的策略；长度加倍，表现变差；乘以 10，更差。越加长 episode、越减少训练所需的监督，最后几乎学不会做任务。她说这只是一个很简单的鱼控制任务，用鱼能做的动作游到某个位置，即使这么简单，不常复位也学不出好策略。

两个原因

  1. 偏离（Drift）：可能犯错、到了很难恢复的状态空间区域。这个环境里大概不会把尾巴弄断，但会偏离好的状态分布，因为偏离，很难回到奖励高的部分附近。
  2. 状态分布塌缩：更微妙一点。即使在某次 episode（一次复位后或就在这次）最终到达了目标，拿到了奖励，它可能就一直待在那个区域。如果在那里收集了大量数据、拿了很多奖励，学习过程看起来很好；但如果目标是学一个从初始状态到目标的策略，它并没有访问能学出好策略的那些状态。

设 $\rho^\ast$ 是从起点到目标的最优策略的状态分布。分 episode 学习时总能从初始状态分布重试；自主（非分 episode）学习时会从上次停下的地方继续，探索可能让你偏离到达目标所需的好状态；即使最终到了目标，回放缓冲区里的状态分布也可能塌缩，集中在目标附近，而不是覆盖最优策略附近的状态分布。没有最优策略的状态，到了状态空间的那一部分就不知道该做什么动作。结果是永远学不出好策略。

04. 前向后向强化学习

录像位置 0:21:15–0:27:33 · Forward-backward learning / Implementing FBRL

既然允许从初始状态分布复位时能学成功，一个很简单的想法就是学一个策略，把你从尝试任务之后所在的地方带回初始状态分布，叫复位策略或后向策略，它在撤销任务而不是做任务。这叫前向后向强化学习（Forward-Backward RL，FBRL）：学一个做任务的前向策略和一个撤销任务的后向策略。

  1. 定义后向奖励函数 $r_b$：到达初始状态分布中的状态就给奖励；
  2. 初始化，从初始状态分布采样一个初始状态（初始化 agent）；
  3. 运行前向策略 $\pi_f$，用完成任务的前向奖励函数 $r_f$ 更新 $\pi_f$，最大化奖励和；
  4. 不复位，运行后向策略 $\pi_b$，用 $r_b$ 更新它（它要做前向任务的反向）；
  5. 关键：跑完后向策略也不复位，回到第 3 步，重复。

更新步骤可以用你喜欢的任何强化学习算法。也可以偶尔复位一次，以防真的卡在很难的状态。测试时，扔掉后向策略，只部署前向策略，它理想情况下学会了怎样高效地从初始状态分布到达目标，或者一般地最大化前向奖励函数。

要决定前向策略跑多久。最简单的是跑固定的 $H$ 步。也可以更复杂：前向策略还什么都没学到时，它不怎么移动，后向策略也就没事可做，所以一开始可以让前向跑久一点，但到某个时候也得让后向多跑一些；用固定步数更简单。而且如果整个过程是自主的，步数没那么重要，因为机器人学的时候你可以去睡觉。

有学生问前向和后向策略之间共享信息吗？用回放缓冲区时，可以在两者之间共享数据，把前向的奖励重标注给后向，反之亦然。实践中比较常见的是不怎么共享，也可以共享图像编码器之类的部分权重，有帮助，但它们学的东西某种程度上很不一样，比较麻烦。后面会看到共享更多的算法。

优点是很简单。缺点之一是这个撤销任务的后向策略最终没什么用，学它似乎有点浪费，但它确实让自主学习成为可能。幻灯片上的参考：Han 等，Learning Compound Multi-Step Controllers under Unknown Dynamics（IROS 2015）；Eysenbach 等，Leave no Trace: Learning to Reset for Safe and Autonomous Reinforcement Learning。

其他选择

  1. 改后向策略的奖励，不一定复位到起点，可以复位到更多样的状态；
  2. 不只学一个任务的前向和后向，而是练习一个由多个任务组成的循环；
  3. 在特殊情况下，把任务设置成可以反复做的（幻灯片上戏称“forward-forward RL”）。

05. 复位到专家状态分布：MEDAL，以及 EARL 基准

录像位置 0:27:33–0:38:48 · Alternative approaches / MEDAL algorithm / Benchmarking results / Real robot experiments

前向后向强化学习里是做任务、回去、做任务、回去。最终要从初始状态分布完成任务，但也要知道沿整个专家状态分布怎样做好动作。所以可以不每次都回到起点，而是复位到专家状态分布中的不同状态。有工作表明，如果能这样做，即使在分 episode 的设定里，也比总从初始状态分布出发学得更高效（幻灯片引 Kakade 与 Langford，Approximately Optimal Approximate Reinforcement Learning，ICML 2002）。

做法和前面一样，只有两处小改动：

  • 要近似专家状态分布，所以假设有少量演示：给定一组专家轨迹，是完成任务的示例。
  • 后向策略的奖励函数不再是到达初始状态分布，而是到达专家访问过的状态，而且这个奖励函数是学出来的。和奖励学习那一讲一样，训练一个判别器区分好状态和坏状态，用策略的状态作坏状态的例子：这里训练它区分策略访问的状态和演示中访问的状态，训练后向策略时就是要骗过这个奖励函数，让它以为访问的是专家的状态而不是策略的状态。

理想情况：运行前向策略；后向策略学到一定程度后，把你带回专家分布（粉色区域）里的某处；再运行前向策略，再被带回粉色区域某处。测试时同样扔掉后向策略，部署前向策略。这个方法叫 MEDAL（Matching Expert Distributions for Autonomous Learning）。它解决了两个难题：agent 不会偏离；后向策略避免了状态分布塌缩。另外前向策略从大范围的初始状态尝试任务，包括离目标近的容易状态和远的困难状态，提高了样本效率。演示也可以放进回放缓冲区，帮助训练前向和后向策略。

课堂问答

  • agent 完成任务后，后向策略会待在那里吗？不会。前向后向强化学习里它会回到初始状态；MEDAL 里它会把策略推到专家状态分布中的某个状态。训练区分策略状态和专家状态的分类器时，用的是轨迹和演示中的所有状态，所以它会回到中间某处，让策略练习从那里做任务，而不只从目标状态练习。
  • 目标状态也在演示里，什么阻止它一直待在目标？她本想不讲细节：这个奖励函数实际上是一个状态分布匹配目标，要让自己访问的状态和演示里的状态分布一致。如果它只复位到目标状态，判别器会学到“只在目标状态的大概来自策略而不是专家演示”，就能区分。形式化地说，可以看作后向策略访问的状态分布和专家访问的状态分布之间的散度。

EARL 基准

有一个专门针对自主强化学习的基准叫 EARL（Sharma、Xu 等，Autonomous Reinforcement Learning: Formalism and Benchmarking，ICLR 2022）。训练时每 20 万个环境步才复位一次，很少；评估是从某个初始状态分布出发时策略有多好。最简单的任务是抓起一个杯子移动它，有个很简单的抓取机构让任务容易些。

  • 只跑 SAC、没有后向策略、复位极少：和鱼的例子一样，表现不好，学不出好的前向策略。
  • 能频繁复位的 Oracle（分 episode 的 SAC）：能学到好策略。
  • 几种无复位算法：鼓励访问新状态的扰动方法（R3L，Zhu 等，ICLR 2020），原始的前向后向强化学习（橙色），给目标课程的方法（VaPRL，Sharma 等，NeurIPS 2021，她没有细讲），以及复位回演示状态的 MEDAL（蓝色）。

主要结论：专为自主或无复位设定设计的算法比不为它设计的好得多；简单环境里它们表现相近；更复杂的环境里前向后向强化学习和 MEDAL 最好，鼓励访问各种状态或目标的算法不太行。

  • 专家轨迹怎么来？有多种方式。真实机器人上通常用遥操作设备：木偶式操控、VR 手柄、3D 鼠标或键盘。仿真里可以是人设计的脚本策略，也可以是事先用强化学习训练好的策略，只为测试算法。
  • “分 episode”是什么？指传统强化学习设定：尝试任务，复位，再尝试，每次尝试是一个 episode。她说这不是最好的术语；非分 episode 指没有这些复位的设定，只是一个很长的学习过程，有时也叫无复位（Reset-free）。

她补充：其中一个任务的前向任务是关门、后向任务是开门，取决于机械臂从哪开始，后向任务可能比前向难不少。前向和后向任务的难度经常不匹配，两个策略学的速度不同，会让学习更难。比如前向任务是后空翻，后空翻很难，而站起来准备后空翻相对容易。

真实机器人

这些算法可以在真实机器人上跑，看延时摄影很酷。左边是前向后向强化学习，学前向和后向策略，两个策略都会犯错，但能通过完全自主的过程变好。右边是 MEDAL，能看到如果前向策略没抓到，后向策略就没什么可做的。奖励也是需要提供的，所以把奖励学习算法和自主（无复位）算法结合很常见；这两个例子里奖励都来自模型而不是人，所以整个过程可以自主，比如跑一整晚。

有学生问，后向策略不好就很难学前向策略，反之前向策略不好就永远拿不起毛巾、得不到好的状态，怎么办？一种办法是为前向和后向任务都提供演示，帮两者引导学习。除此之外，平衡两者本身就是难点，算法在有些设定里能工作。她也说这些工作大多仍处在研究阶段，不是机器人公司今天在用的东西。

06. 任务循环和任务提议

录像位置 0:38:48–0:52:33 · Task cycles and graph RL / Task proposal systems / Multi-stage manipulation / VLM task proposal / Hierarchical RL comparison

如果要学的是多个任务，就可以不只是前后来回，而是按所在状态循环练习不同任务。比如机器人做咖啡：第一个子任务是把杯子放进咖啡机，尝试时不小心把杯子掉了。传统做法是让人把杯子放回原处，我们不想这样。既然犯了错，第二个任务就不该是打开咖啡机，而是捡起杯子。于是有这样的循环：练任务 1，失败了就练任务 2（任务 2 相当于复位任务 1），再回到任务 1；任务 2 没成功就接着练；任务 1 成功了就去任务 3，依此类推。这是一个由不同任务组成的图或循环，根据所在状态练习当前可行的任务，排除不可行的。

  1. 初始化一个任务条件的（多任务）策略 $\pi(a\mid s, z)$；
  2. 观察当前状态，根据状态提议一个要练习的任务 $z_i$（任务描述）；
  3. 以 $z_i$ 为条件运行策略 $H$ 步；
  4. 更新策略，奖励函数要考虑正在练的任务，所以需要所有可能任务的奖励函数。on-policy 算法就针对这个任务更新；离策略算法可以针对任意任务更新；
  5. 不复位（或很少复位），回到第 2 步提议别的任务。

测试时部署这个多任务策略，它能做多个任务而不只一个。

例子

  • 多阶段操作（Gupta 等，Reset-Free Reinforcement Learning via Multi-Task Learning: Learning Dexterous Manipulation Behaviors without Human Intervention，2021）：要拿起物体、翻转、旋转。一开始不会翻转也不会转，就练习从手里拿起再放下；拿起练好了，就开始翻转、旋转。根据所处状态练习合理的事，也能解决任务不平衡的问题：前向策略还没成功改变状态时，可能根本不在适合跑后向策略的状态，就继续练当前合理的任务。
  • 四足机器人同时学向前走、向后走和摔倒后站起来（Smith 等，Legged Robots that Keep on Learning: Fine-Tuning Locomotion Policies in the Real World，2021），在前进和后退之间切换，太靠后了就不再后退，改练前进。
  • 七阶段任务（Han、Levine、Abbeel）：拿起扳手、定位、反复拧，按所在状态运行不同的策略或控制器，最终也会运行“把扳手放回桌上”的后向策略。

怎样选要练的任务

有学生问怎样选这些任务？她说有两类做法，这也是研究前沿：一是预先定义一组任务和那张图，比如“任务 1 失败了就练任务 2”，事先定好各种情况下该做什么，然后按图行动；二是训练一个提议任务的模型。一般来说，某个时刻该为哪个任务收集数据是开放问题，但可以问语言模型“在这个环境里我能做哪些事来提高”，然后练习它描述的任务。

例子（SOAR，Zhou、Atreya 等，Autonomous Improvement of Instruction Following Skills via Foundation Models）：在这一帧画面里，能打开玩具微波炉、拿起香蕉、推茄子、移动锅；但如果让它拿起胡萝卜，在这个场景里做不到。想训练它做很多不同的事，任务是依场景而定的，所以可以让视觉语言模型（VLM）想想在这个环境里能做什么，比如预测“把香蕉从银色锅里拿出来”，然后练习这个任务。

有学生问这和分层学习有什么区别？这个任务提议器和告诉你某种情况下该做什么的高层策略有相似之处，但目的很不一样：它提议的是环境里能练习的事，希望给你很多不同的东西让你学会很多事；分层系统里高层策略的目标是“下一个子任务是什么才能最终达成某个结果”，目标导向得多。这项工作选择用了分层方法，基于之前讲过的一项工作：把提议输入图像编辑扩散模型，生成目标图像，再训练策略到达这个目标图像。好处是：这个算法需要用每个任务的奖励函数更新，为所有任务定义奖励函数很难；有了目标图像，奖励就可以基于是否接近这张图像，容易定义得多。

有学生问冰球的例子里，提议器会给出“练传球还是练射门”吗？完全可以。这个框架用在简单的机器人场景上，但也可以问它在这种情况下能做什么。对那些例子，要练的东西有限，一节练射门、一节练传球也合理；但也可以用这种想法提议在不同情况下尝试什么。

还有一类情况可以把任务设置成能反复做：幻灯片上的例子是给商家叠餐巾，要叠很多餐巾。这方面研究不多。上面这些都是想学一个策略（目标是得到好策略），不同于火星车那种最大化一生奖励的例子。

07. 单次生命强化学习

录像位置 0:52:33–0:56:54 · Single-life RL concept / SLRL deployment challenges

第二类问题：前面通过无复位的练习提高策略质量，但到某个时候要部署，希望策略很好。也许部署后一切顺利，但现实中不是，即使训练了很多，自然世界里还是会出问题。这个设定考虑的是：学到某个策略之后，它在世界里独自运行时，能否从错误中恢复、在部署之后继续学习？人也会这样：视频里一个人开门，仔细看会发现他犯了个错，又在一瞬间适应完成了任务：用力时钥匙没插对，他把钥匙往回抽一点，再插进锁孔。

和之前的设定比较：课程大部分讲的是分 episode 设定，从初始状态反复尝试，然后部署一次；今天讲了无复位设定，学会尝试任务和撤销任务，反复练习后部署；这个较新的设定是：有一些先验训练数据，也许已经训练了策略，现在处在某个新的、分布外的情况下，要在尝试任务的同时做一些问题求解，在部署期间、在一个 episode 内、没有复位地适应和学习，也就是有了之前的数据或训练之后，你只有一条命来自主完成任务。这叫单次生命强化学习（Single-Life RL，Chen、Sharma、Levine、Finn，You Only Live Once: Single-Life Reinforcement Learning，NeurIPS 2022）。

简单例子：训练时只在平地上跑，某个时候遇到训练中没见过的障碍，要想办法越过去，希望用强化学习的想法在 episode 内实时适应新情况。能不能在测试时继续用强化学习微调策略？犯错时就边执行边用 TD 更新或策略梯度更新。这样做的结果：策略确实越过了第一个没见过的障碍，但最后翻倒卡住了；它仍在跑强化学习，能看出它在努力起身，但基本卡住了，无法从没见过的状态中自己恢复。理想情况是策略能弄清怎样起身、怎样在新情况下部署时重试。

08. 单次生命里的问题求解，安全和小结

录像位置 0:56:54–1:05:44 · Problem solving in SLRL / Leveraging pre-training / Real-time adaptation / Safety and final thoughts

她说这也是研究前沿，只介绍几个看起来很有帮助的想法：

  • 引导回熟悉的状态：卡住时到了很难恢复的状态。如果做强化学习更新时目标是到达目标，不如改成回到熟悉的状态，也就是之前经验里访问过的好状态，可能更容易脱困，比如这些状态离目标更近，能把 agent 拉回它熟悉的地方，再继续做任务。
  • 利用预训练：在低层动作空间对策略权重做强化学习，能改变的程度有限、适应方式有限。如果能在更高层的空间里适应，比如有一组预训练技能，就能更大幅度地适应，改变所采取的策略，而不只是改变权重或动作。比如有向前走和重新站起来两个预训练技能，与其在新状态下继续向前走，不如探索已有的技能，试试站起来，就可能更成功，因为是在试不同的策略而不是不同的动作。
  • 预训练的 LLM 可能有一些常识推理，帮 agent 适应新情况、尝试不同策略。

例子

  • 在同一个例子上用第一个想法：环境仍是分布外的，它还是会翻倒，但尝试之后能重新站起来：翻倒时它努力回到熟悉的状态（比如四脚着地），最终恢复并到达目标。
  • 低层空间的适应：一个从最近历史在低层空间适应的系统（RMA，Kumar、Fu、Pathak、Malik，Rapid Motor Adaptation for Legged Robots，RSS 2021），能处理一些小的分布外情况，比如不同地形。
  • 高层空间的适应：遇到差别大得多的情况时，在更高层的空间适应很有帮助（Chen、Lessing 等，Commonsense Reasoning for Legged Robot Adaptation with Vision-Language Models，ICRA 2025）。四足机器人要到达那边的目标，只看到这张图像，试着往前走，往后退；如果不带上下文一直运行策略，它会一直试着往前，因为不知道之前试过往前。如果带着上下文和适应尝试不同策略，比如向左、后退，即使它从没见过这个环境，也能一路解决障碍、导航到目标。如果在低层电机空间里适应、尝试不同的关节位置，就很难在这种情况下解决问题。

怎样加入安全约束

有学生问怎样把安全约束放进去？另一类需要人监督的情况就是可能犯安全关键错误时：腿式机器人可能摔得损坏自己；机械臂可能把玻璃杯掉到地上，也可能用力撞到东西。有工作直接建立在这些想法上：学习某种安全概念，学会判断什么时候处在高风险状态，然后回到风险较低的状态，比如学一个恢复策略，回到已知更安全的状态；几年前就有一些这样的想法在安全设定中研究过。另一个实际的做法是尽可能在控制器上加安全约束，比如别让电机用到过热，在机器人周围设一个框，不允许对状态空间的某些部分施加很大的力。这不是处处可行，学习安全概念可能是一般情况下唯一的办法；但要学安全，就需要失败的例子，所以总体上很棘手。

有学生提到，在人周围导航时，可以问 VLM 在不同情况下高层上该怎么做。她说这项工作就是用 VLM 结合过去经验指出该尝试什么好策略，这些模型可能有一些常识，比如不该撞到人，或者应该等一等，利用这些常识很有希望。

小结

  • 为什么强化学习算法没有让机器人拥有自主学习能力：真实世界不能 env.reset()，复位要靠人。
  • 问题定义的两个实例：关心一生中的奖励，或者关心学到一个好策略。
  • 对应的算法：学后向策略（FBRL、MEDAL），学任务图、尝试不同任务；以及单次生命强化学习，防止偏离、在部署中适应。

这一讲的要点

  • 自主强化学习：只初始化一次环境，此后不复位（或极少复位）地交互；评估可以看部署策略 $\mathbb{E}_{s_0\sim\rho_0}[\sum_t\gamma^t r]$，也可以看学习过程中的平均奖励 $\lim_{H\to\infty}\mathbb{E}[\frac{1}{H}\sum_t r_t]$。
  • 直接加长 episode 会失败：agent 偏离好的状态，或在目标附近导致回放缓冲区的状态分布塌缩。
  • 前向后向强化学习：交替运行完成任务的 $\pi_f$（奖励 $r_f$）和回到初始状态的 $\pi_b$（奖励 $r_b$），测试时只部署 $\pi_f$。MEDAL 改为让 $\pi_b$ 用判别器奖励匹配专家状态分布，在 EARL 基准的复杂任务上表现最好。
  • 多任务时按状态提议可行任务循环练习，可预先定义任务图或用 VLM 提议（SOAR）。
  • 单次生命强化学习：部署后在一条命内适应；有效的想法包括引导回熟悉状态、在预训练技能空间适应、利用 VLM 常识。安全需要学习风险或在控制器上加约束。
