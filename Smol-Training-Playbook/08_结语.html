01. 回顾

原书小节：Conclusion

全书从一个简单的问题出发：在 2026 年训练一个高性能的 LLM，实际需要什么？（导读里写的是“今天”，结语写的是 2026 年。）为了回答它，作者走完了从预训练到后训练的完整流程，讲了他们用的技术，也讲了让这些技术奏效的方法论。

预训练部分先给出训练罗盘，用来决定到底要不要训练，然后讲怎样把目标落到具体的架构决策上。接着讲怎样搭可靠的消融流程，一次只测一个改动，再从几十亿 token 的实验扩展到几万亿 token 的正式训练。书里记录了规模变大后会冒出来的基础设施问题：吞吐骤降、dataloader 瓶颈、隐蔽的 bug，以及怎样靠监控和系统性的去风险（derisking）尽早发现、快速调试。

后训练部分说明，从基础模型（Base Model）到好用的助手也需要一套系统的做法：训练任何东西之前先把评测建好，反复迭代 SFT 的数据混合，做偏好优化，需要的话再用强化学习往前推。书里展示了 vibe test（人工随手和模型聊几轮、凭感觉检查）怎样抓出指标看不到的 bug，chat template（把多轮对话拼成模型输入格式的模板）怎样悄悄破坏指令遵循，以及为什么数据混合的平衡在后训练里和在预训练里一样重要。

作者说，预训练和后训练两个阶段里，他们反复回到同样几条经验：

  • 所有决定都用实验验证；
  • 一次只改一样东西；
  • 预期规模变大会以新的方式把东西弄坏；
  • 让你的使用场景来驱动决策，不要追每一篇新论文。

按这个流程，他们训练出了 SmolLM3：一个有竞争力的 3B 多语言推理模型，支持长上下文。书里把成功和失败都记录了下来。

02. 接下来做什么

原书小节：What's Next?

这本书讲的是现代 LLM 训练的基础，领域本身变化很快。作者给了三条往深里走的路：

  • 自己跑实验。读消融实验有用，自己跑一遍才知道什么真正重要。挑一个小模型，把评测搭起来，开始实验。
  • 读源代码。Nanotron、TRL 等训练框架都开源，读它们的实现能看到论文里一笔带过的细节。
  • 跟进最新工作。最先进模型的论文显示了领域的走向，下面的参考资料是作者精选的论文和资源。

作者希望这本书能帮读者更有把握地开始下一个训练项目，不管是在前沿大实验室，还是在解决具体问题的小团队。最后一句是：去训练点什么吧；等你的 loss 在凌晨 2 点莫名其妙飙升时，记住每个好模型背后都有调试的故事。

致谢部分感谢了 Guilherme、Hugo、Mario 的反馈，以及 Abubakar 在 Trackio 功能上的帮助。

03. 参考资料

原书小节：References

原书说这是一份精选清单，列的是在他们训练 LLM 的过程中给过启发的论文、书和博客。

LLM 架构

  • 稠密模型（Dense Model，每个 token 用到全部参数）：Llama 3、OLMo 2、MobileLLM
  • MoE（Mixture of Experts，每个 token 只激活一部分专家网络）：DeepSeek-V2、DeepSeek-V3、Scaling Laws of Efficient MoEs
  • 混合模型（把注意力层和线性注意力或状态空间层混用）：MiniMax-01、Mamba2

优化器与训练参数

  • Muon is Scalable for LLM Training、Fantastic Pretraining Optimizers
  • Large Batch Training（OpenAI 关于批大小上限的经验模型）、DeepSeek LLM

数据整理

  • 网页数据：FineWeb & FineWeb-Edu、FineWeb2、DCLM
  • 代码：The Stack v2、To Code or Not to Code
  • 数学：DeepSeekMath、FineMath、MegaMath
  • 数据混合：SmolLM2、Does Your Data Spark Joy?

缩放定律

  • Kaplan、Chinchilla、Scaling Data-Constrained Language Models

后训练

这一类原书给每条都写了评语，下面照原意转述。

  • InstructGPT：OpenAI 把基础模型变成好用助手的奠基论文，ChatGPT 的前身。
  • Llama 2 和 Llama 3：Meta 写得极其详细的技术报告，里面有大量关于人工数据采集的经验，包括人类偏好数据和模型评测。
  • Secrets of RLHF in LLMs，Part I 和 Part II：讲 RLHF 的具体做法，尤其是怎样训练强的奖励模型（Reward Model，给回答打分的模型）。
  • Direct Preference Optimization：2023 年的突破性论文，原书的说法是它“让所有人不再用 RL 训练 LLM”。
  • DeepSeek-R1：2025 年的突破性论文，原书的说法是它“让所有人又开始用 RL 训练 LLM”。
  • Understanding R1-Zero-Like Training (Dr. GRPO)：理解 GRPO 内置偏差以及如何修正的重要论文之一。
  • DAPO：字节跳动公开了很多实现细节，让社区能稳定地做 R1-Zero 式训练。
  • ScaleRL：Meta 推导 RL 缩放定律的工作，花了超过 40 万 GPU 小时，得到一套在多个数量级算力上都能稳定扩展的训练配方。
  • LoRA Without Regret：一篇博客，发现用低秩 LoRA 做 RL 可以达到全参数微调的效果，原书说这是一个很出人意料的结果。
  • Command A：Cohere 的技术报告，详细讲了多种高效后训练 LLM 的策略。

基础设施

  • Ultra-Scale Playbook（Hugging Face 讲大规模并行训练的上一本书）
  • Jax scaling book（本站有中文笔记：How to Scale Your Model）
  • Modal GPU Glossary

训练框架

  • Megatron-LM、DeepSpeed、TorchTitan、Nanotron、NanoChat、TRL

评测

  • LLM Evaluation Guidebook、OLMES、FineTasks、Lessons from the Trenches

这一章的要点

  • 流程：先用训练罗盘决定要不要训练，再定架构、搭消融、扩到正式训练；后训练先建评测，再做 SFT、偏好优化，最后可选 RL。
  • 作者反复强调的经验：用实验验证，一次改一样，预期规模会带来新问题，用场景驱动决策。
  • 后续建议：自己跑小模型实验，读 Nanotron、TRL 等框架源码，跟进前沿模型论文。
