CS329A: Self-Improving AI Agents

Stanford 2025 年秋季学期：怎样让大模型和 Agent 用推理时算力、验证器、环境反馈和强化学习不断改进自己

主讲：Aakanksha Chowdhery（Stanford 兼职教授，Reflection AI）、Azalia Mirhoseini（Stanford 计算机系助理教授）
整理：Joyce（@JOYCE9896）

这门课讲什么

这是两位老师第二次开这门课。主线是一个循环：让模型多次尝试（推理时扩展），用验证器或环境反馈判断哪些尝试是对的，再把好的结果拿回去训练模型（训练时扩展、强化学习），模型变强后再进入下一轮。课程沿着这个循环依次讲推理时扩展、验证器、工具和代码反馈、规划与多步推理、强化学习、搜索与深度研究 Agent、Agent 评估，最后一讲回顾并讨论未来方向。每讲基本是精读三四篇论文，并穿插课堂讨论。

需要一些机器学习基础，比如知道什么是语言模型、微调和强化学习。没有基础的话，可以先读本站的 AI 基础。

笔记依据 Stanford Online 公开的九段课堂录像字幕整理，每篇开头有录像链接。课上还有一讲讲开放式探索（AlphaEvolve 等）和几场嘉宾讲座，没有公开录像，这里没有收录。

笔记目录（9 讲）

01. 课程概览：从大语言模型到 Agent

缩放规律和涌现能力，指令微调和 RLHF，反复采样，推理模型，Agent 和 Agent 工作流的组成部分，课程安排。

02. 推理时扩展

反复采样的覆盖率为什么符合幂律，生成—验证差距，并行采样与串行修改，ORM 和 PRM，用架构搜索组合推理时技术的 Archon。

03. 验证器

GSM8K 与训练验证器，逐步验证与 PRM800K，不用人工标注的 Math-Shepherd，用弱验证器集成的 Weaver。

04. 从工具、代码和反馈中学习

ReAct 交替推理和行动，RLEF 用代码执行结果做强化学习，Constitutional AI 让模型按原则批评自己。

05. 规划与多步推理

LATS 的蒙特卡洛树搜索，SPRINT 让推理模型并行思考，SWiRL 用离线合成数据做逐步强化学习。

06. 训练时扩展与强化学习

STaR 用自我解释自举推理，DeepSeekMath 的数据和 GRPO，DAPO 让长推理链上的强化学习稳定。

07. 搜索：竞赛编程与深度研究 Agent

AlphaCode 的大规模采样、过滤和聚类，AlphaCode 2 的打分模型，Search-o1 在推理中按需检索并提炼文档。

08. Agent 评估与长周期任务

METR 的时间跨度，GDPval 在真实工作上和专家比，DeepScholar-Bench 写相关工作综述。

09. 未来的研究方向

多 Agent 微调、DeepSeekMath-V2 的元验证、Absolute Zero 让模型自己出题，每瓦智能与本地推理，持续学习等开放问题。
