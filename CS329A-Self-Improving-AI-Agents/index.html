CS329A: Self-Improving AI Agents

大语言模型的自我演进、强化学习与测试期推理算力分配

主讲：Aakanksha Chowdhery（Google PaLM 共同一作）、Azalia Mirhoseini（AlphaChip 共同一作，Stanford 助理教授）
整理：Joyce（@JOYCE9896）

核心概念说明

本课程探讨语言模型如何超越单次前向预测，通过强化学习、测试期搜索与环境交互实现自我迭代。阅读本课程常涉及以下概念：

1. Pre-training 与 Post-training

Pre-training（预训练）让模型在海量网页和图书文本上做 Next-token prediction，习得通识语言表征与广泛常识。但这一阶段模型缺乏多步逻辑验证与任务拆解能力，且公开高质量自然文本在 2024-2025 年前后基本已被主流实验室用尽。

Post-training（后训练）包括监督微调（SFT）和强化学习（RL）。Anthropic 的 Claude 系列在代码生成与长逻辑推理上表现优异，核心在于其后训练设计：采用 Constitutional AI（宪法自对齐），依靠模型根据预设原则进行自检自修，大幅降低对外包人工标注的依赖；同时接入代码沙盒运行环境做执行反馈强化学习（RLEF），根据真实报错信息定位并修正代码。

2. 常见 Benchmark 的测试重点

评估模型能力的 Benchmark 在过去几年经历了明显的变迁：

  • MMLU：包含 57 个学科的四选一单选题，主要考察知识储备。由于选项有限且存在训练集污染风险，高分难以直接对应复杂的实际问题解决能力。
  • GSM8K：基础小学数学应用题，前沿模型大多已达到 95% 以上，辨识度逐步饱和。
  • HumanEval / MBPP：短 Python 函数的代码生成测试，主要检验语法与基础算法。
  • SWE-bench / SWE-bench Verified：直接从真实 GitHub 开源项目提取的 Issue，要求 Agent 在大型工程仓库中定位 Bug、编写补丁并通过单元测试，是目前衡量工程级代码能力的行业基准。
  • GAIA：要求结合网页浏览、文件读取、计算等多步工具调用，考察解决复杂综合任务的稳定性。
  • GDPVal：评估模型在金融建模、芯片硬件描述语言等高门槛工作场景下的完成质量与算力成本。

3. Test-time compute 与自演进机制

传统的推理方式是用户发送请求后模型单向生成固定长度回复。Test-time compute（测试期算力）允许模型在输出最终答案前分配更多计算资源，例如生成多条候选解（反复采样）、引入树搜索（MCTS）进行剪枝、或在沙盒中反复执行校验。通过将验证机制引入模型迭代循环，模型能够在较少依赖人工新标注的情况下持续提升。

背景与问题定义

固定权重的模型在部署后不再更新。面对单轮事实问答尚可应付，但面对多步骤的长程任务时，自回归生成的误差会随步数累积：若单步成功率为 p，连续 T 步无纠错决策的全局成功率为 P = pT，即使每步成功率高达 0.98，连续 50 步后成功率也会降到约 36.4%。

因此，构建具有自主演进能力的 Agent 需要三大支撑：测试期算力的高效分配、独立可靠的过程验证器（PRM）、以及模型基于环境真实反馈（如代码编译器报错）的强化学习闭环。

课程目录（10 讲笔记）

01. 自演进闭环与静态模型终结

讨论预训练数据的存量边界、自回归序列的累积误差机制，以及从静态概率预测向状态机决策转移的系统架构。

02. 测试期算力缩放与反复采样极限

分析测试期采样算力分配规律、Pass@k 的覆盖率变化，以及 Majority Voting（多数投票）在长尾逻辑题中的局限性。

03. 鲁棒验证机制与生成验证剪刀差

对比 ORM（结果奖励）与 PRM（过程奖励）的优劣，探讨弱验证器加权集成（WEAVER）在算力约束下的判决精度。

04. 工具代码反馈与执行强化学习

梳理代码执行沙盒作为客观环境反馈源的价值，解析 RLEF 训练框架与 Anthropic Constitutional AI 自对齐流程。

05. 多步规划树搜索与自适应分枝

分析顺序 CoT 在分支任务下的容错短板，介绍结合树搜索（LATS）与并行探索（SPRINT）的多步规划算法。

06. 训练期算力扩展与强化学习熵崩溃

探讨 DeepSeek GRPO 算法省去 Critic 网络的显存机制，以及强化学习中应对策略熵快速衰减的裁剪防御策略。

07. 开放式演进与AI科学家全自动研发

以 Sakana AI 的 The AI Scientist 与 AlphaEvolve 为案例，讨论全自动科研与代码变异演进的工程流程及安全边界。

08. 深度研究Agent与搜索增强推理

分析 AlphaCode 2 的聚类过滤策略、CoT 内部交织搜索逻辑（Search-o1），以及 GAIA 对综合办公任务的考察方式。

09. 长周期任务评估与真实经济价值陷阱

梳理主流 Benchmark 演进历程，分析 LLM-as-a-Judge 存在的自洽性偏差，介绍基于实际专业产出的 GDPVal 评估方案。

10. 未来研究范式与顶尖嘉宾思想总汇

整理 Denny Zhou 关于思维链本质的观点、Thang Luong 团队在 Lean 4 形式化数学验证（AlphaProof）中的实践，以及分布式 KV Cache 内存优化。
