Ashvin Nair：强化学习与推理的 2025

在 NeurIPS 2025 现场录的一期：前 OpenAI 推理团队成员、现在在 Cursor 做 Composer 的 Ashvin Nair 讲 o1 怎么起步、IOI 金牌为什么没有改变世界、RL 为什么“尖峰化”不泛化，以及 Cursor 每两小时更新一次策略的在线学习

这一期的内容

这期是 swyx 在 NeurIPS 2025 现场做的专题采访，只有他一位主持。Ashvin Nair 2017 年在 OpenAI 实习过（那时公司只有机器人、Dota 和大约 15 个实习生），2017 到 2022 年在 Berkeley 跟 Sergey Levine 读博做机器人 RL，2022 年 9 月左右加入 OpenAI 的代码生成团队，后来参与 o1、o3 这条推理线，录制时刚到 Cursor 三个月，专做 Composer 模型。他经历过学术界 RL 最热的那几年，也在实验室里看着 RL 在 LLM 上跑通，所以能对比两个时代。

这期围绕几个问题：为什么拿到 IOI 金牌之后生活好像没变；2017 到 2022 年的 RL 研究为什么大多没用上；o1 的信念从哪来、最初的原型是什么；实验室内部进展为什么比外面看起来平滑；他为什么离开 OpenAI 去 Cursor；持续学习下一步会是什么样。swyx 追问最多的是“OpenAI 资源无限，你为什么不留下”，以及持续学习要不要筛选数据、权重容量够不够。两人看法明显不同的一处是 OpenAI 放弃“一个模型通吃”：swyx 认为这是方向上的变化，Ashvin 认为更多是组织架构问题。节目结尾 Cursor 的招聘信息只简单带过。

01. 从机器人到 LLM：Agent 会比机器人先成万亿市场

节目位置 0:00:00–0:09:11 · Introduction: From Robotics to Cursor via OpenAI / The Robotics to LLM Agent Transition: Why Code Won

2017 年的 OpenAI 实习

swyx 问从机器人转到语言模型奇不奇怪。Ashvin 说他 2017 年读博前就在 OpenAI 实习做机器人，那时是一家很不一样的公司：机器人、Dota，加上那个夏天大约 15 个实习生，每人一个挺有意思的独立项目。那批实习生后来去向都不错，比如 NYU 的 Lerrel Pinto（文字稿写作 Léo Pinto），还有一位后来在 xAI 负责推理的人，他一时想不起名字。

他认为机器人背景很适合做 LLM：两边做的事相似，都要看大量数据；机器人领域很难把东西跑通，会练出很“磨得住”、爱看数据的人。swyx 讲了他前一晚和 Lex Fridman 小范围吃饭的事：Lex 以前也做机器人，他说 NeurIPS 上最值得聊的是机器人方向的人，因为他们和真实世界打交道，没得选，最脱离现实的是做模拟的人。Ashvin 说他同意，他读博时两种都做：先在模拟里做原型，再到真实机器人上跑通。

机器人还在 GPT-1 到 GPT-2 之间

Ashvin 说机器人大概是最感受不到 AGI 的方向，离能用太远；不过过去一年 Physical Intelligence、Sunday 等公司的演示让他开始觉得有点意思。他现场看过 Physical Intelligence 在某人客厅里叠衣服的演示，很厉害。swyx 问 OpenAI 重启机器人团队是不是认真的，Ashvin 说他在很不一样的部门，知道的很少，但他认为是认真的。

他说自己 2022 年离开机器人时以为还会回去，现在的看法是：LLM Agent 会在机器人连 100 亿美元市场都还不到时，先成为万亿美元市场。原因是 LLM Agent 已经在创造价值；AI 机器人很难说已经做了什么有用的事，就算做到了，还要算得过单位经济账，可靠性、维修都难。他觉得市场是有效的：LLM 公司融几百亿，机器人公司融几亿。swyx 纠正说最近已经到了个位数十亿。Ashvin 说这就是让他意外的地方，融资跑在实际进展前面。

他说机器人现在大概在 GPT-1 到 GPT-2 的阶段。swyx 问什么任务算拐点，他说有点像“看到就知道”，Sunday 的演示挺酷，细节很重要，必须是在没见过的新场景里，也就是分布外泛化；GPT-2 也是这样，开始看到泛化的苗头。他说这个阶段投机器人基本是在投团队，还谈不上投技术，并补充自己不在这个领域，只是猜测。

加入 OpenAI 代码团队，以及 IOI 金牌悖论

他大约在 2022 年 9 月 ChatGPT 发布前加入 OpenAI。读博读到倦怠，本想去一个“轻松的研究实验室”，结果 ChatGPT 一出，什么都变了，很多工作重新聚焦。他加入的是代码生成团队，就是发布 Codex 的那个团队；他加入时主要在做模型的工具调用之类，是发布 ChatGPT 团队的姊妹团队，目标是让模型更聪明，比如做编程竞赛题。

swyx 问当时 IOI 金牌（国际信息学奥林匹克竞赛）看起来能不能拿到。Ashvin 说他现在反复跟人讲：如果当时有人告诉他能拿 IOI 金牌，他会以为大家都可以去度假了，AI 已经解决，没必要再工作。可真拿到了，生活还是一样。他说他没有很好的解释，但这是他花很多时间想的问题；国际象棋、围棋被解决后也是这样，每次都让人意外。

swyx 给了两个解释：我们一直在挪球门；我们对 AGI 的定义很差，说“做到这个就是 AGI”时并不是真心的，比如“语言模型拿 IOI 金牌就是 AGI”就是错的。Ashvin 说某种程度上挪球门是对的，因为大家一直在对现有目标做 Goodhart（古德哈特定律：一个指标一旦成为目标就不再是好指标）。swyx 说 Goodhart 太负面了，像是作弊，拿金牌算不上作弊，只是扩大测试时算力。Ashvin 说他指的是社区在元层面会默认去追最重要的评测和基准，SWE-bench Verified 肯定是这样；IOI 金牌某种程度上也是：世上大多数程序员根本做不了 IOI，模型却仍然没法自动化大多数编程工作。swyx 总结为：语言模型平时在初级到高级开发者之间，到了 IOI 突然冒出一个尖峰。

02. RL 研究的寒冬：整个社区在对基准过拟合

节目位置 0:09:11–0:11:45 · RL Research Winter and Academic Overfitting

Ashvin 说他在 RL 研究里也在元层面看到过同样的事。他 2017 到 2022 年在 Berkeley 跟 Sergey Levine 读博，那时从 2015 年左右的 DQN 开始，RL 很热。大家最兴奋的方法是离策略学习（off-policy learning，用旧策略或别处收集的数据来训练当前策略）、价值函数（value function，估计某个状态或动作未来能拿多少奖励）这一类。这些后来基本没有成功，原因也不完全清楚。

当时学术文献里大家以为进展很大。他现在回看，认为大家对基准过拟合得很严重：方法给了自己很多新的可调旋钮，然后不知不觉把旋钮调到适合基准。大家多少都知道单篇论文会这样，但很难意识到整个社区在元层面也在这样做。结果是那个时代很多 RL 研究现在没什么人用，原因类似，都是在刷基准。

swyx 直接说那就是 RL 寒冬，当时以此为前提创办的整批创业公司基本放弃了，有的死了，有的转型。Ashvin 说他在学术界，那里仍然很兴奋，但他那时有些沮丧：学术界的一个毛病是不奖励简单有效的想法，更奖励偏数学的想法；数学化的想法又带来更多隐含的旋钮，方便过拟合。真正有效的往往是旋钮少、能泛化到很多场景的简单方法。swyx 补了一句：除了砸算力没什么秘方，所以在智力上不有趣。Ashvin 说很多读博的人天生想研究新奇有趣的东西，扩展时代对他们来说大概很难受。

03. 扩展时代还在：RL 很尖峰，要把有用的任务带进训练分布

节目位置 0:11:45–0:18:16 · The Scaling Era and Moving Goalposts: IOI Gold Doesn't Mean AGI

为什么还没有自动化所有工作

swyx 问扩展时代是不是结束了。Ashvin 说他是从 Ilya Sutskever 那期访谈里被带到这个话题的。他不认为结束了，实验室还在发新的预训练模型，比以前好很多；但有些有意思的事在发生，值得认真追问：为什么我们现在没有在自动化所有工作。

他的看法是：RL 现在用在 LLM 上的方式是一个“奇怪又有趣的工具”，它在训练分布之外泛化得不多。有一些泛化，而且方式有趣，但很尖峰（peaky）：它能把训练分布“彻底打穿”，不费太多力气就做到世界最好，但不怎么泛化。所以如果决定把 RL 当工具，就得把有经济价值的任务带进 RL 的训练分布。他说明年也可能出现某种持续学习之类的东西改变范式；但如果 RL 是工具，模型的智能似乎已不是瓶颈，瓶颈是产品要把一个人想做的事的全部上下文带进来，让 LLM 能看到，再在上面做 RL。

GDPval

swyx 问这是不是 GDPval 那种东西。Ashvin 说看过但没细看。swyx 介绍：128 个任务，覆盖占 GDP 5% 以上的各种白领工作，把上下文都做好，评测了所有模型；他还开玩笑说 OpenAI 的评测团队每次都发现 Anthropic 的模型最好，而且照样发表，这是真正的科学。Ashvin 说他没细看 GDPval 的轨迹，不清楚会计的工作到底包括什么、产品里需要什么上下文。swyx 说他们尽量贴近原始文件，比如 PDF，不能人为把数据清理干净方便 LLM 处理，“PDF 丢给 Agent，开始”。

Ashvin 说这大致是对的形态。落地方式是产品和模型一起设计（co-design）。编程可能是最容易的第一步，因为关心的上下文大多就是代码库和在终端里跑东西，即便如此离自动化也还不算近。其他工作的上下文多得吓人：和同事的所有对话、Slack 消息。

他拿自己在 OpenAI 的工作举例：他做超参数扩展研究，类似 2020 年前后“深度学习科学”那类问题，比如层要怎样初始化才能扩展得好，他做的是 RL 版本。他写的代码不多，写代码不是瓶颈；他做的是一年里跑参数扫描、看不同超参数的相互作用，积累一年的各种图。要自动化他的工作，模型也得把这些都放进上下文，而那些图“就在我脑子里”，所以很难。要做的是一个能把这些上下文带进来的产品，再在上面用 RL 教模型使用这些上下文。

“一个模型通吃”的结束？

swyx 说今年另一个话题是“一个模型通吃”的终结，AGI 里的 G 本来就是一个模型通吃，而 OpenAI 今年明显放弃了这一点：Fidji Simo 写了一篇博客，标题大意是不再一个模型通吃，Mark Chen 或另一位高管也在播客里这么说。他梳理了一遍：先有 Codex，又有 InstructGPT，然后 GPT-4、4o、o1，o1 本来是推理版的通用模型；接着 4o 和 o1、o3 两条线合并成 GPT-5；现在又拆成 GPT-5 和 GPT-5 Codex。

Ashvin 说不要把这些当成关于宇宙的科学事实，更多是 OpenAI 喜欢调整组织架构。他承认当前推理范式确实在适应那种在某些领域尖峰化的特点，但他认为这和模型容量关系不大，更多是组织问题：如果你特别在意编程，大概就没有做其他事的数据。如果拥有所有数据，大概在所有数据上一起训练会更好，各领域之间也会有一些泛化，只是很难找到一个同时在意所有这些事的组织。

04. The Blip：2023 年感恩节和 OpenAI 的治理

节目位置 0:18:16–0:21:30 · The Blip: Thanksgiving 2023 and OpenAI Governance（视频描述里列出的章节，YouTube 章节未单列）

swyx 说他喜欢问 OpenAI 的人有没有关于“the blip”（2023 年 11 月 Sam Altman 被董事会解职又复职的那几天）的故事。Ashvin 说那是感恩节，他和两位 OpenAI 的朋友一起办公，周五下午其中一位说“Sam Altman 刚被开了”，他以为是玩笑。接下来是起起落落的一个周末。swyx 问他是否签了那封联名信，大约 95% 的人签了，他说签了。

但他说自己的想法更复杂一些：他认为治理很重要，无论 AGI 是两年还是十年后到来，都不清楚我们有没有好的治理结构，应该多花时间讨论；那段时间他甚至愿意“先别管股权”，觉得有一场关于治理怎么运作的讨论是健康的。swyx 问现在 OpenAI 非营利组织有一个决定何时达到 AGI 的“秘密影子董事会”，是不是更好。Ashvin 说他没有答案，这超出他的职级，但他很在意。

他说事件发生时他的一个反应是：如果非营利董事会会做出令人意外、甚至反复无常的举动，也许宁可要像微软董事会那样的结构，背后大概是全世界的养老金；利益相关方某种程度上是整个世界，这可能比七个人来管更民主。他也说不知道。他觉得我们连 AI 之外的治理都没解决，比如不健康食品、社交媒体，资本主义的激励好像并不能带来对社会好的结果。

05. o 系列的信念：从十几个人到 300 人

节目位置 0:21:30–0:25:47 · OpenAI's Reasoning Journey: From Codex to O1 / RL for Reasoning: The O-Series Conviction and Scaling

团队规模

swyx 说 Ashvin 之前提到推理团队有 300 人，让他很吃惊。Ashvin 说 o3 变成产品后，参与的人越来越多，他已经记不清数字，很多人负责安全、评测等不同方面。swyx 说他看到 o1 的视频里大概十几个人。Ashvin 说即使那时，看全部贡献者名单大概也有 50 到 100 人。

信念来自哪里

他从 2023 年讲起：那年大家都在讨论扩展定律是不是死了，swyx 插话说每年都在讨论，Ashvin 说那一年感觉特别认真。他说 OpenAI 很擅长对一件事有信念，从第一性原理出发去追；最该归功的大概是 Ilya Sutskever 和 Jakub Pachocki。2017 年的 Dota 在某种意义上也是同一个模板。那里很多人有“AGI 刻在骨子里”的看法，一直相信 RL 是通往 AGI 的路。

他说很多人很早就相信类似的东西应该能行，只是要等预训练足够好才开始有效。swyx 提到人类反馈，Ashvin 说 RLHF（基于人类反馈的强化学习）算是一条支线，因为没法往里倒太多算力，它只是把模型的个性引导得好一点。那里的人相信，到某个时候进步不再靠复制互联网，靠做 RL 才能得到更好的智能。所以有一条以不同方式回到 RL 的长线，大约 2023 年开始真正咔哒一下对上了。

最初的原型

他说有意思的是，最初的模型规模小，表现并没有比现有模型好很多，但大家很会判断“这个有意思”：这里看到的推理过程，准确程度是在别的同类模型上没见过的。他类比 GPT 和 GPT-2，很多人当时不觉得 GPT-2 有多厉害，他自己也是“行吧”，直到 GPT-3 出来，他读博时很焦虑。这需要一点第一性原理的信念去判断“这里有东西，要放大”，而 OpenAI 一旦认定就会一路放大。

swyx 问有没有一个说服大家投资源的内部原型。Ashvin 说就是在一个相当小的模型上跑 RL，产生很有意思的推理轨迹，数学分数出奇地好，而且是不额外做大量预训练就达不到的那种。这之后越来越多资源投入去放大这条新的“定律”，再加上工具调用等。swyx 说大家都盯着大模型，mini 模型被低估了，Ashvin 说他没怎么参与 mini 的工作，没什么可说。

06. 从 o1 到 o3：内部平滑，外部大起大落

节目位置 0:25:47–0:32:23 · O1 to O3: Smooth Internal Progress vs External Hype Cycles

内外领先时间缩到一两个月

Ashvin 说外面的人觉得研究是大跳跃式的，但在 OpenAI 内部感觉很平滑：一堆实验，有的结果不确定，把它们叠起来，继续扩展，每次跑的结果好一点。媒体上一会儿“Google 赢了”，一会儿别的，实验室里面就是一步步往前推，这个月比上个月好一点。

swyx 说以前实验室内部比发布的东西领先六个月左右，ChatGPT 发布时 OpenAI 并不太兴奋，因为他们已经有 GPT-4；现在大家有东西就发。Ashvin 同意，说现在有竞争压力，领先太久会被抢市场份额，比如 Nano Banana Pro 当时很强。他估计现在内部比外部的领先时间大约一到两个月。

The Curve 上的预测

他说大约 2024 年初就感觉这套配方真的有效，进展很稳，那时已经相当可以预测能拿下 IMO、IOI 这类比赛。他讲了一件事：o1 发布前他去了一个叫 The Curve 的讨论 AI 进展的会议（swyx 说他去年也去了，Joseph Gordon-Levitt 也在）。会上大家对 Epoch AI 的数学测试和 Humanity's Last Exam 之类下注，估计 2027 年能到 10% 到 20%；而当时内部已经有模型超过他们的估计，大概差了两年。有意思的是，这些人同时也在预测 2035 年左右会有戴森球。swyx 总结为短期太悲观、长期太乐观，Ashvin 说他也不确定 2035 年会不会有戴森球，但人们的校准确实在不同方向上都有偏差。

他说他很欣赏那个圈子（swyx 问是不是 EA 相关，他说是那一群人）愿意提前公开预测，世上其他人大多事后冷嘲热讽说“我早就看出来了”。他说从 2015 到 2020 年看，那个群体的能力预测大体是对的，当时很多人觉得 AI 是骗局或很久都没用，而他们认为大约 2030 年会达到人类水平智能。swyx 说他总有点怀疑：每个人预测的 AGI 都恰好落在自己有生之年，十八、十九世纪的人做预测也是这样。Ashvin 说这次可能真的会发生，“几乎肯定”。

DeepSeek 时刻和各家收敛

swyx 问今年的 DeepSeek 时刻有没有改变 OpenAI 内部什么。Ashvin 说没有，更多是意外它造成那么大反应，而且有点让人困惑：DeepSeek 说明 Nvidia 芯片比以前以为的更有用，Nvidia 股价却大跌。swyx 替另一方做了最强论证：不需要顶级 Nvidia 芯片，用上一代或卖给中国的阉割版就能做同样的工作。Ashvin 说 OpenAI 内部的感受是当时已经有更好的模型，而更聪明的模型显然很有价值，所以要待在前沿。

swyx 说他更想问的是 DeepSeek 的方法对不对，他们的 R1-Zero 是很酷的一个分支，今年关于 RL 学到了什么。Ashvin 说看起来各家实验室基本收敛到相似的 RL 做法，又回到同一个前沿水平。他举例 Anthropic 的 Opus 4.5 在 ARC-AGI-2 上的曲线和 OpenAI 的看起来一模一样，大家用不同办法做到了差不多的事。

07. 为什么去 Cursor：产品和模型一起设计，每两小时更新一次

节目位置 0:32:23–0:36:19 · Why Cursor: Co-Designing Products and Models for Real Work / Composer and the Future: Online Learning Every Two Hours / Continual Learning（前段）

swyx 的追问：OpenAI 资源无限，为什么离开

swyx 问 Cursor 为什么吸引了这么多 RL 好手。Ashvin 说从 Cursor 的角度，不用什么都依赖外部实验室；而且自己做模型，才有机会和产品一起设计。swyx 反驳：OpenAI 资源无限、数据无限，还有 Codex，你本可以留下。Ashvin 说他离开前后大家才开始大量用 Codex，几乎是他刚走就发生了；之前 OpenAI 内部大多用 Cursor，也有一点 Windsurf 留下来的用户。所以当时并不显然。

他说更关键的还是前面那个观点：RL 是不太泛化的工具，要做的是把整个测试分布放进训练分布。他在 Cursor 看到了直接做这件事的机会，Cursor 的人也很认同这个方向；这里地方小，产品的人就坐在 ML 的人旁边。

在线 Tab：每两小时一次策略更新

他提到 Cursor 的 Jacob Jackson 最近写了一篇关于在线 Tab 的博客：大约每两小时做一次策略更新（policy update，用新收集的用户反馈更新模型）。他说这种事在 OpenAI 很难想象，因为产品复杂，产品和 RL 的人在组织里离得很远。swyx 说真想做也能做，Tab 只是自动补全，模型更小，没那么复杂。Ashvin 说他不认为这是 Cursor 能做到的原因，更多是组织更小、更聚焦。

持续学习要不要筛数据

swyx 问：做持续学习不是得筛选数据吗？不能把用户做的事直接扔进去，那会把模型拉向分布中间，而你想要的是尖峰。Ashvin 说这取决于怎么理解持续学习。人很擅长处理坏数据：看到别人做蠢事，你会决定不做。这也不止于过滤，你大概有某种价值函数，看到别人碰热炉子，你不需要自己去碰。swyx 开玩笑说你可以故意重新发现热炉子，Ashvin 说没必要。

他认为这里有很深的东西：模型离那种数据效率还差几个数量级。人做错一次，比如在代码里引入一个 bug，就不会再犯；模型会很乐意继续犯，在同一个上下文里都会，跨上下文更不用说。他猜这可能在接下来一年左右带来范式转变，但他完全不知道会是什么。

08. Composer：够聪明，也够快

节目位置 0:36:19–0:40:13 · Continual Learning: The Missing Paradigm Shift（中段）

20 到 25 人的 ML 团队

他在 Cursor 只做 Composer（Cursor 自己训练的编程 Agent 模型），这基本是 ML 团队的主要工作：发布更好的 Composer。ML 团队只有二三十人（他说 20 到 25 人），考虑到规模，Composer 的好让他很意外，这还不是一个大研究实验室。

他说 Composer 是产品和模型共同设计的开端：大家喜欢它，一个原因是它够聪明，让人真愿意用；它也快，用的时候能一直和模型保持在一个循环里。其他聪明模型都慢，你会切走去做别的再回来。他说作为程序员，切换上下文很糟糕，“像得了 ADHD”。Composer 是往更同步的方向走了一步。整个公司都是想写代码的人，连联合创始人都是最好的“高品味测试者”，这让他对发布的东西有信心。swyx 问有没有 Composer 还解决不了、他很想解决的测试，他说讽刺的是他自己是个“低品味测试者”，整天写慢吞吞的机器学习代码、想算法。

目标：自动化软件工程这个过程

他说现在模型越来越擅长回答用户的提示，这是 Composer 1 不错的原因；但真正的目标是自动化软件工程这个过程：写代码，去 Datadog 看看发生了什么，回来提出哪种更好的假设，再重跑。他认为 Cursor 在这点上位置独特：如果软件工程师做的大部分事都在产品里发生，就能用这些数据让模型越来越擅长整份工作，写代码只是其中一部分。

内部工具

swyx 说他和 Sasha（Sasha Rush，也在 Cursor）聊过很多 Cursor 内部的工具，比如集群可视化，问这是不是每家实验室都有。Ashvin 说 Cursor 的工具很好，因为大家都愿意 vibe code 自己的工具、自己测试；比如可以 SSH 进用户环境，看代码是不是按用户那样跑。他说机器学习的大教训之一是要离数据很近、很懂数据，Cursor 做的是代码产品，大家都看得懂；在 OpenAI 时如果他去看一道生物题，完全不知道在讲什么。

09. 持续学习：经历一次就写进权重

节目位置 0:40:13–0:43:53 · Continual Learning: The Missing Paradigm Shift（后段）

swyx 问除了 OpenAI 和 Cursor，还有谁的 RL 工作影响了他。Ashvin 说他在 OpenAI 养成了不怎么读外部工作、主要读内部 Slack 帖子的习惯，最近没有特别启发他的外部成果。但持续学习这个方向他觉得很有意思，甚至学术界也可能在这里取得大突破。

swyx 问持续学习是不是指 Tab 那样。Ashvin 说可以是 Tab 那样，也可以是一种“有无限记忆的上下文学习”：一旦在上下文里经历过某件事，它就应该进入权重，以后不再犯同样的错。

权重容量够不够

swyx 追问：权重记东西的容量有限，这样做太多会遗忘。Ashvin 说模型一开始是从数万亿 token 里学习的，部署时只会经历几千或几百万 token。swyx 插话说这些只需要训练一遍（one epoch）。Ashvin 说如果能从部署时那几百万 token 里学到足够多，他不认为有压垮模型容量的风险，因为在一万亿 token 上训练都没问题，按比例这是水桶里的一滴。除非跑上好几年，也许会到某个程度。

swyx 说他只做过一期讲语言模型信息论的播客，理论容量是多少、用了多少，应该去跟踪：如果要把东西存在权重里，就把它当硬盘，容量就是参数占用的比特数，物理上存不了更多。Ashvin 说 Cursor 的 Jacob 最近提过一个看法：神经网络有“硬盘视角”和“CPU 视角”，权重里发生的是在记忆东西，还是有少数电路在做大量工作。他说有很多这种偏科学的问题他很想研究，但和实证工作冲突：在任何时刻，搞懂这些问题都不像是短期甚至未来几年改进模型最快的路。照理这是学术界的角色，可学术界算力不够也很难研究。他希望某天回去研究这些基础科学问题。

10. 面试题：离策略 RL 为什么不稳定

节目位置 0:43:53–0:45:13 · Hiring at Cursor and Why Off-Policy RL is Unstable

swyx 临时问他：有什么 RL 面试题，答得上来就该马上加入 Cursor？Ashvin 说 Cursor 其实不太做白板面试，做两天的工作试用（work trial），他认为更有代表性，因为能看到人实际怎么做事。如果要出一道题，他会问“离策略 RL 为什么不稳定”，他说这道题考的更多是你是否经历过 2017 到 2022 年那个时代，和懂不懂 RL 关系不大。swyx 说他不知道答案，得去查。节目以 Cursor 的招聘口播结束：他们特别需要做代码方向数据和奖励的人。
